## 1. 아이디어

꼭대기에서 바닥까지 내려가며 거친 수의 합이 최대인 경로를 구하는 문제다. 높이가 최대 500이라 경로가 $2^{499}$개에 이를 수 있어 전부 따라 내려갈 수는 없지만, 어떤 칸까지의 경로 중 합이 최대인 것만 알면 그 아래의 선택에는 그곳까지 어떻게 왔는지가 영향을 주지 않는다. 위에서 $i$번째 줄, 왼쪽에서 $j$번째 칸까지의 경로 합의 최댓값을 `dp[i][j]`라 하면 이 칸으로 내려올 수 있는 칸은 윗줄의 $j - 1$번째와 $j$번째 칸뿐이므로, `dp[i][j]`는 `dp[i - 1][j - 1]`과 `dp[i - 1][j]` 중 큰 값에 이 칸의 수를 더한 것이다. 줄의 양 끝 칸은 윗줄에서 올 수 있는 칸이 하나뿐인데, 범위 밖 칸을 0으로 두면 수가 모두 0 이상이라 이 0이 최댓값에 끼어들어도 실제 칸의 값을 넘지 못해 따로 처리할 필요가 없다. 윗줄이 통째로 범위 밖인 꼭대기 칸도 같은 이유로 자기 수가 그대로 된다. 바닥은 어느 칸에서 끝나도 되므로 마지막 줄의 `dp` 중 최댓값이 답이다.

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.util.*;

class Solution {
    public int solution(int[][] triangle) {
        int n = triangle.length;
        int[][] dp = new int[1 + n][1 + n];

        for (int i = 1; i <= n; i++) {
            for (int j = 1; j <= i; j++) {
                dp[i][j] = Math.max(dp[i - 1][j - 1], dp[i - 1][j]) + triangle[i - 1][j - 1];
            }
        }

        return Arrays.stream(dp[n]).max().getAsInt();
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int solution(vector<vector<int>> triangle) {
    int n = triangle.size();
    vector<vector<int>> dp(1 + n, vector<int>(1 + n));

    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= i; j++) {
            dp[i][j] = max(dp[i - 1][j - 1], dp[i - 1][j]) + triangle[i - 1][j - 1];
        }
    }

    return *max_element(dp[n].begin(), dp[n].end());
}
```

```python
def solution(triangle):
    n = len(triangle)
    dp = [[0] * (1 + n) for _ in range(1 + n)]

    for i in range(1, n + 1):
        for j in range(1, i + 1):
            dp[i][j] = max(dp[i - 1][j - 1], dp[i - 1][j]) + triangle[i - 1][j - 1]

    return max(dp[n])
```
