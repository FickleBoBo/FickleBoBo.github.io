## 1. 아이디어

[[BaekJoon] #15650 - N과 M (2)](/posts/baekjoon-15650/)처럼 오름차순 수열인 조합을 구하되 1부터 $N$까지가 아니라 입력으로 주어진 수에서 $M$개를 골라 사전 순으로 출력하는 문제다. 정렬한 배열에서 입력의 수가 모두 다르므로 값이 오름차순이라는 것은 인덱스가 증가한다는 것과 같고, 그래서 같은 백트래킹에서 다음 칸을 직전에 쓴 인덱스보다 하나 큰 인덱스부터 시도하면 된다. 이미 쓴 인덱스는 항상 이번 칸의 시작 인덱스보다 작아 사용 여부를 표시하지 않아도 된다.

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;
import java.util.*;

public class Main {

    static StringBuilder sb = new StringBuilder();
    static int n, m;
    static int[] arr;
    static int[] sel;

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());

        n = Integer.parseInt(st.nextToken());
        m = Integer.parseInt(st.nextToken());

        arr = new int[n];
        st = new StringTokenizer(br.readLine());
        for (int i = 0; i < n; i++) {
            arr[i] = Integer.parseInt(st.nextToken());
        }
        Arrays.sort(arr);

        sel = new int[m];

        dfs(0, 0);
        System.out.println(sb);
    }

    static void dfs(int start, int depth) {
        if (depth == m) {
            for (int x : sel) {
                sb.append(x).append(" ");
            }
            sb.append("\n");
            return;
        }

        for (int i = start; i < n; i++) {
            sel[depth] = arr[i];
            dfs(i + 1, depth + 1);
        }
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int n, m;
int arr[8];
int sel[8];

void dfs(int start, int depth) {
    if (depth == m) {
        for (int i = 0; i < m; i++) {
            cout << sel[i] << ' ';
        }
        cout << '\n';
        return;
    }

    for (int i = start; i < n; i++) {
        sel[depth] = arr[i];
        dfs(i + 1, depth + 1);
    }
}

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    cin >> n >> m;
    for (int i = 0; i < n; i++) cin >> arr[i];
    sort(arr, arr + n);

    dfs(0, 0);
}
```

```python
import sys
from itertools import combinations

input = sys.stdin.readline

n, m = map(int, input().split())
arr = sorted(map(int, input().split()))
out = [" ".join(map(str, seq)) for seq in combinations(arr, m)]
print("\n".join(out))
```

`combinations`는 입력의 순서를 유지하므로 `sorted`로 정렬한 배열을 넘겨 오름차순 수열과 사전 순을 맞췄다.
