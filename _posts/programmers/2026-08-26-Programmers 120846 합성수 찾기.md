## 1. 아이디어

합성수는 약수가 세 개 이상인 수, 즉 1과 자기 자신 말고도 약수가 있는 수다. 1은 약수가 하나뿐이라 합성수가 아니므로 2 이상의 수 $i$마다 2부터 $i - 1$까지 나누어떨어지는 수가 하나라도 있는지 확인하면 되고, $n$이 100 이하로 작아 수마다 이렇게 따져도 충분하다.

$n$이 커지면 수마다 따로 나눠 보는 비용이 커지므로, 에라토스테네스의 체로 소수를 한꺼번에 걸러 내고 2 이상 $n$ 이하에서 소수가 아닌 수를 센다. 합성수는 2 이상의 수 중 소수가 아닌 수이기 때문이다.

## 2. 코드

### 풀이 1: 완전 탐색 [Java][C++][Python]

```java
class Solution {
    public int solution(int n) {
        int cnt = 0;
        for (int i = 1; i <= n; i++) {
            for (int j = 2; j < i; j++) {
                if (i % j == 0) {
                    cnt++;
                    break;
                }
            }
        }

        return cnt;
    }
}
```

```python
def solution(n):
    return sum(1 for i in range(1, n + 1) if any(i % j == 0 for j in range(2, i)))
```

`any`는 참인 값을 만나면 바로 멈추므로 약수를 하나 찾으면 더 확인하지 않았다.

### 풀이 2: 에라토스테네스의 체 [Java][C++][Python]

```java
import java.util.*;

class Solution {
    public int solution(int n) {
        boolean[] isPrime = sieve(n);
        int cnt = 0;

        for (int i = 2; i <= n; i++) {
            if (!isPrime[i]) cnt++;
        }

        return cnt;
    }

    static boolean[] sieve(int n) {
        boolean[] isPrime = new boolean[1 + n];
        Arrays.fill(isPrime, true);
        isPrime[0] = isPrime[1] = false;
        for (int i = 2; i * i <= n; i++) {
            if (isPrime[i]) {
                for (int j = i * i; j <= n; j += i) {
                    isPrime[j] = false;
                }
            }
        }
        return isPrime;
    }
}
```

```python
import math


def sieve(n):
    is_prime = [True] * (1 + n)
    is_prime[0] = is_prime[1] = False
    for i in range(2, math.isqrt(n) + 1):
        if is_prime[i]:
            is_prime[i * i :: i] = [False] * len(range(i * i, n + 1, i))
    return is_prime


def solution(n):
    is_prime = sieve(n)
    return is_prime[2:].count(False)
```
