## 1. 아이디어

[[BaekJoon] #15654 - N과 M (5)](/posts/baekjoon-15654/)와 같은 순열이지만 입력에 같은 수가 여러 번 주어질 수 있어서, 인덱스만 다르고 값이 같은 선택이 같은 수열을 여러 번 만들어 내므로 중복 출력을 막아야 한다. 입력을 정렬해 같은 수를 이웃하게 두면 작은 값부터 시도해 사전 순이 유지되고, 백트래킹의 한 칸에서 직전에 시도한 값과 같은 수는 남는 수의 구성이 같아 그 아래에서 나오는 수열이 직전 시도와 완전히 같으므로 건너뛰어도 된다. 이때 기억할 것은 이 칸에서 직전에 시도한 값 하나이고, 이미 쓰여 건너뛴 인덱스는 시도한 것이 아니므로 기억을 갱신하지 않는다. 입력이 `1 1 2`이고 $M = 2$일 때 첫 칸에 첫 번째 `1`을 쓰고 둘째 칸으로 내려가면 첫 번째 `1`은 이미 쓴 인덱스라 건너뛰는데, 이때 기억을 `1`로 갱신하면 두 번째 `1`까지 건너뛰어 `1 1`이 빠진다.

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;
import java.util.*;

public class Main {

    static StringBuilder sb = new StringBuilder();
    static int n, m;
    static int[] arr;
    static int[] sel;
    static boolean[] vis;

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());

        n = Integer.parseInt(st.nextToken());
        m = Integer.parseInt(st.nextToken());

        arr = new int[n];
        st = new StringTokenizer(br.readLine());
        for (int i = 0; i < n; i++) {
            arr[i] = Integer.parseInt(st.nextToken());
        }
        Arrays.sort(arr);

        sel = new int[m];
        vis = new boolean[n];

        dfs(0);
        System.out.println(sb);
    }

    static void dfs(int depth) {
        if (depth == m) {
            for (int x : sel) {
                sb.append(x).append(" ");
            }
            sb.append("\n");
            return;
        }

        int prv = 0;
        for (int i = 0; i < n; i++) {
            if (vis[i]) continue;
            if (arr[i] == prv) continue;

            prv = sel[depth] = arr[i];
            vis[i] = true;
            dfs(depth + 1);
            vis[i] = false;
        }
    }
}
```

`prv`의 초깃값 0은 입력이 자연수라 어떤 원소와도 겹치지 않는다.

```c++
#include <bits/stdc++.h>
using namespace std;

int n, m;
int arr[8];
int sel[8];
bool vis[8];

void dfs(int depth) {
    if (depth == m) {
        for (int i = 0; i < m; i++) cout << sel[i] << ' ';
        cout << '\n';
        return;
    }

    int prv = 0;
    for (int i = 0; i < n; i++) {
        if (vis[i]) continue;
        if (arr[i] == prv) continue;

        prv = sel[depth] = arr[i];
        vis[i] = true;
        dfs(depth + 1);
        vis[i] = false;
    }
}

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    cin >> n >> m;
    for (int i = 0; i < n; i++) cin >> arr[i];
    sort(arr, arr + n);

    dfs(0);
}
```

`prv`의 초깃값 0은 입력이 자연수라 어떤 원소와도 겹치지 않는다.

```python
import sys
from itertools import permutations

input = sys.stdin.readline

n, m = map(int, input().split())
arr = list(map(int, input().split()))
out = [" ".join(map(str, seq)) for seq in sorted(set(permutations(arr, m)))]
print("\n".join(out))
```

같은 수가 있으면 `permutations`가 같은 수열을 여러 번 만들어 내므로 `set`으로 중복을 없앴고, `set`은 순서를 보장하지 않아 `sorted`로 사전 순을 다시 맞췄다.
