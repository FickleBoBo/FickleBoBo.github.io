## 1. 아이디어

가위(`2`), 바위(`0`), 보(`5`)를 낸 순서대로 적힌 문자열이 주어질 때, 각 판을 이기는 손을 같은 순서로 적은 문자열을 반환하는 문제다. 각 판에서 이기는 손은 상대의 손 하나로만 정해지고 판끼리 영향을 주지 않으므로, 문자마다 `2`는 `0`으로, `0`은 `5`로, `5`는 `2`로 바꾸면 된다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public String solution(String rsp) {
        StringBuilder sb = new StringBuilder();
        for (char c : rsp.toCharArray()) {
            if (c == '0') {
                sb.append("5");
            } else if (c == '2') {
                sb.append("0");
            } else {
                sb.append("2");
            }
        }

        return sb.toString();
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

string solution(string rsp) {
    string s;
    for (char c : rsp) {
        if (c == '0') {
            s += '5';
        } else if (c == '2') {
            s += '0';
        } else {
            s += '2';
        }
    }

    return s;
}
```

```python
def solution(rsp):
    return rsp.translate(str.maketrans("025", "502"))
```

`str.maketrans`로 문자 대응표를 만들고 `translate`로 한 번에 바꿨다.
