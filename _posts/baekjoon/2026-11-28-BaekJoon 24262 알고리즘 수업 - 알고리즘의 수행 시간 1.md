## 1. 아이디어

배열의 원소 하나를 반환하는 알고리즘에서 코드1의 수행 횟수와, 그 횟수를 다항식으로 나타냈을 때의 차수를 구하는 문제다. 코드1은 반복문이 없는 알고리즘의 반환문이라 $n$이 얼마든 정확히 한 번 실행되고, 상수 1은 0차 다항식이다. 두 값 모두 $n$과 무관하므로 입력을 읽지 않고 1과 0을 출력한다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
public class Main {
    public static void main(String[] args) {
        System.out.println(1);
        System.out.println(0);
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    cout << 1 << '\n';
    cout << 0;
}
```

```python
print(1)
print(0)
```
