## 1. 아이디어

문자열에 커서를 두고 이동·삭제·삽입 명령을 차례로 처리한 뒤의 문자열을 구하는 문제다. 문자열은 최대 600,000글자까지 늘어나는데 하나의 배열에 담으면 중간에서 삽입하거나 삭제할 때마다 뒤 글자를 모두 밀거나 당겨야 해서 0.3초 안에 최대 500,000개의 명령을 처리하기 어렵다.

그런데 모든 명령은 커서 바로 양옆의 글자만 건드리므로, 커서를 경계로 왼쪽 글자들과 오른쪽 글자들을 두 덱에 나눠 담으면 `L`과 `D`는 커서에 붙은 글자 하나를 반대쪽 덱으로 옮기는 일이 되고 `B`와 `P`는 왼쪽 덱의 맨 뒤에서 빼거나 넣는 일이 되어 모두 상수 시간에 끝난다. 처음에는 커서가 맨 뒤에 있으니 초기 문자열은 전부 왼쪽 덱에 담고, 글자를 꺼내야 하는 쪽 덱이 비어 있으면 커서가 문장의 맨 앞이나 맨 뒤에 있는 것이므로 명령을 무시한다. 두 덱 모두 앞에서 뒤로 현재 문장의 좌우 순서를 유지하므로 마지막에는 왼쪽 덱과 오른쪽 덱을 차례로 이어 출력하면 된다.

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringBuilder sb = new StringBuilder();

        Deque<Character> f = new ArrayDeque<>();
        Deque<Character> b = new ArrayDeque<>();

        String s = br.readLine();
        for (char c : s.toCharArray()) {
            f.offerLast(c);
        }

        int m = Integer.parseInt(br.readLine());
        while (m-- > 0) {
            StringTokenizer st = new StringTokenizer(br.readLine());
            char op = st.nextToken().charAt(0);

            if (op == 'L') {
                if (!f.isEmpty()) b.offerFirst(f.pollLast());
            } else if (op == 'D') {
                if (!b.isEmpty()) f.offerLast(b.pollFirst());
            } else if (op == 'B') {
                if (!f.isEmpty()) f.pollLast();
            } else {
                f.offerLast(st.nextToken().charAt(0));
            }
        }

        for (char c : f) {
            sb.append(c);
        }
        for (char c : b) {
            sb.append(c);
        }

        System.out.println(sb);
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    deque<char> f, b;

    string s;
    cin >> s;

    for (char c : s) {
        f.push_back(c);
    }

    int m;
    cin >> m;

    while (m--) {
        char op;
        cin >> op;

        if (op == 'L') {
            if (!f.empty()) {
                b.push_front(f.back());
                f.pop_back();
            }
        } else if (op == 'D') {
            if (!b.empty()) {
                f.push_back(b.front());
                b.pop_front();
            }
        } else if (op == 'B') {
            if (!f.empty()) f.pop_back();
        } else {
            char c;
            cin >> c;
            f.push_back(c);
        }
    }

    for (char c : f) cout << c;
    for (char c : b) cout << c;
}
```

```python
import sys
from collections import deque

input = sys.stdin.readline

f = deque(input().rstrip())
b = deque()

m = int(input())
for _ in range(m):
    tokens = input().split()
    op = tokens[0]

    if op == "L":
        if f:
            b.appendleft(f.pop())
    elif op == "D":
        if b:
            f.append(b.popleft())
    elif op == "B":
        if f:
            f.pop()
    else:
        f.append(tokens[1])

print("".join(f) + "".join(b))
```

`sys.stdin.readline`은 줄바꿈까지 읽어 오므로 `rstrip`으로 지워 줄바꿈이 덱에 글자로 들어가지 않게 했다.
