## 1. 아이디어

$a \oplus b$와 $b \oplus a$는 두 수를 어느 순서로 이어 붙이느냐만 다르다. 어느 수를 앞에 둬야 큰지는 두 수의 크기만으로 정해지지 않으므로(9와 91은 9를 앞에 둘 때, 89와 8은 89를 앞에 둘 때 더 크다) 두 값을 직접 만들어 큰 쪽을 고른다. 두 값이 같을 때는 어느 쪽을 반환해도 같아 `max`로 충분하다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int solution(int a, int b) {
        int x = Integer.parseInt("" + a + b);
        int y = Integer.parseInt("" + b + a);
        return Math.max(x, y);
    }
}
```

`"" + a + b`처럼 빈 문자열에 먼저 붙여, 덧셈이 아니라 문자열 연결이 되게 했다.

```c++
#include <bits/stdc++.h>
using namespace std;

int solution(int a, int b) {
    int x = stoi(to_string(a) + to_string(b));
    int y = stoi(to_string(b) + to_string(a));
    return max(x, y);
}
```

```python
def solution(a, b):
    x = int(f"{a}{b}")
    y = int(f"{b}{a}")
    return max(x, y)
```
