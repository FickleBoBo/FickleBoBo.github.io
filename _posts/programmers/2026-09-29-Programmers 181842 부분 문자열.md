## 1. 아이디어

`str1`이 `str2`의 연속된 일부인지 확인하는 문제다. 길이가 최대 20이라 시작 위치마다 직접 맞대 봐도 글자 비교가 110번을 넘지 않아 검색 비용은 신경 쓰지 않아도 된다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int solution(String str1, String str2) {
        return str2.contains(str1) ? 1 : 0;
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int solution(string str1, string str2) {
    return str2.find(str1) != -1;
}
```

```python
def solution(str1, str2):
    return int(str1 in str2)
```
