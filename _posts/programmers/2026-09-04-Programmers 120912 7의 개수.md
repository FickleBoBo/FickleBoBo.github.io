## 1. 아이디어

배열의 원소를 십진수로 썼을 때 나오는 숫자 `7`의 총 개수를 구하는 문제다. 77에는 `7`이 두 번 들어 있으므로 원소 자체가 `7`인지가 아니라 각 자리가 `7`인지를 세야 한다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int solution(int[] array) {
        int cnt = 0;
        for (int x : array) {
            while (x > 0) {
                if (x % 10 == 7) cnt++;
                x /= 10;
            }
        }

        return cnt;
    }
}
```
