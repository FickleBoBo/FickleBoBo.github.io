## 1. 아이디어

문자열 `my_string`의 각 문자를 순회하며 소문자면 대문자로, 대문자면 소문자로 바꿔 이어붙이면 된다.

---

## 2. 복잡도

| 접근 | 시간   | 공간   |
| ---- | ------ | ------ |
| 풀이 | $O(N)$ | $O(N)$ |

($N$ = `my_string`의 길이)

---

## 3. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public String solution(String my_string) {
        StringBuilder sb = new StringBuilder();
        for (char c : my_string.toCharArray()) {
            if (Character.isLowerCase(c)) {
                sb.append(Character.toUpperCase(c));
            } else {
                sb.append(Character.toLowerCase(c));
            }
        }

        return sb.toString();
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

string solution(string my_string) {
    string s;
    for (char c : my_string) {
        if (islower(c)) {
            s += toupper(c);
        } else {
            s += tolower(c);
        }
    }

    return s;
}
```

```python
def solution(my_string):
    return my_string.swapcase()
```

`swapcase`는 문자열의 대문자는 소문자로, 소문자는 대문자로 뒤집은 새 문자열을 반환하는 것을 활용했다.
