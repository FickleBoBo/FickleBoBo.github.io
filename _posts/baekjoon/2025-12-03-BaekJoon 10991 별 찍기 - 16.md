## 1. 아이디어

각 라인마다 별을 포함한 구간에 대해 홀수 번째에는 별을, 짝수 번째에는 공백을 출력하면 된다.

---

## 2. 복잡도

| 접근 | 시간     | 공간   |
| ---- | -------- | ------ |
| 풀이 | $O(N^2)$ | $O(1)$ |

($N$ = 입력값 `n`. Java는 전체 출력을 `StringBuilder`에 모았다가 출력하므로 공간 $O(N^2)$)

---

## 3. 코드

### 풀이 [Java][C++]

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringBuilder sb = new StringBuilder();

        int n = Integer.parseInt(br.readLine());

        for (int i = 1; i <= n; i++) {
            sb.repeat(" ", n - i);

            for (int j = 1; j <= 2 * i - 1; j++) {
                if (j % 2 != 0) {
                    sb.append("*");
                } else {
                    sb.append(" ");
                }
            }

            sb.append("\n");
        }

        System.out.println(sb);
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    int n;
    cin >> n;

    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= n - i; j++) {
            cout << ' ';
        }

        for (int j = 1; j <= 2 * i - 1; j++) {
            if (j % 2) {
                cout << '*';
            } else {
                cout << ' ';
            }
        }

        cout << '\n';
    }
}
```
