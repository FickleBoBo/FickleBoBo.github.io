## 1. 아이디어

1부터 $n$까지의 합을 구하는 문제로, $n$이 최대 10,000이라 차례로 더하는 반복 합산만으로 충분하다.

등차수열 합 공식으로 반복 없이 구할 수도 있다. 합을 $S$라 할 때 1부터 $n$까지를 오름차순으로 쓴 줄과 $n$부터 1까지를 내림차순으로 쓴 줄을 같은 자리끼리 더하면 자리마다 합이 $n + 1$이고 자리가 $n$개이므로 $2S = n(n + 1)$, 즉 $S = n(n + 1) / 2$이다. $n(n + 1)$은 연속한 두 정수의 곱이라 항상 짝수여서 2로 나누어도 정수 나눗셈이 정확하고, 최대 $100{,}010{,}000$이라 32비트 정수에 들어간다.

## 2. 코드

### 풀이 1: 반복 합산 [Java][C++][Python]

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        int n = Integer.parseInt(br.readLine());

        int sum = 0;
        for (int i = 1; i <= n; i++) {
            sum += i;
        }

        System.out.println(sum);
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    int n;
    cin >> n;

    int sum = 0;
    for (int i = 1; i <= n; i++) {
        sum += i;
    }

    cout << sum;
}
```

```python
import sys

input = sys.stdin.readline

n = int(input())

total = 0
for i in range(1, n + 1):
    total += i

print(total)
```

### 풀이 2: 등차수열 합 공식 [Java][C++][Python]

import java.io.*;
