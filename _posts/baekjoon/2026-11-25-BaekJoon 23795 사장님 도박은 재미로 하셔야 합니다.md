## 1. 아이디어

윤성이가 도박판에서 잃은 돈의 총합을 구하는 문제로, 한 번도 공의 위치를 찾지 못했으므로 베팅한 돈이 모두 날아가 잃은 돈은 베팅액의 합이고, `-1`이 입력되면 거기서 멈춘다. 합이 2,147,483,647 이하라 32비트 정수로 충분하다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        int sum = 0;
        while (true) {
            int x = Integer.parseInt(br.readLine());
            if (x == -1) break;
            sum += x;
        }

        System.out.println(sum);
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);

}
```
