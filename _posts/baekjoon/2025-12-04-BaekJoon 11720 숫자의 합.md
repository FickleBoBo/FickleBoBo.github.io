## 1. 아이디어

주어진 $N$개의 숫자에 대해 각 자릿수의 합을 구하는 문제로, 주어진 숫자들을 문자열로 입력 받은 후 각 자리의 수를 더하는 방식으로 해결하면 된다.

---

## 2. 복잡도

| 접근 | 시간   | 공간   |
| ---- | ------ | ------ |
| 풀이 | $O(N)$ | $O(N)$ |

($N$ = `s`의 길이)

---

## 3. 코드

### 풀이 [Java][C++]

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        br.readLine();
        String s = br.readLine();

        int sum = 0;
        for (char c : s.toCharArray()) {
            sum += c - '0';
        }

        System.out.println(sum);
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
```
