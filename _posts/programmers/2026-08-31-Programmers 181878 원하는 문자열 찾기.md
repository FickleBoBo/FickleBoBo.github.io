## 1. 아이디어

알파벳 대소문자를 구분하지 않으므로 `myString`과 `pat`을 모두 소문자로 바꾼 뒤, `pat`이 `myString`의 연속된 부분 문자열로 존재하는지 판정한다. 존재하면 1, 그렇지 않으면 0을 return한다.

---

## 2. 복잡도

| 접근 | 시간            | 공간       |
| ---- | --------------- | ---------- |
| 풀이 | $O(N \times M)$ | $O(N + M)$ |

($N$ = `myString`의 길이, $M$ = `pat`의 길이)

---

## 3. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int solution(String myString, String pat) {
        return myString.toLowerCase().contains(pat.toLowerCase()) ? 1 : 0;
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int solution(string myString, string pat) {
    for (char& c : myString) c = tolower(c);
    for (char& c : pat) c = tolower(c);

    return myString.find(pat) != -1;
}
```

```python
def solution(myString, pat):
    return int(pat.lower() in myString.lower())
```
