## 1. 아이디어

아이디 뒤에 `??!`를 붙여 출력한다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        System.out.println(br.readLine() + "??!");
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    string s;
    cin >> s;
    cout << s << "??!";
}
```

`??!`는 `-std=c++14`처럼 ISO 표준 모드에서 트라이그래프로 해석돼 `|`로 바뀐다. 트라이그래프는 C++17에서 제거돼 이 코드는 C++17부터 `??!` 그대로 출력된다.

```python
import sys

input = sys.stdin.readline

s = input().strip()
print(f"{s}??!")
```

`sys.stdin.readline`은 줄바꿈까지 읽어 오므로 `strip`으로 지운 뒤 `??!`를 붙였다.
