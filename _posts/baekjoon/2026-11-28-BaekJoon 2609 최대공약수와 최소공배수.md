## 1. 아이디어

두 자연수의 최대공약수와 최소공배수를 구하는 문제다. 두 수를 모두 나누는 수는 큰 수를 작은 수로 나눈 나머지도 나누고, 작은 수와 그 나머지를 모두 나누는 수는 큰 수도 나누므로, 두 수를 작은 수와 나머지로 바꿔도 최대공약수는 그대로다. 나머지는 작은 수보다 작아 바꿀 때마다 수가 줄어드니 결국 0에 이른다. 이 교체를 반복하는 것이 유클리드 호제법이고, 나머지가 0이 되면 그때의 작은 수가 큰 수를 나누므로 그 수가 최대공약수다. 소인수마다 최대공약수는 두 수의 지수 중 작은 쪽을, 최소공배수는 큰 쪽을 가지므로 두 수의 곱은 최대공약수와 최소공배수의 곱과 같고, 따라서 최소공배수도 바로 나온다.

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());

        int a = Integer.parseInt(st.nextToken());
        int b = Integer.parseInt(st.nextToken());

        System.out.println(gcd(a, b));
        System.out.println(lcm(a, b));
    }

    static int gcd(int a, int b) {
        if (b == 0) return a;
        return gcd(b, a % b);
    }

    static int lcm(int a, int b) {
        return a / gcd(a, b) * b;
    }
}
```

`lcm`은 `a`를 최대공약수로 먼저 나눈 뒤 `b`를 곱해 중간값이 커지지 않게 했다.

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    int a, b;
    cin >> a >> b;
    cout << gcd(a, b) << '\n';
    cout << lcm(a, b) << '\n';
}
```

`std::gcd`와 `std::lcm`은 C++17부터 쓸 수 있다.

```python
import math
import sys

input = sys.stdin.readline

a, b = map(int, input().split())
print(math.gcd(a, b))
print(math.lcm(a, b))
```

`math.lcm`은 Python 3.9부터 쓸 수 있다.
