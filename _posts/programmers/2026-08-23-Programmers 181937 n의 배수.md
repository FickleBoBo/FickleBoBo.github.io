## 1. 아이디어

`num`이 $n$의 배수라는 것은 `num`을 $n$으로 나눈 나머지가 0이라는 뜻이므로, 나머지만 확인하면 된다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int solution(int num, int n) {
        return num % n == 0 ? 1 : 0;
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int solution(int num, int n) {
    return num % n == 0;
}
```

```python
def solution(num, n):
    return int(num % n == 0)
```
