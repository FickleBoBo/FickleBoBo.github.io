## 1. 아이디어

연립방정식 $ax + by = c$, $dx + ey = f$의 해 $x$, $y$를 구하는 문제로, $x$와 $y$가 각각 -999 이상 999 이하의 정수로 보장되어 가능한 모든 $(x, y)$ 쌍이 $1{,}999^2$개, 약 $4 \times 10^6$개뿐이므로 모든 쌍을 두 식에 대입해 보는 브루트 포스로 풀 수 있고, 해가 유일해 둘 다 만족하는 쌍이 곧 답이다. 쌍마다 식 두 개를 확인하는 상수 시간이라 충분히 빠르다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());

        int a = Integer.parseInt(st.nextToken());
        int b = Integer.parseInt(st.nextToken());
        int c = Integer.parseInt(st.nextToken());
        int d = Integer.parseInt(st.nextToken());
        int e = Integer.parseInt(st.nextToken());
        int f = Integer.parseInt(st.nextToken());

        for (int x = -999; x <= 999; x++) {
            for (int y = -999; y <= 999; y++) {
                if (a * x + b * y == c && d * x + e * y == f) {
                    System.out.println(x + " " + y);
                    return;
                }
            }
        }
    }
}
```
