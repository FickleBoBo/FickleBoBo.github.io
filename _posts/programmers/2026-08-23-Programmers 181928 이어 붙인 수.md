## 1. 아이디어

원소가 한 자리 수이므로 어떤 수의 뒤에 원소를 이어 붙이는 일은 그 수에 10을 곱하고 원소를 더하는 것과 같다. 그래서 리스트를 앞에서부터 한 번 훑으며 홀수와 짝수를 각각 이 식으로 누적하면 순서대로 이어 붙인 두 수가 만들어지고, 마지막에 더하면 된다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int solution(int[] num_list) {
        int odd = 0, even = 0;

        for (int x : num_list) {
            if (x % 2 != 0) {
                odd = odd * 10 + x;
            } else {
                even = even * 10 + x;
            }
        }

        return odd + even;
    }
}
```
