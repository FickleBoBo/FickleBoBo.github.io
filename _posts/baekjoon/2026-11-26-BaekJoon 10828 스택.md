## 1. 아이디어

정수 스택을 구현해 명령을 처리하는 문제로, 스택은 한쪽 끝에서만 넣고 빼므로 배열의 앞에서부터 값을 쌓고 쌓인 개수만 관리하면 된다. 이 개수가 곧 다음 값을 넣을 인덱스이고 맨 위는 그 바로 앞 칸이라 모든 명령을 상수 시간에 처리한다. 명령이 10,000개 이하라 넣는 횟수도 10,000번을 넘지 않으므로 크기 10,000인 배열이면 충분하다.

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;
import java.util.*;

public class Main {

    static final int MAX_N = 10000;
    static int[] stack = new int[MAX_N];
    static int pos = 0;

    static void push(int x) {
        stack[pos++] = x;
    }

    static int pop() {
        return stack[--pos];
    }

    static int size() {
        return pos;
    }

    static boolean empty() {
        return pos == 0;
    }

    static int top() {
        return stack[pos - 1];
    }

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringBuilder sb = new StringBuilder();
        StringTokenizer st;

        int n = Integer.parseInt(br.readLine());
        while (n-- > 0) {
            st = new StringTokenizer(br.readLine());
            String op = st.nextToken();

            if (op.equals("push")) {
                int x = Integer.parseInt(st.nextToken());
                push(x);
            } else if (op.equals("pop")) {
                if (empty()) {
                    sb.append("-1\n");
                } else {
                    sb.append(pop()).append("\n");
                }
            } else if (op.equals("size")) {
                sb.append(size()).append("\n");
            } else if (op.equals("empty")) {
                if (empty()) {
                    sb.append("1\n");
                } else {
                    sb.append("0\n");
                }
            } else {
                if (empty()) {
                    sb.append("-1\n");
                } else {
                    sb.append(top()).append("\n");
                }
            }
        }

        System.out.println(sb);
    }
}
```

`bool`은 `cout`에서 1과 0으로 출력되므로 `empty`의 반환값을 분기 없이 그대로 썼다.

```python
import sys

input = sys.stdin.readline
out = []

MAX_N = 10000


class Stack:
    def __init__(self):
        self.st = [0] * MAX_N
        self.pos = 0

    def push(self, x):
        self.st[self.pos] = x
        self.pos += 1

    def pop(self):
        self.pos -= 1
        return self.st[self.pos]

    def size(self):
        return self.pos

    def empty(self):
        return self.pos == 0

    def top(self):
        return self.st[self.pos - 1]


stack = Stack()

n = int(input())
for _ in range(n):
    tokens = input().split()
    op = tokens[0]

    if op == "push":
        stack.push(int(tokens[1]))
    elif op == "pop":
        if stack.empty():
            out.append(-1)
        else:
            out.append(stack.pop())
    elif op == "size":
        out.append(stack.size())
    elif op == "empty":
        if stack.empty():
            out.append(1)
        else:
            out.append(0)
    else:
        if stack.empty():
            out.append(-1)
        else:
            out.append(stack.top())

print("\n".join(map(str, out)))
```
