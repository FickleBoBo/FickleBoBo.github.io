## 1. 아이디어

가운데 정렬 삼각형에서 왼쪽 변과 오른쪽 변을 별로 찍고 마지막 줄은 별 $2N - 1$개로 채워 밑변을 닫는다. 마지막 줄을 뺀 위에서부터 $i$번째 줄은 앞 공백 $N - i$개 뒤에 길이 $2i - 1$인 구간이 오고, 이 구간의 첫 칸과 마지막 칸이 별이며 그 사이는 공백이다. $N$이 1이면 첫 줄이 곧 마지막 줄이라 별 하나만 찍힌다.

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringBuilder sb = new StringBuilder();

        int n = Integer.parseInt(br.readLine());

        for (int i = 1; i < n; i++) {
            for (int j = 1; j <= n - i; j++) {
                sb.append(" ");
            }

            for (int j = 1; j <= 2 * i - 1; j++) {
                if (j == 1 || j == 2 * i - 1) {
                    sb.append("*");
                } else {
                    sb.append(" ");
                }
            }

            sb.append("\n");
        }

        for (int j = 1; j <= 2 * n - 1; j++) {
            sb.append("*");
        }

        System.out.println(sb);
    }
}
```

                cout << ' ';
            }
        }

        cout << '\n';
    }

        cout << '*';
    }
}
