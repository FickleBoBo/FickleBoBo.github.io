## 1. 아이디어

50 이상의 짝수는 2로 나누고 50 미만의 홀수는 2를 곱한 뒤 1을 더하는 변환을 배열에 한 단계씩 적용하다가, 더 변하지 않는 배열에 처음 도달하기까지 변환한 횟수를 구하는 문제다. [[Programmers] #181882 - 조건에 맞게 수열 변환하기 1](/posts/programmers-181882/)과 같은 틀이지만 50 미만의 홀수에 2를 곱한 뒤 1을 더한다는 점과, 변환을 한 번이 아니라 배열이 고정될 때까지 반복한다는 점이 다르다. 각 원소는 다른 원소와 무관하게 자기 값만으로 변하므로 배열이 고정되기까지의 단계는 원소별 단계의 최댓값이다. 값이 100 이하일 때 가장 오래 걸리는 원소는 1이다. 50 미만의 홀수는 $x + 1$이 단계마다 두 배가 되어 50 이상이 될 때까지 걸리는 단계가 $x$가 작을수록 많고, 1은 $1 \to 3 \to 7 \to 15 \to 31 \to 63$의 5단계를 거친다(63은 50 이상의 홀수라 멈춘다). 50 이상의 짝수는 100이 50, 25, 51을 거치는 3단계가 최대다. 그래서 원소가 최대 100만 개여도 이 시뮬레이션은 충분히 빠르다.

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.util.*;

class Solution {
    public int solution(int[] arr) {
        int[] prv = arr;
        int cnt = 0;

        while (true) {
            int[] cur = step(prv);

            if (Arrays.equals(prv, cur)) return cnt;
            prv = cur;
            cnt++;
        }
    }

    static int[] step(int[] arr) {
        int[] res = arr.clone();

        for (int i = 0; i < res.length; i++) {
            if (res[i] >= 50 && res[i] % 2 == 0) {
                res[i] /= 2;
            } else if (res[i] < 50 && res[i] % 2 != 0) {
                res[i] = res[i] * 2 + 1;
            }
        }

        return res;
    }
}
```

`arr.clone()`으로 복사본을 만들어 직전 배열을 보존했고, 배열의 `==`는 참조 비교라 `Arrays.equals`로 내용을 비교했다.

```c++
#include <bits/stdc++.h>
using namespace std;

vector<int> step(vector<int> v) {
    for (int& x : v) {
        if (x >= 50 && x % 2 == 0) {
            x /= 2;
        } else if (x < 50 && x % 2) {
            x = x * 2 + 1;
        }
    }
    return v;
}

int solution(vector<int> arr) {
    vector<int> prv = arr;
    int cnt = 0;

    while (true) {
        vector<int> cur = step(prv);

        if (prv == cur) return cnt;
        prv = cur;
        cnt++;
    }
}
```

`step`에 `std::vector`를 값으로 넘겨 복사본의 원소를 `int&`로 바로 바꿨고, 직전 배열 `prv`는 건드리지 않았다.

```python
def transform(x):
    if x >= 50 and x % 2 == 0:
        return x // 2
    if x < 50 and x % 2:
        return x * 2 + 1
    return x


def solution(arr):
    prv = arr
    cnt = 0

    while True:
        cur = [transform(x) for x in prv]
        if prv == cur:
            return cnt
        prv = cur
        cnt += 1
```
