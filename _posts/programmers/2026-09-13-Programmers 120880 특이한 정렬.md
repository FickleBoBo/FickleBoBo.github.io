## 1. 아이디어

기준 수 $n$과의 거리가 가까운 순으로 정렬하되 거리가 같으면 큰 수를 앞에 두는 문제다. 거리를 1순위, 값의 내림차순을 2순위로 하는 정렬 기준 하나로 한 번에 정렬하면 된다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.util.*;

class Solution {
    public int[] solution(int[] numlist, int n) {
        int len = numlist.length;
        int[][] arr = new int[len][2];
        for (int i = 0; i < len; i++) {
            arr[i][0] = Math.abs(n - numlist[i]);
            arr[i][1] = numlist[i];
        }
        Arrays.sort(arr, (o1, o2) -> {
            if (o1[0] != o2[0]) return Integer.compare(o1[0], o2[0]);
            return Integer.compare(o2[1], o1[1]);
        });

        int[] ans = new int[len];
        for (int i = 0; i < len; i++) {
            ans[i] = arr[i][1];
        }

        return ans;
    }
}
```

(거리, 값) 쌍을 `int[]`로 묶어 `int[][]`에 담았다. `Arrays.sort`에 `Comparator`를 넘기려면 원소가 객체여야 하는데 `int[]`는 객체라서 `Integer[]`로 바꾸지 않아도 된다.

```c++
#include <bits/stdc++.h>
using namespace std;

vector<int> solution(vector<int> numlist, int n) {
    sort(numlist.begin(), numlist.end(), [&](auto& a, auto& b) {
        int da = abs(n - a), db = abs(n - b);
        if (da != db) return da < db;
        return a > b;
    });

    return numlist;
}
```

```python
def solution(numlist, n):
    numlist.sort(key=lambda x: (abs(n - x), -x))
    return numlist
```

`key`에 (거리, -값) 튜플을 줘서 거리가 같으면 값이 큰 쪽이 앞에 오게 했다.
