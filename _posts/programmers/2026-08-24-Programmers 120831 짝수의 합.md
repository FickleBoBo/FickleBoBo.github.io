## 1. 아이디어

$n$ 이하의 짝수를 모두 더하는 문제다. $n$이 1,000 이하로 작아 2부터 $n$까지 2씩 늘려 가며 그대로 더해도 충분하다.

반복 없이 구하려면 $n$ 이하의 짝수가 $2, 4, \dots, 2k$ ($k = \lfloor n / 2 \rfloor$)인 등차수열이라는 점을 쓴다. 이 합은 $2(1 + 2 + \dots + k) = k(k + 1)$이므로 계산 한 번으로 끝난다.

---

## 2. 코드

### 풀이 1: 반복 합산 [Java][C++][Python]

```java
class Solution {
    public int solution(int n) {
        int sum = 0;
        for (int i = 2; i <= n; i += 2) {
            sum += i;
        }

        return sum;
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int solution(int n) {
    int sum = 0;
    for (int i = 2; i <= n; i += 2) {
        sum += i;
    }

    return sum;
}
```

```python
def solution(n):
    return sum(range(2, n + 1, 2))
```

`range`의 세 번째 인자로 2씩 건너뛰며 합했다.

---

### 풀이 2: 등차수열 합 공식 [Java][C++][Python]

```java
class Solution {
    public int solution(int n) {
        int k = n / 2;
        return k * (k + 1);
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int solution(int n) {
    int k = n / 2;
    return k * (k + 1);
}
```

```python
def solution(n):
    k = n // 2
    return k * (k + 1)
```
