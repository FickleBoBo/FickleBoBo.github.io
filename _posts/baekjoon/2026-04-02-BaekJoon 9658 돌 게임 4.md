## 1. 아이디어

돌 게임 3과 같은 규칙에서 마지막 돌을 가져가는 사람이 지는 문제다. 돌이 `i`개 남은 차례의 사람이 이기면 `true`인 `dp[i]`를 두면 점화식은 `dp[i - 1]`, `dp[i - 3]`, `dp[i - 4]` 중 `false`가 하나라도 있으면 `true`라는 점에서 돌 게임 3과 같고, 달라지는 것은 초기값뿐이다. 돌이 1개 남은 차례는 그 돌을 가져가야 하므로 지는 상태라 `dp[1] = false`이고, 2개 남았을 때는 1개를 가져가 상대에게 마지막 돌을 떠넘기므로 `dp[2] = true`이다. 3개 남았을 때는 3개를 가져가면 마지막 돌을 가져가서 지고 1개를 가져가면 상대가 `dp[2] = true`를 받으므로 `dp[3] = false`이며, 4개 남았을 때는 3개를 가져가 1개를 남기면 되므로 `dp[4] = true`이다. 이 네 값을 채워 두고 5개부터 차례로 구하면 된다.

| 풀이 | $O(N)$ | $O(N)$ |

($N$ = 입력값 `n`)

## 3. 코드

### 풀이 [Java][C++]

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        int n = Integer.parseInt(br.readLine());

        boolean[] dp = new boolean[1 + 1000];
        dp[2] = dp[4] = true;
        for (int i = 5; i <= n; i++) {
            if (!dp[i - 1] || !dp[i - 3] || !dp[i - 4]) {
                dp[i] = true;
            }
        }

        if (dp[n]) {
            System.out.println("SK");
        } else {
            System.out.println("CY");
        }
    }
}
```
