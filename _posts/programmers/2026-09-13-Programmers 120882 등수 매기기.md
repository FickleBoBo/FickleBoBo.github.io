## 1. 아이디어

영어와 수학 점수의 평균으로 등수를 매기는 문제로, 동점이면 같은 등수를 받고 그다음 등수는 건너뛴다. 한 학생의 등수는 자기보다 평균이 높은 학생의 수에 1을 더한 값이다. 동점자는 서로를 세지 않으므로 같은 등수가 되고, 그보다 낮은 학생은 동점자 전원을 자기보다 높은 쪽으로 세므로 이들의 등수는 동점자의 등수에 동점자 수를 더한 값부터 시작한다. 평균은 합을 2로 나눈 값이라 평균의 대소는 합의 대소와 같으므로 합으로 비교하면 된다.

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int[] solution(int[][] score) {
        int n = score.length;
        int[] ans = new int[n];

        for (int i = 0; i < n; i++) {
            int order = 1;
            for (int j = 0; j < n; j++) {
                if (score[i][0] + score[i][1] < score[j][0] + score[j][1]) order++;
            }
            ans[i] = order;
        }

        return ans;
    }
}
```

```python
def solution(score):
    total = [a + b for a, b in score]
    return [1 + sum(t > x for t in total) for x in total]
```
