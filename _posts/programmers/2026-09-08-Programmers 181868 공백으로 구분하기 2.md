## 1. 아이디어

단어 사이가 공백 한 칸일 수도 여러 칸일 수도 있고 양끝에도 공백이 있을 수 있어서, 공백 하나를 구분자로 단순히 자르면 빈 문자열이 섞여 나온다. 그래서 연속한 공백을 하나의 구분자로 보고 양끝의 공백은 버리는 분리를 써야 단어만 순서대로 남는다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public String[] solution(String my_string) {
        return my_string.trim().split("\\s+");
    }
}
```

`split("\\s+")`는 맨 앞에 공백이 있으면 결과 맨 앞에 빈 문자열이 생겨서, 먼저 `trim()`으로 양끝 공백을 제거했다.

```c++
#include <bits/stdc++.h>
using namespace std;

vector<string> solution(string my_string) {
    stringstream ss(my_string);
    vector<string> tokens;
    string token;
    while (ss >> token) tokens.push_back(token);

    return tokens;
}
```

`std::stringstream`에서 `>>`로 단어를 하나씩 꺼냈다. `>>`가 앞쪽 공백을 건너뛰어 연속 공백과 양끝 공백이 문제되지 않는다.

```python
def solution(my_string):
    return my_string.split()
```

인자 없이 `split()`을 호출했다. 인자를 비우면 연속한 공백이 하나의 구분자로 처리되고 양끝 공백은 버려진다.
