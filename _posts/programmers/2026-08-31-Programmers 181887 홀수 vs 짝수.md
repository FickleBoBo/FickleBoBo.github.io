## 1. 아이디어

첫 원소를 1번으로 센다고 했으므로 홀수 번째 원소는 인덱스가 짝수인 원소이고 짝수 번째 원소는 인덱스가 홀수인 원소다. 이 두 합을 각각 구해 큰 쪽을 반환하면 되고, 두 합이 같으면 최댓값도 그 값이라 따로 분기하지 않는다.

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int solution(int[] num_list) {
        int odd = 0, even = 0;
        for (int i = 0; i < num_list.length; i++) {
            if (i % 2 != 0) {
                odd += num_list[i];
            } else {
                even += num_list[i];
            }
        }

        return Math.max(odd, even);
    }
}
```

```c++
#include <bits/stdc++.h>
```
