## 1. 아이디어

문자열이 알파벳으로만 이루어져 있어 모든 글자에 대문자 변환을 그대로 적용하면 되고, 이미 대문자인 글자는 변환해도 달라지지 않는다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public String solution(String myString) {
        return myString.toUpperCase();
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

string solution(string myString) {
    for (char& c : myString) c = toupper(c);
    return myString;
}
```

`char&`로 받은 문자마다 `std::toupper`를 적용해 제자리에서 바꿨다.

```python
def solution(myString):
    return myString.upper()
```
