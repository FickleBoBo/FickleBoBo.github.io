## 1. 아이디어

$i$부터 $j$까지 모든 수의 십진 표기에서 숫자 $k$가 등장하는 횟수를 모두 더하는 문제다. 한 수에 같은 숫자가 여러 번 나올 수 있으므로(11에는 `1`이 두 번 있다) 수마다 $k$가 들어 있는지가 아니라 자리마다 $k$인지를 세어야 한다. $j$가 100,000 이하라서 모든 수의 모든 자리를 훑어도 충분하다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int solution(int i, int j, int k) {
        int ans = 0;
        for (int x = i; x <= j; x++) {
            ans += count(x, k);
        }

        return ans;
    }

    static int count(int x, int k) {
        int cnt = 0;
        while (x > 0) {
            if (x % 10 == k) cnt++;
            x /= 10;
        }
        return cnt;
    }
}
```
