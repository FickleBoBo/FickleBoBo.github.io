## 1. 아이디어

주어진 글자들을 세로로 읽는 문제로 2차원 배열을 활용하여 입력을 받고 이를 열 우선 순회로 탐색하면 된다.

---

## 2. 복잡도

| 접근 | 시간   | 공간   |
| ---- | ------ | ------ |
| 풀이 | $O(L)$ | $O(L)$ |

($L$ = `line`의 길이의 최댓값)

---

## 3. 코드

### 풀이 [Java][C++]

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringBuilder sb = new StringBuilder();

        char[][] grid = new char[5][15];
        for (int i = 0; i < 5; i++) {
            String line = br.readLine();
            for (int j = 0; j < line.length(); j++) {
                grid[i][j] = line.charAt(j);
            }
        }

        for (int j = 0; j < 15; j++) {
            for (int i = 0; i < 5; i++) {
                if (grid[i][j] != '\u0000') sb.append(grid[i][j]);
            }
        }

        System.out.println(sb);
    }
}
```

`char` 타입 배열의 초깃값이 `'\u0000'`인 점을 활용했다.

```c++
#include <bits/stdc++.h>
using namespace std;

char grid[5][15 + 1];

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    for (int i = 0; i < 5; i++) {
        cin >> grid[i];
    }

    for (int j = 0; j < 15; j++) {
        for (int i = 0; i < 5; i++) {
            if (grid[i][j] != '\0') cout << grid[i][j];
        }
    }
}
```

`char` 타입 배열의 초깃값이 `'\0'`인 점을 활용했다.
