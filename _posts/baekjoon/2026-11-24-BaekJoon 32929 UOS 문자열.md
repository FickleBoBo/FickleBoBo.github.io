## 1. 아이디어

$x$가 최대 $10^9$라 문자열을 직접 만들 수 없지만 `UOS`가 주기 3으로 반복되므로 $x$번째 문자는 `UOS`에서 $x - 1$을 3으로 나눈 나머지를 인덱스로 하는 문자이다. 번호는 1부터, 인덱스는 0부터 세므로 1을 먼저 뺀다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        int x = Integer.parseInt(br.readLine());
        System.out.println("UOS".charAt((x - 1) % 3));
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    int x;
    cin >> x;
    cout << "UOS"[(x - 1) % 3];
}
```

```python
import sys

input = sys.stdin.readline

x = int(input())
```
