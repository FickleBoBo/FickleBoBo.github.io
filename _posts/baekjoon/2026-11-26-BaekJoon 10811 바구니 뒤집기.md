## 1. 아이디어

1번부터 $N$번까지 번호가 순서대로 적힌 바구니에 구간 뒤집기를 $M$번 적용한 뒤의 배치를 구하는 문제로, 각 뒤집기는 앞선 뒤집기의 결과에 적용되므로 입력 순서대로 실제로 뒤집어 나간다. 뒤집기 한 번은 길어야 $N$칸이고 $N$과 $M$이 100 이하라 이렇게 해도 충분히 빠르다.

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringBuilder sb = new StringBuilder();
        StringTokenizer st = new StringTokenizer(br.readLine());

        int n = Integer.parseInt(st.nextToken());
        int m = Integer.parseInt(st.nextToken());

        int[] arr = new int[n];
        for (int i = 0; i < n; i++) {
            arr[i] = i + 1;
        }

        while (m-- > 0) {
            st = new StringTokenizer(br.readLine());
            int s = Integer.parseInt(st.nextToken()) - 1;
            int e = Integer.parseInt(st.nextToken()) - 1;

            while (s < e) {
                int tmp = arr[s];
                arr[s] = arr[e];
                arr[e] = tmp;
                s++;
                e--;
            }
        }

        for (int x : arr) {
            sb.append(x).append(" ");
        }

        System.out.println(sb);
    }
}
```

양 끝에서부터 두 원소씩 맞바꾸며 `s < e`인 동안만 반복했다. 가운데를 지나서도 계속 바꾸면 이미 바꾼 원소가 원래 자리로 돌아간다.

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    int n, m;
    cin >> n >> m;

    vector<int> v(n);
    iota(v.begin(), v.end(), 1);

    while (m--) {
        int s, e;
        cin >> s >> e;
        reverse(v.begin() + s - 1, v.begin() + e);
    }

    for (int x : v) {
        cout << x << ' ';
    }
}
```

`std::iota`로 `v`를 1부터 차례로 채웠다. `std::reverse`는 끝 이터레이터를 포함하지 않아 `e`번째까지 뒤집도록 `v.begin() + e`를 넘겼다.

```python
import sys

input = sys.stdin.readline

n, m = map(int, input().split())
arr = list(range(1, n + 1))

for _ in range(m):
    s, e = map(int, input().split())
    arr[s - 1 : e] = arr[s - 1 : e][::-1]

print(*arr)
```

슬라이스의 끝 인덱스는 포함되지 않아 `arr[s - 1 : e]`로 `e`번째까지를 잘랐고, `[::-1]`로 뒤집은 복사본을 같은 구간에 다시 대입했다.
