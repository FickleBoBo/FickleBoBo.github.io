## 1. 아이디어

`num_list`의 원소의 순서를 거꾸로 뒤집은 배열을 반환하면 되는 간단한 문제다.

---

## 2. 복잡도

| 접근 | 시간   | 공간   |
| ---- | ------ | ------ |
| 풀이 | $O(N)$ | $O(1)$ |

($N$ = `num_list`의 길이)

---

## 3. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int[] solution(int[] num_list) {
        int n = num_list.length;
        for (int i = 0; i < n / 2; i++) {
            int tmp = num_list[i];
            num_list[i] = num_list[n - 1 - i];
            num_list[n - 1 - i] = tmp;
        }

        return num_list;
    }
}
```

앞뒤 인덱스(`i`, `n - 1 - i`)를 맞바꿔가며 `num_list`를 제자리에서 뒤집었다. 끝까지 돌면 이미 바꾼 쌍을 도로 바꾸게 되므로, 절반(`n / 2`)까지만 순회해야 한다.

```c++
#include <bits/stdc++.h>
using namespace std;

vector<int> solution(vector<int> num_list) {
    reverse(num_list.begin(), num_list.end());
    return num_list;
}
```

`std::reverse`로 `num_list`를 제자리에서 뒤집었다.

```python
def solution(num_list):
    num_list.reverse()
    return num_list
```

`reverse`로 `num_list`를 제자리에서 뒤집었다.
