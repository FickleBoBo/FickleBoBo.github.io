## 1. 아이디어

$N$명이 원을 이루고 $K$번째 사람을 계속 제거하는 순서를 구하는 문제다. 사람들을 큐에 넣어 두고 앞에서 $K - 1$명을 꺼내 뒤로 돌린 다음 맨 앞의 사람을 제거하면 원을 따라 $K$번째를 센 것과 같고, 다음 사람이 바로 맨 앞에 와서 같은 동작이 이어진다. 남은 사람이 $K$명보다 적어져도 같은 동작이 통하고, 큐가 한 바퀴를 넘게 돌 뿐이다. $K \le N \le 1{,}000$이라 제거마다 $K - 1$번 옮겨도 전체가 $10^6$번 안팎이다.

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringBuilder sb = new StringBuilder();
        StringTokenizer st = new StringTokenizer(br.readLine());

        int n = Integer.parseInt(st.nextToken());
        int k = Integer.parseInt(st.nextToken());

        Queue<Integer> q = new ArrayDeque<>();
        for (int i = 1; i <= n; i++) {
            q.offer(i);
        }

        sb.append("<");
        while (!q.isEmpty()) {
            for (int i = 1; i < k; i++) {
                q.offer(q.poll());
            }

            sb.append(q.poll());

            if (!q.isEmpty()) sb.append(", ");
        }
        sb.append(">");

        System.out.println(sb);
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    int n, k;
    cin >> n >> k;

    queue<int> q;
    for (int i = 1; i <= n; i++) {
        q.push(i);
    }

    cout << '<';
    while (!q.empty()) {
        for (int i = 1; i < k; i++) {
            q.push(q.front());
            q.pop();
        }

        cout << q.front();
        q.pop();

        if (!q.empty()) cout << ", ";
    }
    cout << '>';
}
```

```python
import sys
from collections import deque

input = sys.stdin.readline
out = []

n, k = map(int, input().split())

q = deque(range(1, n + 1))
while q:
    q.rotate(-(k - 1))
    out.append(q.popleft())

print("<" + ", ".join(map(str, out)) + ">")
```

`rotate`는 음수를 넘기면 왼쪽으로 돌려 앞의 원소를 뒤로 보내므로, `rotate(-(k - 1))`로 앞의 `k - 1`명을 한 번에 뒤로 옮겼다.
