## 1. 아이디어

맨 위에서 대각선 아래로 내려오며 고른 수의 합이 최대가 되는 경로를 구하는 문제이다. $i$층 $j$번째 칸까지 내려오는 합의 최댓값을 $f(i, j)$, 그 칸의 수를 $t(i, j)$라 하면 그 칸에는 바로 위층의 $(i - 1, j - 1)$ 또는 $(i - 1, j)$에서만 올 수 있으므로 $f(i, j) = \max(f(i - 1, j - 1), f(i - 1, j)) + t(i, j)$이고, 답은 맨 아래층의 $f(n, j)$ 중 최댓값이다. 양 끝 칸은 위에서 올 수 있는 칸이 하나뿐인데, 수가 모두 0 이상이라 위층 칸까지의 합도 0 이상이므로 삼각형 바깥을 0으로 두어도 바깥 칸 때문에 최댓값이 바뀌는 일이 없어 같은 식을 그대로 쓸 수 있다.

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        int n = Integer.parseInt(br.readLine());

        int[][] arr = new int[1 + n][1 + n];
        for (int i = 1; i <= n; i++) {
            StringTokenizer st = new StringTokenizer(br.readLine());
            for (int j = 1; j <= i; j++) {
                arr[i][j] = Integer.parseInt(st.nextToken());
            }
        }

        int[][] dp = new int[1 + n][1 + n];
        for (int i = 1; i <= n; i++) {
            for (int j = 1; j <= i; j++) {
                dp[i][j] = Math.max(dp[i - 1][j - 1], dp[i - 1][j]) + arr[i][j];
            }
        }

        int max = 0;
        for (int i = 1; i <= n; i++) {
            max = Math.max(max, dp[n][i]);
        }

        System.out.println(max);
    }
}
```

        }
    }

    int mx = 0;
    for (int i = 1; i <= n; i++) {

}

```python
import sys

input = sys.stdin.readline

n = int(input())

arr = [[0] * (1 + n) for _ in range(1 + n)]
for i in range(1, n + 1):
    arr[i][1 : i + 1] = map(int, input().split())

dp = [[0] * (1 + n) for _ in range(1 + n)]
for i in range(1, n + 1):
    for j in range(1, i + 1):
        dp[i][j] = max(dp[i - 1][j - 1], dp[i - 1][j]) + arr[i][j]

print(max(dp[n]))
```
