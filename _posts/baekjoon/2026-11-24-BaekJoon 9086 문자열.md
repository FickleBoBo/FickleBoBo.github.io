## 1. 아이디어

문자열의 첫 글자와 마지막 글자를 이어 출력한다. 길이가 1이면 첫 글자와 마지막 글자가 같은 글자라 그 글자를 두 번 출력한다(`O`는 `OO`).

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringBuilder sb = new StringBuilder();

        int t = Integer.parseInt(br.readLine());
        while (t-- > 0) {
            String s = br.readLine();
            sb.append(s.charAt(0)).append(s.charAt(s.length() - 1)).append("\n");
        }

        System.out.println(sb);
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    int t;
    cin >> t;

    while (t--) {
        string s;
        cin >> s;
        cout << s.front() << s.back() << '\n';
    }
}
```

```python
import sys

input = sys.stdin.readline

t = int(input())
for _ in range(t):
    s = input().rstrip()
    print(s[0] + s[-1])
```

`sys.stdin.readline`은 줄바꿈까지 읽어 오므로 `rstrip`으로 지워 `s[-1]`이 줄바꿈이 되지 않게 했다.
