## 1. 아이디어

`arr`에서 `delete_list`에 있는 값을 모두 지우고 나머지의 순서를 유지하는 문제다. 지울지는 원소의 값 하나로 정해지므로 `arr`를 앞에서부터 보며 `delete_list`에 없는 원소만 남기면 순서가 그대로 유지된다. 지울 값을 미리 표시해 두면 각 원소의 삭제 여부를 바로 확인할 수 있다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.util.*;

class Solution {
    public int[] solution(int[] arr, int[] delete_list) {
        boolean[] seen = new boolean[1 + 1000];
        for (int x : delete_list) {
            seen[x] = true;
        }

        return Arrays.stream(arr).filter(x -> !seen[x]).toArray();
    }
}
```

두 배열의 원소가 1 이상 1,000 이하라 값 자체를 인덱스로 쓰는 `boolean` 배열에 지울 값을 표시했다. 인덱스 1,000까지 쓰므로 크기를 `1 + 1000`으로 잡았다.

```c++
#include <bits/stdc++.h>
using namespace std;

vector<int> solution(vector<int> arr, vector<int> delete_list) {
    for (int x : delete_list) erase(arr, x);
    return arr;
}
```

`delete_list`의 값마다 `std::erase`로 같은 값의 원소를 지웠다. `std::erase`는 C++20에서 추가됐고 남은 원소의 순서는 유지된다.

```python
def solution(arr, delete_list):
    seen = set(delete_list)
    return [x for x in arr if x not in seen]
```
