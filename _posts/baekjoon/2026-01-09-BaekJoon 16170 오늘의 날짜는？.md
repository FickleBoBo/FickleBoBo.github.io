## 1. 아이디어

오늘 날짜를 양식에 맞춰 출력만 하면 된다. 한국 시간은 세계 표준시보다 9시간 빨라서 한국 시간으로 오전 9시 전까지는 하루 전 날짜를 출력해야 한다.

---

## 2. 복잡도

| 접근 | 시간   | 공간   |
| ---- | ------ | ------ |
| 풀이 | $O(1)$ | $O(1)$ |

---

## 3. 코드

### 풀이 [Java][C++]

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("2026");
        System.out.println("01");
        System.out.println("09");
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    cout << "2026" << '\n';
    cout << "01" << '\n';
    cout << "09" << '\n';
}
```
