## 1. 아이디어

원소 $a$를 앞에서부터 차례로 볼 때마다 결과 배열 뒤에 $a$를 $a$번 붙이면 되고, 항상 뒤에만 붙이므로 앞서 만든 부분은 바뀌지 않아 입력 순서가 결과에 그대로 이어진다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.util.*;

class Solution {
    public int[] solution(int[] arr) {
        List<Integer> list = new ArrayList<>();
        for (int x : arr) {
            for (int i = 0; i < x; i++) {
                list.add(x);
            }
        }

        return list.stream().mapToInt(Integer::intValue).toArray();
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

vector<int> solution(vector<int> arr) {
    vector<int> v;
    for (int x : arr) {
        for (int i = 0; i < x; i++) {
            v.push_back(x);
        }
    }

    return v;
}
```

```python
def solution(arr):
    return [x for x in arr for _ in range(x)]
```

리스트 컴프리헨션에서 `for` 절을 두 번 써서 앞의 `for x in arr`가 바깥 반복이 되게 했다.
