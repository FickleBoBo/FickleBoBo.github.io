## 1. 아이디어

두 원소를 곱해 만들 수 있는 최댓값을 구하는 문제다. 음수 두 개의 곱은 양수라서 가장 큰 두 수를 곱한 값이 항상 답은 아니며(첫 번째 예에서는 -3과 -5의 곱 15가 답이다), 길이가 100 이하이므로 가능한 모든 쌍의 곱을 비교해 최댓값을 고르면 충분하다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int solution(int[] numbers) {
        int max = Integer.MIN_VALUE;
        for (int i = 0; i < numbers.length - 1; i++) {
            for (int j = i + 1; j < numbers.length; j++) {
                max = Math.max(max, numbers[i] * numbers[j]);
            }
        }

        return max;
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int solution(vector<int> numbers) {
    int mx = INT_MIN;
    for (int i = 0; i < numbers.size() - 1; i++) {
        for (int j = i + 1; j < numbers.size(); j++) {
            mx = max(mx, numbers[i] * numbers[j]);
        }
    }

    return mx;
}
```

```python
from itertools import combinations


def solution(numbers):
    return max(a * b for a, b in combinations(numbers, 2))
```
