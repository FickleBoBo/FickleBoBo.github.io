## 1. 아이디어

예제 출력의 콜센터에 앉아 있는 C3PO 그림을 열 줄로 그대로 출력한다. 마지막 세 줄은 두 `|` 사이에 공백이 10개씩 들어간다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

문자열 안에서 백슬래시는 이스케이프 문자라 `\`를 한 글자 출력하려고 `\\`로 두 번 썼다.

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("     /~\\");
        System.out.println("    ( oo|");
        System.out.println("    _\\=/_");
        System.out.println("   /  _  \\");
        System.out.println("  //|/.\\|\\\\");
        System.out.println(" ||  \\ /  ||");
        System.out.println("============");
        System.out.println("|          |");
        System.out.println("|          |");
        System.out.println("|          |");
    }
}
```

