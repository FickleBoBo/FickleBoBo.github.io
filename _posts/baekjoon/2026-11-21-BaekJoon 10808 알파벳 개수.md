## 1. 아이디어

소문자가 26종뿐이라 `a`부터 `z`까지 문자마다 단어에 나오는 횟수를 카운팅 배열로 세고, 나오지 않는 문자도 0을 포함해 26개를 모두 차례로 출력한다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringBuilder sb = new StringBuilder();

        String s = br.readLine();
        int[] cnt = new int[26];

        for (char c : s.toCharArray()) {
            cnt[c - 'a']++;
        }

        for (int x : cnt) {
            sb.append(x).append(" ");
        }

        System.out.println(sb);
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int cnt[26];

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    string s;
    cin >> s;

    for (char c : s) {
        cnt[c - 'a']++;
    }

    for (int x : cnt) {
        cout << x << ' ';
    }
}
```

```python
import string
import sys

input = sys.stdin.readline

s = input().rstrip()
print(*[s.count(c) for c in string.ascii_lowercase])
```

`string.ascii_lowercase`로 `a`부터 `z`까지를 순회하며 카운팅 배열 대신 문자마다 `count`로 횟수를 셌다.
