## 1. 아이디어

`Hook`을 `#`로 그린 네 줄을 출력하는 문제로, 글자 사이와 글자 안의 공백 개수까지 예제 출력과 같아야 하므로 예제의 네 줄을 그대로 출력한다.

## 2. 코드

### 풀이 [Java][C++][Python]

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("#  # #### #### #  #");
        System.out.println("#### #  # #  # # #");
        System.out.println("#### #  # #  # # #");
        System.out.println("#  # #### #### #  #");
    }
}
```
