## 1. 아이디어

두 정수의 합을 그대로 반환하면 되는 문제다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int solution(int num1, int num2) {
        return num1 + num2;
    }
}
```
