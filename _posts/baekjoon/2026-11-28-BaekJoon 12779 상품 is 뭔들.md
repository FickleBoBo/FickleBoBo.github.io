## 1. 아이디어

$a$보다 크고 $b$ 이하인 번호 중 약수의 개수가 홀수인 번호의 비율을 기약분수로 구하는 문제다. 약수는 곱해서 그 수가 되는 둘끼리 짝을 이루는데 자기 자신과 짝이 되는 약수는 제곱수에만 하나 있으므로, 약수의 개수가 홀수인 수는 곧 제곱수다. 1부터 $x$까지의 제곱수는 $\lfloor \sqrt{x} \rfloor$개이니 구간의 제곱수는 $\lfloor \sqrt{b} \rfloor - \lfloor \sqrt{a} \rfloor$개이고, 비율은 이 개수를 전체 번호의 수 $b - a$로 나눈 값이므로 둘을 최대공약수로 약분하면 된다.

$b$가 $2^{60}$까지라 번호를 하나씩 확인할 수 없다. 제곱근을 부동소수점으로 계산하면 $2^{60} - 1$의 제곱근이 $2^{30}$으로 나와 내림값 $2^{30} - 1$과 어긋나므로, 제곱근의 내림은 이분 탐색처럼 정수 연산만 쓰는 방법으로 구한다.

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());

        long a = Long.parseLong(st.nextToken());
        long b = Long.parseLong(st.nextToken());

        long cnt = upperBound(b) - upperBound(a);

        if (cnt == 0) {
            System.out.println(0);
        } else {
            long g = gcd(cnt, b - a);
            System.out.printf("%d/%d", cnt / g, (b - a) / g);
        }
    }

    static long upperBound(long key) {
        long lo = 0, hi = Integer.MAX_VALUE;
        while (lo < hi) {
            long mid = lo + (hi - lo) / 2;
            if (mid * mid <= key) {
                lo = mid + 1;
            } else {
                hi = mid;
            }
        }
        return lo;
    }

    static long gcd(long a, long b) {
        if (b == 0) return a;
        return gcd(b, a % b);
    }
}
```

`upperBound`는 제곱이 `key`를 넘는 첫 정수를 이분 탐색으로 찾으므로 제곱근(내림)보다 1 큰 값을 반환하는데, 두 값을 빼면 1이 상쇄된다. `mid`는 $2^{31}$ 미만이라 `mid * mid`가 `long`에 담긴다. 제곱근이 $2^{30}$ 이하라 탐색 상한은 `Integer.MAX_VALUE`면 충분하다.

```c++
#include <bits/stdc++.h>
using namespace std;

long long upperBound(long long key) {
    long long lo = 0, hi = INT_MAX;
    while (lo < hi) {
        long long mid = lo + (hi - lo) / 2;
        if (mid * mid <= key) {
            lo = mid + 1;
        } else {
            hi = mid;
        }
    }
    return lo;
}

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    long long a, b;
    cin >> a >> b;

    long long cnt = upperBound(b) - upperBound(a);

    if (cnt == 0) {
        cout << 0;
    } else {
        long long g = gcd(cnt, b - a);
        cout << cnt / g << '/' << (b - a) / g;
    }
}
```

`upperBound`는 제곱이 `key`를 넘는 첫 정수를 이분 탐색으로 찾으므로 제곱근(내림)보다 1 큰 값을 반환하는데, 두 값을 빼면 1이 상쇄된다. `mid`는 $2^{31}$ 미만이라 `mid * mid`가 `long long`에 담긴다. 제곱근이 $2^{30}$ 이하라 탐색 상한은 `INT_MAX`면 충분하다.

`std::gcd`는 C++17부터 쓸 수 있다.

```python
import math
import sys

input = sys.stdin.readline

a, b = map(int, input().split())
cnt = math.isqrt(b) - math.isqrt(a)

if cnt == 0:
    print(0)
else:
    g = math.gcd(cnt, b - a)
    print(f"{cnt // g}/{(b - a) // g}")
```

`math.isqrt`로 실수를 거치지 않고 정수 제곱근을 구했다. `math.isqrt`는 Python 3.8부터 쓸 수 있다.
