## 1. 아이디어

1개 또는 3개씩 돌을 가져가며 마지막 돌을 가져가는 사람이 이기는 돌 게임에서 승자를 구하는 문제다. 1과 3이 모두 홀수라서 한 번 가져갈 때마다 남은 돌의 홀짝이 바뀌므로, 처음 돌이 홀수 개이면 상근이는 매번 짝수 개를 넘기게 되고 창영이는 짝수 개에서 어떻게 가져가도 홀수 개가 남아 0개를 만들 수 없다. 돌은 계속 줄어들어 게임이 끝나므로 마지막 돌은 상근이가 가져가고, 처음 돌이 짝수 개이면 역할이 뒤바뀌어 창영이가 이긴다. 결국 $N$이 홀수이면 `SK`, 짝수이면 `CY`를 출력하면 된다.

---

## 2. 복잡도

| 접근 | 시간   | 공간   |
| ---- | ------ | ------ |
| 풀이 | $O(1)$ | $O(1)$ |

## 3. 코드

### 풀이 [Java][C++]

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        int n = Integer.parseInt(br.readLine());
        if (n % 2 != 0) {
            System.out.println("SK");
        } else {
            System.out.println("CY");
        }
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    int n;
    cin >> n;

    if (n % 2) {
        cout << "SK";
    } else {
        cout << "CY";
    }
}
```
