## 1. 아이디어

두 정수의 최소공배수를 구하는 문제다. 공배수를 작은 것부터 찾으면 확인할 배수가 1억 개 가까이 될 수 있지만, 두 수의 곱을 최대공약수로 나눈 값이 최소공배수이므로 유클리드 호제법으로 최대공약수만 구하면 된다. 두 수가 $10^8$ 미만이라 최소공배수는 $10^{16}$에 가까워질 수 있으므로 64비트 정수가 필요하다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());

        long a = Long.parseLong(st.nextToken());
        long b = Long.parseLong(st.nextToken());
        System.out.println(lcm(a, b));
    }

    static long gcd(long a, long b) {
        if (b == 0) return a;
        return gcd(b, a % b);
    }

    static long lcm(long a, long b) {
        return a / gcd(a, b) * b;
    }
}
```

`lcm`은 `a`를 최대공약수로 먼저 나눈 뒤 `b`를 곱해 중간값이 커지지 않게 했다.

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    long long a, b;
    cin >> a >> b;
    cout << lcm(a, b);
}
```

`a`, `b`를 `long long`으로 받아 `std::lcm`의 결과도 `long long`이 되게 했다. `std::lcm`은 C++17부터 쓸 수 있다.

```python
import math
import sys

input = sys.stdin.readline

a, b = map(int, input().split())
print(math.lcm(a, b))
```

`math.lcm`으로 최소공배수를 바로 구했다. 이 함수는 Python 3.9부터 쓸 수 있다.
