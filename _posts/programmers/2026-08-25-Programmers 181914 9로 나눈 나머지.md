## 1. 아이디어

10을 9로 나눈 나머지가 1이므로 10의 거듭제곱을 9로 나눈 나머지도 항상 1이다. 그래서 각 자리의 숫자에 곱해지는 자릿값(1, 10, 100, ...)을 모두 1로 바꿔도 나머지가 같아진다. 따라서 수를 9로 나눈 나머지는 각 자리 숫자의 합을 9로 나눈 나머지와 같다. 최대 10만 자리의 수는 정수 하나에 담을 수 없지만 자리 숫자의 합은 최대 90만이라 32비트 정수로 충분하다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int solution(String number) {
        int sum = 0;
        for (char c : number.toCharArray()) {
            sum += c - '0';
        }

        return sum % 9;
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int solution(string number) {
    int sum = 0;
    for (char c : number) sum += c - '0';
    return sum % 9;
}
```

```python
def solution(number):
    return sum(int(c) for c in number) % 9
```
