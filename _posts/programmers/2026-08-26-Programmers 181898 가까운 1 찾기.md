## 1. 아이디어

`idx`부터 배열 끝까지 순회하면서 처음으로 값이 1인 위치를 만나면 그 인덱스를 반환하고, 끝까지 찾지 못하면 -1을 반환하면 된다. 앞에서부터 훑기 때문에 가장 먼저 만나는 1이 곧 가장 작은 인덱스다.

---

## 2. 복잡도

| 접근 | 시간   | 공간   |
| ---- | ------ | ------ |
| 풀이 | $O(N)$ | $O(1)$ |

($N$ = `arr`의 길이)

---

## 3. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int solution(int[] arr, int idx) {
        for (int i = idx; i < arr.length; i++) {
            if (arr[i] == 1) return i;
        }

        return -1;
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int solution(vector<int> arr, int idx) {
    for (int i = idx; i < arr.size(); i++) {
        if (arr[i] == 1) return i;
    }

    return -1;
}
```

```python
def solution(arr, idx):
    return next((i for i in range(idx, len(arr)) if arr[i] == 1), -1)
```

`next`에 제너레이터와 기본값 -1을 함께 넘기면, 조건을 만족하는 첫 인덱스를 반환하고 그런 인덱스가 없으면 -1을 반환한다.
