## 1. 아이디어

이모티콘 $S$개를 만드는 과정은 BFS를 활용하면 해결할 수 있다. 탐색은 현재 화면에 있는 이모티콘 수와 클립보드에 있는 이모티콘 수가 모두 필요하므로 두 가지 파라미터를 갖는 객체를 활용해 3가지 연산을 적용하며 BFS를 돌렸다.

---

## 2. 복잡도

| 접근 | 시간     | 공간     |
| ---- | -------- | -------- |
| 풀이 | $O(K^2)$ | $O(K^2)$ |

($K$ = 값의 범위 $10^3 + 1$)

---

## 3. 코드

### 풀이 [Java][C++]

```java
import java.io.*;
import java.util.*;

public class Main {

    static final int MAX = 1000;

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        int s = Integer.parseInt(br.readLine());
        System.out.println(bfs(s));
    }

    static int bfs(int s) {
        Queue<int[]> q = new ArrayDeque<>();
        q.offer(new int[]{1, 0});

        boolean[][] vis = new boolean[1 + MAX][1 + MAX];
        vis[1][0] = true;

        int dist = 0;

        while (!q.isEmpty()) {
            int sz = q.size();

            while (sz-- > 0) {
                int[] cur = q.poll();
                if (cur[0] == s) return dist;

                if (!vis[cur[0]][cur[0]]) {
                    q.offer(new int[]{cur[0], cur[0]});
                    vis[cur[0]][cur[0]] = true;
                }

                if (cur[0] + cur[1] <= MAX && !vis[cur[0] + cur[1]][cur[1]]) {
                    q.offer(new int[]{cur[0] + cur[1], cur[1]});
                    vis[cur[0] + cur[1]][cur[1]] = true;
                }

                if (cur[0] > 0 && !vis[cur[0] - 1][cur[1]]) {
                    q.offer(new int[]{cur[0] - 1, cur[1]});
                    vis[cur[0] - 1][cur[1]] = true;
                }
            }

            dist++;
        }

        return -1;
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

const int MAX = 1000;
bool vis[1 + MAX][1 + MAX];

int bfs(int s) {
    queue<pair<int, int>> q;
    q.push({1, 0});

    vis[1][0] = true;

    int dist = 0;

    while (!q.empty()) {
        int sz = q.size();

        while (sz--) {
            auto [a, b] = q.front();
            q.pop();

            if (a == s) return dist;

            if (!vis[a][a]) {
                q.push({a, a});
                vis[a][a] = true;
            }

            if (a + b <= MAX && !vis[a + b][b]) {
                q.push({a + b, b});
                vis[a + b][b] = true;
            }

            if (a > 0 && !vis[a - 1][b]) {
                q.push({a - 1, b});
                vis[a - 1][b] = true;
            }
        }

        dist++;
    }

    return -1;
}

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    int s;
    cin >> s;
    cout << bfs(s);
}
```
