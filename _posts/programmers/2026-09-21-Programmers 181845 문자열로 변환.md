## 1. 아이디어

주어진 정수 `n`을 문자열로 변환하는 간단한 문제로 내장 라이브러리를 활용하면 된다.

---

## 2. 복잡도

| 접근 | 시간   | 공간   |
| ---- | ------ | ------ |
| 풀이 | $O(D)$ | $O(D)$ |

($D$ = `n`의 자릿수 $\approx \log_{10} n$)

---

## 3. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public String solution(int n) {
        return String.valueOf(n);
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

string solution(int n) {
    return to_string(n);
}
```

```python
def solution(n):
    return str(n)
```
