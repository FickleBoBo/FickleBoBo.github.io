## 1. 아이디어

두 배열의 대소를 길이로 먼저 가르고, 길이가 같으면 원소의 합으로 가르는 문제다. 길이가 다르면 합은 볼 필요가 없고, 길이가 같을 때도 앞에서부터 원소를 맞대는 사전순 비교와 달리 원소의 순서는 영향이 없어 합만 구하면 된다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.util.*;

class Solution {
    public int solution(int[] arr1, int[] arr2) {
        if (arr1.length > arr2.length) return 1;
        if (arr1.length < arr2.length) return -1;

        int sum1 = Arrays.stream(arr1).sum();
        int sum2 = Arrays.stream(arr2).sum();
        return Integer.compare(sum1, sum2);
    }
}
```

`Integer.compare`는 명세상 음수, 0, 양수만 보장하지만 실제로는 -1, 0, 1을 돌려줘서 결과를 그대로 반환했다.

```c++
#include <bits/stdc++.h>
using namespace std;

int solution(vector<int> arr1, vector<int> arr2) {
    if (arr1.size() > arr2.size()) return 1;
    if (arr1.size() < arr2.size()) return -1;

    int sum1 = 0, sum2 = 0;
    for (int x : arr1) sum1 += x;
    for (int x : arr2) sum2 += x;

    return (sum1 > sum2) - (sum1 < sum2);
}
```

`bool`은 `int`로 바뀌므로 `(sum1 > sum2) - (sum1 < sum2)`가 1, 0, -1이 된다.

```python
def solution(arr1, arr2):
    a = (len(arr1), sum(arr1))
    b = (len(arr2), sum(arr2))
    return (a > b) - (a < b)
```

길이와 합을 튜플로 묶어 비교했다. 튜플 비교는 앞 원소부터 보고 같을 때만 다음 원소를 보므로 문제의 대소 정의와 같다. `(a > b) - (a < b)`로 1, 0, -1을 만들었다.
