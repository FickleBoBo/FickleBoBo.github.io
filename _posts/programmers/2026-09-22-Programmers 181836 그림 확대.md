## 1. 아이디어

그림을 가로와 세로로 $k$배 늘리는 문제다. 가로 확대는 각 글자를 $k$번 반복하는 것이고 세로 확대는 행을 $k$번 반복하는 것이며, 둘은 서로 독립이라 한 행을 가로로 늘린 문자열을 만들어 $k$줄 연속으로 쓰면 된다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public String[] solution(String[] picture, int k) {
        String[] arr = new String[picture.length * k];
        int idx = 0;

        for (String s : picture) {
            StringBuilder sb = new StringBuilder();
            for (char c : s.toCharArray()) {
                sb.repeat(c, k);
            }

            String res = sb.toString();
            for (int j = 0; j < k; j++) {
                arr[idx++] = res;
            }
        }

        return arr;
    }
}
```

Java 21에서 추가된 `StringBuilder.repeat`로 문자 `c`를 `k`번 붙였다.

```c++
#include <bits/stdc++.h>
using namespace std;

vector<string> solution(vector<string> picture, int k) {
    vector<string> v;
    for (string& row : picture) {
        string s;
        for (char c : row) {
            s += string(k, c);
        }
        for (int j = 0; j < k; j++) {
            v.push_back(s);
        }
    }

    return v;
}
```

문자 `c`를 `k`개 채운 문자열을 `std::string(k, c)`로 만들어 이어 붙였다.

```python
def solution(picture, k):
    ans = []
    for row in picture:
        line = "".join(c * k for c in row)
        ans.extend([line] * k)

    return ans
```

`c * k`로 문자를 반복하고 `[line] * k`로 같은 줄을 `k`번 담았다. `[line] * k`는 같은 문자열 객체를 `k`번 참조하지만 문자열은 바뀌지 않아 문제가 없다.
