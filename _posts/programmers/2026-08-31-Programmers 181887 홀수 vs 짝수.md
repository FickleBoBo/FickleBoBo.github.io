## 1. 아이디어

첫 원소를 1번으로 셀 때 홀수 번째 원소는 0-indexed 인덱스로는 짝수 자리(0, 2, 4, ...)에, 짝수 번째 원소는 홀수 자리에 놓인다. 짝수 자리와 홀수 자리에 위치한 원소들의 합을 각각 구해서 더 큰 값을 반환하면 된다.

---

## 2. 복잡도

| 접근 | 시간   | 공간   |
| ---- | ------ | ------ |
| 풀이 | $O(N)$ | $O(1)$ |

($N$ = `num_list`의 길이. Python은 `[::2]`/`[1::2]` 슬라이스로 사본을 만들어 공간 $O(N)$)

---

## 3. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int solution(int[] num_list) {
        int odd = 0, even = 0;
        for (int i = 0; i < num_list.length; i++) {
            if (i % 2 != 0) {
                odd += num_list[i];
            } else {
                even += num_list[i];
            }
        }

        return Math.max(odd, even);
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int solution(vector<int> num_list) {
    int odd = 0, even = 0;
    for (int i = 0; i < num_list.size(); i++) {
        if (i % 2) {
            odd += num_list[i];
        } else {
            even += num_list[i];
        }
    }

    return max(odd, even);
}
```

```python
def solution(num_list):
    return max(sum(num_list[::2]), sum(num_list[1::2]))
```
