## 1. 아이디어

먼저 집이 일렬로 늘어서 있고 인접한 두 집을 함께 털 수 없는 경우를 생각한다. `dp[i]`를 "왼쪽에서 i번째 집까지만 두고 봤을 때 훔칠 수 있는 최대 금액"으로 정의하면, i번째 집을 처리할 때 선택은 이 집을 터느냐 마느냐 둘뿐이다. 안 털면 조건이 하나도 늘지 않으므로 `dp[i - 1]`이 그대로 답이 된다. 털면 바로 옆 `i - 1`번째 집은 인접해서 같이 못 터므로 `i - 2`번째까지의 최적해에 이 집의 금액을 더한 값이 된다. 두 값 중 큰 쪽이 `dp[i]`이고, 이 갱신이 점화식이다.

이 점화식이 성립하는 이유는 `dp[i - 1]`과 `dp[i - 2]`가 각각 "거기까지의 최대 금액"이라는 하나의 수로 요약되고, 그 값을 만들 때 어떤 집들을 골랐는지는 i번째 이후의 선택에 영향을 주지 않기 때문이다. 그래서 앞 구간의 답을 그대로 가져다 뒤를 이어서 계산할 수 있다. 맨 앞 한두 칸은 참조할 이전 값이 없는데, 이때 0으로 두면 "아직 아무것도 훔치지 않은 상태"와 같아 별도의 경계 처리가 필요 없다.

이 문제는 집이 원형이라 첫 집과 마지막 집도 서로 인접하다는 점만 다르다. 인접한 두 집을 동시에 털 수 없으므로 어떤 선택이든 첫 집과 마지막 집 중 적어도 하나는 빠진다. 그래서 첫 집을 뺀 구간과 마지막 집을 뺀 구간에 각각 선형 DP를 적용하고 두 결과 중 큰 값을 답으로 삼는다. 첫 집과 마지막 집을 모두 터는 경우만 어느 구간에도 들어가지 않는데, 이 경우는 애초에 규칙 위반이라 제외되어야 하므로 정확히 걸러진다. 두 집을 모두 안 터는 선택은 양쪽 구간에서 중복으로 계산되지만 최댓값을 취하므로 영향이 없다.

배열 DP는 갱신값을 `dp` 배열에 모두 저장하고, 공간 최적화 버전은 점화식이 직전 두 값만 참조한다는 점을 이용해 변수 두 개만으로 같은 계산을 하여 공간을 $O(1)$로 줄였다.

## 2. 복잡도

| 접근        | 시간   | 공간   |
| ----------- | ------ | ------ |
| 배열 DP     | $O(N)$ | $O(N)$ |
| 공간 최적화 | $O(N)$ | $O(1)$ |

($N$ = `money`의 길이)

## 3. 코드

### 풀이: 배열 DP [Java][C++][Python]

```java
class Solution {
    public int solution(int[] money) {
        int n = money.length;

        int case1 = solve(money, 1, n - 1);
        int case2 = solve(money, 2, n);
        return Math.max(case1, case2);
    }

    static int solve(int[] money, int l, int r) {
        int n = money.length;
        int[] dp = new int[1 + n];

        for (int i = l; i <= r; i++) {
            dp[i] = Math.max(dp[i - 1], dp[Math.max(i - 2, 0)] + money[i - 1]);
        }

        return dp[r];
    }
}
```

def solve(money, l, r):

        dp[i] = max(dp[i - 1], dp[i - 2] + money[i - 1])

### 풀이 2: 공간 최적화 [Java][C++][Python]

```java
class Solution {
    public int solution(int[] money) {
        int n = money.length;

        int case1 = solve(money, 0, n - 1);
        int case2 = solve(money, 1, n);
        return Math.max(case1, case2);
    }

    static int solve(int[] money, int l, int r) {
        int prv2 = 0, prv1 = 0;

        for (int i = l; i < r; i++) {
            int cur = Math.max(prv1, prv2 + money[i]);
            prv2 = prv1;
            prv1 = cur;
        }

        return prv1;
    }
}
```
