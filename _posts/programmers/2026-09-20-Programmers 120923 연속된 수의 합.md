## 1. 아이디어

연속된 `num`개의 수의 합이 `total`이 될 때 원래 수열을 구하는 문제로 등차수열의 합 공식을 응용하면 해결할 수 있다. 등차수열의 초항을 $a$, 공차를 $d$라고 할 때, $total = \dfrac{(a + a + (num - 1) \times d) \times num}{2}$이고 연속된 정수라서 공차가 `1`이므로, 식을 정리하면 $a = \dfrac{total}{num} - \dfrac{num - 1}{2}$가 된다.

---

## 2. 복잡도

| 접근 | 시간   | 공간   |
| ---- | ------ | ------ |
| 풀이 | $O(N)$ | $O(N)$ |

($N$ = 입력값 `num`)

---

## 3. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int[] solution(int num, int total) {
        int[] arr = new int[num];
        int a = total / num - (num - 1) / 2;
        for (int i = 0; i < num; i++) {
            arr[i] = a + i;
        }

        return arr;
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

vector<int> solution(int num, int total) {
    vector<int> v(num);
    iota(v.begin(), v.end(), total / num - (num - 1) / 2);
    return v;
}
```

```python
def solution(num, total):
    a = total // num - (num - 1) // 2
    return list(range(a, a + num))
```
