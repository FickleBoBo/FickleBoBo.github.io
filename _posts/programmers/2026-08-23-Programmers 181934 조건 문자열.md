## 1. 아이디어

두 수 `n`, `m`에 대해 문자열 `ineq`와 `eq`의 조합에 따라 아래와 같은 조건을 비교만 해주면 된다.

- `ineq = ">"`, `eq = "="` → `n >= m`
- `ineq = "<"`, `eq = "="` → `n <= m`
- `ineq = ">"`, `eq = "!"` → `n > m`
- `ineq = "<"`, `eq = "!"` → `n < m`

---

## 2. 복잡도

| 접근 | 시간   | 공간   |
| ---- | ------ | ------ |
| 풀이 | $O(1)$ | $O(1)$ |

---

## 3. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int solution(String ineq, String eq, int n, int m) {
        if (ineq.equals(">")) {
            if (eq.equals("=")) return n >= m ? 1 : 0;
            return n > m ? 1 : 0;
        } else {
            if (eq.equals("=")) return n <= m ? 1 : 0;
            return n < m ? 1 : 0;
        }
    }
}
```
