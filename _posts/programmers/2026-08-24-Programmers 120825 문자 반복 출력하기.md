## 1. 아이디어

문자열의 각 문자를 $n$번씩 반복해 이어 붙인 문자열을 반환하는 문제다. 문자의 순서는 그대로이고 각 문자만 $n$개씩 연달아 놓이므로, 앞에서부터 문자를 하나씩 $n$번 반복해 붙이면 된다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public String solution(String my_string, int n) {
        StringBuilder sb = new StringBuilder();
        for (char c : my_string.toCharArray()) {
            sb.repeat(c, n);
        }

        return sb.toString();
    }
}
```

`StringBuilder`의 `repeat`로 문자를 `n`번 덧붙였다.

```c++
#include <bits/stdc++.h>
using namespace std;

string solution(string my_string, int n) {
    string s;
    for (char c : my_string) {
        s.append(n, c);
    }

    return s;
}
```

`append(n, c)`로 문자 `c`를 `n`번 덧붙였다.

```python
def solution(my_string, n):
    return "".join(c * n for c in my_string)
```

문자열에 정수를 곱해 반복하고 `"".join`으로 이어 붙였다.
