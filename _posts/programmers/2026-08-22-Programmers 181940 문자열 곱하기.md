## 1. 아이디어

문자열 `my_string`을 `k`번 반복해서 이어붙인 문자열을 반환하면 되는 간단한 문제다.

---

## 2. 복잡도

| 접근 | 시간            | 공간            |
| ---- | --------------- | --------------- |
| 풀이 | $O(N \times K)$ | $O(N \times K)$ |

($N$ = `my_string`의 길이, $K$ = `k`)

---

## 3. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public String solution(String my_string, int k) {
        return my_string.repeat(k);
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

string solution(string my_string, int k) {
    string s;
    while (k--) s += my_string;
    return s;
}
```

```python
def solution(my_string, k):
    return my_string * k
```
