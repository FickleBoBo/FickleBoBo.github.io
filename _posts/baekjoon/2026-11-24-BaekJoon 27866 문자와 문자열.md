## 1. 아이디어

$S$의 $i$번째 글자를 출력하는 문제로, $i$는 1부터 세지만 문자열의 인덱스는 0부터 시작하므로 인덱스 $i - 1$의 문자를 꺼낸다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        String s = br.readLine();
        int i = Integer.parseInt(br.readLine());
        System.out.println(s.charAt(i - 1));
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    string s;
    int i;
    cin >> s >> i;
    cout << s[i - 1];
}
```

```python
import sys

input = sys.stdin.readline

s = input().rstrip()
i = int(input())
print(s[i - 1])
```
