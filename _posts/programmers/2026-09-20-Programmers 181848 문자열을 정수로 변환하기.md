## 1. 아이디어

숫자로만 이루어진 문자열 `n_str`을 정수로 변환하는 문제로 내장 라이브러리를 활용하면 간단하게 해결할 수 있다.

---

## 2. 복잡도

| 접근 | 시간   | 공간   |
| ---- | ------ | ------ |
| 풀이 | $O(N)$ | $O(1)$ |

($N$ = `n_str`의 길이)

---

## 3. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int solution(String n_str) {
        return Integer.parseInt(n_str);
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int solution(string n_str) {
    return stoi(n_str);
}
```

```python
def solution(n_str):
    return int(n_str)
```
