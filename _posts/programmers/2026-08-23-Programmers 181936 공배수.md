## 1. 아이디어

정수 `number`가 `n`과 `m`의 공배수인지 판별하는 워밍업 문제다. `number`를 `n`과 `m`으로 각각 나눈 나머지가 모두 0이면 공배수이므로 1을, 그렇지 않으면 0을 반환하면 된다.

---

## 2. 복잡도

| 접근 | 시간   | 공간   |
| ---- | ------ | ------ |
| 풀이 | $O(1)$ | $O(1)$ |

---

## 3. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int solution(int number, int n, int m) {
        return number % n == 0 && number % m == 0 ? 1 : 0;
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int solution(int number, int n, int m) {
    return number % n == 0 && number % m == 0;
}
```

```python
def solution(number, n, m):
    return int(number % n == 0 and number % m == 0)
```
