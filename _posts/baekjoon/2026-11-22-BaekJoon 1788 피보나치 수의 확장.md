## 1. 아이디어

$F(n)$의 부호와 절댓값을 1,000,000,000으로 나눈 나머지를 구하는 문제이고 $n$은 음수일 수 있다. 지문은 점화식 $F(n) = F(n - 1) + F(n - 2)$가 음수 $n$에서도 성립하게 하라고 하므로, $F(k - 2) = F(k) - F(k - 1)$로 거슬러 내려가면 $F(-1) = 1$, $F(-2) = -1$, $F(-3) = 2$, $F(-4) = -3$처럼 음수 쪽 값이 나온다. 이 값들은 모든 $k \ge 1$에서 $F(-k) = (-1)^{k + 1} F(k)$를 따른다. $k = 1, 2$는 위 값으로 확인되고, 그다음은 $F(-(k + 1)) = F(-(k - 1)) - F(-k) = (-1)^k F(k - 1) + (-1)^k F(k) = (-1)^k F(k + 1)$이다. 그래서 양의 방향으로 $|n|$번째 항까지 크기를 구하고, 부호는 $n = 0$이면 0, $n > 0$이거나 $|n|$이 홀수이면 양수, 그 밖에는 음수로 정하면 된다. 음수 방향으로 점화식을 그대로 돌려 나머지의 부호에서 얻을 수도 있다.

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;

public class Main {

    static final int MOD = 1_000_000_000;

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        int n = Integer.parseInt(br.readLine());
        if (n >= 0) {
            int[] dp = new int[1 + n + 1];
            dp[1] = 1;
            for (int i = 2; i <= n; i++) {
                dp[i] = (dp[i - 1] + dp[i - 2]) % MOD;
            }

            System.out.println(Integer.signum(dp[n]));
            System.out.println(dp[n]);
        } else {
            n = Math.abs(n);
            int[] dp = new int[1 + n];
            dp[1] = 1;
            for (int i = 2; i <= n; i++) {
                dp[i] = (dp[i - 2] - dp[i - 1]) % MOD;
            }

            System.out.println(Integer.signum(dp[n]));
            System.out.println(Math.abs(dp[n]));
        }
    }
}
```

`%`는 피제수의 부호를 따르므로 음수 방향의 점화식 `dp[i] = (dp[i - 2] - dp[i - 1]) % MOD`가 만드는 `dp[i]`는 $F(-i)$를 1,000,000,000으로 나눈 나머지이고 부호가 번갈아 나온다. 그래서 `Integer.signum`으로 부호를, `Math.abs`로 크기를 얻었다.

```c++
#include <bits/stdc++.h>
using namespace std;

const int MOD = 1'000'000'000;
int dp[1 + 1'000'000];

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    int n;
    cin >> n;

    dp[1] = 1;
    if (n >= 0) {
        for (int i = 2; i <= n; i++) {
            dp[i] = (dp[i - 1] + dp[i - 2]) % MOD;
        }

        cout << (dp[n] > 0) - (dp[n] < 0) << '\n';
        cout << dp[n];
    } else {
        n = abs(n);
        for (int i = 2; i <= n; i++) {
            dp[i] = (dp[i - 2] - dp[i - 1]) % MOD;
        }

        cout << (dp[n] > 0) - (dp[n] < 0) << '\n';
        cout << abs(dp[n]);
    }
}
```

`%`는 피제수의 부호를 따르므로 음수 방향의 점화식이 만드는 `dp[i]`는 $F(-i)$를 1,000,000,000으로 나눈 나머지이고 부호가 번갈아 나온다. C++에는 1, 0, -1을 돌려주는 표준 함수가 없어 `(dp[n] > 0) - (dp[n] < 0)`으로 부호를, `std::abs`로 크기를 얻었다.

```python
import sys

input = sys.stdin.readline

MOD = 1_000_000_000

n = int(input())
m = abs(n)
dp = [0] * (1 + m + 1)
dp[1] = 1
for i in range(2, m + 1):
    dp[i] = (dp[i - 1] + dp[i - 2]) % MOD

if n == 0:
    sign = 0
elif n > 0 or m % 2 != 0:
    sign = 1
else:
    sign = -1

print(sign)
print(dp[m])
```

`%`의 결과는 나누는 수가 양수이면 항상 0 이상이라 나머지에서 부호를 읽을 수 없다. 그래서 양의 방향으로 크기 `dp[m]`만 구하고, 부호는 `n`이 0인지, 양수인지, `m`이 홀수인지로 정했다.
