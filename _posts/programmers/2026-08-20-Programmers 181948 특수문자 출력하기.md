## 1. 아이디어

출력할 문자열에 역슬래시와 큰따옴표가 들어 있어서, 문자열 리터럴로 쓸 때는 각각 `\\`, `\"`로 이스케이프해야 한다. 작은따옴표는 큰따옴표로 감싼 리터럴 안에서는 그대로 써도 된다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
public class Solution {
    public static void main(String[] args) {
        System.out.println("!@#$%^&*(\\'\"<>?:;");
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    cout << "!@#$%^&*(\\'\"<>?:;";
}
```

```python
print("!@#$%^&*(\\'\"<>?:;")
```
