## 1. 아이디어

`flag`에 따라 다른 수식을 계산해서 return하는 문제로 삼항 연산자를 활용해서 간단하게 해결했다.

---

## 2. 복잡도

| 시간복잡도 | 공간복잡도 |
| :--------: | :--------: |
|   $O(1)$   |   $O(1)$   |

---

## 3. 코드

### 풀이 [Java][C++]

```java
class Solution {
    public int solution(int a, int b, boolean flag) {
        return flag ? a + b : a - b;
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int solution(int a, int b, bool flag) {
    return flag ? a + b : a - b;
}
```
