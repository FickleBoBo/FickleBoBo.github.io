## 1. 아이디어

`n`명이 최소 한 조각 이상의 피자를 먹어야하며 피자 한판은 `slice` 조각으로 나뉜다. 피자 한판당 `slice`명만큼 피자 조각을 할당할 수 있으므로 `n`을 `slice`로 올림 나눗셈한만큼 피자가 필요하다.

---

## 2. 복잡도

| 시간복잡도 | 공간복잡도 |
| :--------: | :--------: |
|   $O(1)$   |   $O(1)$   |

---

## 3. 코드

### 풀이 [Java][C++]

```java
class Solution {
    public int solution(int slice, int n) {
        return (n + slice - 1) / slice;
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int solution(int slice, int n) {
    return (n + slice - 1) / slice;
}
```
