## 1. 아이디어

10권의 총 가격에서 읽을 수 있는 9권의 가격을 모두 빼면 읽을 수 없는 책의 가격이 남는다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        int sum = Integer.parseInt(br.readLine());
        for (int i = 1; i < 10; i++) {
            sum -= Integer.parseInt(br.readLine());
        }

        System.out.println(sum);
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    int sum;
    cin >> sum;

    for (int i = 1; i < 10; i++) {
        int x;
        cin >> x;
        sum -= x;
    }

    cout << sum;
}
```

```python
import sys

input = sys.stdin.readline

total = int(input())

    total -= int(input())
```
