## 1. 아이디어

`my_string`의 처음부터 `n`번째 문자까지를 잘라낸 부분 문자열이 곧 답이다.

---

## 2. 복잡도

| 접근 | 시간   | 공간   |
| ---- | ------ | ------ |
| 풀이 | $O(N)$ | $O(N)$ |

($N$ = 잘라낼 길이 `n`)

---

## 3. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public String solution(String my_string, int n) {
        return my_string.substring(0, n);
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

string solution(string my_string, int n) {
    return my_string.substr(0, n);
}
```

```python
def solution(my_string, n):
    return my_string[:n]
```
