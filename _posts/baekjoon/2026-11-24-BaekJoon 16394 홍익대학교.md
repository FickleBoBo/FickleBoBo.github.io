## 1. 아이디어

연도 $N$이 홍익대학교가 개교한 1946년으로부터 몇 주년인지 구하는 문제로, 1946년이 개교 0주년이므로 $N$에서 1946을 뺀 값이 개교 주년이다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        int n = sc.nextInt();
        System.out.println(n - 1946);
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    int n;
    cin >> n;
    cout << n - 1946;
}
```

```python
import sys

input = sys.stdin.readline

n = int(input())
print(n - 1946)
```
