## 1. 아이디어

세 선분 중 두 개 이상이 겹치는 부분의 길이를 구하는 문제다. 끝점이 모두 정수이므로 수직선을 길이 1인 구간으로 쪼개면 각 선분은 그중 몇 개를 통째로 덮고, 겹치는 부분의 길이는 두 개 이상의 선분이 덮은 구간의 개수와 같다. 좌표 범위가 작아서 구간마다 덮은 선분 수를 직접 세어도 충분하다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int solution(int[][] lines) {
        int[] cnt = new int[100 + 1 + 100];
        for (int[] line : lines) {
            for (int i = line[0]; i < line[1]; i++) {
                cnt[i + 100]++;
            }
        }

        int ans = 0;
        for (int x : cnt) {
            if (x >= 2) ans++;
        }

        return ans;
    }
}
```


```python
from collections import Counter


def solution(lines):
    cnt = Counter()

    for s, e in lines:
        for i in range(s, e):
            cnt[i] += 1

    return sum(v >= 2 for v in cnt.values())
```

`Counter`는 없는 키를 0으로 보므로 초기화 없이 `+= 1`로 셌다. 조건식이 참이면 1로 세어져 `sum`을 겹친 구간의 개수로 썼다.
