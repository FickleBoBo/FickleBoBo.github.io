## 1. 아이디어

윷짝 네 개를 세 번 던진 결과가 주어질 때 각 결과가 도, 개, 걸, 윷, 모 중 무엇인지 한 줄씩 출력하는 문제다. 네 값을 더하면 등(`1`)의 개수가 되고 이것으로 결과가 정해진다. 도, 개, 걸, 윷은 순서대로 등이 3, 2, 1, 0개인 경우이고 모만 4개다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        for (int i = 0; i < 3; i++) {
            StringTokenizer st = new StringTokenizer(br.readLine());
            int cnt = 0;
            for (int j = 0; j < 4; j++) {
                cnt += Integer.parseInt(st.nextToken());
            }

            if (cnt == 0) {
                System.out.println("D");
            } else if (cnt == 1) {
                System.out.println("C");
            } else if (cnt == 2) {
                System.out.println("B");
            } else if (cnt == 3) {
                System.out.println("A");
            } else {
                System.out.println("E");
            }
        }
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    for (int i = 0; i < 3; i++) {
        int cnt = 0;
        for (int j = 0; j < 4; j++) {
            int x;
            cin >> x;
            cnt += x;
        }

        if (cnt == 0) {
            cout << 'D' << '\n';
        } else if (cnt == 1) {
            cout << 'C' << '\n';
        } else if (cnt == 2) {
            cout << 'B' << '\n';
        } else if (cnt == 3) {
            cout << 'A' << '\n';
        } else {
            cout << 'E' << '\n';
        }
    }
}
```

    if cnt == 0:
        print("D")
    elif cnt == 1:
        print("C")
    elif cnt == 2:
        print("B")
    elif cnt == 3:
        print("A")
