## 1. 아이디어

입력을 그대로 출력하는 문제다. 줄 안에 공백이 있을 수 있어 단어가 아니라 줄 단위로 읽어야 하고, 줄 수가 주어지지 않으므로 입력이 끝날 때까지 한 줄씩 읽어 출력한다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        BufferedWriter bw = new BufferedWriter(new OutputStreamWriter(System.out));

        String line;
        while ((line = br.readLine()) != null) {
            bw.write(line);
            bw.newLine();
        }

        bw.flush();
    }
}
```

`readLine`은 입력이 끝나면 `null`을 반환하므로 이를 반복의 종료 조건으로 삼았다.

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    string line;
    while (getline(cin, line)) {
        cout << line << '\n';
    }
}
```

`std::getline`으로 공백까지 포함한 한 줄을 읽었다. 더 읽을 줄이 없으면 반환된 스트림이 거짓이 돼 반복이 끝난다.

```python
import sys

input = sys.stdin.readline

while True:
    line = input()
    if not line:
        break
    print(line.rstrip())
```

`sys.stdin.readline`은 입력이 끝나면 빈 문자열을 반환하므로 이때 반복을 멈췄다. 줄 끝의 개행 문자는 `rstrip`으로 지웠는데, 줄이 공백으로 끝나지 않아 내용은 지워지지 않는다.
