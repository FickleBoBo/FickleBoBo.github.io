## 1. 아이디어

접미사는 시작 인덱스마다 하나씩이라 문자열의 길이만큼 있고, 길이가 100 이하라 전부 만들어 정렬해도 충분하다. 문자열의 기본 비교가 사전순이라 정렬만 하면 요구하는 순서가 된다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.util.*;

class Solution {
    public String[] solution(String my_string) {
        int n = my_string.length();
        String[] arr = new String[n];

        for (int i = 0; i < n; i++) {
            arr[i] = my_string.substring(i);
        }
        Arrays.sort(arr);

        return arr;
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

vector<string> solution(string my_string) {
    vector<string> v;
    for (int i = 0; i < my_string.size(); i++) {
        v.push_back(my_string.substr(i));
    }
    sort(v.begin(), v.end());

    return v;
}
```

```python
def solution(my_string):
    return sorted(my_string[i:] for i in range(len(my_string)))
```
