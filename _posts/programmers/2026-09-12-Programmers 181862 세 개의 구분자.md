## 1. 아이디어

`"a"`, `"b"`, `"c"` 세 글자를 구분자로 잘라 나온 조각을 순서대로 모으되 빈 조각은 넣지 않는 문제다. 빈 조각은 구분자가 연달아 있거나 맨 앞·맨 끝에 있을 때만 생기므로, 빈 조각을 버리는 것은 구분자가 아닌 글자가 이어진 구간만 뽑는 것과 같다. 그런 구간이 하나도 없으면 `"EMPTY"` 하나만 담은 배열을 반환한다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.util.*;

class Solution {
    public String[] solution(String myStr) {
        StringTokenizer st = new StringTokenizer(myStr, "abc");
        if (!st.hasMoreTokens()) return new String[]{"EMPTY"};

        String[] arr = new String[st.countTokens()];
        for (int i = 0; i < arr.length; i++) {
            arr[i] = st.nextToken();
        }

        return arr;
    }
}
```

`StringTokenizer`에 `"abc"`를 넘겨 세 글자를 각각 구분자로 썼다. 두 번째 인자는 구분 문자열이 아니라 구분 문자의 집합이고, 연속한 구분자 사이의 빈 토큰은 만들어지지 않는다.

```c++
#include <bits/stdc++.h>
using namespace std;

vector<string> solution(string myStr) {
    for (char& c : myStr) {
        if (c == 'a' || c == 'b' || c == 'c') c = ' ';
    }

    stringstream ss(myStr);
    vector<string> ans;
    string token;
    while (ss >> token) ans.push_back(token);

    if (ans.empty()) return {"EMPTY"};
    return ans;
}
```

구분자를 공백으로 바꾼 뒤 `std::stringstream`에서 `>>`로 읽었다. `>>`는 연속한 공백을 하나로 보고 앞뒤 공백을 건너뛰어 빈 조각이 생기지 않으며, 입력이 소문자뿐이라 원래 있던 공백과 섞일 일도 없다.

```python
def solution(myStr):
    ans = myStr.translate(str.maketrans("abc", "   ")).split()
    return ans if ans else ["EMPTY"]
```

`str.maketrans("abc", "   ")`로 구분자를 공백으로 바꾸고 인자 없는 `split()`을 썼다. 이 호출은 연속한 공백을 하나로 보고 앞뒤 공백을 무시해 빈 문자열이 나오지 않는다.
