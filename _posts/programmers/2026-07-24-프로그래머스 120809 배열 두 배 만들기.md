## 1. 아이디어

정수 배열 `numbers`에 대해 `numbers`의 각 원소에 두배한 원소를 가진 배열을 return하는 문제로 매개변수로 주어진 `numbers`의 각 원소들을 두배한 후 `numbers`를 그대로 return하는 방식으로 해결했다.

---

## 2. 복잡도

| 시간복잡도 | 공간복잡도 |
| :--------: | :--------: |
|   $O(N)$   |   $O(1)$   |

> $N$ = `numbers` 길이

---

## 3. 코드

### 풀이 [Java][C++]

```java
class Solution {
    public int[] solution(int[] numbers) {
        for (int i = 0; i < numbers.length; i++) {
            numbers[i] *= 2;
        }

        return numbers;
    }
}
```

`numbers` 벡터의 원소를 두배하기 위해 참조자(`&`)를 활용해줬다.

```c++
#include <vector>

using namespace std;

vector<int> solution(vector<int> numbers) {
    for (int& x : numbers) {
        x *= 2;
    }

    return numbers;
}
```
