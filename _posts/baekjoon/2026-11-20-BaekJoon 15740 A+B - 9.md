## 1. 아이디어

$A$와 $B$의 절댓값이 $10^{10000}$까지 가능해 64비트 정수형에는 담을 수 없고 음수도 주어지지만 부호까지 다루는 큰 수 자료형으로 두 수를 읽어 더하면 같은 덧셈으로 처리되므로 결과를 그대로 출력한다.

---

## 2. 코드

### 풀이 [Java][Python]

```java
import java.io.*;
import java.math.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());

        BigInteger a = new BigInteger(st.nextToken());
        BigInteger b = new BigInteger(st.nextToken());
        System.out.println(a.add(b));
    }
}
```

```python
import sys

input = sys.stdin.readline

sys.set_int_max_str_digits(0)

a, b = map(int, input().split())
print(a + b)
```

10,001자리 입력만으로도 4,300자리 제한에 걸려 `ValueError`가 나고, 결과를 문자열로 출력할 때도 같은 제한이 걸린다. `sys.set_int_max_str_digits(0)`으로 제한을 없앴다. 이 함수는 Python 3.11부터 쓸 수 있다.
