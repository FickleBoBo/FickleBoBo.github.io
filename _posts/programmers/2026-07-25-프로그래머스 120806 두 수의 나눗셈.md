## 1. 아이디어

정수 `num1`을 `num2`로 나눈 값에 1,000을 곱한 후 정수 부분을 return 하는 문제로 `num1`에 1,000을 먼저 곱한 후 `num2`로 나누었을 때 몫과 해당 값이 동일함을 활용하면 해결할 수 있다.

---

## 2. 복잡도

| 시간복잡도 | 공간복잡도 |
| :--------: | :--------: |
|   $O(1)$   |   $O(1)$   |

---

## 3. 코드

### 풀이 [Java][C++]

```java
class Solution {
    public int solution(int num1, int num2) {
        return num1 * 1000 / num2;
    }
}
```

```c++
int solution(int num1, int num2) {
    return num1 * 1000 / num2;
}
```
