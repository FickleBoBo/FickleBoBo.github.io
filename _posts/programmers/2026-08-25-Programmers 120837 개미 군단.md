## 1. 아이디어

장군개미(공격력 5), 병정개미(3), 일개미(1)로 체력을 정확히 맞추면서 마릿수를 최소로 하는 문제다. 큰 개미부터 쓰는 그리디가 최적인지는 교환 논증으로 확인한다.

일개미 3마리는 병정개미 1마리로 바꾸면 마릿수가 줄므로 일개미는 2마리 이하다. 병정개미 2마리는 장군개미와 일개미 1마리씩으로 바꿔도 마릿수가 같으면서 장군개미가 늘어나므로 병정개미는 1마리 이하다. 병정개미 1마리와 일개미 2마리(공격력 합 5)도 장군개미 1마리로 바꾸면 마릿수가 줄어 쓰지 않는다. 바꿀 때마다 마릿수가 줄거나 장군개미가 늘어 이 과정은 언젠가 끝나므로, 최적해에서 병정개미와 일개미가 채우는 체력은 4 이하다. 따라서 장군개미는 체력을 5로 나눈 몫만큼, 병정개미는 나머지를 3으로 나눈 몫만큼, 일개미는 그 나머지만큼 쓰면 되고, 이것이 큰 공격력부터 쓰는 그리디다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int solution(int hp) {
        return hp / 5 + hp % 5 / 3 + hp % 5 % 3;
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

    return hp / 5 + hp % 5 / 3 + hp % 5 % 3;
}
```

def solution(hp):
    return hp // 5 + hp % 5 // 3 + hp % 5 % 3
