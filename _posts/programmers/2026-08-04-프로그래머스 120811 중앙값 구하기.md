## 1. 아이디어

길이가 홀수인 정수 배열 `array`의 중앙값을 return하는 문제로 배열을 정렬한 후 중간 인덱스에 중앙값이 존재함을 활용했다.

---

## 2. 복잡도

|  시간복잡도   | 공간복잡도 |
| :-----------: | :--------: |
| $O(N \log N)$ |   $O(1)$   |

> N = `array` 길이

---

## 3. 코드

### 풀이 [Java][C++]

```java
import java.util.*;

class Solution {
    public int solution(int[] array) {
        Arrays.sort(array);
        return array[array.length / 2];
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int solution(vector<int> array) {
    sort(array.begin(), array.end());
    return array[array.size() / 2];
}
```
