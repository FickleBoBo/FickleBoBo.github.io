## 1. 아이디어

`ineq`가 부등호의 방향(`>`, `<`)을, `eq`가 등호를 포함하는지(`=`이면 포함, `!`이면 포함하지 않음)를 정하므로, 둘의 조합 네 가지에 맞는 비교를 하면 된다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int solution(String ineq, String eq, int n, int m) {
        if (ineq.equals(">")) {
            if (eq.equals("=")) return n >= m ? 1 : 0;
            return n > m ? 1 : 0;
        } else {
            if (eq.equals("=")) return n <= m ? 1 : 0;
            return n < m ? 1 : 0;
        }
    }
}
```

```c++
#include <bits/stdc++.h>
```
