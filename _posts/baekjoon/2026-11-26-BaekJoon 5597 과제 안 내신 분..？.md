## 1. 아이디어

1번부터 30번까지의 학생 중 과제를 낸 28명의 번호가 주어질 때 내지 않은 두 명의 번호를 구하는 문제로, 제출한 번호를 표시해 두고 1번부터 차례로 훑으며 표시가 없는 번호를 출력하면 요구한 대로 작은 번호가 먼저 나온다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        boolean[] vis = new boolean[1 + 30];
        for (int i = 0; i < 28; i++) {
            int n = Integer.parseInt(br.readLine());
            vis[n] = true;
        }

        for (int i = 1; i <= 30; i++) {
            if (vis[i]) continue;
            System.out.println(i);
        }
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

bool vis[1 + 30];

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    for (int i = 0; i < 28; i++) {
        int n;
        cin >> n;
        vis[n] = true;
    }

    for (int i = 1; i <= 30; i++) {
        if (vis[i]) continue;
        cout << i << '\n';
    }
}
```

```python
import sys

input = sys.stdin.readline

vis = [False] * (1 + 30)
for _ in range(28):
    n = int(input())
    vis[n] = True

for i in range(1, 30 + 1):
    if vis[i]:
        continue
    print(i)
```
