## 1. 아이디어

`num_list`에 $n$이 하나라도 있는지 확인하는 문제다. 길이가 최대 100이라 처음부터 훑으며 같은 값을 만나면 곧바로 있다고 답하면 된다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int solution(int[] num_list, int n) {
        for (int x : num_list) {
            if (x == n) return 1;
        }

        return 0;
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int solution(vector<int> num_list, int n) {
    return find(num_list.begin(), num_list.end(), n) != num_list.end();
}
```

```python
def solution(num_list, n):
    return int(n in num_list)
```
