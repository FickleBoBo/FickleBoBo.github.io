## 1. 아이디어

상의와 하의의 색이 다른 조합을 세는 문제다. 색상이 모두 서로 다르므로 색이 같은 조합은 $i$번째 상의와 $i$번째 하의 쌍뿐이라 $N$가지이고, 전체 $N^2$가지에서 이를 빼면 $N^2 - N$이다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        int n = Integer.parseInt(br.readLine());
        System.out.println(n * n - n);
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    int n;
    cin >> n;
    cout << n * n - n;
}
```

```python
import sys
```
