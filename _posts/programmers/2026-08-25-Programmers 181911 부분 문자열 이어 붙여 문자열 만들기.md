## 1. 아이디어

`my_strings[i]`에서 `parts[i] = [s, e]`가 가리키는 인덱스 `s`부터 `e`까지(양 끝 포함)의 부분 문자열을 잘라내고, 이를 순서대로 이어 붙이면 답이 되는 문제다.

---

## 2. 복잡도

| 접근 | 시간            | 공간            |
| ---- | --------------- | --------------- |
| 풀이 | $O(N \times L)$ | $O(N \times L)$ |

($N$ = `my_strings`의 길이, $L$ = 각 문자열의 최대 길이)

---

## 3. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public String solution(String[] my_strings, int[][] parts) {
        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < my_strings.length; i++) {
            sb.append(my_strings[i], parts[i][0], parts[i][1] + 1);
        }

        return sb.toString();
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

string solution(vector<string> my_strings, vector<vector<int>> parts) {
    string s;
    for (int i = 0; i < my_strings.size(); i++) {
        s += my_strings[i].substr(parts[i][0], parts[i][1] - parts[i][0] + 1);
    }

    return s;
}
```

```python
def solution(my_strings, parts):
    return "".join(s[a : b + 1] for s, (a, b) in zip(my_strings, parts))
```
