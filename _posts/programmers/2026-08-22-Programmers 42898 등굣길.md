## 1. 아이디어

오른쪽과 아래쪽으로만 움직여 집에서 학교까지 가는 경로의 수를 구하는 문제로, 물에 잠긴 칸은 지나갈 수 없다. 한 칸에 도착하기 직전의 칸은 바로 위나 바로 왼쪽뿐이고 두 경우는 서로 다른 경로이므로, 위에서 $i$번째 행, 왼쪽에서 $j$번째 열의 칸까지 가는 경로의 수를 `dp[i][j]`라 하면 `dp[i][j] = dp[i - 1][j] + dp[i][j - 1]`이다. 물에 잠긴 칸은 `dp[i][j]`를 0으로 두면 그 칸을 거치는 경로가 세어지지 않는다. 시작 칸의 경로 수는 1인데, 격자 바깥의 칸은 0으로 두되 시작 칸 바로 위의 칸 `dp[0][1]`만 1로 두면 시작 칸과 첫 행, 첫 열도 같은 점화식으로 채워진다. 경로 수는 매우 커질 수 있고 합의 나머지는 나머지끼리 더한 합의 나머지와 같으므로 매 칸 1,000,000,007로 나눈 나머지만 유지한다.

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {

    static final int MOD = 1_000_000_007;

    public int solution(int m, int n, int[][] puddles) {
        boolean[][] chk = new boolean[1 + n][1 + m];
        for (int[] p : puddles) {
            chk[p[1]][p[0]] = true;
        }

        int[][] dp = new int[1 + n][1 + m];
        dp[0][1] = 1;

        for (int i = 1; i <= n; i++) {
            for (int j = 1; j <= m; j++) {
                if (chk[i][j]) continue;
                dp[i][j] = (dp[i - 1][j] + dp[i][j - 1]) % MOD;
            }
        }

        return dp[n][m];
    }
}
```

MOD = 1_000_000_007


def solution(m, n, puddles):
    chk = [[False] * (1 + m) for _ in range(1 + n)]
    for x, y in puddles:
        chk[y][x] = True

    dp = [[0] * (1 + m) for _ in range(1 + n)]
    dp[0][1] = 1

    for i in range(1, n + 1):
        for j in range(1, m + 1):
            if chk[i][j]:
                continue
            dp[i][j] = (dp[i - 1][j] + dp[i][j - 1]) % MOD

    return dp[n][m]
