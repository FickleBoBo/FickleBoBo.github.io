## 1. 아이디어

두 수의 곱을 구하는 문제이고 수의 길이가 300,000자리까지 가므로 64비트 정수형에는 담을 수 없다. 큰 수를 다룰 수 있는 정수 자료형으로 두 수를 읽어 그대로 곱해 출력한다.

---

## 2. 코드

### 풀이 [Java][Python]

```java
import java.io.*;
import java.math.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());

        BigInteger a = new BigInteger(st.nextToken());
        BigInteger b = new BigInteger(st.nextToken());
        System.out.println(a.multiply(b));
    }
}
```

```python
import sys

input = sys.stdin.readline

sys.set_int_max_str_digits(0)

a, b = map(int, input().split())
print(a * b)
```

Python에는 정수와 문자열을 서로 바꿀 때 기본으로 4,300자리 제한이 있어 300,000자리 입력을 정수로 바꾸거나 결과를 문자열로 출력하면 `ValueError`가 난다. `sys.set_int_max_str_digits(0)`으로 제한을 없앴다. 이 함수는 Python 3.11부터 쓸 수 있다.
