## 1. 아이디어

특수문자 조합 `!@#$%^&*(\'"<>?:;`을 그대로 출력하면 되는 문제다. 문자열에 포함된 역슬래시(`\`)와 큰따옴표(`"`)만 각 언어의 이스케이프 문법에 맞게 처리하면 나머지 특수문자는 그대로 출력할 수 있다.

---

## 2. 복잡도

| 접근 | 시간   | 공간   |
| ---- | ------ | ------ |
| 풀이 | $O(1)$ | $O(1)$ |

---

## 3. 코드

### 풀이 [Java][C++][Python]

```java
public class Solution {
    public static void main(String[] args) {
        System.out.println("!@#$%^&*(\\'\"<>?:;");
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    cout << "!@#$%^&*(\\'\"<>?:;";
}
```

```python
print("!@#$%^&*(\\'\"<>?:;")
```
