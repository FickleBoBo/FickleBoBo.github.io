## 1. 아이디어

문자열 $A$를 오른쪽으로 한 칸씩 밀어 $B$를 만들 수 있는 최소 횟수를 구하는 문제다. 문자열의 길이만큼 밀면 원래 문자열로 돌아오므로 길이보다 작은 횟수만 확인하면 모든 경우를 본 것이고, 횟수를 0부터 늘려 가며 처음 $B$와 같아지는 때가 최소다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int solution(String A, String B) {
        int len = A.length();
        for (int i = 0; i < len; i++) {
            if (A.equals(B)) return i;
            A = A.substring(len - 1) + A.substring(0, len - 1);
        }

        return -1;
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int solution(string A, string B) {
    for (int i = 0; i < A.size(); i++) {
        if (A == B) return i;
        rotate(A.begin(), A.end() - 1, A.end());
    }

    return -1;
}
```

`std::rotate`로 `A.end() - 1`이 새 시작이 되도록 구간을 회전시켜 마지막 문자를 맨 앞으로 옮겼다.

```python
def solution(A, B):
    for i in range(len(A)):
        if A == B:
            return i
        A = A[-1] + A[:-1]

    return -1
```
