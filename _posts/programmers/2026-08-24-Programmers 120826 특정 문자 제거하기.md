## 1. 아이디어

문자열에서 주어진 문자를 모두 지운 문자열을 반환하는 문제다. 지울 문자는 길이가 1인 영문자이고 대소문자를 구분하므로, 일치하는 문자만 등장하는 모든 자리에서 지우면 된다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public String solution(String my_string, String letter) {
        return my_string.replace(letter, "");
    }
}
```

`replace`는 일치하는 부분을 모두 바꾸므로 빈 문자열로 바꿔 해당 문자를 전부 지웠다.

```c++
#include <bits/stdc++.h>
using namespace std;

string solution(string my_string, string letter) {
    erase(my_string, letter[0]);
    return my_string;
}
```

`std::erase`로 값이 같은 문자를 모두 지웠다. `letter`는 길이가 1이라 첫 문자를 넘겼다.

```python
def solution(my_string, letter):
    return my_string.replace(letter, "")
```

`replace`는 일치하는 부분을 모두 바꾸므로 빈 문자열로 바꿔 해당 문자를 전부 지웠다.
