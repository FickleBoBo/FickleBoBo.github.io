## 1. 아이디어

`my_string`의 뒤 `n`글자를 반환하는 문제다. 전체 길이에서 `n`을 뺀 인덱스부터 끝까지의 부분 문자열이 곧 답이므로, 그 구간을 그대로 잘라 반환하면 된다.

---

## 2. 복잡도

| 접근 | 시간   | 공간   |
| ---- | ------ | ------ |
| 풀이 | $O(N)$ | $O(N)$ |

($N$ = 잘라낼 길이, 파라미터 `n`)

---

## 3. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public String solution(String my_string, int n) {
        return my_string.substring(my_string.length() - n);
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

string solution(string my_string, int n) {
    return my_string.substr(my_string.size() - n);
}
```

```python
def solution(my_string, n):
    return my_string[-n:]
```
