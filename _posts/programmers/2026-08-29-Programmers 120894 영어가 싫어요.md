## 1. 아이디어

문자열 `numbers`는 `zero`부터 `nine`까지의 영어 숫자 단어 조합이 공백 없이 이어져 있다. `zero`부터 `nine`까지 각 문자열을 `0`부터 `9`까지의 문자열로 치환하면 `numbers`를 `result`로 깔끔하게 변환할 수 있다.

---

## 2. 복잡도

| 접근 | 시간   | 공간   |
| ---- | ------ | ------ |
| 풀이 | $O(N)$ | $O(N)$ |

($N$ = `numbers`의 길이. C++는 `find`로 매번 처음부터 다시 탐색하고 `replace`로 구간을 밀어내 시간 $O(N^2)$, 대신 인자로 받은 `numbers` 사본을 제자리 수정하므로 공간 $O(1)$)

---

## 3. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public long solution(String numbers) {
        numbers = numbers
                .replace("zero", "0")
                .replace("one", "1")
                .replace("two", "2")
                .replace("three", "3")
                .replace("four", "4")
                .replace("five", "5")
                .replace("six", "6")
                .replace("seven", "7")
                .replace("eight", "8")
                .replace("nine", "9");

        return Long.parseLong(numbers);
    }
}
```

`zero`부터 `nine`까지 각 단어를 대응하는 숫자로 바꾸는 `replace` 메서드를 이어붙였다. `replace`는 문자열에 등장하는 해당 부분 문자열을 모두 바꾼 새 문자열을 반환하므로, 메서드 체이닝을 통해 열 번의 호출이면 모든 단어가 잘 치환된다.

```c++
#include <bits/stdc++.h>
using namespace std;

string words[10] = {"zero", "one", "two", "three", "four", "five", "six", "seven", "eight", "nine"};

long long solution(string numbers) {
    for (int d = 0; d < 10; d++) {
        int pos;
        while ((pos = numbers.find(words[d])) != -1) {
            numbers.replace(pos, words[d].size(), to_string(d));
        }
    }

    return stoll(numbers);
}
```

인덱스가 그 단어가 나타내는 숫자가 되는 `words` 배열을 먼저 만들었다. 각 단어에 대해 `find`로 등장 위치를 찾을 때마다 `replace`로 그 구간(`words[d].size()` 길이)을 숫자 문자열로 바꾸고, `find`가 더는 위치를 반환하지 않을 때까지(= -1) 반복해 같은 단어가 여러 번 나와도 모두 처리했다.

```python
def solution(numbers):
    words = [
        "zero",
        "one",
        "two",
        "three",
        "four",
        "five",
        "six",
        "seven",
        "eight",
        "nine",
    ]

    for d, w in enumerate(words):
        numbers = numbers.replace(w, str(d))

    return int(numbers)
```

인덱스가 그 단어가 나타내는 숫자가 되는 `words` 리스트를 먼저 만들었다. `enumerate`로 `(숫자, 단어)` 쌍을 돌며 `replace`로 그 단어를 전부 해당 숫자 문자로 바꾼 뒤 `int`로 정수로 변환했다. `replace`가 매칭되는 부분을 모두 바꾸므로 단어당 한 번의 호출로 모든 단어를 처리할 수 있다.
