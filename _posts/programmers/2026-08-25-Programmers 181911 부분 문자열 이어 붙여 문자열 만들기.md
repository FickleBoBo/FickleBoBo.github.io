## 1. 아이디어

각 `my_strings[i]`에서 `parts[i]`가 가리키는 구간을 잘라 순서대로 이어 붙인다. 구간 $[s, e]$는 인덱스 $e$까지 포함하므로, 끝을 포함하지 않는 방식으로 구간을 받는 연산에는 $e + 1$을 넘겨야 한다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public String solution(String[] my_strings, int[][] parts) {
        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < my_strings.length; i++) {
            sb.append(my_strings[i], parts[i][0], parts[i][1] + 1);
        }

        return sb.toString();
    }
}
```

`append`에 구간까지 넘겨 부분 문자열을 따로 만들지 않고 바로 붙였다.

```c++
#include <bits/stdc++.h>
using namespace std;

string solution(vector<string> my_strings, vector<vector<int>> parts) {
    string s;
    for (int i = 0; i < my_strings.size(); i++) {
        s.append(my_strings[i], parts[i][0], parts[i][1] - parts[i][0] + 1);
    }

    return s;
}
```

`append`의 세 번째 인자는 끝 인덱스가 아니라 길이라 `parts[i][1] - parts[i][0] + 1`을 넘겼다.

```python
def solution(my_strings, parts):
    return "".join(word[s : e + 1] for word, (s, e) in zip(my_strings, parts))
```
