## 1. 아이디어

실수의 정수 부분은 소수점 아래를 버린 값이다. 음수라면 소수점 아래 버리기와 내림이 달라지지만 0 이상이라 같으므로, 소수점 아래를 버리는 형변환 하나로 충분하다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int solution(double flo) {
        return (int) flo;
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int solution(double flo) {
    return (int)flo;
}
```

```python
def solution(flo):
    return int(flo)
```
