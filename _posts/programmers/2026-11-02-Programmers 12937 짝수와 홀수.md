## 1. 아이디어

정수가 짝수인지 홀수인지 판별하는 문제다. 짝수는 2로 나눈 나머지가 0인 수이므로 나머지가 0인지로 가르면 된다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public String solution(int num) {
        return num % 2 != 0 ? "Odd" : "Even";
    }
}
```

음수가 입력되면 홀수의 나머지가 -1이라 `== 1`로 비교하면 틀리므로 `!= 0`으로 비교했다.

```c++
#include <bits/stdc++.h>
using namespace std;

string solution(int num) {
    return num % 2 ? "Odd" : "Even";
}
```

음수가 입력되면 홀수의 나머지가 -1이라 `== 1`로 비교하면 틀리므로, 0이 아닌 값은 참이라는 점을 이용해 나머지를 그대로 조건에 썼다.

```python
def solution(num):
    return "Odd" if num % 2 else "Even"
```

0이 아닌 값은 참이라는 점을 이용해 나머지를 그대로 조건에 썼다.
