## 1. 아이디어

단어가 팰린드롬인지 판정하는 문제다. 팰린드롬은 앞으로 읽을 때와 거꾸로 읽을 때가 같은 단어이므로, 뒤집은 문자열이 원래 단어와 같은지 확인한다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        String s = br.readLine();
        String rs = new StringBuilder(s).reverse().toString();

        if (s.equals(rs)) {
            System.out.println(1);
        } else {
            System.out.println(0);
        }
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    string s;
    cin >> s;

    string rs(s.rbegin(), s.rend());
    cout << (s == rs);
}
```

`bool`이 1과 0으로 출력되는 것을 이용해 `s == rs`를 분기 없이 그대로 출력했다.

```python
import sys

input = sys.stdin.readline

s = input().rstrip()
print(int(s == s[::-1]))
```

`sys.stdin.readline`이 줄바꿈까지 읽어 오므로 `rstrip`으로 지워, 뒤집은 문자열의 맨 앞에 줄바꿈이 붙어 항상 다르다고 나오지 않게 했다. `s == s[::-1]`은 `True` 또는 `False`라서 `int`로 바꿔 1과 0을 출력했다.
