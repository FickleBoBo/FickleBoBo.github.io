## 1. 아이디어

중앙값은 정렬했을 때 가운데 값이므로 정렬한 뒤 가운데 원소를 고르면 된다. 길이가 홀수라 가운데가 정확히 한 원소로 정해지고, 배열의 길이를 $n$이라 하면 그 인덱스(0부터 센다)는 $\lfloor n / 2 \rfloor$이다(길이 5면 인덱스 2).

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.util.*;

class Solution {
    public int solution(int[] array) {
        Arrays.sort(array);
        return array[array.length / 2];
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int solution(vector<int> array) {
    sort(array.begin(), array.end());
    return array[array.size() / 2];
}
```

```python
def solution(array):
    array.sort()
    return array[len(array) // 2]
```
