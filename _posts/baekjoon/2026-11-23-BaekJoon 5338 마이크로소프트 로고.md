## 1. 아이디어

예제 출력의 마이크로소프트 로고를 다섯 줄로 그대로 출력한다. 줄 안의 공백 개수까지 예제와 같아야 하고, 첫 줄은 공백으로 시작한다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("       _.-;;-._");
        System.out.println("'-..-'|   ||   |");
        System.out.println("'-..-'|_.-;;-._|");
        System.out.println("'-..-'|   ||   |");
        System.out.println("'-..-'|_.-''-._|");
    }
}
```

```c++
#include <bits/stdc++.h>

}
```
