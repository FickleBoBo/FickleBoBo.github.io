## 1. 아이디어

나이는 태어난 연도에 1살이고 매년 1월 1일마다 1살씩 증가한다. 기준 연도가 2022년이므로 출생 연도는 $2022 - \text{age} + 1$이 되고, 이를 정리하면 $2023 - \text{age}$가 된다.

---

## 2. 복잡도

| 접근 | 시간   | 공간   |
| ---- | ------ | ------ |
| 풀이 | $O(1)$ | $O(1)$ |

---

## 3. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int solution(int age) {
        return 2023 - age;
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int solution(int age) {
    return 2023 - age;
}
```

```python
def solution(age):
    return 2023 - age
```
