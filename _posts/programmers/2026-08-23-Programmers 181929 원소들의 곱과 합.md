## 1. 아이디어

모든 원소의 곱과 합의 제곱을 각각 구해 곱이 더 작은지 비교한다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int solution(int[] num_list) {
        long mul = 1, sum = 0;
        for (int x : num_list) {
            mul *= x;
            sum += x;
        }

        return mul < sum * sum ? 1 : 0;
    }
}
```

곱이 최대 $9^{10}$이라 `int` 범위를 넘으므로 `long`을 썼다.

```c++
#include <bits/stdc++.h>
using namespace std;

int solution(vector<int> num_list) {
    long long mul = 1, sum = 0;
    for (int x : num_list) {
        mul *= x;
        sum += x;
    }

    return mul < sum * sum;
}
```
