## 1. 아이디어

$n$을 2로 나눈 나머지가 0이면 짝수, 아니면 홀수이므로 짝수이면 `is even`, 홀수이면 `is odd`를 $n$ 뒤에 붙여 출력한다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;

public class Solution {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        int n = Integer.parseInt(br.readLine());
        if (n % 2 != 0) {
            System.out.println(n + " is odd");
        } else {
            System.out.println(n + " is even");
        }
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    int n;
    cin >> n;

    if (n % 2) {
        cout << n << " is odd";
    } else {
        cout << n << " is even";
    }
}
```

```python
import sys

input = sys.stdin.readline

n = int(input())
if n % 2:
    print(f"{n} is odd")
else:
    print(f"{n} is even")
```
