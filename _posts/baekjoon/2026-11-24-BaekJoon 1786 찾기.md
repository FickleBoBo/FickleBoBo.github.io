## 1. 아이디어

텍스트 $T$에서 패턴 $P$가 나타나는 모든 시작 위치를 찾는 문제다. $T$, $P$의 길이를 $n$, $m$이라 하면 시작 위치마다 $P$를 처음부터 비교하는 방법은 $O((n - m + 1)m)$이라 $n$이 100만, $m$이 50만쯤일 때 시간 안에 끝나지 않는다. 어긋났을 때 $T$를 되돌아가지 않고, 지금까지 맞은 $P$의 앞부분에서 접두사이면서 접미사이기도 한 가장 긴 길이(자기 자신 제외)만큼 $P$의 비교 위치를 되돌리는 KMP 알고리즘을 쓰면 실패 함수 계산과 탐색을 합쳐 $O(n + m)$이다. 패턴이 끝까지 맞은 뒤에도 같은 방식으로 위치를 옮겨 이어 가면 겹치는 매칭을 놓치지 않는다(`AAAA`에서 `AA`는 세 곳에서 나타난다).

## 2. 코드

### 풀이 [C++]

```c++
#include <bits/stdc++.h>
using namespace std;

vector<int> failure(string& s) {
    vector<int> pi(s.size());
    int j = 0;
    for (int i = 1; i < s.size(); i++) {
        while (j > 0 && s[i] != s[j]) j = pi[j - 1];
        if (s[i] == s[j]) pi[i] = ++j;
    }
    return pi;
}

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    string t, p;
    getline(cin, t);
    getline(cin, p);

    vector<int> pi = failure(p);
    vector<int> res;
    int j = 0;
    for (int i = 0; i < t.size(); i++) {
        while (j > 0 && t[i] != p[j]) j = pi[j - 1];
        if (t[i] == p[j]) j++;
        if (j == p.size()) {
            res.push_back(i - j + 1);
            j = pi[j - 1];
        }
    }

    cout << res.size() << '\n';
    for (int x : res) {
        cout << x + 1 << ' ';
    }
}
```

텍스트와 패턴에 공백이 들어 있어 `cin >>` 대신 `std::getline`으로 한 줄씩 읽었다.
