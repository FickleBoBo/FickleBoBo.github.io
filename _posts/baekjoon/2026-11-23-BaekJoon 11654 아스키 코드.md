## 1. 아이디어

한 글자가 주어지면 그 글자의 아스키 코드값을 출력한다. 숫자 글자도 숫자가 아니라 문자로 읽어야 하며, 예를 들어 글자 `0`의 코드값은 48이다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        char c = br.readLine().charAt(0);
        System.out.println((int) c);
    }
}
```

`char`를 그대로 출력하면 문자가 나오므로 `int`로 캐스팅해 코드값을 출력했다.

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    char c;
    cin >> c;
    cout << (int)c;
}
```

`char`를 `cout`에 그대로 넣으면 문자가 출력되므로 `int`로 캐스팅했다.

```python
import sys

input = sys.stdin.readline

c = input().rstrip()
print(ord(c))
```

`sys.stdin.readline`은 줄바꿈까지 읽어 오는데 길이가 2인 문자열이 `ord`에 들어가면 오류가 나므로 `rstrip`으로 지웠다.
