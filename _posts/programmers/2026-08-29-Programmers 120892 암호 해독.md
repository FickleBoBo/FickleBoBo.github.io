## 1. 아이디어

해독된 암호 문자열은 `cipher`에서 `code`의 배수 번째 글자만 모은 문자열이다. `code`가 첫 문자를 1번으로 판정하므로 `code - 1`부터 `code`만큼 더한 것에 해당하는 인덱스의 문자만 모으면 된다.

---

## 2. 복잡도

| 접근 | 시간   | 공간   |
| ---- | ------ | ------ |
| 풀이 | $O(N)$ | $O(N)$ |

($N$ = `cipher`의 길이)

---

## 3. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public String solution(String cipher, int code) {
        StringBuilder sb = new StringBuilder();
        for (int i = code - 1; i < cipher.length(); i += code) {
            sb.append(cipher.charAt(i));
        }

        return sb.toString();
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

string solution(string cipher, int code) {
    string s;
    for (int i = code - 1; i < cipher.size(); i += code) {
        s += cipher[i];
    }

    return s;
}
```

```python
def solution(cipher, code):
    return cipher[code - 1 :: code]
```
