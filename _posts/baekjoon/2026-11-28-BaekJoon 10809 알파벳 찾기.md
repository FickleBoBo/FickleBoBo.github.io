## 1. 아이디어

소문자 단어에서 `a`부터 `z`까지 각 알파벳이 처음 나오는 위치를 구하는 문제다. 알파벳이 26개뿐이고 단어가 100글자를 넘지 않으므로, 알파벳마다 단어를 앞에서부터 훑어 처음 만나는 위치를 찾으면 충분하다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringBuilder sb = new StringBuilder();

        String s = br.readLine();
        for (int i = 0; i < 26; i++) {
            sb.append(s.indexOf(i + 'a')).append(" ");
        }

        System.out.println(sb);
    }
}
```

`indexOf`는 문자 코드를 `int`로 받으므로 `i + 'a'`를 형변환 없이 넘겼다. 없는 문자면 -1이 반환된다.

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    string s;
    cin >> s;

    for (int i = 0; i < 26; i++) {
        int pos = s.find(i + 'a');
        cout << pos << ' ';
    }
}
```

`find`는 못 찾으면 `std::string::npos`를 반환하는데, `int`에 담으면 -1이 되므로 `pos`에 받은 뒤 출력했다.

```python
import string
import sys

input = sys.stdin.readline

s = input().rstrip()
print(*[s.find(c) for c in string.ascii_lowercase])
```

없는 문자에 `ValueError`가 발생하는 `index` 대신 -1을 반환하는 `find`를 썼다.
