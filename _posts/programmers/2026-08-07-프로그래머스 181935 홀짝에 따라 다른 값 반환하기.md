## 1. 아이디어

`n`이 홀수면 `n` 이하의 모든 홀수의 합을, `n`이 짝수면 `n` 이하인 모든 짝수의 제곱의 합을 return하는 문제로 홀수, 짝수 여부를 조건문으로 분기 처리한 후 반복문으로 합을 계산해줬다.

---

## 2. 복잡도

| 시간복잡도 | 공간복잡도 |
| :--------: | :--------: |
|   $O(n)$   |   $O(1)$   |

> $n$ = 입력 정수(매개변수 `n`)

---

## 3. 코드

### 풀이 [Java][C++]

```java
class Solution {
    public int solution(int n) {
        if (n % 2 == 1) {
            int sum = 0;
            for (int i = 1; i <= n; i += 2) {
                sum += i;
            }

            return sum;
        } else {
            int sum = 0;
            for (int i = 2; i <= n; i += 2) {
                sum += i * i;
            }

            return sum;
        }
    }
}
```
