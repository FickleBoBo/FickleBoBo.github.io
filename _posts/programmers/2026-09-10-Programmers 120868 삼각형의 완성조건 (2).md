## 1. 아이디어

두 변의 길이를 $a \le b$라 할 때 나머지 한 변 $x$가 될 수 있는 정수의 개수를 구하는 문제로, 세 변이 모두 주어진 [[Programmers] #120889 - 삼각형의 완성조건 (1)](/posts/programmers-120889/)과 달리 한 변을 모르는 채로 가능한 길이를 센다. 삼각형은 가장 긴 변이 나머지 두 변의 합보다 작아야 하므로, $x \le b$이면 가장 긴 변이 $b$라서 $b < a + x$, 즉 $b - a < x \le b$여야 하고 이를 만족하는 정수는 $a$개다. $x > b$이면 $x$가 가장 긴 변이므로 $x < a + b$, 즉 $b < x < a + b$여야 하고 이를 만족하는 정수는 $a - 1$개다. 합치면 $2a - 1$개라서 큰 변의 길이와 상관없이 작은 변의 길이만으로 답이 정해진다.

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int solution(int[] sides) {
        return Math.min(sides[0], sides[1]) * 2 - 1;
    }
}
```

```c++
#include <bits/stdc++.h>

    return min(sides[0], sides[1]) * 2 - 1;
}
```
