## 1. 아이디어

각 크기 $k$마다 `=`를 공백 없이 $k$개 이어 붙인 한 줄을 출력한다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringBuilder sb = new StringBuilder();

        int n = Integer.parseInt(br.readLine());
        while (n-- > 0) {
            int k = Integer.parseInt(br.readLine());
            sb.append("=".repeat(k)).append("\n");
        }

        System.out.println(sb);
    }
}
```

`String.repeat`로 루프 없이 `=`를 `k`번 이어 붙였다. `repeat`는 Java 11부터 쓸 수 있다.

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    int n;
    cin >> n;

    while (n--) {
        int k;
        cin >> k;
        cout << string(k, '=') << '\n';
    }
}
```

`std::string(k, '=')`로 `=`가 `k`개인 문자열을 바로 만들었다.

```python
import sys

input = sys.stdin.readline

n = int(input())
for _ in range(n):
    k = int(input())
    print("=" * k)
```
