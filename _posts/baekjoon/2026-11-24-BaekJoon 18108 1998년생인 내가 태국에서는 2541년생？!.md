## 1. 아이디어

불기 연도를 서기 연도로 바꾸는 문제다. 예제에서 불기 2541년이 서기 1998년이라 두 연도의 차이는 543년이므로, 불기 연도에서 543을 빼면 서기 연도이다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        int y = Integer.parseInt(br.readLine());
        System.out.println(y - 543);
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    int y;
    cin >> y;
    cout << y - 543;
}
```

```python
import sys

input = sys.stdin.readline

y = int(input())

```
