## 1. 아이디어

숫자 문자로만 이루어진 문자열을 정수로 바꾸는 문제다. 부호나 공백 같은 예외 입력이 없으므로 내장 변환을 그대로 쓰면 된다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int solution(String n_str) {
        return Integer.parseInt(n_str);
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int solution(string n_str) {
    return stoi(n_str);
}
```

```python
def solution(n_str):
    return int(n_str)
```
