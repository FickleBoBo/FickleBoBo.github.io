## 1. 아이디어

두 이진수 문자열을 더해 그 합의 이진 표기를 구하는 문제다. 길이가 10 이하라 값이 작으므로 자리별로 올림을 계산하지 않고, 두 문자열을 정수로 읽어 더한 뒤 합을 다시 이진 문자열로 바꾸면 된다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public String solution(String bin1, String bin2) {
        int x1 = Integer.parseInt(bin1, 2);
        int x2 = Integer.parseInt(bin2, 2);
        return Integer.toBinaryString(x1 + x2);
    }
}
```

`Integer.parseInt`의 두 번째 인자로 진법 2를 줘서 이진 문자열을 정수로 읽었다. `Integer.toBinaryString`은 접두어 없이 이진 문자열을 만들고 합이 0이면 `"0"`을 반환하므로 따로 처리하지 않았다.

```c++
#include <bits/stdc++.h>
using namespace std;

string solution(string bin1, string bin2) {
    int sum = stoi(bin1, 0, 2) + stoi(bin2, 0, 2);
    if (sum == 0) return "0";

    string ans;
    while (sum > 0) {
        ans += '0' + sum % 2;
        sum /= 2;
    }
    reverse(ans.begin(), ans.end());

    return ans;
}
```

합이 0이면 반복이 돌지 않아 빈 문자열이 되므로 `"0"`을 먼저 반환했다. `'0' + sum % 2`는 `int`지만 `std::string`에 `+=`로 붙이면 `char`로 변환돼 문자로 덧붙는다.

```python
def solution(bin1, bin2):
    return f"{int(bin1, 2) + int(bin2, 2):b}"
```

`bin`은 결과에 `0b` 접두어가 붙으므로 f-string의 `b` 형식 지정자로 이진 문자열을 만들었다.
