## 1. 아이디어

응급도가 높은 환자부터 진료할 때, 각 환자가 몇 번째로 진료받는지를 환자 순서 그대로 담아 반환하는 문제다. 응급도에 중복이 없어 진료 순서가 유일하게 정해지고, 환자의 인덱스를 응급도 내림차순으로 정렬하면 정렬된 결과의 $i$번째(1부터 센다)에 오는 환자가 $i$번째로 진료받는다. 따라서 그 환자의 자리에 $i$를 적으면 된다.

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.util.*;

class Solution {
    public int[] solution(int[] emergency) {
        int n = emergency.length;

        Integer[] idx = new Integer[n];
        for (int i = 0; i < n; i++) {
            idx[i] = i;
        }
        Arrays.sort(idx, (o1, o2) -> Integer.compare(emergency[o2], emergency[o1]));

        int[] ans = new int[n];
        for (int i = 0; i < n; i++) {
            ans[idx[i]] = i + 1;
        }

        return ans;
    }
}
```

`Arrays.sort`에 `Comparator`를 넘기려고 기본형이 아닌 `Integer[]`에 인덱스를 담았다.

```c++
#include <bits/stdc++.h>
using namespace std;

vector<int> solution(vector<int> emergency) {
    int n = emergency.size();

    vector<int> idx(n);
    iota(idx.begin(), idx.end(), 0);
    sort(idx.begin(), idx.end(), [&](auto& a, auto& b) {
        return emergency[a] > emergency[b];
    });

    vector<int> ans(n);
    for (int i = 0; i < n; i++) {
        ans[idx[i]] = i + 1;
    }

    return ans;
}
```

`std::iota`로 `idx`를 0부터 차례로 채웠다.

```python
def solution(emergency):
    n = len(emergency)
    idx = sorted(range(n), key=lambda i: emergency[i], reverse=True)

    ans = [0] * n
    for rank, i in enumerate(idx, start=1):
        ans[i] = rank

    return ans
```
