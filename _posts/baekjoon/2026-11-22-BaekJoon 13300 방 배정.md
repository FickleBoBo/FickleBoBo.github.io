## 1. 아이디어

같은 학년의 같은 성별인 학생끼리만 같은 방을 쓸 수 있으므로 학년과 성별마다 학생 수를 센다. 한 그룹의 학생이 $c$명이고 한 방에 최대 $K$명이면 그 그룹에는 $\lceil c / K \rceil$개의 방이 필요하고, 그룹끼리는 방을 섞을 수 없으므로 그룹마다 올림한 값을 모두 더한 것이 답이다. 올림은 정수 나눗셈으로 $(c + K - 1) / K$와 같고 학생이 없는 그룹($c = 0$)은 0이 나와 따로 거를 필요가 없다.

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());

        int n = Integer.parseInt(st.nextToken());
        int k = Integer.parseInt(st.nextToken());

        int[][] cnt = new int[1 + 6][2];
        while (n-- > 0) {
            st = new StringTokenizer(br.readLine());
            int s = Integer.parseInt(st.nextToken());
            int y = Integer.parseInt(st.nextToken());
            cnt[y][s]++;
        }

        int ans = 0;
        for (int i = 1; i <= 6; i++) {
            for (int j = 0; j <= 1; j++) {
                ans += (cnt[i][j] + k - 1) / k;
            }
        }

        System.out.println(ans);
    }
}
```
