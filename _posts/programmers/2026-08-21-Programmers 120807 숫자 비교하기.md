## 1. 아이디어

두 수가 같으면 1, 다르면 -1을 반환하는 단순한 조건 분기다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int solution(int num1, int num2) {
        return num1 == num2 ? 1 : -1;
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int solution(int num1, int num2) {
    return num1 == num2 ? 1 : -1;
}
```

```python
def solution(num1, num2):
    return 1 if num1 == num2 else -1
```
