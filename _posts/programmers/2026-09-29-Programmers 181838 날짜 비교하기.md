## 1. 아이디어

`date1`이 `date2`보다 앞서는 날짜인지 판정하는 문제다. 날짜는 큰 단위부터 비교하므로 연도가 다르면 연도가, 같으면 월이, 월도 같으면 일이 결과를 정한다. 배열이 연, 월, 일 순이라 이는 앞 원소부터 차례로 비교하는 사전순 비교와 같다. 세 값이 모두 같으면 앞서는 날짜가 아니므로 0을 반환한다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int solution(int[] date1, int[] date2) {
        if (date1[0] < date2[0]) return 1;
        if (date1[0] == date2[0] && date1[1] < date2[1]) return 1;
        if (date1[0] == date2[0] && date1[1] == date2[1] && date1[2] < date2[2]) return 1;
        return 0;
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int solution(vector<int> date1, vector<int> date2) {
    return date1 < date2;
}
```

`std::vector`의 `<`는 첫 원소부터 비교하는 사전순 비교라 `date1 < date2`를 그대로 썼다. `bool`은 `int`로 바뀌어 1 또는 0이 반환된다.

```python
def solution(date1, date2):
    return int(date1 < date2)
```

리스트의 `<`도 첫 원소부터 비교하는 사전순 비교라 `date1 < date2`를 그대로 쓰고, `int`로 바꿔 1 또는 0을 반환했다.
