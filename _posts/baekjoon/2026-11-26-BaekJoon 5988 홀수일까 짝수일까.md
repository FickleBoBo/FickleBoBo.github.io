## 1. 아이디어

주어진 정수 $N$개가 각각 홀수인지 짝수인지 판정하는 문제로, 각 정수 $K$가 $10^{60}$까지라 64비트 정수에 담을 수 없지만 10이 짝수이므로 홀짝은 일의 자리 숫자만으로 정해진다. 따라서 $K$를 문자열로 받아 마지막 문자만 확인한다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        BufferedWriter bw = new BufferedWriter(new OutputStreamWriter(System.out));

        int n = Integer.parseInt(br.readLine());
        while (n-- > 0) {
            String k = br.readLine();

            if ((k.charAt(k.length() - 1) - '0') % 2 == 0) {
                bw.write("even\n");
            } else {
                bw.write("odd\n");
            }
        }

        bw.flush();
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    int n;
    cin >> n;

    while (n--) {
        string k;
        cin >> k;

        if ((k.back() - '0') % 2 == 0) {
            cout << "even\n";
        } else {
            cout << "odd\n";
        }
    }
}
```

```python
import sys

input = sys.stdin.readline

n = int(input())
for _ in range(n):
    k = input().rstrip()

    if int(k[-1]) % 2 == 0:
        print("even")
    else:
        print("odd")
```
