## 1. 아이디어

문자열의 맨 앞에 연속한 `0`만 떼는 문제다. 처음으로 `0`이 아닌 글자의 위치를 찾아 그 글자부터 끝까지 남기면 되고, 그 글자 뒤에 나오는 `0`은 앞쪽의 연속이 아니므로 `"854020"`의 `0`처럼 그대로 둔다. 전부 `0`인 입력은 없어서 `0`이 아닌 글자가 반드시 있다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public String solution(String n_str) {
        for (int i = 0; i < n_str.length(); i++) {
            if (n_str.charAt(i) != '0') return n_str.substring(i);
        }

        return null;
    }
}
```

반복문을 빠져나오는 경로에도 반환이 필요해 `return null`을 뒀지만, 전부 `0`인 입력이 없어 도달하지 않는다.

```c++
#include <bits/stdc++.h>
using namespace std;

string solution(string n_str) {
    return n_str.substr(n_str.find_first_not_of('0'));
}
```

전부 `0`인 문자열이면 `find_first_not_of('0')`가 `std::string::npos`를 돌려줘 `substr`가 예외를 던지지만 그런 입력은 없다.

```python
def solution(n_str):
    return n_str.lstrip("0")
```
