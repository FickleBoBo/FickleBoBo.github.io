## 1. 아이디어

현재 값 $x$가 짝수면 2로 나누고 홀수면 $3x + 1$로 바꾸는 과정을 따라가며 거친 값을 기록하는 시뮬레이션이다. 시작값 $n$이 1000 이하이면 1에 도달하는 것이 알려져 있어 반복은 반드시 끝난다. 1도 수열에 들어가므로 1이 되기 전까지만 돌리고 1은 마지막에 붙인다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.util.*;

class Solution {
    public int[] solution(int n) {
        List<Integer> list = new ArrayList<>();
        while (n > 1) {
            list.add(n);
            if (n % 2 != 0) {
                n = 3 * n + 1;
            } else {
                n /= 2;
            }
        }
        list.add(1);

        return list.stream().mapToInt(Integer::intValue).toArray();
    }
}
```

