## 1. 아이디어

바구니의 연속한 구간에 같은 번호의 공을 넣는 일을 $M$번 반복한 뒤 각 바구니의 공을 구하는 문제다. 나중에 넣은 공이 앞의 공을 대신하므로 주어진 순서대로 구간을 덮어쓰면 되고, 빈 바구니를 `0`으로 두면 한 번도 덮이지 않은 바구니는 그대로 `0`으로 남는다. $N$과 $M$이 모두 100 이하라 구간을 한 칸씩 채워도 충분하다.

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringBuilder sb = new StringBuilder();
        StringTokenizer st = new StringTokenizer(br.readLine());

        int n = Integer.parseInt(st.nextToken());
        int m = Integer.parseInt(st.nextToken());

        int[] arr = new int[n];
        while (m-- > 0) {
            st = new StringTokenizer(br.readLine());
            int s = Integer.parseInt(st.nextToken());
            int e = Integer.parseInt(st.nextToken());
            int x = Integer.parseInt(st.nextToken());
            Arrays.fill(arr, s - 1, e, x);
        }

        for (int x : arr) {
            sb.append(x).append(" ");
        }

        System.out.println(sb);
    }
}
```

`Arrays.fill`의 끝 인덱스는 포함되지 않으므로 `e - 1`이 아니라 `e`를 넘겼다.

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    int n, m;
    cin >> n >> m;

    vector<int> v(n);
    while (m--) {
        int s, e, x;
        cin >> s >> e >> x;
        fill(v.begin() + s - 1, v.begin() + e, x);
    }

    for (int x : v) {
        cout << x << ' ';
    }
}
```

`std::fill`의 구간은 끝이 열려 있어 `e`번째까지 채우도록 `v.begin() + e`를 넘겼다.

```python
import sys

input = sys.stdin.readline

n, m = map(int, input().split())

arr = [0] * n
for _ in range(m):
    s, e, x = map(int, input().split())
    arr[s - 1 : e] = [x] * (e - s + 1)

print(*arr)
```

슬라이스에 대입하는 리스트의 길이를 `e - s + 1`로 맞췄다. 길이가 다르면 오류 없이 `arr`의 크기가 바뀐다.
