## 1. 아이디어

정수 배열 `numbers`가 주어질 때, 원소들의 평균값을 반환하면 되는 문제다. 원소들의 합을 배열의 길이로 나누면 되는데, 정수 나눗셈이면 소수점 이하가 버려지므로 합을 실수로 누적한 뒤 나눠주면 된다.

---

## 2. 복잡도

| 접근 | 시간   | 공간   |
| ---- | ------ | ------ |
| 풀이 | $O(N)$ | $O(1)$ |

($N$ = `numbers`의 길이)

---

## 3. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public double solution(int[] numbers) {
        double sum = 0;
        for (int x : numbers) {
            sum += x;
        }

        return sum / numbers.length;
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

double solution(vector<int> numbers) {
    double sum = 0;
    for (int x : numbers) sum += x;
    return sum / numbers.size();
}
```

```python
def solution(numbers):
    return sum(numbers) / len(numbers)
```
