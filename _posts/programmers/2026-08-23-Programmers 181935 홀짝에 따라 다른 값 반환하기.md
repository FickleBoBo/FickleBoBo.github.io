## 1. 아이디어

양의 정수 `n`이 홀수면 1부터 `n`까지의 홀수를 모두 더한 값을, 짝수면 2부터 `n`까지의 짝수를 각각 제곱해 더한 값을 반환하면 되는 문제다. 홀짝에 따라 순회 시작값과 누적하는 값(그 자체 또는 제곱)만 다를 뿐 구조는 동일해서, 두 경우 모두 2씩 증가하는 반복문으로 값을 누적했다.

---

## 2. 복잡도

| 접근 | 시간   | 공간   |
| ---- | ------ | ------ |
| 풀이 | $O(N)$ | $O(1)$ |

($N$ = 입력값 `n`)

---

## 3. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int solution(int n) {
        if (n % 2 == 1) {
            int sum = 0;
            for (int i = 1; i <= n; i += 2) {
                sum += i;
            }
            return sum;
        } else {
            int sum = 0;
            for (int i = 2; i <= n; i += 2) {
                sum += i * i;
            }
            return sum;
        }
    }
}
```


```python
def solution(n):
    if n % 2:
        return sum(range(1, n + 1, 2))
    else:
        return sum(i * i for i in range(2, n + 1, 2))
```
