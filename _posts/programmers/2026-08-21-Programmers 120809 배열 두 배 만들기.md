## 1. 아이디어

정수 배열 `numbers`가 주어질 때, 각 원소를 두 배로 만든 배열을 반환하면 되는 간단한 문제다.

---

## 2. 복잡도

| 접근 | 시간   | 공간   |
| ---- | ------ | ------ |
| 풀이 | $O(N)$ | $O(1)$ |

($N$ = `numbers`의 길이. Python은 새 리스트를 만들어 반환하므로 공간 $O(N)$)

---

## 3. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int[] solution(int[] numbers) {
        for (int i = 0; i < numbers.length; i++) {
            numbers[i] *= 2;
        }

        return numbers;
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

vector<int> solution(vector<int> numbers) {
    for (int& x : numbers) x *= 2;
    return numbers;
}
```

원소를 참조(`int&`)로 받아 원본 벡터를 수정 후 반환했다.

```python
def solution(numbers):
    return [x * 2 for x in numbers]
```

리스트 컴프리헨션으로 새 리스트를 만들어서 반환했다.
