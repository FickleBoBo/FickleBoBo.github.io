## 1. 아이디어

맞닿은 두 링은 접점에서 같은 길이만큼 움직이므로, 반지름이 $a$인 링이 한 바퀴 돌 때 맞닿은 반지름 $b$인 링은 $a / b$바퀴 돈다. 첫 링부터 이 비율을 이어 곱하면 중간 링의 반지름이 분자와 분모에서 상쇄된다. 첫 링의 반지름을 $R_1$, $i$번째 링의 반지름을 $R_i$라 하면 $i$번째 링은 $R_1 / R_i$바퀴 돈다. 출력은 기약분수여야 하므로 $R_1$과 $R_i$를 최대공약수로 나눈다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringBuilder sb = new StringBuilder();

        int n = Integer.parseInt(br.readLine());
        StringTokenizer st = new StringTokenizer(br.readLine());

        int first = Integer.parseInt(st.nextToken());
        for (int i = 0; i < n - 1; i++) {
            int r = Integer.parseInt(st.nextToken());
            int g = gcd(first, r);
            sb.append(first / g).append("/").append(r / g).append("\n");
        }

        System.out.println(sb);
    }

    static int gcd(int a, int b) {
        if (b == 0) return a;
        return gcd(b, a % b);
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    int n;
    cin >> n;

    int first;
    cin >> first;

    for (int i = 0; i < n - 1; i++) {
        int r;
        cin >> r;
        int g = gcd(first, r);
        cout << first / g << '/' << r / g << '\n';
    }
}
```

`std::gcd`는 C++17부터 쓸 수 있다.

```python
import math
import sys

input = sys.stdin.readline

input()
arr = list(map(int, input().split()))

first = arr[0]
for r in arr[1:]:
    g = math.gcd(first, r)
    print(f"{first // g}/{r // g}")
```
