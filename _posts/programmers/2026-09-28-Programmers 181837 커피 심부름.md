## 1. 아이디어

주문마다 라테면 5000, 아니면 4500을 더해 총합을 구하는 문제다. 온도는 가격에 영향이 없고 `"anything"`은 아메리카노로 치므로 가격을 가르는 건 라테인지뿐이다. 라테인 원소는 모두 `"cafelatte"`를 포함하고 아메리카노 계열과 `"anything"`은 포함하지 않으므로, 이 문자열의 포함 여부로 구분한다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int solution(String[] order) {
        int sum = 0;
        for (String s : order) {
            sum += s.contains("cafelatte") ? 5000 : 4500;
        }

        return sum;
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int solution(vector<string> order) {
    int sum = 0;
    for (string& s : order) {
        sum += s.find("cafelatte") != -1 ? 5000 : 4500;
    }

    return sum;
}
```

```python
def solution(order):
    return sum(5000 if "cafelatte" in s else 4500 for s in order)
```
