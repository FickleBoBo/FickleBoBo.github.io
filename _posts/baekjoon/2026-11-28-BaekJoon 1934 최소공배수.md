## 1. 아이디어

두 자연수 $A$, $B$의 최소공배수를 테스트 케이스마다 구하는 문제다. 소인수마다 최대공약수는 두 수의 지수 중 작은 쪽을, 최소공배수는 큰 쪽을 가지므로 최대공약수와 최소공배수를 곱하면 $A \times B$가 된다. 따라서 유클리드 호제법으로 최대공약수를 구해 $A \times B$를 나누면 공배수를 하나씩 확인하지 않고 답을 얻는다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringBuilder sb = new StringBuilder();

        int t = Integer.parseInt(br.readLine());
        while (t-- > 0) {
            StringTokenizer st = new StringTokenizer(br.readLine());
            int a = Integer.parseInt(st.nextToken());
            int b = Integer.parseInt(st.nextToken());
            sb.append(lcm(a, b)).append("\n");
        }

        System.out.println(sb);
    }

    static int gcd(int a, int b) {
        if (b == 0) return a;
        return gcd(b, a % b);
    }

    static int lcm(int a, int b) {
        return a / gcd(a, b) * b;
    }
}
```

`lcm`은 `a`를 최대공약수로 먼저 나눈 뒤 `b`를 곱해 중간값이 커지지 않게 했다.

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    int t;
    cin >> t;

    while (t--) {
        int a, b;
        cin >> a >> b;
        cout << lcm(a, b) << '\n';
    }
}
```

`std::lcm`으로 최소공배수를 바로 구했다. 이 함수는 C++17부터 쓸 수 있다.

```python
import math
import sys

input = sys.stdin.readline

t = int(input())
for _ in range(t):
    a, b = map(int, input().split())
    print(math.lcm(a, b))
```

`math.lcm`으로 최소공배수를 바로 구했다. 이 함수는 Python 3.9부터 쓸 수 있다.
