## 1. 아이디어

심어진 가로수를 그대로 두고 사이에 나무를 더 심어 모든 간격을 같게 할 때, 새로 심는 나무의 최소 수를 구하는 문제다. 최종 간격을 $d$라 하면 나무는 맨 앞 나무에서 $d$의 배수만큼 떨어진 자리에 서게 되고, 기존 나무도 모두 그런 자리에 있어야 하므로 $d$는 이웃한 나무 사이의 거리를 전부 나누어야 한다. 반대로 $d$가 이 거리들의 공약수이기만 하면 기존 나무는 모두 그런 자리에 놓인다. 나무를 적게 심으려면 간격이 클수록 좋으니 $d$는 이 거리들의 최대공약수다. 위치가 기준점에서 가까운 순서대로 주어지므로 각 거리는 연이은 두 입력의 차이고, 최대공약수는 유클리드 호제법으로 거리를 하나씩 반영해 구한다.

맨 앞 나무부터 맨 뒤 나무까지 간격 $d$로 채우면 양 끝을 포함한 나무는 두 위치의 차를 $d$로 나눈 값보다 하나 많으므로, 여기서 이미 심어진 $N$그루를 빼면 답이다.

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        int n = Integer.parseInt(br.readLine());

        int[] arr = new int[n];
        for (int i = 0; i < n; i++) {
            arr[i] = Integer.parseInt(br.readLine());
        }

        int g = arr[1] - arr[0];
        for (int i = 2; i < n; i++) {
            g = gcd(g, arr[i] - arr[i - 1]);
        }

        System.out.println((arr[n - 1] - arr[0]) / g + 1 - n);
    }

    static int gcd(int a, int b) {
        if (b == 0) return a;
        return gcd(b, a % b);
    }
}
```

```python
import math
import sys

input = sys.stdin.readline

n = int(input())
arr = [int(input()) for _ in range(n)]

g = arr[1] - arr[0]
for i in range(2, n):
    g = math.gcd(g, arr[i] - arr[i - 1])

print((arr[n - 1] - arr[0]) // g + 1 - n)
```
