## 1. 아이디어

수빈이가 한 번에 $D$씩만 걸을 때 모든 동생의 위치에 갈 수 있는 가장 큰 $D$를 구하는 문제다. $S$에서 출발해 앞뒤로 $D$씩 움직이면 $S$와의 거리가 $D$의 배수인 위치에는 모두 갈 수 있고 그 밖의 위치에는 갈 수 없으므로, $D$는 모든 동생과 $S$ 사이 거리의 약수이기만 하면 된다. 따라서 답은 이 거리들의 최대공약수이고, 유클리드 호제법으로 하나씩 합쳐 가며 구한다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

0과 어떤 수의 최대공약수는 그 수 자신이라 `g`를 0에서 시작했다.

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());

        int n = Integer.parseInt(st.nextToken());
        int s = Integer.parseInt(st.nextToken());

        int[] arr = new int[n];
        st = new StringTokenizer(br.readLine());
        for (int i = 0; i < n; i++) {
            arr[i] = Integer.parseInt(st.nextToken());
        }

        int g = 0;
        for (int x : arr) {
            g = gcd(g, Math.abs(s - x));
        }

        System.out.println(g);
    }

    static int gcd(int a, int b) {
        if (b == 0) return a;
        return gcd(b, a % b);
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    int n, s;
    cin >> n >> s;

    vector<int> v(n);
    for (int& x : v) cin >> x;

    int g = 0;
    for (int x : v) {
        g = gcd(g, abs(s - x));
    }

    cout << g;
}
```

`std::gcd`는 C++17부터 쓸 수 있다.

```python
import math
import sys

input = sys.stdin.readline

n, s = map(int, input().split())
arr = list(map(int, input().split()))

g = 0
for x in arr:
    g = math.gcd(g, abs(s - x))

print(g)
```
