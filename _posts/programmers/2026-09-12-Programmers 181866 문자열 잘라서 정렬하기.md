## 1. 아이디어

`"x"`로 자른 조각에서 빈 조각을 빼고 사전순으로 정렬하는 문제다. 문자열의 기본 비교가 사전순이므로 조각을 뽑아 그대로 정렬하면 되고, 빈 조각은 `"x"`가 연달아 있거나 맨 앞·맨 끝에 있을 때만 생기니 `"x"`가 아닌 글자가 이어진 구간만 뽑으면 애초에 만들어지지 않는다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.util.*;

class Solution {
    public String[] solution(String myString) {
        StringTokenizer st = new StringTokenizer(myString, "x");

        String[] arr = new String[st.countTokens()];
        for (int i = 0; i < arr.length; i++) {
            arr[i] = st.nextToken();
        }
        Arrays.sort(arr);

        return arr;
    }
}
```

`StringTokenizer`는 빈 토큰을 만들지 않아 따로 거르지 않았다.

```c++
#include <bits/stdc++.h>
using namespace std;

vector<string> solution(string myString) {
    vector<string> ans;
    stringstream ss(myString);
    string token;

    while (getline(ss, token, 'x')) {
        if (!token.empty()) ans.push_back(token);
    }
    sort(ans.begin(), ans.end());

    return ans;
}
```

`std::getline`에 구분자 `'x'`를 넘겨 조각을 읽었다. `'x'`가 연달아 있으면 빈 조각이 읽히므로 비어 있지 않은 것만 담았다.

```python
def solution(myString):
    return sorted([s for s in myString.split("x") if s])
```
