## 1. 아이디어

원소의 값을 $v$라 하면, 대응하는 불리언 값이 `true`일 때는 $v$를 $2v$번 뒤에 붙이고 `false`일 때는 뒤에서 $v$개를 지우는 과정을 순서대로 따라가는 문제다. 넣고 빼는 곳이 항상 맨 뒤라 배열 끝만 다루는 시뮬레이션이면 충분하고, 원소가 최대 100개이고 값이 최대 9라 한 번에 붙이는 개수도 최대 18개이므로 하나씩 직접 붙이고 지워도 된다.

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.util.*;

class Solution {
    public int[] solution(int[] arr, boolean[] flag) {
        List<Integer> list = new ArrayList<>();
        for (int i = 0; i < flag.length; i++) {
            if (flag[i]) {
                for (int j = 0; j < arr[i] * 2; j++) {
                    list.add(arr[i]);
                }
            } else {
                for (int j = 0; j < arr[i]; j++) {
                    list.removeLast();
                }
            }
        }

        return list.stream().mapToInt(Integer::intValue).toArray();
    }
}
```

Java 21에서 `List`에 추가된 `removeLast`로 뒤에서부터 지웠다.

```c++
#include <bits/stdc++.h>
using namespace std;

vector<int> solution(vector<int> arr, vector<bool> flag) {
    vector<int> v;

    for (int i = 0; i < flag.size(); i++) {
        if (flag[i]) {
            for (int j = 0; j < arr[i] * 2; j++) {
                v.push_back(arr[i]);
            }
        } else {
            for (int j = 0; j < arr[i]; j++) {
                v.pop_back();
            }
        }
    }

    return v;
}
```

```python
def solution(arr, flag):
    res = []

    for a, f in zip(arr, flag):
        if f:
            res += [a] * (a * 2)
        else:
            del res[-a:]

    return res
```

뒤에서 `a`개를 `del res[-a:]`로 지웠다. `a`가 0이면 `-0`이 0이라 전체가 지워지지만 원소가 1 이상이라 문제없다.
