## 1. 아이디어

별의 시작 위치를 가리키는 포인터를 활용해서 구현했다.

---

## 2. 복잡도

| 접근 | 시간     | 공간   |
| ---- | -------- | ------ |
| 풀이 | $O(N^2)$ | $O(1)$ |

($N$ = 입력값 `n`. Java는 전체 출력을 `StringBuilder`에 모았다가 출력하므로 공간 $O(N^2)$)

---

## 3. 코드

### 풀이 [Java][C++]

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringBuilder sb = new StringBuilder();

        int n = Integer.parseInt(br.readLine());

        int pivot = n;
        for (int i = 1; i <= 2 * n - 1; i++) {
            sb.repeat(" ", pivot - 1);
            sb.repeat("*", n - pivot + 1);
            sb.append("\n");

            if (i < n) {
                pivot--;
            } else {
                pivot++;
            }
        }

        System.out.println(sb);
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    int n;
    cin >> n;

    int pivot = n;
    for (int i = 1; i <= 2 * n - 1; i++) {
        for (int j = 1; j < pivot; j++) {
            cout << ' ';
        }
        for (int j = pivot; j <= n; j++) {
            cout << '*';
        }
        cout << '\n';

        if (i < n) {
            pivot--;
        } else {
            pivot++;
        }
    }
}
```
