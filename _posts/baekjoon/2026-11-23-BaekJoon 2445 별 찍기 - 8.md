## 1. 아이디어

양쪽 끝에 붙은 별 사이를 공백으로 비운 $2N - 1$줄의 모양이다. 줄마다 양쪽 별이 하나씩 늘어 $N$번째 줄에서 양쪽 별 $N$개씩이 줄 전체를 채우고, 그 뒤로는 다시 하나씩 줄어든다. 오른쪽 별이 항상 줄의 오른쪽 끝에 붙고 가장 넓은 $N$번째 줄이 별만으로 $2N$칸이므로, 별과 공백을 합친 모든 줄의 길이가 $2N$이다. 양쪽 별이 같은 수만큼 늘고 줄어 왼쪽 별이 $k$개이면 오른쪽 별도 $k$개이며, 그 사이가 공백 $2N - 2k$개다.

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringBuilder sb = new StringBuilder();

        int n = Integer.parseInt(br.readLine());

        int l = 1, r = 2 * n;
        for (int i = 1; i <= 2 * n - 1; i++) {
            for (int j = 1; j <= l; j++) {
                sb.append("*");
            }
            for (int j = l + 1; j < r; j++) {
                sb.append(" ");
            }
            for (int j = r; j <= 2 * n; j++) {
                sb.append("*");
            }
            sb.append("\n");

            if (i < n) {
                l++;
                r--;
            } else {
                l--;
                r++;
            }
        }

        System.out.println(sb);
    }
}
```

    print("*" * l + " " * (r - l - 1) + "*" * (2 * n - r + 1))
    if i < n:
        l += 1
        r -= 1
    else:
        l -= 1
        r += 1
