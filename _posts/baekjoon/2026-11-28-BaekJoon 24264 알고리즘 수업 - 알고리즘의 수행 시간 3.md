## 1. 아이디어

[[BaekJoon] #24263 - 알고리즘 수업 - 알고리즘의 수행 시간 2](/posts/baekjoon-24263/)의 반복문이 이중 반복문으로 늘어난 알고리즘에서 코드1의 수행 횟수와 그 차수를 구하는 문제다. $n$번 도는 바깥 반복의 한 번마다 안쪽 반복이 다시 $n$번 돌아 코드1은 $n^2$번 실행되므로 차수는 2이다. $n$이 최대 500,000이라 $n^2$은 $2.5 \times 10^{11}$까지 커져 32비트 정수 범위를 넘으므로 64비트 정수로 계산한다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        long n = Long.parseLong(br.readLine());
        System.out.println(n * n);
        System.out.println(2);
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    long long n;
    cin >> n;
    cout << n * n << '\n';
    cout << 2;
}
```

```python
import sys

input = sys.stdin.readline

n = int(input())
print(n * n)

```
