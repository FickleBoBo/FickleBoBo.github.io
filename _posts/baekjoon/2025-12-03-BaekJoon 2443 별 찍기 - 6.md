## 1. 아이디어

2중 반복문을 활용해서 출력 양식에 맞춰 출력만 하면 된다.

---

## 2. 복잡도

| 접근 | 시간     | 공간   |
| ---- | -------- | ------ |
| 풀이 | $O(N^2)$ | $O(1)$ |

($N$ = 입력값 `n`)

---

## 3. 코드

### 풀이 [Java][C++]

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringBuilder sb = new StringBuilder();

        int n = Integer.parseInt(br.readLine());

        for (int i = 1; i <= n; i++) {
            sb.repeat(" ", i - 1);
            sb.repeat("*", 2 * (n - i) + 1);
            sb.append("\n");
        }

        System.out.println(sb);
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    int n;
    cin >> n;

    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= i - 1; j++) {
            cout << ' ';
        }
        for (int j = 1; j <= 2 * (n - i) + 1; j++) {
            cout << '*';
        }
        cout << '\n';
    }
}
```
