## 1. 아이디어

$n$ 이하인 $k$의 배수를 오름차순으로 모으는 문제다. $k$의 배수는 $k$, $2k$, $3k$, ...이고 $n$ 이하인 것은 $\lfloor n / k \rfloor$개이므로, $k$부터 $k$씩 건너뛰며 $n$을 넘기 전까지 모으면 된다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int[] solution(int n, int k) {
        int[] arr = new int[n / k];
        int idx = 0;

        for (int i = k; i <= n; i += k) {
            arr[idx++] = i;
        }

        return arr;
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

vector<int> solution(int n, int k) {
    vector<int> v;
    for (int i = k; i <= n; i += k) {
        v.push_back(i);
    }

    return v;
}
```

```python
def solution(n, k):

```
