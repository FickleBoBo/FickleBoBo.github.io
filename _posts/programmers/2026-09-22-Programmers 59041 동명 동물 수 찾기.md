## 1. 아이디어

두 번 이상 쓰인 이름과 그 횟수를 이름 없는 동물은 제외하고 조회하는 문제다. `COUNT(NAME)`은 `NULL`을 세지 않으므로, 이름 없는 동물의 그룹은 개수가 자연히 0이 되어 `HAVING COUNT >= 2` 조건에서 저절로 걸러진다.

---

## 2. 쿼리

### 풀이 [MySQL]

```sql
SELECT NAME, COUNT(NAME) AS COUNT
FROM ANIMAL_INS
GROUP BY NAME
HAVING COUNT >= 2
ORDER BY NAME
```
