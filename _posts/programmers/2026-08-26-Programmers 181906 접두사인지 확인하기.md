## 1. 아이디어

접두사 여부는 `my_string`의 앞부분이 `is_prefix`와 그대로 일치하는지 확인하면 판단할 수 있다. 문자열이 특정 접두사로 시작하는지 판정하는 표준 함수로 바로 처리할 수 있다.

---

## 2. 복잡도

| 접근 | 시간   | 공간   |
| ---- | ------ | ------ |
| 풀이 | $O(N)$ | $O(1)$ |

($N$ = `is_prefix`의 길이)

---

## 3. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int solution(String my_string, String is_prefix) {
        return my_string.startsWith(is_prefix) ? 1 : 0;
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int solution(string my_string, string is_prefix) {
    return my_string.starts_with(is_prefix);
}
```

```python
def solution(my_string, is_prefix):
    return int(my_string.startswith(is_prefix))
```
