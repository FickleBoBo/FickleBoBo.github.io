## 1. 아이디어

`UOS`가 반복되는 문자열에서 $x$번째 문자를 구하는 문제다. 세 문자 단위로 같은 문자가 반복되므로 $x$를 3으로 나눈 나머지로 판단할 수 있다. 문자열에서 첫 번째 문자의 인덱스가 0이므로 $x - 1$번 인덱스의 문자를 구해야 하고, 이는 $x - 1$을 3으로 나눈 나머지와 같다.

---

## 2. 복잡도

| 접근 | 시간   | 공간   |
| ---- | ------ | ------ |
| 풀이 | $O(1)$ | $O(1)$ |

---

## 3. 코드

### 풀이 [Java][C++]

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        int x = Integer.parseInt(br.readLine());
        System.out.println("UOS".charAt((x - 1) % 3));
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    int x;
    cin >> x;
    cout << "UOS"[(x - 1) % 3];
}
```
