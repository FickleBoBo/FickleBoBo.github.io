## 1. 아이디어

정수 배열 `date1`과 `date2`가 주어졌을 때, `date1`이 `date2`보다 앞서는지 판단하는 문제로 연도가 앞서면, 연도가 같으면 월이 앞서면, 연도와 월이 같으면 일이 앞서면 앞서는 것임을 이용하면 된다.

---

## 2. 복잡도

| 접근 | 시간   | 공간   |
| ---- | ------ | ------ |
| 풀이 | $O(1)$ | $O(1)$ |

---

## 3. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int solution(int[] date1, int[] date2) {
        if (date1[0] < date2[0]) return 1;
        if (date1[0] == date2[0] && date1[1] < date2[1]) return 1;
        if (date1[0] == date2[0] && date1[1] == date2[1] && date1[2] < date2[2]) return 1;
        return 0;
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int solution(vector<int> date1, vector<int> date2) {
    return date1 < date2;
}
```

벡터의 정렬 기준을 활용하면 바로 구할 수 있다.

```python
def solution(date1, date2):
    return int(date1 < date2)
```
