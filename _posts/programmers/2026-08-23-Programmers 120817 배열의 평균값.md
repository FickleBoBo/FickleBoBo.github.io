## 1. 아이디어

원소의 합을 개수로 나누는 평균이다. 정답에 .5가 나올 수 있어 정수 나눗셈을 하면 소수 부분이 잘려 나가므로 실수 나눗셈을 해야 한다. 정답의 소수 부분이 .0 또는 .5로 보장되고 이 값들은 부동소수점으로 정확히 표현되므로 오차가 생기지 않는다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public double solution(int[] numbers) {
        double sum = 0;
        for (int x : numbers) {
            sum += x;
        }

        return sum / numbers.length;
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

double solution(vector<int> numbers) {
    double sum = 0;
    for (int x : numbers) sum += x;
    return sum / numbers.size();
}
```

```python
def solution(numbers):
    return sum(numbers) / len(numbers)
```
