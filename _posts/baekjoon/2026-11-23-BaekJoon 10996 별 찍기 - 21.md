## 1. 아이디어

별과 공백이 한 칸씩 번갈아 나오는 체커보드 모양을 $2N$줄 찍고, 한 줄은 $N$칸이다. 줄 번호와 칸 번호를 1부터 센다고 할 때 그 합이 짝수인 칸에 별을 찍으면, 홀수 번째 줄은 첫 칸이 별이고 짝수 번째 줄은 둘째 칸이 별이다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringBuilder sb = new StringBuilder();

        int n = Integer.parseInt(br.readLine());

        for (int i = 1; i <= 2 * n; i++) {
            for (int j = 1; j <= n; j++) {
                if ((i + j) % 2 == 0) {
                    sb.append("*");
                } else {
                    sb.append(" ");
                }
            }
            sb.append("\n");
        }

        System.out.println(sb);
    }
}
```
