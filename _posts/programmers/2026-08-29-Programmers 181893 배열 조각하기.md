## 1. 아이디어

`query`의 값이 가리키는 인덱스는 원래 주어진 `arr`가 아니라 그때까지 잘리고 남은 배열 기준이므로, 쿼리를 앞에서부터 차례로 적용해 배열을 직접 줄여 간다. 쿼리 값을 $q$라 하면 `query`의 짝수 인덱스에 있는 쿼리는 배열의 인덱스 $q$ 뒤를 버려 0부터 $q$까지를 남기고, 홀수 인덱스에 있는 쿼리는 인덱스 $q$ 앞을 버려 $q$부터 끝까지를 남긴다. 어느 쪽이든 인덱스 $q$의 원소는 남는다. 배열의 원소가 최대 $10^5$개이고 쿼리가 50개 미만이라 매번 복사해도 원소 복사가 많아야 $5 \times 10^6$번이다.

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.util.*;

class Solution {
    public int[] solution(int[] arr, int[] query) {
        for (int i = 0; i < query.length; i++) {
            if (i % 2 != 0) {
                arr = Arrays.copyOfRange(arr, query[i], arr.length);
            } else {
                arr = Arrays.copyOfRange(arr, 0, query[i] + 1);
            }
        }

        return arr;
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

vector<int> solution(vector<int> arr, vector<int> query) {
    for (int i = 0; i < query.size(); i++) {
        if (i % 2) {
            arr = vector<int>(arr.begin() + query[i], arr.end());
        } else {
            arr = vector<int>(arr.begin(), arr.begin() + query[i] + 1);
        }
    }

    return arr;
}
```

```python
def solution(arr, query):
    for i, q in enumerate(query):
        arr = arr[q:] if i % 2 else arr[: q + 1]

    return arr
```
