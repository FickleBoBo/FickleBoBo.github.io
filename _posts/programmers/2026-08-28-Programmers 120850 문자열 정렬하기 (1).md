## 1. 아이디어

문자열 `my_string`에 대해 `my_string`을 순회하며 숫자에 해당하는 글자만 골라 정수로 변환해 모은 뒤, 오름차순으로 정렬해 반환하면 된다.

---

## 2. 복잡도

| 접근 | 시간          | 공간   |
| ---- | ------------- | ------ |
| 풀이 | $O(N \log N)$ | $O(N)$ |

($N$ = `my_string`의 길이)

---

## 3. 코드

### 풀이 [Java][C++][Python]

```java
import java.util.*;

class Solution {
    public int[] solution(String my_string) {
        List<Integer> list = new ArrayList<>();
        for (char c : my_string.toCharArray()) {
            if (Character.isDigit(c)) list.add(c - '0');
        }

        return list.stream().mapToInt(Integer::intValue).sorted().toArray();
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

vector<int> solution(string my_string) {
    vector<int> v;
    for (char c : my_string) {
        if (isdigit(c)) v.push_back(c - '0');
    }
    sort(v.begin(), v.end());

    return v;
}
```

```python
def solution(my_string):
    return sorted(int(c) for c in my_string if c.isdigit())
```
