## 1. 아이디어

16진수를 10진수로 바꿔 출력하는 문제로 진법 변환 내장 함수를 활용하면 간단하게 해결할 수 있다.

---

## 2. 복잡도

| 접근 | 시간   | 공간   |
| ---- | ------ | ------ |
| 풀이 | $O(N)$ | $O(N)$ |

($N$ = `s`의 길이)

---

## 3. 코드

### 풀이 [Java][C++]

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        String s = br.readLine();
        System.out.println(Integer.parseInt(s, 16));
    }
}
```

`Integer.parseInt` 메서드로 진법 변환을 할 수 있다.

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    string s;
    cin >> s;
    cout << stoi(s, nullptr, 16);
}
```

`std::stoi` 함수로 진법 변환을 할 수 있다.
