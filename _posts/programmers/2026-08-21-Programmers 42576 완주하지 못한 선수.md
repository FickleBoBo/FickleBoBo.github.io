## 1. 아이디어

참가자 명단에는 있고 완주자 명단에는 없는 한 명을 찾는 문제다. 이름이 같은 참가자가 있을 수 있어서 이름이 완주자 명단에 있는지만 확인하면 틀린다. 미완주자와 같은 이름의 선수가 완주했다면 그 이름은 완주자 명단에 있는데도 미완주자가 남기 때문이다. 그래서 이름별로 참가한 횟수에서 완주한 횟수를 뺀 값을 본다. 완주자 명단은 참가자 명단에서 정확히 한 명이 빠진 것이므로 그 한 명의 이름만 1이고 나머지 이름은 모두 0이다. 따라서 1인 이름이 답이다.

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.util.*;

class Solution {
    public String solution(String[] participant, String[] completion) {
        Map<String, Integer> cnt = new HashMap<>();
        for (String p : participant) {
            cnt.put(p, cnt.getOrDefault(p, 0) + 1);
        }
        for (String c : completion) {
            cnt.put(c, cnt.getOrDefault(c, 0) - 1);
        }

        for (Map.Entry<String, Integer> e : cnt.entrySet()) {
            if (e.getValue() == 1) return e.getKey();
        }

        return null;
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

string solution(vector<string> participant, vector<string> completion) {
    unordered_map<string, int> cnt;
    for (string& p : participant) cnt[p]++;
    for (string& c : completion) cnt[c]--;

    for (auto& [k, v] : cnt) {
        if (v == 1) return k;
    }

    return "";
}
```

```python
from collections import Counter


def solution(participant, completion):
    diff = Counter(participant) - Counter(completion)
    return next(iter(diff))
```

`Counter`끼리의 뺄셈은 개수가 양수인 이름만 남기므로 미완주자 한 명만 남았고, `next(iter(diff))`로 그 키를 꺼냈다.
