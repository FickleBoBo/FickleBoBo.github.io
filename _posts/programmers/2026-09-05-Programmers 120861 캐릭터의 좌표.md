## 1. 아이디어

$(0, 0)$에서 출발해 방향키 입력을 차례로 따라가 최종 좌표를 구하는 시뮬레이션 문제다. 맵의 가로와 세로 크기가 홀수라 $(0, 0)$이 정중앙이고, 각 방향으로 갈 수 있는 최대 칸 수는 해당 크기를 2로 나눈 몫이다(크기가 9이면 양쪽으로 4칸씩). 맵을 벗어나는 입력은 무시하므로 가장자리에서 밖으로 나가려는 입력에는 캐릭터가 제자리에 남아야 한다. 매 입력마다 이동한 좌표가 양쪽 경계를 넘으면 그 경계 값으로 맞추면 제자리에 남게 된다.

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int[] solution(String[] keyinput, int[] board) {
        int x = 0, y = 0;
        int maxX = board[0] / 2, maxY = board[1] / 2;

        for (String s : keyinput) {
            if (s.equals("up")) {
                y = Math.min(y + 1, maxY);
            } else if (s.equals("down")) {
                y = Math.max(y - 1, -maxY);
            } else if (s.equals("left")) {
                x = Math.max(x - 1, -maxX);
            } else {
                x = Math.min(x + 1, maxX);
            }
        }

        return new int[]{x, y};
    }
}
```
