## 1. 아이디어

정수 `n`과 제어 문자열 `control`이 주어질 때, `control`을 앞에서부터 순회하며 문자에 따라 `n`을 조작하면 되는 문제다. `w`는 1 증가, `s`는 1 감소, `d`는 10 증가, `a`는 10 감소를 의미하므로, 각 문자를 확인하며 그에 대응하는 값을 더하거나 빼면 된다.

---

## 2. 복잡도

| 접근 | 시간   | 공간   |
| ---- | ------ | ------ |
| 풀이 | $O(N)$ | $O(1)$ |

($N$ = `control`의 길이)

---

## 3. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int solution(int n, String control) {
        for (char c : control.toCharArray()) {
            if (c == 'w') {
                n++;
            } else if (c == 's') {
                n--;
            } else if (c == 'd') {
                n += 10;
            } else {
                n -= 10;
            }
        }

        return n;
    }
}
```
