## 1. 아이디어

숫자 $n$개의 순서를 바꾸지 않고 각각 더하거나 빼서 타겟 넘버를 만드는 방법의 수를 세는 문제다. 숫자마다 부호는 서로 독립으로 고르므로 만들 수 있는 식은 $2^n$가지이고 $n \le 20$이라 $2^{20}$, 약 100만 가지를 전부 만들어 봐도 충분하다. 앞의 숫자부터 하나씩 처리하며 지금까지 만든 합마다 다음 숫자 $x$를 더하는 갈래와 빼는 갈래로 나누면 숫자 하나를 처리할 때마다 합이 한 단계씩 쌓이고, 마지막 단계까지 간 합 중 타겟과 같은 것의 개수가 답이다. 서로 다른 부호 조합이 같은 합을 만들어도 각각 별개의 방법이므로 합을 합치지 않고 따로 센다.

이 갈래들을 단계별로 쌓는 대신 재귀로 깊이 우선으로 한 경로씩 끝까지 내려가며 세어도 같은 결과이고, 이 경우 합을 층 단위로 보관하지 않고 지금 따라가는 경로만 기억하므로 필요한 깊이는 숫자의 개수만큼이다.

## 2. 코드

### 풀이 1: BFS [Java][C++][Python]

```java
import java.util.*;

class Solution {
    public int solution(int[] numbers, int target) {
        Queue<Integer> q = new ArrayDeque<>();
        q.offer(0);

        for (int x : numbers) {
            int sz = q.size();
            while (sz-- > 0) {
                int cur = q.poll();
                q.offer(cur + x);
                q.offer(cur - x);
            }
        }

        int cnt = 0;
        while (!q.isEmpty()) {
            if (q.poll() == target) cnt++;
        }

        return cnt;
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int solution(vector<int> numbers, int target) {
    queue<int> q;
    q.push(0);

    for (int x : numbers) {
        int sz = q.size();
        while (sz--) {
            int cur = q.front();
            q.pop();

            q.push(cur + x);
            q.push(cur - x);
        }
    }

    int cnt = 0;
    while (!q.empty()) {
        if (q.front() == target) cnt++;
        q.pop();
    }

    return cnt;
}
```

```python
from collections import deque


def solution(numbers, target):
    q = deque([0])

    for x in numbers:
        for _ in range(len(q)):
            cur = q.popleft()
            q.append(cur + x)
            q.append(cur - x)

    return q.count(target)
```

### 풀이 2: DFS [Java][C++][Python]

```java
class Solution {
    public int solution(int[] numbers, int target) {
        return dfs(0, 0, numbers, target);
    }

    static int dfs(int cur, int depth, int[] numbers, int target) {
        if (depth == numbers.length) return cur == target ? 1 : 0;

        return dfs(cur + numbers[depth], depth + 1, numbers, target) +
                dfs(cur - numbers[depth], depth + 1, numbers, target);
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int dfs(int cur, int depth, vector<int>& numbers, int target) {
    if (depth == numbers.size()) return cur == target;

    return dfs(cur + numbers[depth], depth + 1, numbers, target) +
           dfs(cur - numbers[depth], depth + 1, numbers, target);
}

int solution(vector<int> numbers, int target) {
    return dfs(0, 0, numbers, target);
}
```

`numbers`를 `std::vector<int>&`로 받아 재귀 호출마다 복사되지 않게 했다.

```python
import sys

sys.setrecursionlimit(10**6)


def solution(numbers, target):

    def dfs(cur, depth):
        if depth == len(numbers):
            return int(cur == target)
        return dfs(cur + numbers[depth], depth + 1) + dfs(cur - numbers[depth], depth + 1)

    return dfs(0, 0)
```
