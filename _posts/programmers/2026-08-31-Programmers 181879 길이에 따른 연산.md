## 1. 아이디어

리스트의 길이를 확인해 11 이상이면 전체 원소의 합을, 10 이하이면 전체 원소의 곱을 계산해 return한다. 원소를 모두 곱해도 32비트 정수 범위를 넘지 않음이 보장되므로 오버플로우는 따로 다루지 않는다.

---

## 2. 복잡도

| 접근 | 시간   | 공간   |
| ---- | ------ | ------ |
| 풀이 | $O(N)$ | $O(1)$ |

($N$ = `num_list`의 길이)

---

## 3. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int solution(int[] num_list) {
        if (num_list.length >= 11) {
            int sum = 0;
            for (int x : num_list) {
                sum += x;
            }
            return sum;
        } else {
            int mul = 1;
            for (int x : num_list) {
                mul *= x;
            }
            return mul;
        }
    }
}
```
