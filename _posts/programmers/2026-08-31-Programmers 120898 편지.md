## 1. 아이디어

공백을 포함한 모든 문자가 가로 2cm를 차지하므로, 편지지의 최소 가로 길이는 문자열 길이에 2를 곱한 값이다.

---

## 2. 복잡도

| 접근 | 시간   | 공간   |
| ---- | ------ | ------ |
| 풀이 | $O(1)$ | $O(1)$ |

---

## 3. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int solution(String message) {
        return message.length() * 2;
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int solution(string message) {
    return message.size() * 2;
}
```

```python
def solution(message):
    return len(message) * 2
```
