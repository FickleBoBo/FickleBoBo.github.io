## 1. 아이디어

원형 룰렛을 돌렸을 때 12시부터 읽은 모양이 고기를 먹는 모양과 같아질 확률을 구하는 문제다. 룰렛이 멈출 수 있는 상태는 현재 모양을 회전한 $N$가지이고 모두 확률이 같으므로, 고기 모양과 일치하는 회전의 개수를 $N$으로 나누면 된다.

회전마다 처음부터 비교하면 $O(N^2)$인데 $N$이 최대 1,000,000이라 이 방식으로는 통과하기 어렵다. 그런데 현재 모양을 두 번 이어 붙이면 모든 회전이 길이 $N$인 부분 문자열로 나타나므로, 그 안에서 고기 모양을 KMP로 찾으면 $O(N)$에 셀 수 있다. 이때 이어 붙인 문자열의 마지막 글자를 버려야 하는데, 남겨 두면 처음 상태가 맨 뒤에 한 번 더 나타나, 처음 상태가 고기 모양과 일치할 때 두 번 세어지기 때문이다. 일치하는 구간끼리 겹칠 수 있으므로 패턴이 끝까지 맞은 뒤에도 실패 함수를 따라 이어서 찾아야 한다. 마지막에 일치한 개수와 $N$을 최대공약수로 나누면 기약분수가 된다.

## 2. 코드

### 풀이 [C++]

```c++
#include <bits/stdc++.h>
using namespace std;

vector<int> failure(string& s) {
    vector<int> pi(s.size());
    int j = 0;
    for (int i = 1; i < s.size(); i++) {
        while (j > 0 && s[i] != s[j]) j = pi[j - 1];
        if (s[i] == s[j]) pi[i] = ++j;
    }
    return pi;
}

int kmp(string& s, string& p) {
    vector<int> pi = failure(p);
    int cnt = 0;
    int j = 0;
    for (int i = 0; i < s.size(); i++) {
        while (j > 0 && s[i] != p[j]) j = pi[j - 1];
        if (s[i] == p[j]) j++;
        if (j == p.size()) {
            cnt++;
            j = pi[j - 1];
        }
    }

    return cnt;
}

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    int n;
    cin >> n;

    string p;
    for (int i = 0; i < n; i++) {
        char c;
        cin >> c;
        p += c;
    }

    string s;
    for (int i = 0; i < n; i++) {
        char c;
        cin >> c;
        s += c;
    }
    s += s;
    s.pop_back();

    int cnt = kmp(s, p);
    int g = gcd(cnt, n);
    cout << cnt / g << '/' << n / g;
}
```

`std::gcd`는 C++17부터 쓸 수 있다.
