## 1. 아이디어

찾은 흰색 피스의 개수가 주어질 때 올바른 세트를 만들려면 종류별로 몇 개를 더하거나 빼야 하는지 구하는 문제로, 킹·퀸·룩·비숍·나이트·폰의 정해진 개수 1, 1, 2, 2, 2, 8에서 찾은 개수를 빼면 된다. 이렇게 빼면 모자랄 때는 양수, 남을 때는 음수가 되어 지문의 부호 규칙까지 그대로 맞는다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());

        int[] arr = {1, 1, 2, 2, 2, 8};
        for (int n : arr) {
            int x = Integer.parseInt(st.nextToken());
            System.out.print((n - x) + " ");
        }
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int arr[6] = {1, 1, 2, 2, 2, 8};

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    for (int n : arr) {
        int x;
        cin >> x;
        cout << n - x << ' ';
    }
}
```

```python
import sys

input = sys.stdin.readline

arr = [1, 1, 2, 2, 2, 8]
out = [n - x for n, x in zip(arr, map(int, input().split()))]
print(*out)
```
