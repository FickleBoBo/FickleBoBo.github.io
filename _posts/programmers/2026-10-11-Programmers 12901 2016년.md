## 1. 아이디어

2016년 1월 1일이 금요일일 때 $a$월 $b$일의 요일을 구하는 문제다. 1월 1일을 1번째 날로 세어 $a$월 $b$일이 그해의 $d$번째 날이라 하면, 요일은 7일마다 되풀이되므로 $d$를 7로 나눈 나머지만으로 정해진다. 나머지가 1인 날이 금요일이므로 2는 토요일, 3은 일요일 순으로 이어져 6은 수요일이다. 7번째 날은 나머지가 0인데 목요일이므로 나머지 0을 목요일로 대응시켜야 한다. $d$는 $a$월 앞의 달들의 일수를 모두 더한 뒤 $b$를 더해 구하며, 2016년이 윤년이라 2월은 29일이다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public String solution(int a, int b) {
        int[] days = {0, 31, 29, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31};
        int d = 0;
        for (int i = 1; i < a; i++) {
            d += days[i];
        }
        d += b;

        String[] week = {"THU", "FRI", "SAT", "SUN", "MON", "TUE", "WED"};
        return week[d % 7];
    }
}
```

```python
def solution(a, b):
    days = [31, 29, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31]
    week = ["THU", "FRI", "SAT", "SUN", "MON", "TUE", "WED"]
    return week[(sum(days[: a - 1]) + b) % 7]
```
