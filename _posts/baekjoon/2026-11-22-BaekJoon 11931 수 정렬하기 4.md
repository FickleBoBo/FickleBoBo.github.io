## 1. 아이디어

수 $N$개를 내림차순으로 정렬하는 문제이고 $N$이 최대 1,000,000이라 $O(N^2)$ 정렬은 시간이 부족하고 $O(N \log N)$ 정렬이면 충분하다. 내림차순으로 바로 정렬해도 되고, 오름차순으로 정렬한 뒤 거꾸로 읽어도 같은 결과다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringBuilder sb = new StringBuilder();

        int n = Integer.parseInt(br.readLine());

        int[] arr = new int[n];
        for (int i = 0; i < n; i++) {
            arr[i] = Integer.parseInt(br.readLine());
        }
        Arrays.sort(arr);

        for (int i = n - 1; i >= 0; i--) {
            sb.append(arr[i]).append("\n");
        }

        System.out.println(sb);
    }
}
```

`int[]`를 정렬하는 `Arrays.sort`에는 비교자를 넘길 수 없어 오름차순으로 정렬한 뒤 뒤에서부터 출력했다. 출력이 최대 1,000,000줄이라 줄마다 `System.out.println`을 호출하면 느려서 `StringBuilder`에 모아 한 번에 출력했다.

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    int n;
    cin >> n;

    vector<int> v(n);
    for (int& x : v) cin >> x;
    sort(v.rbegin(), v.rend());

    for (int x : v) {
        cout << x << '\n';
    }
}
```

`std::sort`에 역방향 이터레이터 `rbegin`, `rend`를 넘겨 별도 비교 함수 없이 내림차순으로 정렬했다.

```python
import sys

input = sys.stdin.readline

n = int(input())
arr = sorted((int(input()) for _ in range(n)), reverse=True)

print("\n".join(map(str, arr)))
```

출력이 최대 1,000,000줄이라 줄마다 `print`를 호출하는 대신 `join`으로 모아 한 번에 출력했다.
