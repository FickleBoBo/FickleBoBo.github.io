## 1. 아이디어

두 정수 $A$, $B$의 나눗셈을 산술 연산자를 활용하여 구하면 된다. 이때 정수 타입 간 나눗셈 연산은 몫만 구하는 연산이 될 수 있어서 주의해야 한다. 또한 실제 정답과의 오차가 $10^{-9}$ 이하여야 하는 점에 주의해야 한다.

---

## 2. 복잡도

| 접근 | 시간   | 공간   |
| ---- | ------ | ------ |
| 풀이 | $O(1)$ | $O(1)$ |

## 3. 코드

### 풀이 [Java][C++]

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());

        int a = Integer.parseInt(st.nextToken());
        int b = Integer.parseInt(st.nextToken());
        System.out.println((double) a / b);
    }
}
```

`(double) a / b`로 한쪽을 `double`로 형변환해 실수 나눗셈을 했다. `println`의 `double` 기본 출력은 오차 기준 $10^{-9}$보다 훨씬 촘촘한 자릿수까지 나온다.

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    int a, b;
    cin >> a >> b;
    cout << fixed << setprecision(9) << (double)a / b;
}
```

`(double)a / b`로 형변환해 실수 나눗셈을 했다. 기본 출력은 유효숫자 6자리라 오차 기준을 맞추지 못하므로 `std::fixed`와 `std::setprecision(9)`로 소수점 아래 9자리까지 출력하며, 이때 반올림 오차는 최대 $5 \times 10^{-10}$이라 기준 이내다.
