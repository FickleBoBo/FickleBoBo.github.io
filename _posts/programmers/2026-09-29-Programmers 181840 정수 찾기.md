## 1. 아이디어

정수 리스트 `num_list` 안에 정수 `n`이 존재하는지 비교만 하면 되는 간단한 문제다.

---

## 2. 복잡도

| 접근 | 시간   | 공간   |
| ---- | ------ | ------ |
| 풀이 | $O(N)$ | $O(1)$ |

($N$ = `num_list`의 길이)

---

## 3. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int solution(int[] num_list, int n) {
        for (int x : num_list) {
            if (x == n) return 1;
        }

        return 0;
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int solution(vector<int> num_list, int n) {
    return find(num_list.begin(), num_list.end(), n) != num_list.end();
}
```

`std::find`를 활용해 `n`을 찾을 수 있다. 반환된 이터레이터가 벡터의 끝이면 `n`이 존재하지 않는 것이고 끝이 아니면 존재하는 것이다.

```python
def solution(num_list, n):
    return int(n in num_list)
```

`in` 연산자로 간단하게 구할 수 있다.
