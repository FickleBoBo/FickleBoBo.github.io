## 1. 아이디어

마지막에 남는 카드의 번호를 구하는 문제이다. 제일 위 카드를 버리고 그다음 위 카드를 제일 아래로 보내는 과정은 큐에서 맨 앞을 빼서 버리고 다음 맨 앞을 빼서 뒤에 다시 넣는 연산과 같다. 카드가 한 장 남을 때까지 이를 그대로 시뮬레이션하며, 반복마다 카드가 한 장씩 줄어 $N - 1$번 돌고 큐 연산이 $O(1)$이라 $N$이 최대 500,000이어도 전체 $O(N)$에 끝난다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        int n = Integer.parseInt(br.readLine());

        Queue<Integer> q = new ArrayDeque<>();
        for (int i = 1; i <= n; i++) {
            q.offer(i);
        }

        while (q.size() > 1) {
            q.poll();
            q.offer(q.poll());
        }

        System.out.println(q.peek());
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    int n;
    cin >> n;

    queue<int> q;
    for (int i = 1; i <= n; i++) {
        q.push(i);
    }

    while (q.size() > 1) {
        q.pop();
        q.push(q.front());
        q.pop();
    }
    cout << q.front();
}
```

```python
import sys
from collections import deque

input = sys.stdin.readline

n = int(input())
q = deque(range(1, n + 1))
while len(q) > 1:
    q.popleft()
    q.append(q.popleft())

print(q[0])
```
