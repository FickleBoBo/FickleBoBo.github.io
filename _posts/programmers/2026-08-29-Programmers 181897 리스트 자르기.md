## 1. 아이디어

`slicer`의 세 값을 각각 `a`, `b`, `c`로 두고 `n` 값에 따라 분기 처리하면 된다.

---

## 2. 복잡도

| 접근 | 시간   | 공간   |
| ---- | ------ | ------ |
| 풀이 | $O(N)$ | $O(N)$ |

($N$ = `num_list`의 길이)

---

## 3. 코드

### 풀이 [Java][C++][Python]

```java
import java.util.*;

class Solution {
    public int[] solution(int n, int[] slicer, int[] num_list) {
        int a = slicer[0], b = slicer[1], c = slicer[2];

        if (n == 1) return Arrays.copyOfRange(num_list, 0, b + 1);
        if (n == 2) return Arrays.copyOfRange(num_list, a, num_list.length);
        if (n == 3) return Arrays.copyOfRange(num_list, a, b + 1);

        List<Integer> list = new ArrayList<>();
        for (int i = a; i <= b; i += c) {
            list.add(num_list[i]);
        }

        return list.stream().mapToInt(Integer::intValue).toArray();
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

vector<int> solution(int n, vector<int> slicer, vector<int> num_list) {
    int a = slicer[0], b = slicer[1], c = slicer[2];

    if (n == 1) return vector<int>(num_list.begin(), num_list.begin() + b + 1);
    if (n == 2) return vector<int>(num_list.begin() + a, num_list.end());
    if (n == 3) return vector<int>(num_list.begin() + a, num_list.begin() + b + 1);

    vector<int> v;
    for (int i = a; i <= b; i += c) {
        v.push_back(num_list[i]);
    }

    return v;
}
```

```python
def solution(n, slicer, num_list):
    a, b, c = slicer

    if n == 1:
        return num_list[: b + 1]
    if n == 2:
        return num_list[a:]
    if n == 3:
        return num_list[a : b + 1]
    return num_list[a : b + 1 : c]
```
