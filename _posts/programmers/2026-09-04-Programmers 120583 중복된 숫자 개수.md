## 1. 아이디어

배열에서 $n$과 같은 원소의 개수를 세는 문제로, 원소마다 $n$과 같은지만 확인해 세면 된다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int solution(int[] array, int n) {
        int cnt = 0;
        for (int x : array) {
            if (x == n) cnt++;
        }

        return cnt;
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int solution(vector<int> array, int n) {
    return count(array.begin(), array.end(), n);
}
```

```python
def solution(array, n):
    return array.count(n)
```
