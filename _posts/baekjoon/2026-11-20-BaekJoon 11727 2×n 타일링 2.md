## 1. 아이디어

[[BaekJoon] #11726 - 2×n 타일링](/posts/baekjoon-11726/)에서 쓸 수 있는 타일에 2×2가 더해진 문제다. 맨 오른쪽 위 칸을 덮는 타일로 경우를 나누면, 2×1 타일을 세로로 세우는 경우 2×$(n - 1)$이 남는다. 1×2 타일을 가로로 놓는 경우에는 그 아래 칸도 같은 가로 타일로 덮어야 해서 1×2 타일 두 개를 위아래로 쌓아 오른쪽 두 열이 채워지고 2×$(n - 2)$가 남으며, 2×2 타일 하나로 오른쪽 두 열을 채우는 경우에도 2×$(n - 2)$가 남는다. 오른쪽 두 열을 채우는 방식이 둘이 되므로 방법의 수를 $f(n)$이라 하면 $f(n) = f(n - 1) + 2f(n - 2)$이고 $f(1) = 1$, $f(2) = 3$이다. 덧셈과 상수배만 쓰므로 매 항마다 10,007로 나눈 나머지를 취해도 최종 나머지는 같다.

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;

public class Main {

    static final int MOD = 10007;

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        int n = Integer.parseInt(br.readLine());
        int[] dp = new int[1 + n + 1];
        dp[1] = 1;
        dp[2] = 3;
        for (int i = 3; i <= n; i++) {
            dp[i] = (2 * dp[i - 2] + dp[i - 1]) % MOD;
        }

        System.out.println(dp[n]);
    }
}
```

`n`이 1일 때도 `dp[2]`에 값을 넣으므로 크기를 `1 + n + 1`로 잡아 인덱스를 벗어나지 않게 했다.

```c++
#include <bits/stdc++.h>
using namespace std;

const int MOD = 10007;
int dp[1 + 1000] = {0, 1, 3};

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    int n;
    cin >> n;

    for (int i = 3; i <= n; i++) {
        dp[i] = (2 * dp[i - 2] + dp[i - 1]) % MOD;
    }

    cout << dp[n];
}
```
