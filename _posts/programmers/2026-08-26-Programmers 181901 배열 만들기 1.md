## 1. 아이디어

`k`부터 시작해 `k`씩 더해가며 `n`을 넘지 않을 때까지의 값을 배열에 담으면, `k`의 배수가 이미 오름차순으로 얻어진다.

---

## 2. 복잡도

| 접근 | 시간       | 공간       |
| ---- | ---------- | ---------- |
| 풀이 | $O(N / K)$ | $O(N / K)$ |

($N$ = 입력값 `n`, $K$ = 입력값 `k`. 결과 배열의 길이 $N / K$)

---

## 3. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int[] solution(int n, int k) {
        int[] arr = new int[n / k];
        int idx = 0;

        for (int i = k; i <= n; i += k) {
            arr[idx++] = i;
        }

        return arr;
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

vector<int> solution(int n, int k) {
    vector<int> v;
    for (int i = k; i <= n; i += k) {
        v.push_back(i);
    }

    return v;
}
```

```python
def solution(n, k):
    return list(range(k, n + 1, k))
```
