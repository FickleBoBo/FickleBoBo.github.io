## 1. 아이디어

소문자로만 이루어진 단어에서 모음의 개수를 구하는 문제로, 글자를 하나씩 보며 `a`, `e`, `i`, `o`, `u` 중 하나인지 확인해 센다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        int cnt = 0;
        for (char c : br.readLine().toCharArray()) {
            if (c == 'a' || c == 'e' || c == 'i' || c == 'o' || c == 'u') cnt++;
        }

        System.out.println(cnt);
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    string s;
    cin >> s;

    int cnt = 0;
    for (char c : s) {
        if (c == 'a' || c == 'e' || c == 'i' || c == 'o' || c == 'u') cnt++;
    }

    cout << cnt;
}
```

```python
import sys

input = sys.stdin.readline

s = input().rstrip()
print(sum(c in "aeiou" for c in s))
```

조건식의 결과가 `bool`이라 `sum`으로 참인 개수를 셌다.
