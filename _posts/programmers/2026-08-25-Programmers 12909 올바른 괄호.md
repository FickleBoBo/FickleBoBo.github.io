## 1. 아이디어

`(`와 `)`로만 이루어진 문자열이 올바른 괄호인지 판별하는 문제다. 닫는 괄호는 아직 닫히지 않은 열린 괄호 중 가장 나중에 열린 것과 짝이 되므로 열린 괄호를 스택에 쌓고, 닫는 괄호를 만나면 하나를 꺼내 짝지으면 된다. 꺼낼 열린 괄호가 없으면 짝 없는 닫는 괄호가 있는 것이고, 끝까지 읽고도 스택에 열린 괄호가 남아 있으면 닫히지 못한 열린 괄호가 있는 것이므로 둘 다 올바르지 않다.

괄호의 종류가 하나뿐이면 스택에 쌓인 것이 전부 같은 `(`라 짝을 지을 때 맨 위가 무엇인지 확인할 일이 없으므로, 스택의 내용 없이 쌓인 개수만 있어도 같은 판정이 된다. 그래서 열린 괄호에서는 개수를 1 늘리고 닫는 괄호에서는 1 줄인다. 줄이기 전의 개수가 0이면 짝 없는 닫는 괄호이고, 끝까지 읽은 뒤 개수가 0이 아니면 닫히지 못한 열린 괄호가 남은 것으로, 스택의 두 조건과 같다. 괄호가 여러 종류면 맨 위와 종류가 같은지 확인해야 하므로 스택이 필요하다.

## 2. 코드

### 풀이 1: 스택 [Java][C++][Python]

```java
import java.util.*;

class Solution {
    boolean solution(String s) {
        Deque<Character> stack = new ArrayDeque<>();
        for (char c : s.toCharArray()) {
            if (c == '(') {
                stack.push(c);
            } else {
                if (stack.isEmpty()) return false;
                stack.pop();
            }
        }

        return stack.isEmpty();
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

bool solution(string s) {
    stack<char> st;
    for (char c : s) {
        if (c == '(') {
            st.push(c);
        } else {
            if (st.empty()) return false;
            st.pop();
        }
    }

    return st.empty();
}
```

```python
def solution(s):
    stack = []
    for c in s:
        if c == "(":
            stack.append(c)
        else:
            if not stack:
                return False
            stack.pop()

    return not stack
```

### 풀이 2: 카운터 [Java][C++][Python]

```java
class Solution {
    boolean solution(String s) {
        int cnt = 0;
        for (char c : s.toCharArray()) {
            if (c == '(') {
                cnt++;
            } else {
                if (cnt == 0) return false;
                cnt--;
            }
        }

        return cnt == 0;
    }
}
```
