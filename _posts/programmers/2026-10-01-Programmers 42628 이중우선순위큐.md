## 1. 아이디어

삽입, 최댓값 삭제, 최솟값 삭제를 모두 처리한 뒤 남은 값의 최댓값과 최솟값을 구하는 문제다. 세 연산이 모두 빨라야 하는데, 연산의 수를 $N$이라 하면 $N \le 10^6$이라 연산 하나가 $O(N)$이면 전체가 $O(N^2)$이 되어 시간이 모자란다. 우선순위 큐(힙) 하나는 최댓값과 최솟값 중 한쪽 끝만 $O(\log N)$에 꺼낼 수 있고 반대쪽 끝을 지우려면 전체를 훑어야 하며, 정렬된 배열은 삽입할 때 원소를 밀어야 해서 $O(N)$이다. 그래서 삽입과 양 끝 삭제를 모두 $O(\log N)$에 하는 구조를 골라야 하고, 균형 이진 탐색 트리처럼 값을 정렬된 상태로 유지하는 구조가 이를 만족한다. 같은 값이 여러 번 들어올 수 있고 삭제는 그중 하나만 지워야 하므로 값마다 개수를 세거나 중복을 허용해 담으면, 양 끝이 곧 최솟값과 최댓값이다.

최소 힙과 최대 힙을 하나씩 함께 쓰는 방법도 있다. 삽입은 두 힙에 모두 넣고 최솟값과 최댓값은 각각의 힙에서 꺼내는데, 한쪽 힙에서 지운 원소가 다른 쪽 힙에는 남는 문제가 생기므로 지운 원소를 표시해 두고 그 힙의 맨 위로 올라왔을 때 버린다. 각 원소는 두 힙에서 한 번씩만 꺼내지므로 이 방법도 전체가 $O(N \log N)$이다.

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.util.*;

class Solution {
    public int[] solution(String[] operations) {
        TreeMap<Integer, Integer> map = new TreeMap<>();

        for (String op : operations) {
            String[] parts = op.split(" ");
            int x = Integer.parseInt(parts[1]);

            if (parts[0].equals("I")) {
                map.put(x, map.getOrDefault(x, 0) + 1);
            } else {
                if (map.isEmpty()) continue;

                int key = (x == 1) ? map.lastKey() : map.firstKey();
                int cnt = map.get(key);
                if (cnt == 1) {
                    map.remove(key);
                } else {
                    map.put(key, cnt - 1);
                }
            }
        }

        if (map.isEmpty()) return new int[]{0, 0};
        return new int[]{map.lastKey(), map.firstKey()};
    }
}
```

`TreeMap`의 키에 값을, 값에 등장 횟수를 저장해 중복을 처리했다.

```c++
#include <bits/stdc++.h>
using namespace std;

vector<int> solution(vector<string> operations) {
    multiset<int> ms;

    for (string& op : operations) {
        int x = stoi(op.substr(2));

        if (op[0] == 'I') {
            ms.insert(x);
        } else {
            if (ms.empty()) continue;
            ms.erase(x == 1 ? prev(ms.end()) : ms.begin());
        }
    }

    if (ms.empty()) return {0, 0};
    return {*ms.rbegin(), *ms.begin()};
}
```

`std::multiset`에 중복을 허용해 그대로 담았다. 최솟값은 `begin()`, 최댓값은 `end()` 바로 앞인 `std::prev(ms.end())`가 가리키고, `erase`에 값을 넘기면 같은 값이 전부 지워지므로 이 이터레이터를 넘겨 하나만 지웠다.

```python
import heapq


def solution(operations):
    min_h, max_h = [], []
    erased = [False] * len(operations)

    for i, op in enumerate(operations):
        cmd, x = op.split()
        x = int(x)

        if cmd == "I":
            heapq.heappush(min_h, (x, i))
            heapq.heappush(max_h, (-x, i))
        else:
            h = max_h if x == 1 else min_h
            while h and erased[h[0][1]]:
                heapq.heappop(h)

            if not h:
                continue

            erased[h[0][1]] = True
            heapq.heappop(h)

    while min_h and erased[min_h[0][1]]:
        heapq.heappop(min_h)
    while max_h and erased[max_h[0][1]]:
        heapq.heappop(max_h)

    if not min_h or not max_h:
        return [0, 0]
    return [-max_h[0][0], min_h[0][0]]
```

아이디어의 두 번째 방법대로 힙 두 개를 썼고, `heapq`는 최소 힙이라 최대 힙은 값의 부호를 뒤집어 넣었다. 같은 값을 구분하려고 값에 연산 번호를 묶어 두 힙에 넣고, 그 번호로 `erased`에 지운 원소를 표시했다. 삭제 연산에서 맨 위를 쓰기 전과 마지막에 결과를 읽기 전에, 표시된 원소가 맨 위에 있는 동안 버렸다.
