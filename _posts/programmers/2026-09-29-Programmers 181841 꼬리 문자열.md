## 1. 아이디어

문자열 리스트 `str_list`의 각 문자열에 대해 문자열 `ex`를 포함하지 않는 경우만 전부 연결하면 되는 간단한 문제다.

---

## 2. 복잡도

| 접근 | 시간                     | 공간            |
| ---- | ------------------------ | --------------- |
| 풀이 | $O(N \times L \times M)$ | $O(N \times L)$ |

($N$ = `str_list`의 길이, $L$ = `str_list` 원소의 최대 길이, $M$ = `ex`의 길이)

---

## 3. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public String solution(String[] str_list, String ex) {
        StringBuilder sb = new StringBuilder();
        for (String s : str_list) {
            if (!s.contains(ex)) sb.append(s);
        }

        return sb.toString();
    }
}
```

문자열 덧셈이 반복되므로 `StringBuilder`를 활용해 가변으로 처리했다.

```c++
#include <bits/stdc++.h>
using namespace std;

string solution(vector<string> str_list, string ex) {
    string res;
    for (string& s : str_list) {
        if (s.find(ex) == -1) res += s;
    }

    return res;
}
```

```python
def solution(str_list, ex):
    return "".join(s for s in str_list if ex not in s)
```
