## 1. 아이디어

[[BaekJoon] #11650 - 좌표 정렬하기](/posts/baekjoon-11650/)와 같은 틀이지만 정렬 기준이 $y$ 좌표 우선으로 바뀐다. $y$ 좌표가 작은 점이 먼저이고 $y$ 좌표가 같을 때는 $x$ 좌표가 작은 점이 먼저이므로, 점을 $(y, x)$ 순서쌍으로 보고 사전식으로 비교하면 이전 문제처럼 정렬 한 번으로 끝난다.

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringBuilder sb = new StringBuilder();

        int n = Integer.parseInt(br.readLine());

        int[][] arr = new int[n][2];
        for (int i = 0; i < n; i++) {
            StringTokenizer st = new StringTokenizer(br.readLine());
            arr[i][0] = Integer.parseInt(st.nextToken());
            arr[i][1] = Integer.parseInt(st.nextToken());
        }
        Arrays.sort(arr, (o1, o2) -> {
            if (o1[1] != o2[1]) return Integer.compare(o1[1], o2[1]);
            return Integer.compare(o1[0], o2[0]);
        });

        for (int[] pos : arr) {
            sb.append(pos[0]).append(" ").append(pos[1]).append("\n");
        }

        System.out.println(sb);
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    int n;
    cin >> n;

    vector<pair<int, int>> v(n);
    for (auto& [y, x] : v) cin >> x >> y;
    sort(v.begin(), v.end());

    for (auto [y, x] : v) {
        cout << x << ' ' << y << '\n';
    }
}
```

`std::pair`의 첫 번째에 `y`, 두 번째에 `x`가 오도록 구조화 바인딩 이름을 `[y, x]`로 짓고 입력은 `x`, `y` 순서로 받았고 출력도 `x`, `y` 순서로 했다.

```python
import sys

input = sys.stdin.readline

n = int(input())
pos = [tuple(map(int, input().split())) for _ in range(n)]
pos.sort(key=lambda p: (p[1], p[0]))

print("\n".join(f"{x} {y}" for x, y in pos))
```

정렬 키로 튜플 `(p[1], p[0])`을 주어 `y`, `x` 순서로 사전식 비교되게 했다.
