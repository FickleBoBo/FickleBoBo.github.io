## 1. 아이디어

나눈 값에 1,000을 곱한 뒤 정수 부분을 취하는 문제다. 곱셈과 나눗셈은 순서를 바꿔도 값이 같으므로 첫 번째 수에 1,000을 먼저 곱하고 정수 나눗셈을 하면, 두 수가 모두 양수라 그 몫이 곧 정수 부분이 되어 실수 연산이 필요 없다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int solution(int num1, int num2) {
        return num1 * 1000 / num2;
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int solution(int num1, int num2) {
    return num1 * 1000 / num2;
}
```

```python
def solution(num1, num2):
    return num1 * 1000 // num2
```
