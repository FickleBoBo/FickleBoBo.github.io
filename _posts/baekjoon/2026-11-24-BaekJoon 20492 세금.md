## 1. 아이디어

수령액을 두 경우로 나누어 구하는 문제다. 첫 번째 경우는 상금의 22%를 내므로 $0.78N$을 받는다. 두 번째 경우는 필요 경비로 인정받은 80%에는 세금이 없어 $0.8N$을 그대로 받고 나머지 $0.2N$에서만 22%를 내므로 $0.8N + 0.2N \times 0.78$을 받는다. $N = 1{,}000k$이면 두 금액은 $780k$, $956k$로 항상 정수로 떨어지므로 정수 연산만으로 정확히 구할 수 있다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        int n = Integer.parseInt(br.readLine());
        System.out.println((n / 100 * 78) + " " + (n / 100 * 80 + n / 100 * 78 * 20 / 100));
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    int n;

}
```
