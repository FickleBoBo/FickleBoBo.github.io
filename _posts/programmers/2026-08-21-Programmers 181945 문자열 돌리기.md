## 1. 아이디어

문자열을 시계방향으로 90도 돌리면 앞 글자가 위, 뒤 글자가 아래인 세로 배열이 되므로, 문자를 앞에서부터 한 줄에 하나씩 출력하면 된다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;

public class Solution {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        for (char c : br.readLine().toCharArray()) {
            System.out.println(c);
        }
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    string s;
    cin >> s;

    for (char c : s) cout << c << '\n';
}
```

```python
import sys

input = sys.stdin.readline

print(*input(), sep="\n")
```

문자열을 `*`로 언패킹해 문자 하나하나를 인자로 넘기고, `sep="\n"`으로 인자 사이를 줄바꿈으로 이었다.
