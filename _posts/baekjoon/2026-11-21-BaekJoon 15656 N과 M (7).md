## 1. 아이디어

[[BaekJoon] #15651 - N과 M (3)](/posts/baekjoon-15651/)처럼 같은 수를 여러 번 골라도 되는 중복 순열을 구하되 1부터 $N$까지가 아니라 입력으로 주어진 수에서 골라 사전 순으로 출력하는 문제다. 같은 백트래킹에서 칸이 서로 독립이라 사용 여부도 시작 인덱스도 따지지 않고 모든 칸에서 정렬한 배열을 처음부터 끝까지 훑으면 $N^M$개의 수열이 사전 순으로 나오고, 입력의 수가 모두 달라 같은 수열이 두 번 나오지 않는다.

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;
import java.util.*;

public class Main {

    static StringBuilder sb = new StringBuilder();
    static int n, m;
    static int[] arr;
    static int[] sel;

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());

        n = Integer.parseInt(st.nextToken());
        m = Integer.parseInt(st.nextToken());

        arr = new int[n];
        st = new StringTokenizer(br.readLine());
        for (int i = 0; i < n; i++) {
            arr[i] = Integer.parseInt(st.nextToken());
        }
        Arrays.sort(arr);

        sel = new int[m];

        dfs(0);
        System.out.println(sb);
    }

    static void dfs(int depth) {
        if (depth == m) {
            for (int x : sel) {
                sb.append(x).append(" ");
            }
            sb.append("\n");
            return;
        }

        for (int i = 0; i < n; i++) {
            sel[depth] = arr[i];
            dfs(depth + 1);
        }
    }
}
```

출력이 최대 823,543줄이라 줄마다 `System.out.println`을 호출하면 느려서 `StringBuilder`에 모아 한 번에 출력했다.

```c++
#include <bits/stdc++.h>
using namespace std;

int n, m;
int arr[7];
int sel[7];

void dfs(int depth) {
    if (depth == m) {
        for (int i = 0; i < m; i++) {
            cout << sel[i] << ' ';
        }
        cout << '\n';
        return;
    }

    for (int i = 0; i < n; i++) {
        sel[depth] = arr[i];
        dfs(depth + 1);
    }
}

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    cin >> n >> m;
    for (int i = 0; i < n; i++) cin >> arr[i];
    sort(arr, arr + n);

    dfs(0);
}
```

출력이 최대 823,543줄이라 줄바꿈에 `std::endl`을 쓰면 줄마다 출력 버퍼를 비워 느려지므로 `'\n'`을 썼다.

```python
import sys
from itertools import product

input = sys.stdin.readline

n, m = map(int, input().split())
arr = sorted(map(int, input().split()))
out = [" ".join(map(str, seq)) for seq in product(arr, repeat=m)]
print("\n".join(out))
```

`sorted`로 정렬한 배열을 `product`에 넘겨 사전 순을 맞췄다.
