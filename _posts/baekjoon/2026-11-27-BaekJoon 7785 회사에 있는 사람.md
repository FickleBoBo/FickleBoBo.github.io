## 1. 아이디어

출입 기록을 모두 처리한 뒤 회사에 남아 있는 사람을 사전 순의 역순으로 출력하는 문제다. 동명이인이 없으므로 이름이 곧 사람이고, 기록을 차례로 보며 `enter`인 이름은 집합에 넣고 `leave`인 이름은 빼면 마지막에 남은 원소가 답이다. 기록의 수 $n$이 최대 1,000,000이라 목록에서 이름을 하나씩 찾아 지우는 방식은 $O(n^2)$이 될 수 있으므로 삽입과 삭제가 빠른 집합 자료구조를 쓴다. 출력 순서는 이름을 내림차순으로 유지하는 집합을 쓰거나, 순서 없는 집합에 모았다가 마지막에 한 번 정렬해 맞춘다.

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        BufferedWriter bw = new BufferedWriter(new OutputStreamWriter(System.out));

        Set<String> set = new TreeSet<>(Comparator.reverseOrder());

        int n = Integer.parseInt(br.readLine());
        while (n-- > 0) {
            StringTokenizer st = new StringTokenizer(br.readLine());
            String name = st.nextToken();
            String action = st.nextToken();

            if (action.equals("enter")) {
                set.add(name);
            } else {
                set.remove(name);
            }
        }

        for (String name : set) {
            bw.write(name);
            bw.newLine();
        }

        bw.flush();
    }
}
```

`TreeSet`의 생성자에 `Comparator.reverseOrder()`를 넘겨 순회 순서가 내림차순이 되게 했다.

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    set<string, greater<>> st;

    int n;
    cin >> n;

    while (n--) {
        string name, action;
        cin >> name >> action;

        if (action == "enter") {
            st.insert(name);
        } else {
            st.erase(name);
        }
    }

    for (auto& name : st) {
        cout << name << '\n';
    }
}
```

`std::set`의 비교자로 `std::greater<>`를 지정해 순회 순서가 내림차순이 되게 했다.

```python
import sys

input = sys.stdin.readline

st = set()

n = int(input())
for _ in range(n):
    name, action = input().split()
    if action == "enter":
        st.add(name)
    else:
        st.remove(name)

print("\n".join(sorted(st, reverse=True)))
```
