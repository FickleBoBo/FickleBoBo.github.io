## 1. 아이디어

배열 길이를 $N$, 쿼리 수를 $Q$라 하면 쿼리마다 구간을 직접 돌며 1씩 더하는 방법은 $O(NQ)$인데, 둘 다 1,000 이하라 많아야 $10^6$번의 덧셈이어서 충분하다.

입력이 더 커져 이 비용이 문제가 되면 구간 $[s, e]$를 통째로 갱신하지 않는다. 인덱스를 앞에서부터 훑을 때 더해야 하는 양은 $s$에서 0이 1로 바뀌고 $e + 1$에서 다시 0이 되므로, 이 변화량을 쿼리마다 두 곳에만 기록해 한 배열에 모아 두고 마지막에 앞에서부터 누적하면 각 인덱스에 더해진 횟수가 나와서 $O(N + Q)$에 끝난다. 배열의 값은 모든 쿼리를 적용한 뒤에야 필요하므로 누적을 마지막에 한 번만 해도 된다.

## 2. 코드

### 풀이 1: 직접 갱신 [Java][C++][Python]

```java
class Solution {
    public int[] solution(int[] arr, int[][] queries) {
        for (int[] q : queries) {
            for (int i = q[0]; i <= q[1]; i++) {
                arr[i]++;
            }
        }

        return arr;
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

vector<int> solution(vector<int> arr, vector<vector<int>> queries) {
    for (auto& q : queries) {
        for (int i = q[0]; i <= q[1]; i++) {
            arr[i]++;
        }
    }

    return arr;
}
```

```python
def solution(arr, queries):
    for s, e in queries:
        for i in range(s, e + 1):
            arr[i] += 1

    return arr
```

### 풀이 2: 차분 배열 [Java][C++][Python]

구간 끝 인덱스의 다음 칸이 배열 길이와 같아질 수 있어서 변화량 배열은 한 칸 크게 잡았다.

```java
class Solution {
    public int[] solution(int[] arr, int[][] queries) {
        int n = arr.length;
        int[] diff = new int[n + 1];

        for (int[] q : queries) {
            diff[q[0]]++;
            diff[q[1] + 1]--;
        }

        int sum = 0;
        for (int i = 0; i < n; i++) {
            sum += diff[i];
            arr[i] += sum;
        }

        return arr;
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

vector<int> solution(vector<int> arr, vector<vector<int>> queries) {
    int n = arr.size();
    vector<int> diff(n + 1);

    for (auto& q : queries) {
        diff[q[0]]++;
        diff[q[1] + 1]--;
    }

    int sum = 0;
    for (int i = 0; i < n; i++) {
        sum += diff[i];
        arr[i] += sum;
    }

    return arr;
}
```

```python
from itertools import accumulate


def solution(arr, queries):
    diff = [0] * (len(arr) + 1)
    for s, e in queries:
        diff[s] += 1
        diff[e + 1] -= 1

    return [x + d for x, d in zip(arr, accumulate(diff))]
```
