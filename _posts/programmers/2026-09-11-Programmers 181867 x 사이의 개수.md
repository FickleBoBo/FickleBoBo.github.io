## 1. 아이디어

`"x"`를 기준으로 자른 각 조각의 길이를 순서대로 구하는 문제다. `"x"`가 연달아 있거나 문자열의 맨 앞·맨 끝에 있으면 길이가 0인 빈 조각이 생기는데, 이것도 하나의 조각이므로 버리지 않고 0으로 센다. 따라서 조각의 개수는 `"x"`의 개수보다 하나 많고, 마지막 `"x"` 뒤에 남은 부분도 하나의 조각이다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int[] solution(String myString) {
        String[] tokens = myString.split("x", -1);
        int[] ans = new int[tokens.length];
        for (int i = 0; i < tokens.length; i++) {
            ans[i] = tokens[i].length();
        }

        return ans;
    }
}
```

`split("x")`는 끝에 있는 빈 문자열을 버리므로 두 번째 인자로 -1을 넘겨 모두 남겼다.

```c++
#include <bits/stdc++.h>
using namespace std;

vector<int> solution(string myString) {
    int n = myString.size();
    vector<int> v;
    int prv = 0;

    for (int i = 0; i < n; i++) {
        if (myString[i] == 'x') {
            v.push_back(i - prv);
            prv = i + 1;
        }
    }
    v.push_back(n - prv);

    return v;
}
```

`'x'`를 만날 때마다 직전 조각의 길이를 기록하므로, 마지막 `'x'` 뒤의 조각은 반복문이 끝난 뒤에 따로 넣었다.

```python
def solution(myString):
    return [len(s) for s in myString.split("x")]
```
