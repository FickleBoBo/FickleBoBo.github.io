## 1. 아이디어

두 정수 $a$, $b$ 사이의 모든 정수(양 끝 포함)의 합을 구하는 문제다. 이 정수들은 공차가 1인 등차수열이라 합은 첫째 항과 끝 항의 합에 항의 수를 곱해 2로 나눈 값이고, $a$와 $b$ 중 어느 쪽이 크든 첫째 항과 끝 항의 합은 $a + b$, 항의 수는 $\vert b - a \vert + 1$이므로 대소를 비교해 바꾸지 않고 $(a + b)(\vert b - a \vert + 1) / 2$ 하나로 구할 수 있다. 이 곱은 항상 짝수여서 2로 나누어떨어진다($a + b$가 짝수이면 곱이 바로 짝수이고, 홀수이면 $b - a$도 홀수라 $\vert b - a \vert + 1$이 짝수다).

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public long solution(int a, int b) {
        return (long) (a + b) * (Math.abs(b - a) + 1) / 2;
    }
}
```

곱이 최대 약 $10^{14}$로 `int` 범위를 넘으므로 `(a + b)`를 곱하기 전에 `long`으로 바꿨다.

```c++
#include <bits/stdc++.h>
using namespace std;

long long solution(int a, int b) {
    return 1LL * (a + b) * (abs(b - a) + 1) / 2;
}
```

곱이 최대 약 $10^{14}$로 `int` 범위를 넘으므로 `1LL`을 먼저 곱해 `long long`으로 계산했다.

```python
def solution(a, b):
    return (a + b) * (abs(b - a) + 1) // 2
```
