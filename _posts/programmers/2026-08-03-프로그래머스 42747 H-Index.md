## 1. 아이디어

H-Index는 논문 `n`편 중, `h`번 이상 인용된 논문이 `h`편 이상이고 나머지 논문이 `h`번 이하 인용되었을 때 `h`의 최댓값이다. `h`라는 경계를 기준으로 판단이 이루어지므로 `citations`를 먼저 정렬을 해주었다.

이후 반복 변수 `i`를 활용해 `0`부터 `h`까지 순회하며 H-Index를 구해줬는데 H-Index는 논문의 인용 횟수인 `citations[i]`와 `i`번 논문보다 인용 횟수가 많거나 같은 논문의 수인 `citations.length - i` 중 작은 값을 비교해서 이들 중 최댓값을 구하면 된다. 왜냐하면 `i`번 논문의 인용 횟수가 `h1`, `i`번 논문보다 인용 횟수가 많거나 같은 논문의 수를 `h2`라고 할 경우, `h1`이 `h2` 이하면 `h1` 이상 인용된 논문이 `h1` 이상 존재한다는 것이고, `h1`이 `h2` 이상이면 `h2` 이상 인용된 논문이 `h2`임은 보장되기 때문이다.

---

## 2. 복잡도

|  시간복잡도  | 공간복잡도 |
| :----------: | :--------: |
| $O(N\log N)$ |   $O(1)$   |

> $N$ = `citations` 길이

---

## 3. 코드

### 풀이 [Java][C++]

```java
import java.util.*;

class Solution {
    public int solution(int[] citations) {
        Arrays.sort(citations);

        int max = 0;
        for (int i = 0; i < citations.length; i++) {
            max = Math.max(max, Math.min(citations[i], citations.length - i));
        }

        return max;
    }
}
```

```c++
#include <algorithm>
#include <vector>

using namespace std;

int solution(vector<int> citations) {
    sort(citations.begin(), citations.end());

    int mx = 0;
    for (int i = 0; i < citations.size(); i++) {
        mx = max(mx, min(citations[i], (int)citations.size() - i));
    }

    return mx;
}
```
