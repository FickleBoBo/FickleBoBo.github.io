## 1. 아이디어

리스트 `num_list`를 순회하며 각 원소를 2로 나눈 나머지로 짝수/홀수를 구분해 개수를 센 뒤, `[짝수 개수, 홀수 개수]` 순서로 반환하면 되는 문제다.

---

## 2. 복잡도

| 접근 | 시간   | 공간   |
| ---- | ------ | ------ |
| 풀이 | $O(N)$ | $O(1)$ |

($N$ = `num_list`의 길이. 길이 2인 반환 배열은 출력 자체이므로 별도 공간으로 세지 않는다)

---

## 3. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int[] solution(int[] num_list) {
        int odd = 0, even = 0;
        for (int x : num_list) {
            if (x % 2 == 1) {
                odd++;
            } else {
                even++;
            }
        }

        return new int[]{even, odd};
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

vector<int> solution(vector<int> num_list) {
    int odd = 0, even = 0;
    for (int x : num_list) {
        if (x % 2) {
            odd++;
        } else {
            even++;
        }
    }

    return {even, odd};
}
```

```python
def solution(num_list):
    odd = sum(1 for x in num_list if x % 2 == 1)
    even = len(num_list) - odd
    return [even, odd]
```
