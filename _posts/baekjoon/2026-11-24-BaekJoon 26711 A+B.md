## 1. 아이디어

두 양의 정수 $a$, $b$를 더하는 문제로, 각각 최대 5,000자리라 64비트 정수에 담을 수 없어 큰 수 자료형으로 읽어 더한다.

---

## 2. 코드

### 풀이 [Java][Python]

```java
import java.io.*;
import java.math.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        BigInteger a = new BigInteger(br.readLine());
        BigInteger b = new BigInteger(br.readLine());
        System.out.println(a.add(b));
    }
}
```

```python
import sys

input = sys.stdin.readline

sys.set_int_max_str_digits(0)

a = int(input())
b = int(input())
print(a + b)
```

입력이 5,000자리라 `int`로 바꾸거나 합을 출력할 때 4,300자리 제한에 걸려 `ValueError`가 나므로 `sys.set_int_max_str_digits(0)`으로 제한을 없앴다. 이 함수는 Python 3.11에 추가됐다.
