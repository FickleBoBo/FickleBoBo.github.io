## 1. 아이디어

`my_string`에서 인덱스 `num1`과 `num2`에 있는 문자를 서로 맞바꾼 문자열을 반환하면 되는 문제다. 두 인덱스가 모두 문자열 범위 안이고 서로 다름이 보장되므로, 별도 검사 없이 두 자리의 문자를 교환하면 된다.

---

## 2. 복잡도

| 접근 | 시간   | 공간   |
| ---- | ------ | ------ |
| 풀이 | $O(N)$ | $O(N)$ |

($N$ = `my_string`의 길이)

---

## 3. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public String solution(String my_string, int num1, int num2) {
        char[] arr = my_string.toCharArray();
        char tmp = arr[num1];
        arr[num1] = arr[num2];
        arr[num2] = tmp;

        return new String(arr);
    }
}
```

`String`은 불변이라 문자를 직접 바꿀 수 없다. `toCharArray`로 가변 `char[]`를 얻어 두 자리를 교환한 뒤 `new String`으로 문자열을 다시 만들었다.

```c++
#include <bits/stdc++.h>
using namespace std;

string solution(string my_string, int num1, int num2) {
    swap(my_string[num1], my_string[num2]);
    return my_string;
}
```

`std::string`은 가변이므로, 두 문자를 `std::swap`으로 제자리에서 맞바꿔 그대로 반환했다.

```python
def solution(my_string, num1, num2):
    s = list(my_string)
    s[num1], s[num2] = s[num2], s[num1]
    return "".join(s)
```

문자열은 불변이라 인덱스 대입이 안 된다. `list`로 바꿔 두 원소를 튜플 대입으로 교환한 뒤 `"".join`으로 다시 문자열로 합쳤다.
