## 1. 아이디어

첫 번째 수를 두 번째 수로 나눈 나머지를 구하는 문제로, 나머지 연산 한 번으로 끝난다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int solution(int num1, int num2) {
        return num1 % num2;
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int solution(int num1, int num2) {
    return num1 % num2;
}
```

```python
def solution(num1, num2):
    return num1 % num2
```
