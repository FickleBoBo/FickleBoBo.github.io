## 1. 아이디어

테스트 케이스의 개수가 주어지지 않고 입력이 끝날 때까지 줄이 이어지므로, 더 이상 읽을 입력이 없는 EOF까지 반복하며 줄마다 합을 출력한다.

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringBuilder sb = new StringBuilder();

        String line;
        while ((line = br.readLine()) != null) {
            StringTokenizer st = new StringTokenizer(line);
            int a = Integer.parseInt(st.nextToken());
            int b = Integer.parseInt(st.nextToken());
            sb.append(a + b).append("\n");
        }

        System.out.println(sb);
    }
}
```

`readLine`은 입력이 끝나면 `null`을 반환하므로 이를 반복의 종료 조건으로 삼았다.

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    int a, b;
    while (cin >> a >> b) {
        cout << a + b << '\n';
    }
}
```

`cin >> a >> b`를 조건식에 두어 읽기에 실패하는 입력 끝에서 반복이 멈추게 했다.

```python
import sys

input = sys.stdin.readline

while True:
    line = input()
    if not line:
        break

    a, b = map(int, line.split())
    print(a + b)
```

`sys.stdin.readline`은 입력이 끝나면 빈 문자열을 반환하므로 이를 반복의 종료 조건으로 삼았다.
