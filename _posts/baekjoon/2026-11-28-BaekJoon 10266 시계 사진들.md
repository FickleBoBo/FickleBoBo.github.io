## 1. 아이디어

두 사진을 각각 돌려 바늘의 배치를 똑같이 만들 수 있는지 판정하는 문제다. 바늘은 순서 없이 주어지지만 각도가 0 이상 360,000 미만인 서로 다른 정수이므로, 길이 360,000인 배열에 바늘이 있는 각도를 표시하면 한 사진이 하나의 원형 이진 문자열이 된다. 한쪽 사진만 돌려도 두 사진의 상대적인 각도는 모두 만들 수 있고, 두 배치가 겹치려면 한 바늘이 다른 사진의 어떤 바늘 위로 가야 해서 돌리는 양은 두 정수 각도의 차가 된다. 따라서 한 배열을 몇 칸 원형으로 밀어 다른 배열이 되는지만 확인하면 된다.

그런데 미는 칸 수마다 360,000칸을 비교하면 최악의 경우 약 $1.3 \times 10^{11}$번이라 시간 안에 끝나지 않는다. 한 배열을 두 번 이어 붙이고 마지막 한 칸을 버리면 모든 원형 이동이 길이 360,000인 부분 문자열로 한 번씩 나타나므로, 그 안에서 다른 배열을 KMP로 찾으면 배열 길이에 비례하는 시간에 판정할 수 있다.

## 2. 코드

### 풀이 [C++]

```c++
#include <bits/stdc++.h>
using namespace std;

vector<int> failure(vector<bool>& s) {
    vector<int> pi(s.size());
    int j = 0;
    for (int i = 1; i < s.size(); i++) {
        while (j > 0 && s[i] != s[j]) j = pi[j - 1];
        if (s[i] == s[j]) pi[i] = ++j;
    }
    return pi;
}

bool kmp(vector<bool>& s, vector<bool>& p) {
    vector<int> pi = failure(p);
    int j = 0;
    for (int i = 0; i < s.size(); i++) {
        while (j > 0 && s[i] != p[j]) j = pi[j - 1];
        if (s[i] == p[j]) j++;
        if (j == p.size()) return true;
    }

    return false;
}

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    int n;
    cin >> n;

    vector<bool> s(360000);
    for (int i = 0; i < n; i++) {
        int x;
        cin >> x;
        s[x] = true;
    }
    vector<bool> tmp = s;
    s.insert(s.end(), tmp.begin(), tmp.end());
    s.pop_back();

    vector<bool> p(360000);
    for (int i = 0; i < n; i++) {
        int x;
        cin >> x;
        p[x] = true;
    }

    cout << (kmp(s, p) ? "possible" : "impossible");
}
```

벡터 자신의 이터레이터를 `insert`에 넘기면 정의되지 않은 동작이라 복사본 `tmp`를 만들어 이어 붙였다.
