## 1. 아이디어

`start_num`부터 `end_num`까지 1씩 작아지며 두 끝을 모두 포함하므로 원소 수는 `start_num - end_num + 1`개이고 첫 원소는 `start_num`이다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int[] solution(int start_num, int end_num) {
        int[] arr = new int[start_num - end_num + 1];
        for (int i = 0; i < arr.length; i++) {
            arr[i] = start_num - i;
        }

        return arr;
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

vector<int> solution(int start_num, int end_num) {
    vector<int> v;
    for (int i = start_num; i >= end_num; i--) {
        v.push_back(i);
    }

    return v;
}
```

```python
def solution(start_num, end_num):
    return list(range(start_num, end_num - 1, -1))
```

`range`의 끝값은 결과에서 제외되므로, `end_num`까지 나오도록 `end_num - 1`을 끝값으로 넘겼다.
