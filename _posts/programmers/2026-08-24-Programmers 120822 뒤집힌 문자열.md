## 1. 아이디어

문자열 `my_string`의 문자 순서를 거꾸로 뒤집어 반환하면 되는 문제다.

---

## 2. 복잡도

| 접근 | 시간   | 공간   |
| ---- | ------ | ------ |
| 풀이 | $O(N)$ | $O(N)$ |

($N$ = `my_string`의 길이. C++의 `string`은 가변이라 제자리에서 뒤집어 그대로 반환하므로 추가 공간 없이 $O(1)$이다. Java/Python은 문자열이 불변이라 뒤집은 결과를 새 객체로 만들 수밖에 없어 $O(N)$이다.)

---

## 3. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public String solution(String my_string) {
        return new StringBuilder(my_string).reverse().toString();
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

string solution(string my_string) {
    reverse(my_string.begin(), my_string.end());
    return my_string;
}
```

```python
def solution(my_string):
    return my_string[::-1]
```
