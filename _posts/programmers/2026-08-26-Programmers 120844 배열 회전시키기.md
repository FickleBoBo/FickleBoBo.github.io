## 1. 아이디어

한 칸 회전이므로 끝에 있는 원소 하나만 반대쪽 끝으로 옮기면 나머지는 순서를 유지한 채 한 칸씩 밀린다. `direction`이 `"left"`면 맨 앞 원소를 맨 뒤로 보내고, `"right"`면 맨 뒤 원소를 맨 앞으로 보내고 중간 원소들을 한 칸씩 밀면 된다.

---

## 2. 복잡도

| 접근 | 시간   | 공간   |
| ---- | ------ | ------ |
| 풀이 | $O(N)$ | $O(N)$ |

($N$ = `numbers`의 길이. C++는 인자로 받은 벡터를 제자리 회전해 반환하므로 공간 $O(1)$)

---

## 3. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int[] solution(int[] numbers, String direction) {
        int[] arr = new int[numbers.length];
        if (direction.equals("left")) {
            System.arraycopy(numbers, 1, arr, 0, numbers.length - 1);
            arr[numbers.length - 1] = numbers[0];
        } else {
            System.arraycopy(numbers, 0, arr, 1, numbers.length - 1);
            arr[0] = numbers[numbers.length - 1];
        }

        return arr;
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

vector<int> solution(vector<int> numbers, string direction) {
    if (direction == "left") {
        rotate(numbers.begin(), numbers.begin() + 1, numbers.end());
    } else {
        rotate(numbers.begin(), numbers.end() - 1, numbers.end());
    }

    return numbers;
}
```

`std::rotate(first, middle, last)`는 `[first, last)` 구간을 왼쪽으로 돌려 `middle`이 가리키던 원소가 맨 앞에 오도록 만든다.

```python
def solution(numbers, direction):
    if direction == "left":
        return numbers[1:] + numbers[:1]
    else:
        return numbers[-1:] + numbers[:-1]
```
