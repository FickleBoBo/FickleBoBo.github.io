## 1. 아이디어

부가가치세 10%를 더한 가격이 $B = 1.1A$이므로 $A = B \times 10 / 11$이다. $B$가 11의 배수라 $B \times 10$이 11로 나머지 없이 나누어떨어져 실수 연산 없이 정수 연산만으로 정확히 구할 수 있다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        int b = Integer.parseInt(br.readLine());
        System.out.println(b * 10 / 11);
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    int b;
    cin >> b;
    cout << b * 10 / 11;
}
```

```python
import sys

input = sys.stdin.readline

b = int(input())
print(b * 10 // 11)
```
