## 1. 아이디어

문자열 `target`이 문자열 `my_string`의 부분 문자열인지 판단하는 문제로 부분 문자열 여부를 판단하는 내장 라이브러리를 활용하면 간단하게 해결할 수 있다.

---

## 2. 복잡도

| 접근 | 시간            | 공간   |
| ---- | --------------- | ------ |
| 풀이 | $O(N \times M)$ | $O(1)$ |

($N$ = `my_string`의 길이, $M$ = `target`의 길이. Python의 `in`은 CPython 구현상 $O(N + M)$)

---

## 3. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int solution(String my_string, String target) {
        return my_string.contains(target) ? 1 : 0;
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int solution(string my_string, string target) {
    return my_string.find(target) != -1;
}
```

```python
def solution(my_string, target):
    return int(target in my_string)
```
