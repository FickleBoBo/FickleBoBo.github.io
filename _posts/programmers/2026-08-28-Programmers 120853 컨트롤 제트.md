## 1. 아이디어

숫자와 `"Z"`가 공백으로 구분된 문자열 `s`가 주어질 때, `s`의 숫자들을 차례대로 더하는데 이때 `"Z"`가 나오면 바로 전에 더했던 숫자를 빼는 과정을 반복하여 최종 값을 구하는 문제다. `s`를 공백을 기준으로 토큰 단위로 분리한 후 앞에서부터 더하다가 `"Z"`가 등장하는 순간 이전에 더했던 숫자를 다시 빼는 과정을 반복하면 해결할 수 있다. `"Z"`가 연속으로 등장하지 않으므로 별도의 예외 처리 없이 해결할 수 있다.

---

## 2. 복잡도

| 접근 | 시간   | 공간   |
| ---- | ------ | ------ |
| 풀이 | $O(N)$ | $O(N)$ |

($N$ = `s`의 길이)

## 3. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int solution(String s) {
        String[] arr = s.split(" ");
        int sum = 0;

        for (int i = 0; i < arr.length; i++) {
            if (arr[i].equals("Z")) {
                sum -= Integer.parseInt(arr[i - 1]);
            } else {
                sum += Integer.parseInt(arr[i]);
            }
        }

        return sum;
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int solution(string s) {
    stringstream ss(s);
    vector<string> tokens;
    string token;
    while (ss >> token) tokens.push_back(token);

    int sum = 0;
    for (int i = 0; i < tokens.size(); i++) {
        if (tokens[i] == "Z") {
            sum -= stoi(tokens[i - 1]);
        } else {
            sum += stoi(tokens[i]);
        }
    }

    return sum;
}
```

```python
def solution(s):
    tokens = s.split()
    total = 0

    for i, token in enumerate(tokens):
        if token == "Z":
            total -= int(tokens[i - 1])
        else:
            total += int(token)

    return total
```
