## 1. 아이디어

정수 `n`의 각 자리 숫자를 모두 더하면 되는 문제다. `n`을 10으로 나눈 나머지로 마지막 자리 숫자를 얻고, `n`을 10으로 나눈 몫을 취하는 과정을 `n`이 0이 될 때까지 반복하여 더하면 된다.

---

## 2. 복잡도

| 접근 | 시간   | 공간   |
| ---- | ------ | ------ |
| 풀이 | $O(D)$ | $O(1)$ |

($D$ = `n`의 자릿수 $\approx \log_{10} n$. Python은 `n`을 문자열로 변환하므로 공간 $O(D)$)

---

## 3. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int solution(int n) {
        int sum = 0;
        while (n > 0) {
            sum += n % 10;
            n /= 10;
        }

        return sum;
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int solution(int n) {
    int sum = 0;
    while (n > 0) {
        sum += n % 10;
        n /= 10;
    }

    return sum;
}
```

```python
def solution(n):
    return sum(int(d) for d in str(n))
```

`n`을 문자열로 변환 후 `sum`으로 각 자리 숫자를 더하는 방식으로 해결했다.
