## 1. 아이디어

`array`를 순회하며 각 원소가 `height`보다 크면 카운팅하면 된다.

---

## 2. 복잡도

| 접근 | 시간   | 공간   |
| ---- | ------ | ------ |
| 풀이 | $O(N)$ | $O(1)$ |

($N$ = `array`의 길이)

---

## 3. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int solution(int[] array, int height) {
        int cnt = 0;
        for (int x : array) {
            if (x > height) cnt++;
        }

        return cnt;
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int solution(vector<int> array, int height) {
    int cnt = 0;
    for (int x : array) {
        if (x > height) cnt++;
    }

    return cnt;
}
```

```python
def solution(array, height):
    return sum(x > height for x in array)
```
