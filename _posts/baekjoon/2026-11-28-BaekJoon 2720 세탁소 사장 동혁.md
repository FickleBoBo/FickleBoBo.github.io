## 1. 아이디어

거스름돈 $C$센트를 25센트 쿼터, 10센트 다임, 5센트 니켈, 1센트 페니로 거슬러 줄 때, 동전의 수가 가장 적어지는 각 동전의 개수를 구하는 문제다. 페니 5개는 니켈 하나로, 니켈 2개는 다임 하나로, 다임 3개는 쿼터 하나와 니켈 하나로, 다임 2개와 니켈 하나는 쿼터 하나로 바꾸면 동전이 줄어든다. 개수가 가장 적은 조합에서는 이런 교환을 할 수 없어야 하므로 다임은 2개, 니켈은 1개, 페니는 4개를 넘지 않고 다임 2개와 니켈이 함께 있지도 않아 쿼터를 뺀 나머지 동전의 합은 24센트 이하다. 따라서 쿼터의 개수는 $C$를 25로 나눈 몫으로 정해지고, 남은 금액에 쓰는 10, 5, 1센트 동전은 큰 단위가 작은 단위의 배수라 역시 큰 것부터 최대한 쓰면 된다.

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringBuilder sb = new StringBuilder();

        int t = Integer.parseInt(br.readLine());
        while (t-- > 0) {
            int c = Integer.parseInt(br.readLine());

            sb.append(c / 25).append(" ");
            c %= 25;

            sb.append(c / 10).append(" ");
            c %= 10;

            sb.append(c / 5).append(" ");
            c %= 5;

            sb.append(c).append("\n");
        }

        System.out.println(sb);
    }
}
```


```python
import sys

input = sys.stdin.readline

t = int(input())
for _ in range(t):
    c = int(input())
    q, c = divmod(c, 25)
    d, c = divmod(c, 10)
    n, c = divmod(c, 5)
    print(q, d, n, c)
```

`divmod`로 몫과 나머지를 한 번에 받았다.
