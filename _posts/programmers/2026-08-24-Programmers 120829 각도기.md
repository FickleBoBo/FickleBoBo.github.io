## 1. 아이디어

각도 하나가 예각(90도 미만), 직각(90도), 둔각(90도 초과 180도 미만), 평각(180도) 중 무엇인지에 따라 차례로 1, 2, 3, 4를 반환하는 문제다. 각도가 0 초과 180 이하의 정수라 네 구간이 빈틈이나 겹침 없이 이어지므로, 작은 구간부터 차례로 검사하면 앞의 조건에 걸리지 않은 값만 다음 조건으로 넘어와 아래쪽 경계를 따로 쓸 필요가 없다. 마지막에 남는 값은 180뿐이라 조건 없이 4를 반환한다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int solution(int angle) {
        if (angle < 90) return 1;
        if (angle == 90) return 2;
        if (angle < 180) return 3;
        return 4;
    }
}
```

```c++

```
