## 1. 아이디어

메시지 $S'$를 반복해 전송할 때 청취자가 받은 길이 $L$의 문자열 $S$를 보고 가능한 $S'$의 최소 길이를 구하는 문제로, $S$는 $S'$를 반복해 이은 문자열의 부분 문자열이다. $S'$의 길이가 $p$이면 반복한 문자열에서 $p$칸 떨어진 문자가 항상 같으므로 $S$도 $p$를 주기로 가져야 하고, 반대로 $S$의 주기가 $p$이면 $S$의 앞 $p$글자를 $S'$로 삼았을 때 $S$가 그 반복 안에 나타나므로 답은 $S$의 가장 짧은 주기다. $L$이 1,000,000까지라 주기 후보를 하나씩 대조하면 최악의 경우 $O(L^2)$이 된다. 그런데 $S$가 주기 $p$를 갖는다는 것은 길이 $L - p$인 접두사와 접미사가 같다는 뜻이므로, KMP의 실패 함수에서 $S$ 전체의 접두사이면서 접미사이기도 한 가장 긴 부분(자기 자신은 제외)의 길이 $k$를 구하면 가장 짧은 주기 $L - k$를 $O(L)$에 얻는다. 마지막 반복이 중간에 끊겨 있어도 되므로 $L$이 주기의 배수일 필요는 없다.

## 2. 코드

### 풀이 [C++]

```c++
#include <bits/stdc++.h>
using namespace std;

vector<int> failure(string& s) {
    vector<int> pi(s.size());
    int j = 0;
    for (int i = 1; i < s.size(); i++) {
        while (j > 0 && s[i] != s[j]) j = pi[j - 1];
        if (s[i] == s[j]) pi[i] = ++j;
    }
    return pi;
}

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    int l;
    string s;
    cin >> l >> s;

    vector<int> pi = failure(s);
    int p = l - pi.back();

    cout << p;
}
```
