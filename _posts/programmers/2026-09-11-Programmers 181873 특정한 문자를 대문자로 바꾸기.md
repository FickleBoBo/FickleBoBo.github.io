## 1. 아이디어

영소문자로 이루어진 문자열 `my_string`에 대해 `alp`에 해당하는 모든 글자를 대문자로 바꾼 문자열을 반환하면 되는 간단한 문제다.

---

## 2. 복잡도

| 접근 | 시간   | 공간   |
| ---- | ------ | ------ |
| 풀이 | $O(N)$ | $O(N)$ |

($N$ = `my_string`의 길이. C++는 인자 문자열을 제자리 수정해 그대로 반환하므로 공간 $O(1)$)

---

## 3. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public String solution(String my_string, String alp) {
        return my_string.replace(alp.charAt(0), Character.toUpperCase(alp.charAt(0)));
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

string solution(string my_string, string alp) {
    char c = alp[0];
    for (char& x : my_string) {
        if (x == c) x = toupper(x);
    }

    return my_string;
}
```

```python
def solution(my_string, alp):
    return my_string.replace(alp, alp.upper())
```
