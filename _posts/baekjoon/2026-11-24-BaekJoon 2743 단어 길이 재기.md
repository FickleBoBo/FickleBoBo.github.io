## 1. 아이디어

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        String s = br.readLine();
        System.out.println(s.length());
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    string s;
    cin >> s;
    cout << s.size();
}
```

```python
import sys

input = sys.stdin.readline

s = input().rstrip()
print(len(s))
```

`sys.stdin.readline`은 줄바꿈까지 읽어 오므로 `rstrip`으로 지워 길이가 1 더 커지지 않게 했다.
