## 1. 아이디어

1부터 $N$까지의 자연수에서 같은 수를 여러 번 골라도 되는 $M$개의 수열, 즉 길이가 $M$인 중복 순열을 사전 순으로 모두 출력하는 문제다. 수열을 앞 칸부터 채워 가는 백트래킹에서 앞 칸의 선택이 뒤 칸의 후보를 줄이지 않으므로 사용 여부도 시작 값도 따지지 않고 모든 칸을 1부터 $N$까지 차례로 훑으면 $N^M$개의 수열이 사전 순으로 나온다. $N$이 7 이하라 수열이 최대 $7^7 = 823{,}543$개이고, 모두 만들어 출력해도 된다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;
import java.util.*;

public class Main {

    static StringBuilder sb = new StringBuilder();
    static int n, m;
    static int[] sel;

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());

        n = Integer.parseInt(st.nextToken());
        m = Integer.parseInt(st.nextToken());
        sel = new int[m];

        dfs(0);
        System.out.println(sb);
    }

    static void dfs(int depth) {
        if (depth == m) {
            for (int x : sel) {
                sb.append(x).append(" ");
            }
            sb.append("\n");
            return;
        }

        for (int i = 1; i <= n; i++) {
            sel[depth] = i;
            dfs(depth + 1);
        }
    }
}
```

출력이 최대 823,543줄이라 줄마다 `System.out.println`을 호출하면 느려서 `StringBuilder`에 모아 한 번에 출력했다.

```c++
#include <bits/stdc++.h>
using namespace std;

int n, m;
int sel[7];

void dfs(int depth) {
    if (depth == m) {
        for (int i = 0; i < m; i++) cout << sel[i] << ' ';
        cout << '\n';
        return;
    }

    for (int i = 1; i <= n; i++) {
        sel[depth] = i;
        dfs(depth + 1);
    }
}

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    cin >> n >> m;

    dfs(0);
}
```

출력이 최대 823,543줄이라 줄바꿈에 `std::endl`을 쓰면 줄마다 출력 버퍼를 비워 느려지므로 `'\n'`을 썼다.

```python
import sys
from itertools import product

input = sys.stdin.readline

n, m = map(int, input().split())
out = [" ".join(map(str, seq)) for seq in product(range(1, n + 1), repeat=m)]
print("\n".join(out))
```

`product`에 `repeat=m`을 넘겨 `range`의 수를 중복을 허용해 `m`번 고르는 수열을 사전 순으로 얻었다.
