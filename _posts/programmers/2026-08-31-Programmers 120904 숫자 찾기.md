## 1. 아이디어

정수의 자리 숫자 중 $k$가 처음 나타나는 자리가 앞에서 몇 번째인지 구하는 문제다. 정수를 십진 문자열로 바꾸면 각 자리가 문자 하나로 대응하고 $k$도 한 자리 수라 문자 하나이므로, 문자열에서 $k$가 처음 나오는 위치를 찾으면 된다. 위치는 0부터 시작하니 1을 더해 자리 번호로 바꾼다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int solution(int num, int k) {
        int idx = String.valueOf(num).indexOf(String.valueOf(k));
        return idx != -1 ? idx + 1 : -1;
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int solution(int num, int k) {
    int idx = to_string(num).find('0' + k);
    return idx != -1 ? idx + 1 : -1;
}
```

숫자 `k`는 `'0' + k`로 문자로 바꿔 `find`에 넘겼다. `find`가 못 찾으면 반환하는 `std::string::npos`는 `int`에 담으면 -1이 된다.

```python
def solution(num, k):
    idx = str(num).find(str(k))
    return idx + 1 if idx != -1 else -1
```
