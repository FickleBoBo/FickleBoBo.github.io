## 1. 아이디어

모든 $i$, $j$에 대해 `arr[i][j]`와 `arr[j][i]`가 같은지 확인하는 문제다. $(i, j)$와 $(j, i)$는 같은 쌍을 두 번 비교하는 것이고 $i = j$는 자기 자신과의 비교라 항상 성립하므로, $i < j$인 쌍만 확인하면 충분하다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int solution(int[][] arr) {
        for (int i = 0; i < arr.length - 1; i++) {
            for (int j = i + 1; j < arr.length; j++) {
                if (arr[i][j] != arr[j][i]) return 0;
            }
        }

        return 1;
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int solution(vector<vector<int>> arr) {
    for (int i = 0; i < arr.size() - 1; i++) {
        for (int j = i + 1; j < arr.size(); j++) {
            if (arr[i][j] != arr[j][i]) return 0;
        }
    }

    return 1;
}
```

`arr.size()`는 부호 없는 정수라 `arr`가 비어 있으면 `arr.size() - 1`이 -1이 아니라 언더플로우를 일으키지만, `arr`의 길이가 1 이상이라 문제가 없다.

```python
def solution(arr):
    n = len(arr)
    for i in range(n - 1):
        for j in range(i + 1, n):
            if arr[i][j] != arr[j][i]:
                return 0

    return 1
```
