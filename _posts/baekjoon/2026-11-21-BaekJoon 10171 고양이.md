## 1. 아이디어

예제의 고양이 그림을 한 줄씩 그대로 출력한다. 줄 앞의 공백도 그림의 일부라 예제와 한 글자도 다르지 않게 출력해야 한다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

문자열 안에서 백슬래시는 이스케이프 문자라 `\`를 한 글자 출력하려고 `\\`로 두 번 썼다.

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("\\    /\\");
        System.out.println(" )  ( ')");
        System.out.println("(  /  )");
        System.out.println(" \\(__)|");
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    cout << "\\    /\\" << '\n';
    cout << " )  ( ')" << '\n';
    cout << "(  /  )" << '\n';
    cout << " \\(__)|" << '\n';
}
```

```python
print("\\    /\\")
print(" )  ( ')")
print("(  /  )")
print(" \\(__)|")
```
