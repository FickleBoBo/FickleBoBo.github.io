## 1. 아이디어

마지막 돌을 가져가는 사람이 지는 미제르 님 게임에서 승자를 구하는 문제다. 크기가 2 이상인 더미가 있으면 일반 님과 승패가 같아서 Nim-Sum이 0이 아닌 선공이 이긴다. 2 이상인 더미가 하나만 남은 순간에는 그 더미를 전부 가져가거나 1개만 남겨서 크기가 1인 더미의 개수 홀짝을 원하는 대로 맞출 수 있으므로, 일반 님에서 이기는 쪽이 마지막 돌을 상대에게 떠넘길 수 있기 때문이다. 반대로 모든 더미의 크기가 1이면 Nim-Sum은 의미가 없고 한 개씩 번갈아 가져가는 것뿐이어서, 더미가 짝수 개이면 마지막 돌을 후공이 가져가게 되어 선공이 이기고 홀수 개이면 후공이 이긴다.

## 2. 복잡도

| 접근 | 시간   | 공간   |
| ---- | ------ | ------ |
| 풀이 | $O(N)$ | $O(1)$ |

($N$ = 입력값 `n`)

## 3. 코드

### 풀이 [Java][C++]

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st;

        int nimsum = 0;
        int cnt = 0;

        int n = Integer.parseInt(br.readLine());
        st = new StringTokenizer(br.readLine());
        for (int i = 0; i < n; i++) {
            int p = Integer.parseInt(st.nextToken());
            nimsum ^= p;
            if (p == 1) cnt++;
        }

        if ((cnt < n && nimsum != 0) || (cnt == n && cnt % 2 == 0)) {
            System.out.println("koosaga");
        } else {
            System.out.println("cubelover");
        }
    }
}
```
