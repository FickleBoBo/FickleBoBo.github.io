## 1. 아이디어

모두가 한 조각 이상 먹으려면 사람 수 $n$ 이상의 조각이 필요하므로, 필요한 판 수는 $n$을 한 판의 조각 수로 나눈 값의 올림이다. 정수 나눗셈으로 올림을 구하려면 나누는 수에서 1을 뺀 값을 먼저 더하면 된다. 나머지가 0이면 더한 값이 몫을 넘기지 못해 그대로이고, 나머지가 1 이상이면 몫이 정확히 1 늘어난다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int solution(int slice, int n) {
        return (n + slice - 1) / slice;
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int solution(int slice, int n) {
    return (n + slice - 1) / slice;
}
```

```python
def solution(slice, n):
    return (n + slice - 1) // slice
```
