## 1. 아이디어

별이 $2N - 1$개에서 시작해 줄마다 2개씩 줄다가 $N$번째 줄에서 1개가 되고, 그 뒤로 2개씩 다시 늘어나 $2N - 1$개로 끝나는 $2N - 1$줄의 모래시계다. 별은 항상 $N$번째 열을 중심으로 대칭이므로 앞 공백은 별이 줄어드는 동안 한 칸씩 늘고, 별이 늘어나는 동안 한 칸씩 준다.

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringBuilder sb = new StringBuilder();

        int n = Integer.parseInt(br.readLine());

        int l = 1, r = 2 * n - 1;
        for (int i = 1; i <= 2 * n - 1; i++) {
            for (int j = 1; j < l; j++) {
                sb.append(" ");
            }
            for (int j = l; j <= r; j++) {
                sb.append("*");
            }
            sb.append("\n");

            if (i < n) {
                l++;
                r--;
            } else {
                l--;
                r++;
            }
        }

        System.out.println(sb);
    }
}
```

```python
import sys

input = sys.stdin.readline

n = int(input())

l, r = 1, 2 * n - 1
out = []
for i in range(1, 2 * n):
    out.append(" " * (l - 1) + "*" * (r - l + 1))
    if i < n:
        l += 1
        r -= 1
    else:
        l -= 1
        r += 1

print("\n".join(out))
```
