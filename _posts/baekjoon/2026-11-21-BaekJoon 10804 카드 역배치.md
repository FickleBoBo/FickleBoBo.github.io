## 1. 아이디어

1부터 20까지 놓인 카드에 구간 뒤집기를 차례로 적용한 최종 배치를 출력하는 문제다. 카드가 20장이고 구간이 10개뿐이라 구간마다 직접 뒤집으면 된다. 위치는 1부터 20까지로 주어지므로 0부터 시작하는 배열에서는 1씩 줄여 쓴다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringBuilder sb = new StringBuilder();

        int[] arr = new int[20];
        for (int i = 0; i < 20; i++) {
            arr[i] = i + 1;
        }

        for (int i = 0; i < 10; i++) {
            StringTokenizer st = new StringTokenizer(br.readLine());
            int s = Integer.parseInt(st.nextToken()) - 1;
            int e = Integer.parseInt(st.nextToken()) - 1;

            while (s < e) {
                int tmp = arr[s];
                arr[s] = arr[e];
                arr[e] = tmp;
                s++;
                e--;
            }
        }

        for (int x : arr) {
            sb.append(x).append(" ");
        }

        System.out.println(sb);
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    vector<int> v(20);
    iota(v.begin(), v.end(), 1);

    for (int i = 0; i < 10; i++) {
        int s, e;
        cin >> s >> e;
        reverse(v.begin() + s - 1, v.begin() + e);
    }

    for (int x : v) {
        cout << x << ' ';
    }
}
```

`std::reverse`의 구간은 끝이 열려 있어 위치 `s`부터 `e`까지를 뒤집으려면 끝을 `v.begin() + e`로 넘겼다.

```python
import sys

input = sys.stdin.readline

arr = list(range(1, 21))
for _ in range(10):
    s, e = map(int, input().split())
    arr[s - 1 : e] = arr[s - 1 : e][::-1]

print(*arr)
```

슬라이스의 끝은 포함되지 않아 `arr[s - 1 : e]`가 위치 `s`부터 `e`까지이고, `[::-1]`로 뒤집은 복사본을 같은 구간에 다시 대입했다.
