## 1. 아이디어

대소문자를 모두 소문자로 바꾼 뒤 알파벳 순으로 정렬한 문자열을 구하는 문제다. 알파벳 순서는 대소문자를 구분하지 않는 순서인데 문자 코드로는 대문자가 소문자보다 앞서므로, 정렬하기 전에 먼저 소문자로 통일해야 한다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.util.*;

class Solution {
    public String solution(String my_string) {
        char[] arr = my_string.toLowerCase().toCharArray();
        Arrays.sort(arr);
        return new String(arr);
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

string solution(string my_string) {
    for (char& c : my_string) c = tolower(c);
    sort(my_string.begin(), my_string.end());
    return my_string;
}
```

`char&`로 받아야 `std::tolower`의 결과가 문자열에 반영된다.

```python
def solution(my_string):
    return "".join(sorted(my_string.lower()))
```
