## 1. 아이디어

두 주사위가 모두 홀수인지, 하나만 홀수인지, 둘 다 홀수가 아닌지에 따라 점수 공식이 갈리는 문제다. 모두 홀수면 $a^2 + b^2$, 하나만 홀수면 $2(a + b)$, 둘 다 홀수가 아니면 $\vert a - b \vert$를 반환한다. 둘 다 홀수인 경우를 먼저 가르고 나면 남은 경우에서는 둘 중 하나라도 홀수인 것이 곧 하나만 홀수인 것이므로, 하나만 홀수인 조건은 따로 검사하지 않아도 된다.

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int solution(int a, int b) {
        if (a % 2 != 0 && b % 2 != 0) return a * a + b * b;
        if (a % 2 != 0 || b % 2 != 0) return 2 * (a + b);
        return Math.abs(a - b);
    }
}
```

