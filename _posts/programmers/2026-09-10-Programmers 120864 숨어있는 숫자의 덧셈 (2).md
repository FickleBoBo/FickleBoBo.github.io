## 1. 아이디어

[[Programmers] #120851 - 숨어있는 숫자의 덧셈 (1)](/posts/programmers-120851/)에서는 연속한 숫자도 한 자리씩 따로 더하지만, 여기서는 문자열에 들어 있는 자연수들의 합을 구하되 연속한 숫자를 하나의 수로 본다. 숫자가 아닌 문자를 모두 구분자로 바꾸면 남은 숫자 덩어리가 문자열 속 수 하나씩에 해당하고, 연속한 숫자는 사이에 구분자가 끼지 않아 한 덩어리를 이룬다. 따라서 덩어리마다 수로 읽어 더하면 된다.

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.util.*;

class Solution {
    public int solution(String my_string) {
        char[] arr = my_string.toCharArray();
        for (int i = 0; i < arr.length; i++) {
            if (!Character.isDigit(arr[i])) arr[i] = ' ';
        }

        StringTokenizer st = new StringTokenizer(new String(arr));
        int sum = 0;
        while (st.hasMoreTokens()) {
            sum += Integer.parseInt(st.nextToken());
        }

        return sum;
    }
}
```

공백으로 바꾼 문자열을 `StringTokenizer`로 나눴다. 연속한 구분자는 하나로 취급돼 빈 토큰이 생기지 않는다.

```c++
#include <bits/stdc++.h>
using namespace std;

int solution(string my_string) {
    for (char& c : my_string) {
        if (!isdigit(c)) c = ' ';
    }

    stringstream ss(my_string);
    int sum = 0;
    int x;
    while (ss >> x) sum += x;

    return sum;
}
```

```python
def solution(my_string):
    s = "".join(c if c.isdigit() else " " for c in my_string)
    return sum(map(int, s.split()))
```

`split()`을 인자 없이 호출해 연속한 공백을 하나의 구분자로 나눴다. `split(" ")`은 공백이 연속하면 그 사이에 빈 문자열이 생겨 `int`가 에러를 낸다.
