## 1. 아이디어

[[BaekJoon] #15657 - N과 M (8)](/posts/baekjoon-15657/)과 같은 중복 조합이지만 입력에 같은 수가 여러 번 주어질 수 있어서 중복 출력을 막아야 하는 문제다. 같은 수를 몇 번이든 고를 수 있어서 입력의 같은 수는 하나로 합쳐도 되고, 정렬한 배열에서 한 칸마다 직전에 시도한 값과 같은 값을 건너뛰면 서로 다른 값만 남긴 배열을 훑는 것과 같다. 같은 수를 합친 정렬 배열에서는 인덱스가 줄지 않아야 값이 비내림차순이므로 백트래킹에서 다음 칸은 직전에 쓴 인덱스 자신부터 시도한다.

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;
import java.util.*;

public class Main {

    static StringBuilder sb = new StringBuilder();
    static int n, m;
    static int[] arr;
    static int[] sel;

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());

        n = Integer.parseInt(st.nextToken());
        m = Integer.parseInt(st.nextToken());

        arr = new int[n];
        st = new StringTokenizer(br.readLine());
        for (int i = 0; i < n; i++) {
            arr[i] = Integer.parseInt(st.nextToken());
        }
        Arrays.sort(arr);

        sel = new int[m];

        dfs(0, 0);
        System.out.println(sb);
    }

    static void dfs(int start, int depth) {
        if (depth == m) {
            for (int x : sel) {
                sb.append(x).append(" ");
            }
            sb.append("\n");
            return;
        }

        int prv = 0;
        for (int i = start; i < n; i++) {
            if (arr[i] == prv) continue;

            prv = sel[depth] = arr[i];
            dfs(i, depth + 1);
        }
    }
}
```

`prv`의 초깃값 0은 입력이 자연수라 어떤 원소와도 겹치지 않는다.

```c++
#include <bits/stdc++.h>
using namespace std;

int n, m;
int arr[8];
int sel[8];

void dfs(int start, int depth) {
    if (depth == m) {
        for (int i = 0; i < m; i++) {
            cout << sel[i] << ' ';
        }
        cout << '\n';
        return;
    }

    int prv = 0;
    for (int i = start; i < n; i++) {
        if (arr[i] == prv) continue;

        prv = sel[depth] = arr[i];
        dfs(i, depth + 1);
    }
}

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    cin >> n >> m;
    for (int i = 0; i < n; i++) cin >> arr[i];
    sort(arr, arr + n);

    dfs(0, 0);
}
```

`prv`의 초깃값 0은 입력이 자연수라 어떤 원소와도 겹치지 않는다.

```python
import sys
from itertools import combinations_with_replacement

input = sys.stdin.readline

n, m = map(int, input().split())
arr = sorted(set(map(int, input().split())))
out = [" ".join(map(str, seq)) for seq in combinations_with_replacement(arr, m)]
print("\n".join(out))
```

입력에서 먼저 `set`으로 같은 수를 없앤 다음 `sorted`로 정렬해 `combinations_with_replacement`에 넘겼다.
