## 1. 아이디어

주어진 수를 10으로 나눈 나머지로 마지막 자리를 얻고 10으로 나눠 자리를 줄이는 과정을 반복하며, 그 자리 숫자가 3, 6, 9 중 하나인 횟수를 센다.

---

## 2. 복잡도

| 접근 | 시간        | 공간   |
| ---- | ----------- | ------ |
| 풀이 | $O(\log N)$ | $O(1)$ |

($N$ = 입력값 `order`)

---

## 3. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int solution(int order) {
        int cnt = 0;
        while (order > 0) {
            int r = order % 10;
            if (r == 3 || r == 6 || r == 9) cnt++;
            order /= 10;
        }

        return cnt;
    }
}
```


```python
def solution(order):
    return sum(c in "369" for c in str(order))
```

`str(order)`로 각 자리를 문자로 훑으며 `c in "369"`로 그 자리가 3, 6, 9 중 하나인지 판정했다. `c in "369"`는 `True`/`False`를 내놓고 파이썬에서 `True`는 1, `False`는 0으로 더해지므로, 제너레이터 식을 `sum`에 넘기면 조건을 만족하는 자리의 개수가 그대로 나온다.
