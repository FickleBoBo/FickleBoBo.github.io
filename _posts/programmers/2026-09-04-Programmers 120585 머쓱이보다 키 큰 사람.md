## 1. 아이디어

배열에서 머쓱이의 키보다 큰 원소의 개수를 세는 문제다. 키가 같은 사람은 더 큰 것이 아니므로 비교는 '이상'이 아니라 '초과'다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int solution(int[] array, int height) {
        int cnt = 0;
        for (int x : array) {
            if (x > height) cnt++;
        }

        return cnt;
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int solution(vector<int> array, int height) {
    int cnt = 0;
    for (int x : array) {
        if (x > height) cnt++;
    }

    return cnt;
}
```

```python
def solution(array, height):
    return sum(x > height for x in array)
```

조건식의 결과가 `bool`이라 `sum`으로 참인 개수를 셌다.
