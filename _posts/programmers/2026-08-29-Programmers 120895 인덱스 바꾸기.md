## 1. 아이디어

문자열에서 주어진 두 인덱스의 문자를 서로 바꾼 문자열을 구하는 문제다. 두 위치만 맞바꾸고 나머지는 그대로 두면 된다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public String solution(String my_string, int num1, int num2) {
        char[] arr = my_string.toCharArray();
        char tmp = arr[num1];
        arr[num1] = arr[num2];
        arr[num2] = tmp;

        return new String(arr);
    }
}
```

`String`은 불변 객체라 `char[]`로 옮겨 교환한 뒤 새 `String`으로 만들었다.

```c++
#include <bits/stdc++.h>
using namespace std;

string solution(string my_string, int num1, int num2) {
    swap(my_string[num1], my_string[num2]);
    return my_string;
}
```

```python
def solution(my_string, num1, num2):
    s = list(my_string)
    s[num1], s[num2] = s[num2], s[num1]
    return "".join(s)
```

문자열은 불변 객체라 리스트로 옮겨 교환한 뒤 `join`으로 다시 문자열로 만들었다.
