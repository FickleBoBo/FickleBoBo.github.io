## 1. 아이디어

입력을 그대로 출력하는 문제인데, [[BaekJoon] #11718 - 그대로 출력하기](/posts/baekjoon-11718/)와 달리 빈 줄이 주어질 수 있고 줄의 앞뒤에 공백이 있을 수 있다. 줄 수가 주어지지 않아 입력이 끝날 때까지 한 줄씩 읽어 출력하는 틀은 같지만, 줄에서 개행 문자 외에는 아무것도 지우지 않아야 하고 빈 줄을 입력의 끝으로 처리해서도 안 된다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        BufferedWriter bw = new BufferedWriter(new OutputStreamWriter(System.out));

        String line;
        while ((line = br.readLine()) != null) {
            bw.write(line);
            bw.newLine();
        }

        bw.flush();
    }
}
```

`readLine`은 줄바꿈만 떼고 앞뒤 공백은 남기므로 읽은 줄을 그대로 출력했다. 빈 줄은 빈 문자열이라 입력이 끝났을 때의 `null`과 구분된다.

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    string line;
    while (getline(cin, line)) {
        cout << line << '\n';
    }
}
```

`std::getline`으로 앞뒤 공백을 남긴 채 한 줄씩 읽었다. 빈 줄도 읽기에 성공한 것이라 반복이 이어진다.

```python
import sys

input = sys.stdin.readline

while True:
    line = input()
    if not line:
        break
    print(line.rstrip("\n"))
```

`rstrip()`은 줄 끝의 공백까지 지우므로 `rstrip("\n")`으로 개행 문자만 지웠다. 빈 줄은 `"\n"`으로 읽혀 입력의 끝인 빈 문자열과 구분된다.
