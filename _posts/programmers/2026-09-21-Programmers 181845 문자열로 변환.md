## 1. 아이디어

정수 $n$을 십진수 문자열로 바꾸는 문제다. 언어가 제공하는 기본 변환이 이를 그대로 해 주므로 자릿수를 직접 뽑아 이을 필요가 없다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public String solution(int n) {
        return String.valueOf(n);
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

string solution(int n) {
    return to_string(n);
}
```

```python
def solution(n):
    return str(n)
```
