## 1. 아이디어

$n$ 이하의 홀수를 오름차순으로 담는 문제다. 홀수는 1부터 2씩 커지므로 $n$을 넘기 전까지 2씩 늘려 가며 모으면, 짝수를 걸러 낼 필요 없이 오름차순 홀수열이 그대로 나온다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int[] solution(int n) {
        int[] arr = new int[(n + 1) / 2];
        int idx = 0;

        for (int i = 1; i <= n; i += 2) {
            arr[idx++] = i;
        }

        return arr;
    }
}
```

배열의 크기를 `n` 이하 홀수의 개수인 `(n + 1) / 2`로 미리 잡아 두고 채웠다.

```c++
#include <bits/stdc++.h>
using namespace std;

vector<int> solution(int n) {
    vector<int> v;
    for (int i = 1; i <= n; i += 2) {
        v.push_back(i);
    }

    return v;
}
```

```python
def solution(n):
    return list(range(1, n + 1, 2))
```

`range`의 세 번째 인자로 간격을 주어 홀수만 바로 만들었다.
