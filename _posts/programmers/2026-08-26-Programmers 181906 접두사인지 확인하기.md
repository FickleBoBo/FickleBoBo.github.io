## 1. 아이디어

접두사 여부는 두 문자열을 앞에서부터 한 글자씩 맞춰 보고 `is_prefix`의 모든 문자가 같은 위치의 `my_string` 문자와 일치하는지 확인하면 판단할 수 있다. `is_prefix`가 `my_string`보다 길면 그 시점에서 접두사가 될 수 없다.

---

## 2. 복잡도

| 접근 | 시간   | 공간   |
| ---- | ------ | ------ |
| 풀이 | $O(N)$ | $O(1)$ |

($N$ = `is_prefix`의 길이. C++은 `substr`이 길이 `is_prefix.size()`짜리 임시 문자열을 만들어 $O(N)$이다.)

---

## 3. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int solution(String my_string, String is_prefix) {
        return my_string.startsWith(is_prefix) ? 1 : 0;
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int solution(string my_string, string is_prefix) {
    return my_string.substr(0, is_prefix.size()) == is_prefix;
}
```

```python
def solution(my_string, is_prefix):
    return int(my_string.startswith(is_prefix))
```
