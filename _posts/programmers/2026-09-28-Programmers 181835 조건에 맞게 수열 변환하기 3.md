## 1. 아이디어

정수 배열 `arr`과 자연수 `k`가 주어질 때, `k`가 홀수인지 짝수인지 여부에 따라 `arr`을 변환한 배열을 반환하는 문제다. 홀짝만 구한 후 변환만 진행하면 간단하게 해결할 수 있다.

---

## 2. 복잡도

| 접근 | 시간   | 공간   |
| ---- | ------ | ------ |
| 풀이 | $O(N)$ | $O(1)$ |

($N$ = `arr`의 길이. Python은 새 리스트를 만들어 반환해 공간 $O(N)$)

---

## 3. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int[] solution(int[] arr, int k) {
        if (k % 2 != 0) {
            for (int i = 0; i < arr.length; i++) {
                arr[i] *= k;
            }
        } else {
            for (int i = 0; i < arr.length; i++) {
                arr[i] += k;
            }
        }

        return arr;
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

vector<int> solution(vector<int> arr, int k) {
    if (k % 2) {
        for (int& x : arr) x *= k;
    } else {
        for (int& x : arr) x += k;
    }

    return arr;
}
```

```python
def solution(arr, k):
    if k % 2:
        return [x * k for x in arr]
    else:
        return [x + k for x in arr]
```
