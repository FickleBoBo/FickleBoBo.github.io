## 1. 아이디어

한 자리 정수로 이루어진 문자열 `num_str`에서 각 자릿수의 합을 반환하는 문제로 `num_str`의 각 문자를 순회하며 자릿수만 더하면 된다.

---

## 2. 복잡도

| 접근 | 시간   | 공간   |
| ---- | ------ | ------ |
| 풀이 | $O(N)$ | $O(1)$ |

($N$ = `num_str`의 길이)

---

## 3. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int solution(String num_str) {
        int sum = 0;
        for (char c : num_str.toCharArray()) {
            sum += c - '0';
        }

        return sum;
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int solution(string num_str) {
    int sum = 0;
    for (char c : num_str) sum += c - '0';
    return sum;
}
```

```python
def solution(num_str):
    return sum(int(c) for c in num_str)
```
