## 1. 아이디어

1부터 $N$까지의 자연수에서 중복 없이 $M$개를 골라 오름차순으로 놓은 수열, 즉 길이가 $M$인 조합을 사전 순으로 모두 출력하는 문제다. 수열을 앞 칸부터 한 칸씩 채워 가는 백트래킹으로 만들되, 오름차순 수열은 고른 수의 집합이 정해지면 정렬된 순서 하나로만 놓이므로, 순서만 다른 수열을 따로 만들지 않고 각 칸에 직전 칸의 수보다 큰 수만 넣으면 집합마다 정확히 한 번씩 나온다. 그래서 다음 칸은 직전에 넣은 수보다 하나 큰 수부터 시도하면 되고, 이미 쓴 수는 항상 이번 칸의 시작 수보다 작아 다시 고를 일이 없으므로 사용 여부를 표시할 필요가 없다. 작은 수부터 시도하는 순서는 그대로여서 출력은 사전 순이다.

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;
import java.util.*;

public class Main {

    static StringBuilder sb = new StringBuilder();
    static int n, m;
    static int[] sel;

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());

        n = Integer.parseInt(st.nextToken());
        m = Integer.parseInt(st.nextToken());
        sel = new int[m];

        dfs(1, 0);
        System.out.println(sb);
    }

    static void dfs(int start, int depth) {
        if (depth == m) {
            for (int x : sel) {
                sb.append(x).append(" ");
            }
            sb.append("\n");
            return;
        }

        for (int i = start; i <= n; i++) {
            sel[depth] = i;
            dfs(i + 1, depth + 1);
        }
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int n, m;
int sel[8];

void dfs(int start, int depth) {
    if (depth == m) {
        for (int i = 0; i < m; i++) cout << sel[i] << ' ';
        cout << '\n';
        return;
    }

    for (int i = start; i <= n; i++) {
        sel[depth] = i;
        dfs(i + 1, depth + 1);
    }
}

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    cin >> n >> m;

    dfs(1, 0);
}
```

```python
import sys
from itertools import combinations

input = sys.stdin.readline

n, m = map(int, input().split())
out = [" ".join(map(str, seq)) for seq in combinations(range(1, n + 1), m)]
print("\n".join(out))
```

`combinations`는 입력의 순서를 유지한 채 고르므로 오름차순 `range`를 넘겨 오름차순 수열을 사전 순으로 얻었다.
