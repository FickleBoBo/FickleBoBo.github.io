## 1. 아이디어

서로 다른 $k$개의 수를 모아 배열을 만드는 문제로, 앞에서부터 보며 처음 나오는 수만 순서대로 담으면 문제가 설명한 방식 그대로 배열이 만들어진다. 이미 나온 수는 기록해 두었다가 다시 나오면 건너뛰고, $k$개가 차면 나머지는 볼 필요가 없으며, 끝까지 봐도 $k$개가 안 되면 남은 칸은 -1로 둔다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.util.*;

class Solution {
    public int[] solution(int[] arr, int k) {
        boolean[] seen = new boolean[1 + 100000];
        int[] ans = new int[k];
        Arrays.fill(ans, -1);

        int idx = 0;
        for (int x : arr) {
            if (seen[x]) continue;
            ans[idx++] = x;
            seen[x] = true;

            if (idx == k) break;
        }

        return ans;
    }
}
```

원소가 0 이상 100,000 이하라 값 자체를 인덱스로 하는 `boolean` 배열에 나온 수를 표시했다.

```python
def solution(arr, k):
    seen = set()
    ans = [-1] * k

    idx = 0
    for x in arr:
        if x in seen:
            continue
        ans[idx] = x
        seen.add(x)
        idx += 1

        if idx == k:
            break

    return ans
```
