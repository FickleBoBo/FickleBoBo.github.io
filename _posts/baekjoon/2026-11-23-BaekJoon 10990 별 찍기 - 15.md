## 1. 아이디어

가운데 정렬 삼각형에서 왼쪽 변과 오른쪽 변만 별로 찍는다. 위에서부터 $i$번째 줄은 앞 공백 $N - i$개 뒤에 길이 $2i - 1$인 구간이 오고, 이 구간의 첫 칸과 마지막 칸이 별이며 그 사이는 공백이다. 첫 줄은 구간의 길이가 1이라 첫 칸과 마지막 칸이 같은 칸이므로 별이 하나만 찍힌다.

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringBuilder sb = new StringBuilder();

        int n = Integer.parseInt(br.readLine());

        for (int i = 1; i <= n; i++) {
            for (int j = 1; j <= n - i; j++) {
                sb.append(" ");
            }

            for (int j = 1; j <= 2 * i - 1; j++) {
                if (j == 1 || j == 2 * i - 1) {
                    sb.append("*");
                } else {
                    sb.append(" ");
                }
            }

            sb.append("\n");
        }

        System.out.println(sb);
    }
}
```

```python
import sys

input = sys.stdin.readline

n = int(input())

out = []
for i in range(1, n + 1):
    line = " " * (n - i)
    for j in range(1, 2 * i):
        if j == 1 or j == 2 * i - 1:
            line += "*"
        else:
            line += " "
    out.append(line)

print("\n".join(out))
```
