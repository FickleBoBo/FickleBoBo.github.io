## 1. 아이디어

1개, 3개 또는 4개씩 돌을 가져가며 마지막 돌을 가져가는 사람이 이기는 게임에서 두 사람이 최선을 다했을 때의 승자를 구하는 문제다. 두 사람이 최선을 다하면 돌이 `i`개 남은 상태는 그 차례의 사람이 이기는 상태와 지는 상태 둘 중 하나로 정해지므로, 이기면 `true`인 `dp[i]`를 정의할 수 있다. 1개, 3개, 4개를 가져가면 상대에게 `dp[i - 1]`, `dp[i - 3]`, `dp[i - 4]` 상태가 넘어가는데 이 중 상대가 지는 상태(`false`)가 하나라도 있으면 `dp[i]`는 `true`이고, 셋 모두 `true`이면 어떻게 가져가도 상대가 이기므로 `false`이다. 초기값은 한 번에 다 가져갈 수 있는 `dp[1] = dp[3] = dp[4] = true`이고, 돌이 2개일 때는 1개를 가져가면 상대가 남은 1개를 가져가 이기므로 `dp[2] = false`이다. 점화식이 `i - 4`까지 참조하므로 이 네 값을 채워 두고 5개부터 차례로 구하면 된다.

| 풀이 | $O(N)$ | $O(N)$ |

($N$ = 입력값 `n`)

## 3. 코드

### 풀이 [Java][C++]

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        int n = Integer.parseInt(br.readLine());

        boolean[] dp = new boolean[1 + 1000];
        dp[1] = dp[3] = dp[4] = true;
        for (int i = 5; i <= n; i++) {
            if (!dp[i - 1] || !dp[i - 3] || !dp[i - 4]) {
                dp[i] = true;
            }
        }

        if (dp[n]) {
            System.out.println("SK");
        } else {
            System.out.println("CY");
        }
    }
}
```
