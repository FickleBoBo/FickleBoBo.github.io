## 1. 아이디어

두 분수의 합을 기약분수로 나타내는 문제다. 두 분모를 곱한 값을 공통 분모 $q$로 잡으면, 각 분자에 상대 분수의 분모를 곱해 더한 값이 통분한 분자 $p$가 된다. 이렇게 만든 $\dfrac{p}{q}$는 약분만 안 됐을 뿐 두 분수의 합과 같으므로, 기약분수로 만들려면 $p$와 $q$를 최대공약수로 나누면 된다. 최대공약수로 나눈 두 수에는 더 이상 공약수가 남지 않기 때문이다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int[] solution(int numer1, int denom1, int numer2, int denom2) {
        int p = numer1 * denom2 + numer2 * denom1;
        int q = denom1 * denom2;
        int g = gcd(p, q);
        return new int[]{p / g, q / g};
    }

    static int gcd(int a, int b) {
        if (b == 0) return a;
        return gcd(b, a % b);
    }
}
```

`gcd`는 유클리드 호제법으로 직접 구현했다.

```c++
#include <bits/stdc++.h>
using namespace std;

vector<int> solution(int numer1, int denom1, int numer2, int denom2) {
    int p = numer1 * denom2 + numer2 * denom1;
    int q = denom1 * denom2;
    int g = gcd(p, q);
    return {p / g, q / g};
}
```

`std::gcd`로 최대공약수를 직접 구현하지 않고 구할 수 있다.

```python
import math


def solution(numer1, denom1, numer2, denom2):
    p = numer1 * denom2 + numer2 * denom1
    q = denom1 * denom2
    g = math.gcd(p, q)
    return [p // g, q // g]
```

`math.gcd`로 최대공약수를 직접 구현하지 않고 구할 수 있다.
