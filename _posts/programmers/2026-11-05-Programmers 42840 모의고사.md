## 1. 아이디어

수포자 세 명이 정해진 패턴을 반복해서 찍은 답을 정답과 비교해 가장 많이 맞힌 사람을 찾는 문제로, 세 사람의 패턴은 각각 길이 5, 8, 10의 주기로 반복되므로 0부터 센 $i$번째 문제에서 찍는 답은 패턴에서 $i$를 주기로 나눈 나머지 위치의 값이다.

문제가 최대 10,000개이고 수포자가 셋뿐이라 모든 문제를 직접 채점해도 충분하다. 최고 점수가 같은 사람이 여럿이면 번호 오름차순으로 반환해야 하므로 번호가 작은 사람부터 담는다.

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int[] solution(int[] answers) {
        int[] a = {1, 2, 3, 4, 5};
        int[] b = {2, 1, 2, 3, 2, 4, 2, 5};
        int[] c = {3, 3, 1, 1, 2, 2, 4, 4, 5, 5};

        int[] cnt = new int[3];
        for (int i = 0; i < answers.length; i++) {
            if (answers[i] == a[i % 5]) cnt[0]++;
            if (answers[i] == b[i % 8]) cnt[1]++;
            if (answers[i] == c[i % 10]) cnt[2]++;
        }

        if (cnt[0] == cnt[1] && cnt[1] == cnt[2]) {
            return new int[]{1, 2, 3};
        } else if (cnt[0] == cnt[1] && cnt[1] > cnt[2]) {
            return new int[]{1, 2};
        } else if (cnt[0] == cnt[2] && cnt[2] > cnt[1]) {
            return new int[]{1, 3};
        } else if (cnt[1] == cnt[2] && cnt[2] > cnt[0]) {
            return new int[]{2, 3};
        } else if (cnt[0] > cnt[1] && cnt[0] > cnt[2]) {
            return new int[]{1};
        } else if (cnt[1] > cnt[0] && cnt[1] > cnt[2]) {
            return new int[]{2};
        } else {
            return new int[]{3};
        }
    }
}
```

```python
def solution(answers):
    patterns = [[1, 2, 3, 4, 5], [2, 1, 2, 3, 2, 4, 2, 5], [3, 3, 1, 1, 2, 2, 4, 4, 5, 5]]
    cnt = [0] * 3

    for i, answer in enumerate(answers):
        for j, pattern in enumerate(patterns):
            if answer == pattern[i % len(pattern)]:
                cnt[j] += 1

    return [i + 1 for i, x in enumerate(cnt) if x == max(cnt)]
```
