## 1. 아이디어

`"ad"`를 포함한 문자열을 빼고 나머지를 원래 순서대로 남기는 문제다. 포함 여부는 문자열 하나만 보고 정해지므로 앞에서부터 하나씩 확인해 포함하지 않는 것만 차례로 모으면 순서가 그대로 유지된다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.util.*;

class Solution {
    public String[] solution(String[] strArr) {
        List<String> list = new ArrayList<>();
        for (String s : strArr) {
            if (s.contains("ad")) continue;
            list.add(s);
        }

        return list.toArray(new String[0]);
    }
}
```

`toArray`에 `new String[0]`을 넘겨 `String[]`로 바꿨다. 넘긴 배열은 원소 타입을 알려 주는 용도이고 결과 배열의 크기는 리스트에 맞춰진다.

```c++
#include <bits/stdc++.h>
using namespace std;

vector<string> solution(vector<string> strArr) {
    vector<string> v;
    for (string& s : strArr) {
        if (s.find("ad") != -1) continue;
        v.push_back(s);
    }

    return v;
}
```

```python
def solution(strArr):
    return [s for s in strArr if "ad" not in s]
```
