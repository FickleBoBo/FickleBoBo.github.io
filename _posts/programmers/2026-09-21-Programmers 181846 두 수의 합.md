## 1. 아이디어

두 수가 최대 100,000자리라 정수형에 담을 수 없으므로, 큰 정수를 지원하는 타입을 쓰거나 자릿수별로 직접 더해야 한다. 직접 더할 때는 낮은 자리부터 두 수의 해당 자리와 올림을 더해 그 합의 일의 자리를 결과에 쓰고, 10으로 나눈 몫을 다음 자리의 올림으로 넘긴다. 낮은 자리부터 쓰므로 결과는 마지막에 뒤집는다. 한쪽 수가 먼저 끝나도 두 수와 올림이 모두 끝날 때까지 반복해야 `"99"`와 `"1"`을 더한 `"100"`처럼 자릿수가 늘어나는 경우도 처리된다.

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.math.*;

class Solution {
    public String solution(String a, String b) {
        BigInteger x = new BigInteger(a);
        BigInteger y = new BigInteger(b);
        return x.add(y).toString();
    }
}
```

`BigInteger`는 임의 길이의 정수를 담을 수 있어 문자열 그대로 받아 더했다.

```c++
#include <bits/stdc++.h>
using namespace std;

string solution(string a, string b) {
    string s;
    int i = a.size() - 1, j = b.size() - 1, carry = 0;
    while (i >= 0 || j >= 0 || carry) {
        int sum = carry;
        if (i >= 0) sum += a[i--] - '0';
        if (j >= 0) sum += b[j--] - '0';
        s += sum % 10 + '0';
        carry = sum / 10;
    }
    reverse(s.begin(), s.end());

    return s;
}
```

```python
import sys

sys.set_int_max_str_digits(0)

```

Python `int`는 크기 제한이 없지만 문자열과 정수 사이의 변환은 기본으로 4,300자리까지만 허용된다. 입력이 최대 100,000자리라 `sys.set_int_max_str_digits(0)`으로 제한을 풀었다.
