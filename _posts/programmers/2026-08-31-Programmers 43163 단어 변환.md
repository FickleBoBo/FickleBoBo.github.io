## 1. 아이디어

`begin`에서 출발해 한 번에 한 글자씩, `words`에 있는 단어로만 바꿔 `target`을 만드는 최소 변환 횟수를 구하는 문제다. 단어를 정점, 한 글자만 다른 두 단어 사이를 간선으로 보면 변환 한 번이 간선 하나이고 비용이 모두 같으므로, 최소 변환 횟수는 `begin`에서 `target`까지의 최단 경로이고 BFS로 단계를 세면 구해진다. 어떤 단어에서 한 번에 바꿀 수 있는 단어는 한 글자를 다른 소문자로 바꾼 후보뿐이므로, 그 후보를 만들어 `words`에 있는지만 확인하면 간선을 따라갈 수 있다. 한 번 방문한 단어는 이미 더 짧은 경로로 닿은 것이라 다시 넣지 않고, `target`에 닿지 못하면 0이다(`target`이 `words`에 없는 경우도 여기에 포함된다).

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.util.*;

class Solution {
    public int solution(String begin, String target, String[] words) {
        Set<String> dict = new HashSet<>(List.of(words));

        Queue<String> q = new ArrayDeque<>();
        q.offer(begin);

        Set<String> vis = new HashSet<>();
        vis.add(begin);

        int dist = 0;

        while (!q.isEmpty()) {
            int sz = q.size();
            while (sz-- > 0) {
                String cur = q.poll();
                if (cur.equals(target)) return dist;

                for (int i = 0; i < cur.length(); i++) {
                    for (char c = 'a'; c <= 'z'; c++) {
                        String nxt = cur.substring(0, i) + c + cur.substring(i + 1);
                        if (!dict.contains(nxt) || vis.contains(nxt)) continue;

                        q.offer(nxt);
                        vis.add(nxt);
                    }
                }
            }

            dist++;
        }

        return 0;
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int solution(string begin, string target, vector<string> words) {
    unordered_set<string> dict(words.begin(), words.end());

    queue<string> q;
    q.push(begin);

    unordered_set<string> vis;
    vis.insert(begin);

    int dist = 0;

    while (!q.empty()) {
        int sz = q.size();
        while (sz--) {
            string cur = q.front();
            q.pop();

            if (cur == target) return dist;

            for (int i = 0; i < cur.size(); i++) {
                string nxt = cur;
                for (char c = 'a'; c <= 'z'; c++) {
                    nxt[i] = c;
                    if (!dict.contains(nxt) || vis.contains(nxt)) continue;

                    q.push(nxt);
                    vis.insert(nxt);
                }
            }
        }

        dist++;
    }

    return 0;
}
```

```python
import string
from collections import deque


def solution(begin, target, words):
    words = set(words)

    q = deque([begin])
    vis = {begin}
    dist = 0

    while q:
        for _ in range(len(q)):
            cur = q.popleft()
            if cur == target:
                return dist

            for i in range(len(cur)):
                for c in string.ascii_lowercase:
                    nxt = cur[:i] + c + cur[i + 1 :]
                    if nxt not in words or nxt in vis:
                        continue

                    q.append(nxt)
                    vis.add(nxt)

        dist += 1

    return 0
```
