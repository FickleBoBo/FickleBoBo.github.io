## 1. 아이디어

`n`의 각 자리 숫자를 모두 더하는 워밍업 문제다. `10`으로 나눈 나머지로 마지막 자리 숫자를 얻고 `n`을 `10`으로 나누는 과정을 `n`이 0이 될 때까지 반복하며 누적하거나, 10진수 문자열의 각 문자를 숫자로 바꿔 더하면 된다. `n`이 0이면 두 방법 모두 0을 반환한다.

---

## 2. 복잡도

| 접근 | 시간   | 공간   |
| ---- | ------ | ------ |
| 풀이 | $O(D)$ | $O(D)$ |

($D$ = `n`의 자릿수, $D \approx \log_{10} n$)

---

## 3. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int solution(int n) {
        int sum = 0;
        while (n > 0) {
            sum += n % 10;
            n /= 10;
        }

        return sum;
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

}
```
