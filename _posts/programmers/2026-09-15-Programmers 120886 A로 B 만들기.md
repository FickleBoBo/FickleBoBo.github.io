## 1. 아이디어

주어진 두 문자열 중 한쪽의 글자 순서를 바꿔 다른 쪽을 만들 수 있는지 판별하는 문제다. 순서만 바꾸면 글자 구성(글자별 개수)은 변하지 않고, 구성이 같은 두 문자열은 항상 순서를 바꿔 서로 만들 수 있으므로 두 문자열의 글자 구성이 같은지만 비교하면 된다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int solution(String before, String after) {
        int[] cnt = new int[26];
        for (char c : before.toCharArray()) {
            cnt[c - 'a']++;
        }
        for (char c : after.toCharArray()) {
            cnt[c - 'a']--;
        }

        for (int x : cnt) {
            if (x != 0) return 0;
        }

        return 1;
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int solution(string before, string after) {
    sort(before.begin(), before.end());
    sort(after.begin(), after.end());
    return before == after;
}
```

```python
from collections import Counter


def solution(before, after):
    return int(Counter(before) == Counter(after))
```

`Counter`끼리 `==`로 비교해 글자별 개수가 모두 같은지 한 번에 확인했다. `int`로 감싸 `True`는 1, `False`는 0으로 반환했다.
