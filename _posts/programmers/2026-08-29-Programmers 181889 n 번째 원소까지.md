## 1. 아이디어

정수 리스트 `num_list`의 첫 원소부터 `n`번째 원소까지, 즉 앞에서부터 `n`개의 원소를 잘라낸 부분 리스트가 곧 답이다.

---

## 2. 복잡도

| 접근 | 시간   | 공간   |
| ---- | ------ | ------ |
| 풀이 | $O(N)$ | $O(N)$ |

($N$ = 입력값 `n`)

---

## 3. 코드

### 풀이 [Java][C++][Python]

```java
import java.util.*;

class Solution {
    public int[] solution(int[] num_list, int n) {
        return Arrays.copyOf(num_list, n);
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

vector<int> solution(vector<int> num_list, int n) {
    return vector<int>(num_list.begin(), num_list.begin() + n);
}
```

```python
def solution(num_list, n):
    return num_list[:n]
```
