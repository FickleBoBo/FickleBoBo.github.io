## 1. 아이디어

각 원소를 서로 독립적으로 두 배 하면 되는 문제다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int[] solution(int[] numbers) {
        for (int i = 0; i < numbers.length; i++) {
            numbers[i] *= 2;
        }

        return numbers;
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

vector<int> solution(vector<int> numbers) {
    for (int& x : numbers) x *= 2;
    return numbers;
}
```

`int&`로 받아야 복사본이 아닌 원소 자체가 바뀐다.

```python
def solution(numbers):
    return [x * 2 for x in numbers]
```
