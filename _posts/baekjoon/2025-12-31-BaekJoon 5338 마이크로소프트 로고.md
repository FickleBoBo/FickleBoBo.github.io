## 3. 코드

### 풀이 [Java][C++]

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("       _.-;;-._");
        System.out.println("'-..-'|   ||   |");
        System.out.println("'-..-'|_.-;;-._|");
        System.out.println("'-..-'|   ||   |");
        System.out.println("'-..-'|_.-''-._|");
    }
}
```

#include <bits/stdc++.h>

    cout << "'-..-'|_.-;;-._|" << '\n';
    cout << "'-..-'|   ||   |" << '\n';

}
