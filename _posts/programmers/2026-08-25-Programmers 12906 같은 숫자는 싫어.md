## 1. 아이디어

배열에서 연속으로 나타나는 같은 숫자를 하나만 남기는 문제다. 연속으로 이어진 같은 값의 묶음에서는 첫 원소만 남기면 되고, 어떤 원소가 묶음의 첫 원소라는 것은 바로 앞 원소와 값이 다르다는 것과 같다(맨 앞 원소는 항상 남긴다). 그래서 앞에서부터 훑으며 남긴 값들을 스택처럼 쌓으면, 맨 위의 값은 언제나 바로 앞 원소와 같은 값이므로(바로 앞 원소를 쌓았다면 그 원소가 맨 위이고, 버렸다면 같은 값이 이미 맨 위에 있다) 맨 위와 같은 원소는 버리고 다른 원소만 쌓으면 된다. 떨어져서 다시 나타나는 같은 숫자(예: `1, 1, 3, 3, 0, 1, 1`의 마지막 `1`)는 연속이 아니라 남겨야 하므로, 중복을 통째로 제거하는 집합 방식은 쓸 수 없다.

문제가 요구하는 연산이 연속한 같은 값을 하나로 합치는 것 그 자체라, 직접 비교하는 반복문 없이 이 연산을 하는 표준 기능을 한 번 호출해도 같은 결과를 얻는다.

## 2. 코드

### 풀이 1: 직전 원소 비교 [Java][C++][Python]

```java
import java.util.*;

public class Solution {
    public int[] solution(int[] arr) {
        Deque<Integer> dq = new ArrayDeque<>();
        for (int x : arr) {
            if (dq.isEmpty() || dq.peekLast() != x) dq.offerLast(x);
        }

        return dq.stream().mapToInt(Integer::intValue).toArray();
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

vector<int> solution(vector<int> arr) {
    vector<int> v;
    for (int x : arr) {
        if (v.empty() || v.back() != x) v.push_back(x);
    }

    return v;
}
```

```python
def solution(arr):
    ans = []
    for x in arr:
        if not ans or ans[-1] != x:
            ans.append(x)

    return ans
```

### 풀이 2: 표준 라이브러리 [C++][Python]

```c++
#include <bits/stdc++.h>
using namespace std;

vector<int> solution(vector<int> arr) {
    arr.erase(unique(arr.begin(), arr.end()), arr.end());
    return arr;
}
```

`std::unique`는 연속한 같은 값을 앞쪽으로 모으고 새 끝 위치만 반환할 뿐 원소를 지우지 않아서, 그 위치부터 끝까지를 `erase`로 지웠다.

```python
from itertools import groupby


def solution(arr):
    return [k for k, _ in groupby(arr)]
```

`groupby`는 연속한 같은 값끼리만 묶으므로 떨어져 있는 같은 값은 별개의 묶음이 된다. 묶음마다 키 하나씩만 모았다.
