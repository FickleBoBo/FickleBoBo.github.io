## 1. 아이디어

가운데 정렬 삼각형 틀에서 별과 공백이 번갈아 나오게 찍는다. 위에서부터 $i$번째 줄은 앞 공백 $N - i$개 뒤에 길이 $2i - 1$인 구간이 오고, 이 구간의 홀수 번째 칸에 별을 찍으면 별이 $i$개 놓이고 구간의 양 끝이 모두 별이 된다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringBuilder sb = new StringBuilder();

        int n = Integer.parseInt(br.readLine());

        for (int i = 1; i <= n; i++) {
            for (int j = 1; j <= n - i; j++) {
                sb.append(" ");
            }

            for (int j = 1; j <= 2 * i - 1; j++) {
                if (j % 2 != 0) {
                    sb.append("*");
                } else {
                    sb.append(" ");
                }
            }

            sb.append("\n");
        }

        System.out.println(sb);
    }
}
```

```c++
        }

        for (int j = 1; j <= 2 * i - 1; j++) {
            if (j % 2) {
                cout << '*';
            } else {
                cout << ' ';
            }
        }

        cout << '\n';
    }
}
```

```python
import sys

input = sys.stdin.readline

n = int(input())

for i in range(1, n + 1):
    line = " " * (n - i)
    for j in range(1, 2 * i):
        if j % 2:
            line += "*"
        else:
            line += " "
    print(line)
```
