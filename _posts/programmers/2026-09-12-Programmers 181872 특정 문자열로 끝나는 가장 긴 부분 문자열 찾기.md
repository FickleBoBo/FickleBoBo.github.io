## 1. 아이디어

원래 문자열의 부분 문자열이 찾는 문자열로 끝나려면 그 끝이 찾는 문자열의 어떤 등장이 끝나는 위치와 같아야 한다. 가장 길게 만들려면 시작은 맨 앞으로 두고 끝은 가장 뒤쪽 등장의 끝으로 잡아야 하므로, 마지막으로 등장한 위치를 구해 처음부터 그 끝까지 자르면 된다. 찾는 문자열은 반드시 원래 문자열 안에 있어 못 찾는 경우는 따로 처리하지 않는다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public String solution(String myString, String pat) {
        return myString.substring(0, myString.lastIndexOf(pat) + pat.length());
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

string solution(string myString, string pat) {
    return myString.substr(0, myString.rfind(pat) + pat.size());
}
```

```python
def solution(myString, pat):
    return myString[: myString.rfind(pat) + len(pat)]
```
