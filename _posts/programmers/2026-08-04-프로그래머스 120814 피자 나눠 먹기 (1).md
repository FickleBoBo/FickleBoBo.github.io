## 1. 아이디어

피자를 나눠먹을 사람의 수 `n`에 대해 모든 사람이 피자를 한 조각 이상 먹으려면 `n`을 7로 나눈 몫만큼 피자가 필요하고 나머지가 존재하면 이들을 위해서도 피자 한판이 필요하다. 따라서 `n`을 7로 올림 나눗셈한만큼 피자가 필요하므로 $\dfrac{n + 6}{7}$ 만큼의 피자가 필요하다.

---

## 2. 복잡도

| 시간복잡도 | 공간복잡도 |
| :--------: | :--------: |
|   $O(1)$   |   $O(1)$   |

---

## 3. 코드

### 풀이 [Java][C++]

```java
class Solution {
    public int solution(int n) {
        return (n + 6) / 7;
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int solution(int n) {
    return (n + 6) / 7;
}
```
