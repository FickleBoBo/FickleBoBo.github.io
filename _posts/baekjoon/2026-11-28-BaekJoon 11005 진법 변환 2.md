## 1. 아이디어

[[BaekJoon] #2745 - 진법 변환](/posts/baekjoon-2745/)과 반대로 10진법 수 $N$을 $B$진법으로 바꾸는 문제다. $N$을 $B$로 나눈 나머지가 $B$진법의 가장 낮은 자리이고 몫은 그 자리를 뺀 윗부분이므로, 몫이 0이 될 때까지 나눗셈을 반복하면 낮은 자리부터 하나씩 나온다. 따라서 얻은 순서를 뒤집어 출력해야 하며, 10 이상인 자리는 `A`부터 `Z`까지의 문자로 바꾼다.

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());

        int n = Integer.parseInt(st.nextToken());
        int b = Integer.parseInt(st.nextToken());
        System.out.println(Integer.toString(n, b).toUpperCase());
    }
}
```

`Integer.toString`의 두 번째 인자로 진법을 넘겼는데, 10 이상의 자리가 소문자로 나와 `toUpperCase`로 바꿨다.

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    int n, b;
    cin >> n >> b;

    string digits = "0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZ";
    string ans;

    while (n > 0) {
        ans += digits[n % b];
        n /= b;
    }
    reverse(ans.begin(), ans.end());

    cout << ans;
}
```

```python
import string
import sys

input = sys.stdin.readline

n, b = map(int, input().split())
digits = string.digits + string.ascii_uppercase
res = []
while n:
    n, d = divmod(n, b)
    res.append(digits[d])

print("".join(reversed(res)))
```

`string.digits`와 `string.ascii_uppercase`를 이어 자리 문자표를 만들었고, `divmod`로 몫과 나머지를 한 번에 받았다.
