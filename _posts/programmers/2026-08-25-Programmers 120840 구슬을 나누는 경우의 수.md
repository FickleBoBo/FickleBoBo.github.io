## 1. 아이디어

서로 다른 구슬 중 일부를 고르는 경우의 수를 구하는 문제다. 구슬의 수를 $n$, 고르는 수를 $m$이라 하면 순서를 따지지 않으므로 답은 조합 $\binom{n}{m}$이다. $n$이 최대 30이라 정의대로 팩토리얼을 구해 나누면 $n!$이 64비트 정수로도 담기지 않으므로, $i$를 1부터 $m$까지 늘리며 결과에 $n - i + 1$을 곱한 뒤 $i$로 나눈다. $i$번째 단계가 끝난 값은 $\binom{n}{i}$이고 $\binom{n}{i - 1}(n - i + 1) = i\binom{n}{i}$이므로, 곱한 값이 항상 $i$로 나누어떨어져 정수 나눗셈으로도 오차가 생기지 않는다.

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int solution(int balls, int share) {
        long ans = 1;
        for (int i = 1; i <= share; i++) {
            ans = ans * (balls - i + 1) / i;
        }

        return (int) ans;
    }
}
```

`ans * (balls - i + 1)`이 `int` 범위를 넘을 수 있어 `long`을 썼다.
