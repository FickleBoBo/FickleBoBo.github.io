## 1. 아이디어

문자열의 각 알파벳을 $n$만큼 미는 문제인데, 알파벳은 26자가 원형으로 이어져 `z`를 밀면 `a`로 돌아오므로, 각 알파벳을 `a`(대문자는 `A`)로부터의 거리 0~25로 바꿔 $n$을 더한 뒤 26으로 나눈 나머지를 취하면 밀기가 된다. 소문자와 대문자는 각자의 범위 안에서만 돌아야 대소문자가 유지되고, 알파벳이 아닌 공백은 밀지 않고 그대로 둔다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public String solution(String s, int n) {
        char[] arr = s.toCharArray();
        for (int i = 0; i < arr.length; i++) {
            if ('A' <= arr[i] && arr[i] <= 'Z') {
                arr[i] = (char) ((arr[i] - 'A' + n) % 26 + 'A');
            } else if ('a' <= arr[i] && arr[i] <= 'z') {
                arr[i] = (char) ((arr[i] - 'a' + n) % 26 + 'a');
            }
        }

        return new String(arr);
    }
}
```

`char`끼리의 산술 결과가 `int`라서 `char`로 캐스팅한 뒤 배열에 다시 넣었다.

```c++
#include <bits/stdc++.h>
using namespace std;

string solution(string s, int n) {
    for (char& c : s) {
        if ('A' <= c && c <= 'Z') {
            c = (c - 'A' + n) % 26 + 'A';
        } else if ('a' <= c && c <= 'z') {
            c = (c - 'a' + n) % 26 + 'a';
        }
    }

    return s;
}
```

```python
import string


def solution(s, n):
    lower = string.ascii_lowercase
    upper = string.ascii_uppercase

    return s.translate(str.maketrans(lower + upper, lower[n:] + lower[:n] + upper[n:] + upper[:n]))
```

`str.maketrans`로 알파벳을 `n`칸 민 문자열과 짝지은 변환표를 만들어 `translate`에 넘겼고, 변환표에 없는 공백은 그대로 남는다.
