## 1. 아이디어

1부터 $N$까지의 자연수에서 같은 수를 여러 번 골라도 되는 $M$개를 비내림차순으로 놓은 수열, 즉 길이가 $M$인 중복 조합을 사전 순으로 모두 출력하는 문제다. 같은 수를 반복해도 되지만 앞 수보다 작아져서는 안 되므로 각 칸의 후보는 직전 칸에 넣은 수 이상의 수이고, 비내림차순 수열은 어떤 수를 몇 번씩 골랐는지가 정해지면 정렬된 순서 하나로만 놓이므로 구성마다 정확히 한 번씩 나온다. 그래서 백트래킹의 다음 칸 시작 값을 직전에 넣은 수 자신으로 넘긴다. 중복 없이 고르는 조합이라면 직전 수보다 하나 큰 수부터였겠지만 비내림차순은 같은 수를 다시 쓸 수 있기 때문이다.

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;
import java.util.*;

public class Main {

    static StringBuilder sb = new StringBuilder();
    static int n, m;
    static int[] sel;

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());

        n = Integer.parseInt(st.nextToken());
        m = Integer.parseInt(st.nextToken());
        sel = new int[m];

        dfs(1, 0);
        System.out.println(sb);
    }

    static void dfs(int start, int depth) {
        if (depth == m) {
            for (int x : sel) {
                sb.append(x).append(" ");
            }
            sb.append("\n");
            return;
        }

        for (int i = start; i <= n; i++) {
            sel[depth] = i;
            dfs(i, depth + 1);
        }
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int n, m;
int sel[8];

void dfs(int start, int depth) {
    if (depth == m) {
        for (int i = 0; i < m; i++) cout << sel[i] << ' ';
        cout << '\n';
        return;
    }

    for (int i = start; i <= n; i++) {
        sel[depth] = i;
        dfs(i, depth + 1);
    }
}

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    cin >> n >> m;

    dfs(1, 0);
}
```

```python
import sys
from itertools import combinations_with_replacement

input = sys.stdin.readline

n, m = map(int, input().split())
out = [" ".join(map(str, seq)) for seq in combinations_with_replacement(range(1, n + 1), m)]
print("\n".join(out))
```

`combinations_with_replacement`로 같은 원소를 다시 고를 수 있는 조합을 만들어 비내림차순 수열을 사전 순으로 얻었다.
