## 1. 아이디어

정수 `num`이 `n`의 배수인지 판별하는 문제로 `num`을 `n`으로 나눈 나머지가 0이면 배수인 것을 활용하면 된다.

---

## 2. 복잡도

| 접근 | 시간   | 공간   |
| ---- | ------ | ------ |
| 풀이 | $O(1)$ | $O(1)$ |

---

## 3. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int solution(int num, int n) {
        return num % n == 0 ? 1 : 0;
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int solution(int num, int n) {
    return num % n == 0;
}
```

```python
def solution(num, n):
    return int(num % n == 0)
```
