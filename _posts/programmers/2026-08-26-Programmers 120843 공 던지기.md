## 1. 아이디어

원형으로 선 사람들 중 1번이 처음 공을 던지고, 매번 바로 옆 사람을 건너뛰고 그다음 사람에게 던질 때 $k$번째로 공을 던지는 사람의 번호를 구하는 문제다. 공이 한 번 던져질 때마다 두 칸씩 이동하고 첫 번째로 던지는 사람에서 $k$번째로 던지는 사람까지 $k - 1$번 던져지므로, $k$번째로 던지는 사람은 처음 사람에서 $2(k - 1)$칸 떨어진 자리에 있다. 사람이 원형으로 서 있어 사람 수를 $m$이라 하면 $2(k - 1)$을 $m$으로 나눈 나머지만큼 움직인 것과 같고, 번호가 1번부터 순서대로 놓여 있으므로 그 위치의 번호가 답이다. 결국 던지는 과정을 직접 흉내 내지 않고 나머지 연산 하나로 구하면 된다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int solution(int[] numbers, int k) {
        return numbers[2 * (k - 1) % numbers.length];
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int solution(vector<int> numbers, int k) {
    return numbers[2 * (k - 1) % numbers.size()];
}
```

```python
def solution(numbers, k):
    return numbers[2 * (k - 1) % len(numbers)]
```
