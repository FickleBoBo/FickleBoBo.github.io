## 1. 아이디어

배열을 한 번 순회하며 `n`과의 절댓값 차이가 가장 작은 원소를 추적한다. 차이가 같은 원소가 나오면 더 작은 값으로 갱신한다.

---

## 2. 복잡도

| 접근 | 시간   | 공간   |
| ---- | ------ | ------ |
| 풀이 | $O(N)$ | $O(1)$ |

($N$ = `array`의 길이)

---

## 3. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int solution(int[] array, int n) {
        int ans = 0;
        int diff = 100;

        for (int x : array) {
            if (Math.abs(x - n) < diff) {
                ans = x;
                diff = Math.abs(x - n);
            } else if (Math.abs(x - n) == diff && x < ans) {
                ans = x;
            }
        }

        return ans;
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int solution(vector<int> array, int n) {
    int ans = 0;
    int diff = 100;

    for (int x : array) {
        if (abs(x - n) < diff) {
            ans = x;
            diff = abs(x - n);
        } else if (abs(x - n) == diff && x < ans) {
            ans = x;
        }
    }

    return ans;
}
```

```python
def solution(array, n):
    return min(array, key=lambda x: (abs(x - n), x))
```

`min`에 `key`로 `(abs(x - n), x)` 튜플을 넘겼다. 튜플은 앞 원소부터 차례로 비교되므로 먼저 `n`과의 절댓값 차이가 가장 작은 원소가 뽑히고, 그 차이가 같은 원소가 여럿이면 두 번째 원소인 원소값이 더 작은 쪽이 선택된다. 별도의 동점 처리 분기 없이 정렬 키 하나로 두 조건이 동시에 해결된다.
