## 1. 아이디어

각 자릿수를 다섯제곱해 더하는 문제로, $n$을 문자열로 읽어 한 글자씩 숫자로 바꾸면 나눗셈 없이 자릿수를 얻는다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        String s = br.readLine();
        int sum = 0;

        for (char c : s.toCharArray()) {
            int d = c - '0';
            sum += d * d * d * d * d;
        }

        System.out.println(sum);
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    string s;
    cin >> s;

    int sum = 0;
    for (char c : s) {
        int d = c - '0';
        sum += d * d * d * d * d;
    }

    cout << sum;
}
```

```python
import sys

input = sys.stdin.readline

print(sum(int(c) ** 5 for c in input().strip()))
```

`sys.stdin.readline`은 줄바꿈까지 읽어 오는데 줄바꿈이 `int`에 들어가면 `ValueError`가 나므로 `strip`으로 지웠다.
