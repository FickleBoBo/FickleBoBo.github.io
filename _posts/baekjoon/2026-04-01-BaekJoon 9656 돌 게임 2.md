## 1. 아이디어

돌 게임과 규칙은 같지만 이번에는 마지막 돌을 가져가는 사람이 지는 문제다. 1과 3이 모두 홀수라서 한 번 가져갈 때마다 남은 돌의 홀짝이 바뀌므로, 처음 돌이 짝수 개이면 상근이는 자기 차례마다 짝수 개를 마주하게 된다. 짝수 개가 남은 차례에는 1개나 3개를 가져가도 돌이 남아서 마지막 돌을 가져갈 수 없으니 상근이는 지지 않고, 결국 마지막 돌은 창영이가 가져가게 된다. 처음 돌이 홀수 개이면 역할이 뒤바뀌어 창영이가 이긴다. 결국 $N$이 짝수이면 `SK`, 홀수이면 `CY`를 출력하면 된다.

## 3. 코드

### 풀이 [Java][C++]

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        int n = Integer.parseInt(br.readLine());
        if (n % 2 == 0) {
            System.out.println("SK");
        } else {
            System.out.println("CY");
        }
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    int n;
    cin >> n;

    if (n % 2 == 0) {
        cout << "SK";
    } else {
        cout << "CY";
    }
}
```
