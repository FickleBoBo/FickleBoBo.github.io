## 1. 아이디어

`code`를 앞에서부터 읽으며 `"1"`이면 `mode`를 바꾸고, 아니면 `mode`에 따라 `ret`에 문자를 추가하는 문제다. `mode`가 0이면 짝수 인덱스의 문자를, 1이면 홀수 인덱스의 문자를 추가하므로 둘을 합쳐 인덱스를 2로 나눈 나머지가 `mode`와 같을 때 문자를 추가한다고 쓸 수 있다. `"1"`을 만나면 문자는 추가하지 않고 `mode`만 바꾸는데, 이때도 `"1"`이 있던 자리까지 세므로 인덱스는 항상 `code`에서의 원래 위치 기준이다.

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public String solution(String code) {
        StringBuilder ret = new StringBuilder();
        int mode = 0;

        for (int i = 0; i < code.length(); i++) {
            char c = code.charAt(i);
            if (c == '1') {
                mode = 1 - mode;
                continue;
            }

            if (i % 2 == mode) ret.append(c);
        }

        if (ret.isEmpty()) return "EMPTY";
        return ret.toString();
    }
}
```

`StringBuilder.isEmpty()`는 Java 15부터 쓸 수 있다.

```c++
#include <bits/stdc++.h>
using namespace std;

string solution(string code) {
    string ret;
    int mode = 0;

    for (int i = 0; i < code.size(); i++) {
        char c = code[i];
        if (c == '1') {
            mode = 1 - mode;
            continue;
        }

        if (i % 2 == mode) ret += c;
    }

    if (ret.empty()) return "EMPTY";
    return ret;
}
```

```python
def solution(code):
    ret = []
    mode = 0

    for i, c in enumerate(code):
        if c == "1":
            mode = 1 - mode
            continue

        if i % 2 == mode:
            ret.append(c)

    if ret:
        return "".join(ret)
    return "EMPTY"
```
