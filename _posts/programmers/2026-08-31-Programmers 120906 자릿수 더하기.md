## 1. 아이디어

정수의 각 자리 숫자를 더하는 문제다. 10으로 나눈 나머지가 가장 낮은 자리 숫자이고 몫이 그 자리를 떼어 낸 수라서, 수가 0이 될 때까지 나머지를 더하며 몫으로 넘어가면 모든 자리를 한 번씩 거친다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int solution(int n) {
        int sum = 0;
        while (n > 0) {
            sum += n % 10;
            n /= 10;
        }

        return sum;
    }
}
```

