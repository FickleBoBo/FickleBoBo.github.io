## 1. 아이디어

배열 `arr`에 담긴 문자들을 순서대로 이어 붙인 문자열을 반환하면 되는 간단한 문제다.

---

## 2. 복잡도

| 접근 | 시간   | 공간   |
| ---- | ------ | ------ |
| 풀이 | $O(N)$ | $O(N)$ |

($N$ = `arr`의 길이)

---

## 3. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public String solution(String[] arr) {
        return String.join("", arr);
    }
}
```

`String`의 `join`으로 한번에 이어붙여서 반환했다.

```c++
#include <bits/stdc++.h>
using namespace std;

string solution(vector<string> arr) {
    string ans;
    for (string& s : arr) ans += s;
    return ans;
}
```

C++는 `std::string`이 가변이므로 누적해서 더해준 후 반환했다.

```python
def solution(arr):
    return "".join(arr)
```

`join`으로 한번에 이어붙여서 반환했다.
