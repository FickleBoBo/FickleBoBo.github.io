## 1. 아이디어

문자열 `my_string`에서 중복된 문자를 제거하고 하나의 문자만 남긴 문자열을 반환하는 문제로 해시 집합을 활용하면 해결할 수 있다. `my_string`의 각 문자를 순회하며 해시 집합에 존재하지 않는 문자면 결과 문자열에 붙이고, 존재하는 문자면 건너뛰는 과정을 반복했다.

---

## 2. 복잡도

| 접근 | 시간   | 공간   |
| ---- | ------ | ------ |
| 풀이 | $O(N)$ | $O(N)$ |

($N$ = `my_string`의 길이)

---

## 3. 코드

### 풀이 [Java][C++][Python]

```java
import java.util.*;

class Solution {
    public String solution(String my_string) {
        StringBuilder sb = new StringBuilder();
        Set<Character> seen = new HashSet<>();

        for (char c : my_string.toCharArray()) {
            if (seen.add(c)) sb.append(c);
        }

        return sb.toString();
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

string solution(string my_string) {
    string s;
    unordered_set<char> seen;

    for (char c : my_string) {
        if (seen.insert(c).second) s += c;
    }

    return s;
}
```

```python
def solution(my_string):
    return "".join(dict.fromkeys(my_string))
```

`dict.fromkeys`는 문자열의 각 문자를 키로 하는 딕셔너리를 만든다. 딕셔너리 키는 중복되지 않고 삽입 순서를 유지하므로, 같은 문자는 첫 등장 자리에 하나만 남는다. 이 키들을 `join`으로 이어 붙여 결과 문자열을 얻는 방식을 활용했다.
