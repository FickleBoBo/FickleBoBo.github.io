## 1. 아이디어

첫 번째 수를 두 번째 수로 나눈 몫이므로 정수 나눗셈을 그대로 쓰면 된다. 두 수가 모두 양수라 정수 나눗셈의 몫이 곧 소수 부분을 버린 값이다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int solution(int num1, int num2) {
        return num1 / num2;
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int solution(int num1, int num2) {
    return num1 / num2;
}
```

```python
def solution(num1, num2):
    return num1 // num2
```
