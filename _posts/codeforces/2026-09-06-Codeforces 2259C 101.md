## 1. 아이디어

점수는 양 끝이 `1`이고 사이가 전부 `0`인 부분 배열의 최대 길이, 곧 사이에 다른 `1`이 없는 두 `1`을 양 끝으로 하는 구간 중 가장 긴 것의 길이이고, `-1`을 `0` 또는 `1`로 바꿔 이를 최대로 만드는 문제다. `0`이 아닌 첫 원소 앞과 `0`이 아닌 마지막 원소 뒤는 전부 `0`이라 `1`이 놓일 수 있는 범위는 그 둘 사이로 한정되고, 이미 `1`인 원소는 어떤 배치에서도 그대로 `1`이다. 이 범위 안의 `-1`을 `1`로 바꾸면 사이에 다른 `1`이 없는 두 `1`의 구간을 쪼갤 뿐 늘려 주지 않으므로 안쪽의 `-1`은 전부 `0`으로 바꾼다. 범위 양 끝의 원소는 `-1`이든 `1`이든 `1`로 놓아 구간이 가장 길어지게 하는데, 끝의 `-1`을 `0`으로 두면 그 끝을 양 끝으로 하는 구간이 아예 생기지 않아 `1`로 두는 편이 항상 이득이다. 이렇게 만든 배치의 `1`은 처음부터 있던 `1`과 범위 양 끝뿐이고, 이들로 범위를 자른 조각(이웃한 두 `1`을 양 끝으로 하는 구간) 하나하나가 이 배치의 구간이 된다. 어떤 배치에서든 구간은 이 범위 안에 있고 처음부터 있던 `1`을 사이에 품을 수 없으므로 이 조각 중 하나 안에 들어가고, 따라서 이 배치가 최선이다. `0`이 아닌 원소가 하나뿐이면 그 칸이 `1`이 되어 길이 1짜리 구간이 점수가 되고, 하나도 없으면 바꿀 것이 없어 그대로 출력한다.

## 2. 코드

### 풀이 [C++]

```c++
#include <bits/stdc++.h>
using namespace std;

void solve() {
    int n;
    cin >> n;

    vector<int> a(n);
    for (int& x : a) cin >> x;

    int s = 0, e = n - 1;
    while (s < n && a[s] == 0) s++;
    while (e >= 0 && a[e] == 0) e--;

    if (s <= e) {
        a[s] = a[e] = 1;
        for (int i = s + 1; i < e; i++) {
            if (a[i] == -1) a[i] = 0;
        }
    }

    for (int x : a) {
        cout << x << ' ';
    }
    cout << '\n';
}

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    int t;
    cin >> t;
    while (t--) solve();
}
```
