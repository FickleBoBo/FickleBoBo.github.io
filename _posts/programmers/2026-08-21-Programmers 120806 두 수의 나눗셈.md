## 1. 아이디어

정수 `num1`, `num2`가 주어질 때, `num1`을 `num2`로 나눈 값에 1,000을 곱한 결과의 정수 부분을 반환하면 되는 간단한 문제다. 나눗셈보다 곱셈을 먼저 계산해(`num1 * 1000`) 정수 나눗셈으로 처리하면, 실수 연산 없이 오차 없는 정수 부분을 구할 수 있다.

---

## 2. 복잡도

| 접근 | 시간   | 공간   |
| ---- | ------ | ------ |
| 풀이 | $O(1)$ | $O(1)$ |

---

## 3. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int solution(int num1, int num2) {
        return num1 * 1000 / num2;
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int solution(int num1, int num2) {
    return num1 * 1000 / num2;
}
```

```python
def solution(num1, num2):
    return num1 * 1000 // num2
```
