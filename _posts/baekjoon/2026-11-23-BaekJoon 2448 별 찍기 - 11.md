## 1. 아이디어

$N$이 $3 \times 2^k$일 때 프랙탈 형태로 높이 $N$의 별 삼각형을 찍는 문제다. 크기 $N$의 삼각형은 크기 $N / 2$의 삼각형 세 개를 위에 하나, 아래에 둘 놓은 모양이다. 삼각형의 크기를 $n$이라 하면 삼각형은 폭 $2n$칸의 구획을 차지하고 별은 그중 $2n - 1$칸을 쓴다. 그래서 전체 격자의 폭은 $2N$이고, 위 삼각형은 폭 $N$인 구획이 그 가운데에 오도록 구획의 왼쪽 끝을 기준으로 전체의 왼쪽 끝에서 $N / 2$칸 오른쪽에 놓이며, 아래 두 삼각형은 $N / 2$행 아래에서 구획의 왼쪽 끝이 서로 $N$칸 차이 난다. 계속 반으로 나누면 크기 3에 이르고, 크기 3은 1줄에 별 1개, 2줄에 별 2개, 3줄에 별 5개로 모두 별 8개의 모양이다.

재귀는 삼각형 단위로 그려지지만 출력은 줄 단위이므로 별이 놓이는 칸을 폭 $2N$의 격자에 먼저 표시한 뒤 줄 순서대로 출력한다.

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;

public class Main {

    static boolean[][] vis;

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        BufferedWriter bw = new BufferedWriter(new OutputStreamWriter(System.out));

        int n = Integer.parseInt(br.readLine());
        vis = new boolean[n][n * 2];

        dfs(0, 0, n);

        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n * 2; j++) {
                if (vis[i][j]) {
                    bw.write("*");
                } else {
                    bw.write(" ");
                }
            }
            bw.newLine();
        }

        bw.flush();
    }

    static void dfs(int sr, int sc, int n) {
        if (n == 3) {
            vis[sr][sc + 2] = true;
            vis[sr + 1][sc + 1] = true;
            vis[sr + 1][sc + 3] = true;
            vis[sr + 2][sc] = true;
            vis[sr + 2][sc + 1] = true;
            vis[sr + 2][sc + 2] = true;
            vis[sr + 2][sc + 3] = true;
            vis[sr + 2][sc + 4] = true;
            return;
        }

        dfs(sr, sc + n / 2, n / 2);
        dfs(sr + n / 2, sc, n / 2);
        dfs(sr + n / 2, sc + n, n / 2);
    }
}
```

```python
import sys

input = sys.stdin.readline
out = []


def dfs(sr, sc, n):
    if n == 3:
        vis[sr][sc + 2] = True
        vis[sr + 1][sc + 1] = True
        vis[sr + 1][sc + 3] = True
        vis[sr + 2][sc] = True
        vis[sr + 2][sc + 1] = True
        vis[sr + 2][sc + 2] = True
        vis[sr + 2][sc + 3] = True
        vis[sr + 2][sc + 4] = True
        return
    dfs(sr, sc + n // 2, n // 2)
    dfs(sr + n // 2, sc, n // 2)
    dfs(sr + n // 2, sc + n, n // 2)


n = int(input())

vis = [[False] * (n * 2) for _ in range(n)]
dfs(0, 0, n)

for row in vis:
    out.append("".join("*" if x else " " for x in row))

print("\n".join(out))
```
