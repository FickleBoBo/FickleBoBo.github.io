## 1. 아이디어

분수 $a / b$가 유한소수인지 판별하는 문제로, 기약분수의 분모가 2와 5 이외의 소인수를 갖지 않을 때 유한소수다. 약분 전의 분모에는 분자와 공유하는 소인수가 남아 있을 수 있으므로(분수 $11 / 22$의 분모 22는 소인수 11을 갖지만 약분하면 $1 / 2$다) 먼저 $b$를 $\gcd(a, b)$로 나눠 기약분수의 분모를 구하고, 그 분모에서 소인수 2와 5를 가능한 만큼 걷어 낸다. 다른 소인수가 있으면 1이 아닌 값이 남고 없으면 1이 되므로 남은 값이 1인지로 판정한다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int solution(int a, int b) {
        int q = b / gcd(a, b);
        while (q % 2 == 0) {
            q /= 2;
        }
        while (q % 5 == 0) {
            q /= 5;
        }

        return q == 1 ? 1 : 2;
    }

    static int gcd(int a, int b) {
        if (b == 0) return a;
        return gcd(b, a % b);
    }
}
```

`gcd`는 유클리드 호제법으로 직접 구현했다.

```c++
#include <bits/stdc++.h>
using namespace std;

int solution(int a, int b) {
    int q = b / gcd(a, b);
    while (q % 2 == 0) q /= 2;
    while (q % 5 == 0) q /= 5;

    return q == 1 ? 1 : 2;
}
```

`std::gcd`로 최대공약수를 직접 구현하지 않고 구했다.

```python
import math


def solution(a, b):
    q = b // math.gcd(a, b)
    while q % 2 == 0:
        q //= 2
    while q % 5 == 0:
        q //= 5

    return 1 if q == 1 else 2
```

`math.gcd`로 최대공약수를 직접 구현하지 않고 구했다.
