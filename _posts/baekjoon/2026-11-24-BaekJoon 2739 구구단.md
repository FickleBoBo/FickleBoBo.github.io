## 1. 아이디어

$N$에 1부터 9까지 곱한 결과를 지문의 출력 형식(곱셈 기호는 `*`)에 맞춰 줄마다 출력한다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        int n = Integer.parseInt(br.readLine());
        for (int i = 1; i <= 9; i++) {
            System.out.printf("%d * %d = %d\n", n, i, n * i);
        }
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    int n;
    cin >> n;

    for (int i = 1; i <= 9; i++) {
        cout << n << " * " << i << " = " << n * i << '\n';
    }
}
```

```python
import sys

input = sys.stdin.readline

n = int(input())
for i in range(1, 10):
    print(f"{n} * {i} = {n * i}")
```
