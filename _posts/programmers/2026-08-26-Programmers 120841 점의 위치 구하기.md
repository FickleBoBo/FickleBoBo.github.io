## 1. 아이디어

점이 축 위에 놓이지 않음이 보장되므로, `x`와 `y`가 각각 양수인지 음수인지만 따지면 사분면이 하나로 정해진다.

- `x`가 양수면 `y`가 양수일 때 1사분면, 음수일 때 4사분면이다.
- `x`가 음수면 `y`가 양수일 때 2사분면, 음수일 때 3사분면이다.

---

## 2. 복잡도

| 접근 | 시간   | 공간   |
| ---- | ------ | ------ |
| 풀이 | $O(1)$ | $O(1)$ |

---

## 3. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int solution(int[] dot) {
        int x = dot[0], y = dot[1];

        if (x > 0) {
            if (y > 0) {
                return 1;
            } else {
                return 4;
            }
        } else {
            if (y > 0) {
                return 2;
            } else {
                return 3;
            }
        }
    }
}
```
