## 1. 아이디어

영어 대소문자로 이루어진 문자열 `my_string`에 대해 전부 소문자로 변환 후 알파벳 순서대로 정렬한 문자열을 반환하면 되는 간단한 문제다.

---

## 2. 복잡도

| 접근 | 시간          | 공간   |
| ---- | ------------- | ------ |
| 풀이 | $O(N \log N)$ | $O(N)$ |

($N$ = `my_string`의 길이. C++는 인자를 제자리 수정해 반환하므로 공간 $O(1)$)

---

## 3. 코드

### 풀이 [Java][C++][Python]

```java
import java.util.*;

class Solution {
    public String solution(String my_string) {
        char[] arr = my_string.toLowerCase().toCharArray();
        Arrays.sort(arr);
        return new String(arr);
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

string solution(string my_string) {
    for (char& c : my_string) c = tolower(c);
    sort(my_string.begin(), my_string.end());
    return my_string;
}
```

```python
def solution(my_string):
    return "".join(sorted(my_string.lower()))
```
