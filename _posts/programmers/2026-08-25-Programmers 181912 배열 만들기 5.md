## 1. 아이디어

각 문자열에서 인덱스 $s$부터 길이 $l$만큼 잘라 정수로 바꾸고, $k$보다 큰 것만 순서대로 모은다. $l$이 8 이하라 잘라낸 값은 최대 8자리여서 32비트 정수로 바꿔도 넘치지 않는다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.util.*;

class Solution {
    public int[] solution(String[] intStrs, int k, int s, int l) {
        List<Integer> list = new ArrayList<>();
        for (String intStr : intStrs) {
            int x = Integer.parseInt(intStr.substring(s, s + l));
            if (x > k) list.add(x);
        }

        return list.stream().mapToInt(Integer::intValue).toArray();
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

vector<int> solution(vector<string> intStrs, int k, int s, int l) {
    vector<int> v;
    for (string& intStr : intStrs) {
        int x = stoi(intStr.substr(s, l));
        if (x > k) v.push_back(x);
    }

    return v;
}
```

```python
def solution(intStrs, k, s, l):
    ans = []
    for int_str in intStrs:
        x = int(int_str[s : s + l])
        if x > k:
            ans.append(x)

    return ans
```
