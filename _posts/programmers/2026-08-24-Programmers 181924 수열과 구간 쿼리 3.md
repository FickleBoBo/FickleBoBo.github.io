## 1. 아이디어

각 쿼리는 두 인덱스로 이루어져 있고, 두 인덱스에 해당하는 `arr`의 원소를 서로 바꾸면 된다. 쿼리 개수만큼 반복하면서 두 위치를 스왑하면 끝나는 간단한 구현 문제다.

---

## 2. 복잡도

| 접근 | 시간   | 공간   |
| ---- | ------ | ------ |
| 풀이 | $O(Q)$ | $O(1)$ |

($Q$ = `queries`의 길이)

---

## 3. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int[] solution(int[] arr, int[][] queries) {
        for (int[] q : queries) {
            int tmp = arr[q[0]];
            arr[q[0]] = arr[q[1]];
            arr[q[1]] = tmp;
        }

        return arr;
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

vector<int> solution(vector<int> arr, vector<vector<int>> queries) {
    for (auto& q : queries) {
        swap(arr[q[0]], arr[q[1]]);
    }

    return arr;
}
```

```python
def solution(arr, queries):
    for i, j in queries:
        arr[i], arr[j] = arr[j], arr[i]

    return arr
```
