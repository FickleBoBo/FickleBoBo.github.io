## 1. 아이디어

1부터 세는 `n` 번째 원소는 0-indexed로 `n - 1` 위치이므로, `num_list`를 `n - 1`부터 끝까지 잘라내면 된다.

---

## 2. 복잡도

| 접근 | 시간   | 공간   |
| ---- | ------ | ------ |
| 풀이 | $O(N)$ | $O(N)$ |

($N$ = `num_list`의 길이)

---

## 3. 코드

### 풀이 [Java][C++][Python]

```java
import java.util.*;

class Solution {
    public int[] solution(int[] num_list, int n) {
        return Arrays.copyOfRange(num_list, n - 1, num_list.length);
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

vector<int> solution(vector<int> num_list, int n) {
    return vector<int>(num_list.begin() + n - 1, num_list.end());
}
```

```python
def solution(num_list, n):
    return num_list[n - 1 :]
```
