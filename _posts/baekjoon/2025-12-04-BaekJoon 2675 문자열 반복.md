## 1. 아이디어

각 문자열 $S$의 각 문자를 $R$번 반복한 문자열 $P$를 출력하는 문제로 문자열의 각 문자에 접근만 할 줄 알면 간단하게 해결할 수 있다.

---

## 2. 복잡도

| 접근 | 시간                     | 공간   |
| ---- | ------------------------ | ------ |
| 풀이 | $O(T \times L \times R)$ | $O(L)$ |

($T$ = 테스트 케이스 수, $L$ = 케이스당 `s`의 길이의 최댓값, $R$ = 케이스당 `r`의 최댓값)

---

## 3. 코드

### 풀이 [Java][C++]

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringBuilder sb = new StringBuilder();
        StringTokenizer st;

        int t = Integer.parseInt(br.readLine());
        while (t-- > 0) {
            st = new StringTokenizer(br.readLine());
            int r = Integer.parseInt(st.nextToken());
            String s = st.nextToken();

            for (char c : s.toCharArray()) {
                sb.repeat(c, r);
            }
            sb.append("\n");
        }

        System.out.println(sb);
    }
}
```

`StringBuilder`의 `repeat` 메서드로 각 문자를 `r`번 이어붙이는 방식으로 해결했다.

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    int t;
    cin >> t;

    while (t--) {
        int r;
        string s;
        cin >> r >> s;

        for (char c : s) {
            cout << string(r, c);
        }
        cout << '\n';
    }
}
```

`std::string`의 생성자를 활용해서 문자열 반복을 하는 방식으로 해결했다.
