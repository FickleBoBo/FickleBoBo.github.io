## 1. 아이디어

두 자연수의 곱이 `n`이 되는 순서쌍 $(a, b)$의 개수를 구하는 문제다. $a$가 정해지면 $b = n / a$도 함께 정해지므로, 곱이 `n`이 되는 $a$는 결국 `n`의 약수여야 한다. 즉 구하는 순서쌍의 개수는 `n`의 약수 개수와 같다.

가장 단순한 방법은 `1`부터 `n`까지 모든 정수 `i`에 대해 `n`이 `i`로 나누어떨어지는지 확인하며 약수 개수를 세는 것이다.

약수는 $\sqrt{n}$을 기준으로 대칭적으로 나타난다 — `i`가 약수면 `n / i`도 약수이므로, `i`를 `1`부터 $\sqrt{n}$까지만 순회하면서 약수 쌍을 세면 더 적은 연산으로 같은 결과를 얻을 수 있다. 이때 `i`와 `n / i`가 같은 경우(`n`이 완전제곱수이고 `i`가 그 제곱근일 때)엔 같은 약수를 두 번 세지 않도록 한 번만 세야 한다.

---

## 2. 복잡도

| 접근          | 시간          | 공간   |
| ------------- | ------------- | ------ |
| 완전탐색      | $O(N)$        | $O(1)$ |
| 약수의 대칭성 | $O(\sqrt{N})$ | $O(1)$ |

($N$ = 주어지는 자연수 `n`)

---

## 3. 코드

### 풀이: 완전탐색 [Java][C++][Python]

```java
class Solution {
    public int solution(int n) {
        int cnt = 0;
        for (int i = 1; i <= n; i++) {
            if (n % i == 0) cnt++;
        }

        return cnt;
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int solution(int n) {
    int cnt = 0;
    for (int i = 1; i <= n; i++) {
        if (n % i == 0) cnt++;
    }

    return cnt;
}
```

```python
def solution(n):
    return sum(n % i == 0 for i in range(1, n + 1))
```

### 풀이 2: 약수의 대칭성(제곱근 최적화) [Java][C++][Python]

```java
class Solution {
    public int solution(int n) {
        int cnt = 0;
        for (int i = 1; i * i <= n; i++) {
            if (n % i == 0) {
                cnt++;
                if (i != n / i) cnt++;
            }
        }

        return cnt;
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int solution(int n) {
    int cnt = 0;
    for (int i = 1; i * i <= n; i++) {
        if (n % i == 0) {
            cnt++;
            if (i != n / i) cnt++;
        }
    }

    return cnt;
}
```

```python
import math


def solution(n):
    cnt = 0
    for i in range(1, math.isqrt(n) + 1):
        if n % i == 0:
            cnt += 1
            if i != n // i:
                cnt += 1

    return cnt
```
