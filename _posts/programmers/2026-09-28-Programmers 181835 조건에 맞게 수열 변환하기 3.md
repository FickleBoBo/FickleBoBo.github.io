## 1. 아이디어

$k$가 홀수면 모든 원소에 $k$를 곱하고 짝수면 더하는 문제다. 모든 원소에 같은 연산을 하므로 $k$의 홀짝은 한 번만 가리면 되고, 원소와 $k$가 100 이하라 곱해도 최대 $100 \times 100 = 10{,}000$이라 범위 걱정이 없다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int[] solution(int[] arr, int k) {
        if (k % 2 != 0) {
            for (int i = 0; i < arr.length; i++) {
                arr[i] *= k;
            }
        } else {
            for (int i = 0; i < arr.length; i++) {
                arr[i] += k;
            }
        }

        return arr;
    }
}
```

`arr`를 새로 만들지 않고 제자리에서 바꿔 반환했다.

```c++
#include <bits/stdc++.h>
using namespace std;

vector<int> solution(vector<int> arr, int k) {
    if (k % 2) {
        for (int& x : arr) x *= k;
    } else {
        for (int& x : arr) x += k;
    }

    return arr;
}
```

`int&`로 순회해 `arr`의 원소를 직접 바꿨다. `arr`는 값으로 받은 복사본이라 호출한 쪽의 배열은 그대로다.

```python
def solution(arr, k):
    if k % 2:
        return [x * k for x in arr]
    else:
        return [x + k for x in arr]
```
