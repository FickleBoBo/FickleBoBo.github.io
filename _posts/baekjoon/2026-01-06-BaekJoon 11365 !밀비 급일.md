## 1. 아이디어

`"END"`가 나오기 전까지 주어진 각 라인을 뒤집어서 출력만 하면 된다. 내장 함수를 활용하면 간단하게 해결할 수 있다.

---

## 2. 복잡도

| 접근 | 시간            | 공간   |
| ---- | --------------- | ------ |
| 풀이 | $O(T \times L)$ | $O(L)$ |

($T$ = 종료 줄을 제외한 테스트 케이스 수, $L$ = 케이스당 `line`의 길이의 최댓값)

---

## 3. 코드

### 풀이 [Java][C++]

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        BufferedWriter bw = new BufferedWriter(new OutputStreamWriter(System.out));

        while (true) {
            String line = br.readLine();
            if (line.equals("END")) break;

            bw.write(new StringBuilder(line).reverse().toString());
            bw.newLine();
        }

        bw.flush();
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    while (true) {
        string line;
        getline(cin, line);

        if (line == "END") break;

        reverse(line.begin(), line.end());
        cout << line << '\n';
    }
}
```
