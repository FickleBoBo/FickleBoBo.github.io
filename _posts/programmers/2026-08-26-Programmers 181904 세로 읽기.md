## 1. 아이디어

한 줄에 `m` 글자씩 적으면 같은 열의 글자들은 인덱스가 정확히 `m`씩 차이 난다. 1-indexed로 `c`번째 열의 첫 글자는 0-indexed 기준 `c - 1`번 인덱스이므로, `c - 1`에서 출발해 `m`씩 증가시키며 문자열 끝까지 문자를 모아 이어 붙이면 된다.

---

## 2. 복잡도

| 접근 | 시간   | 공간   |
| ---- | ------ | ------ |
| 풀이 | $O(N)$ | $O(N)$ |

($N$ = `my_string`의 길이, $M$ = `m`. 결과 문자열의 길이는 $N / M$이다)

---

## 3. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public String solution(String my_string, int m, int c) {
        StringBuilder sb = new StringBuilder();
        for (int i = c - 1; i < my_string.length(); i += m) {
            sb.append(my_string.charAt(i));
        }

        return sb.toString();
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

string solution(string my_string, int m, int c) {
    string s;
    for (int i = c - 1; i < my_string.size(); i += m) {
        s += my_string[i];
    }

    return s;
}
```

```python
def solution(my_string, m, c):
    return my_string[c - 1 :: m]
```
