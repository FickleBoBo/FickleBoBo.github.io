## 1. 아이디어

별이 1개에서 $2N - 1$개까지 늘었다가 다시 줄어드는 $2N - 1$줄의 마름모다. 예제처럼 별은 항상 $N$번째 열을 중심으로 대칭이므로 별이 놓이는 구간의 왼쪽 끝 열을 $l$, 오른쪽 끝 열을 $r$이라 하면 앞 공백은 $l - 1$개이고 첫 줄은 $l = r = N$이다.

줄마다 $l$을 1 줄이고 $r$을 1 늘리면 구간이 넓어져 $N$번째 줄에서 $l = 1$, $r = 2N - 1$로 가장 넓어지고, 그 뒤로는 반대로 한 칸씩 좁아진다.

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringBuilder sb = new StringBuilder();

        int n = Integer.parseInt(br.readLine());

        int l = n, r = n;
        for (int i = 1; i <= 2 * n - 1; i++) {
            for (int j = 1; j < l; j++) {
                sb.append(" ");
            }
            for (int j = l; j <= r; j++) {
                sb.append("*");
            }
            sb.append("\n");

            if (i < n) {
                l--;
                r++;
            } else {
                l++;
                r--;
            }
        }

        System.out.println(sb);
    }
}
```

        l -= 1
        r += 1

        l += 1
