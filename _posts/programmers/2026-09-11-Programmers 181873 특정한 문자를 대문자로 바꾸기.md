## 1. 아이디어

문자열에서 주어진 소문자 한 글자와 같은 글자를 전부 대문자로 바꾸는 문제다. 글자 하나를 바꾸는 일이 다른 글자에 영향을 주지 않으므로 같은 글자인 곳만 대문자로 바꾸면 되고, 그 글자가 문자열에 없으면 아무것도 바뀌지 않아 원본이 그대로 나온다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public String solution(String my_string, String alp) {
        return my_string.replace(alp, alp.toUpperCase());
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

string solution(string my_string, string alp) {
    for (char& c : my_string) {
        if (c == alp[0]) c = toupper(c);
    }

    return my_string;
}
```

`char&`로 문자열을 순회하며 해당 글자에만 `std::toupper`를 적용해 제자리에서 바꿨다.

```python
def solution(my_string, alp):
    return my_string.replace(alp, alp.upper())
```
