## 1. 아이디어

첫 번째 수에서 두 번째 수를 뺀 값을 그대로 반환하면 되는 문제다. 순서가 바뀌면 부호가 반대가 되므로 빼는 순서만 지킨다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int solution(int num1, int num2) {
        return num1 - num2;
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int solution(int num1, int num2) {
    return num1 - num2;
}
```

```python
def solution(num1, num2):
    return num1 - num2
```
