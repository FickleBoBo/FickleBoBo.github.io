## 1. 아이디어

문자열을 $k$번 이어 붙인 것이 답이다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public String solution(String my_string, int k) {
        return my_string.repeat(k);
    }
}
```

`String.repeat`는 Java 11부터 쓸 수 있다.

```c++
#include <bits/stdc++.h>
using namespace std;

string solution(string my_string, int k) {
    string s;
    while (k--) s += my_string;
    return s;
}
```

C++에는 문자열을 반복하는 함수가 없어 `+=`를 `k`번 되풀이했다.

```python
def solution(my_string, k):
    return my_string * k
```

문자열에 정수를 곱하면 그만큼 반복되는 점을 이용했다.
