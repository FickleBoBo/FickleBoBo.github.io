## 1. 아이디어

별이 1개, 3개, 5개, ...로 늘어나는 가운데 정렬 삼각형이다. 별은 가운데 열을 중심으로 대칭이고, 마지막 줄의 별이 $2N - 1$개로 1번째 열에서 시작하므로 그 가운데 열은 $N$번째 열이다. 줄마다 별이 2개씩 늘어나는 동안 왼쪽 끝은 한 칸씩 왼쪽으로, 오른쪽 끝은 한 칸씩 오른쪽으로 옮겨 가므로, 위에서부터 $i$번째 줄은 별이 $2i - 1$개이고 왼쪽 끝이 $N - i + 1$번째 열이라 앞 공백이 $N - i$개다.

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringBuilder sb = new StringBuilder();

        int n = Integer.parseInt(br.readLine());

        for (int i = 1; i <= n; i++) {
            for (int j = 1; j <= n - i; j++) {
                sb.append(" ");
            }
            for (int j = 1; j <= 2 * i - 1; j++) {
                sb.append("*");
            }
            sb.append("\n");
        }

        System.out.println(sb);
    }
}
```

```python
import sys

input = sys.stdin.readline

n = int(input())

out = []
for i in range(1, n + 1):
    out.append(" " * (n - i) + "*" * (2 * i - 1))

print("\n".join(out))
```
