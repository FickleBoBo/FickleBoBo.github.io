## 1. 아이디어

`00`과 `1` 타일로 길이 $N$인 수열을 만드는 가짓수를 15746으로 나눈 나머지를 구하는 문제이다. 만들 수 있는 수열은 연속한 `0`의 길이가 항상 짝수이고, 왼쪽부터 읽으며 `0`을 만날 때마다 그 `0`과 다음 `0`이 `00` 타일이 되므로 타일 배치와 일대일로 대응한다. 길이 $N$의 수열은 마지막 타일이 `1`이어서 앞에 길이 $N - 1$이 오거나, `00`이어서 앞에 길이 $N - 2$가 오는 두 경우로 겹치지 않게 나뉜다. 그래서 길이 $N$의 수열 수를 $f(N)$이라 하면 $f(N) = f(N - 1) + f(N - 2)$이고 $f(1) = 1$, $f(2) = 2$(`00`, `11`)이다. 덧셈뿐이라 매 항마다 15746으로 나눈 나머지를 취해도 최종 나머지는 같다.

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;

public class Main {

    static final int MOD = 15746;

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        int n = Integer.parseInt(br.readLine());

        int[] dp = new int[1 + n + 1];
        dp[1] = 1;
        dp[2] = 2;
        for (int i = 3; i <= n; i++) {
            dp[i] = (dp[i - 2] + dp[i - 1]) % MOD;
        }

        System.out.println(dp[n]);
    }
}
```

`n`이 1일 때도 `dp[2]`에 값을 넣으므로 크기를 `1 + n + 1`로 잡아 인덱스를 벗어나지 않게 했다.

```c++
#include <bits/stdc++.h>

    for (int i = 3; i <= n; i++) {
        dp[i] = (dp[i - 2] + dp[i - 1]) % MOD;
    }

    cout << dp[n];
}
```
