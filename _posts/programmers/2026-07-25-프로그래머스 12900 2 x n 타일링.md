## 1. 아이디어

전형적인 타일링 문제로 다이나믹 프로그래밍을 활용하면 해결할 수 있다.

가로 길이가 $N$ 인 바닥을 채우는 경우는, 가로 길이가 $N - 2$ 인 바닥을 채우는 경우들에서 오른쪽 끝에 타일을 가로로 배치한 경우이거나, 가로 길이가 $N - 1$ 인 바닥을 채우는 경우들에서 오른쪽 끝에 타일을 세로로 배치한 경우 중 하나이다. 따라서 가로 길이가 $N$ 인 바닥을 채우는 경우의 수를 `dp[N]`이라 할 때, `dp[N] = dp[N - 2] + dp[N - 1]`이 된다.

가로 길이가 $1$ 인 경우는 세로로 배치하는 한 가지, 가로 길이가 $2$ 인 경우는 세로로 배치하는 한 가지와 가로로 배치하는 한 가지 총 두 가지가 있으며, 이후로는 위 점화식을 통해 타일링의 수를 구할 수 있다.

## 2. 복잡도

| 시간복잡도 | 공간복잡도 |
| :--------: | :--------: |
|   $O(N)$   |   $O(N)$   |

> $N$ = 바닥의 가로 길이(매개변수 `n`)

## 3. 코드

### 풀이 [Java][C++]

경우의 수가 많아질 수 있어 1,000,000,007로 나눈 나머지를 return 해야 하는데 오버플로우에 주의해야 한다. MOD 연산의 경우 미리 수행해도 상관없기 때문에 dp 테이블을 갱신하는 과정에서 미리 수행해줬다.

```java
class Solution {

    static int MOD = 1_000_000_007;

    public int solution(int n) {
        int[] dp = new int[1 + 60000];
        dp[1] = 1;
        dp[2] = 2;

        for (int i = 3; i <= n; i++) {
            dp[i] = (dp[i - 2] + dp[i - 1]) % MOD;
        }

        return dp[n];
    }
}
```

```c++
const int MOD = 1'000'000'007;
int dp[1 + 60000] = {0, 1, 2};

int solution(int n) {
    for (int i = 3; i <= n; i++) {
        dp[i] = (dp[i - 2] + dp[i - 1]) % MOD;
    }

    return dp[n];
}
```
