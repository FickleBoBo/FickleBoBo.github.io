## 1. 아이디어

정수 배열 `arr`의 길이가 홀수라면 모든 짝수 인덱스 위치에 `n`을 더하고, 길이가 짝수라면 모든 홀수 인덱스 위치에 `n`을 더한 후 반환하는 문제로 배열의 길이를 2로 나눈 나머지와 인덱스를 2로 나눈 나머지를 비교하는 방식으로 `n`을 더할지 판단하면 된다.

---

## 2. 복잡도

| 접근 | 시간   | 공간   |
| ---- | ------ | ------ |
| 풀이 | $O(N)$ | $O(1)$ |

($N$ = `arr`의 길이. Python은 새 리스트를 만들어 반환해 공간 $O(N)$)

---

## 3. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int[] solution(int[] arr, int n) {
        for (int i = 0; i < arr.length; i++) {
            if (arr.length % 2 != i % 2) arr[i] += n;
        }

        return arr;
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

vector<int> solution(vector<int> arr, int n) {
    for (int i = 0; i < arr.size(); i++) {
        if (arr.size() % 2 != i % 2) arr[i] += n;
    }

    return arr;
}
```

```python
def solution(arr, n):
    return [x + n if len(arr) % 2 != i % 2 else x for i, x in enumerate(arr)]
```
