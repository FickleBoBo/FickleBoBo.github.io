## 1. 아이디어

$N$번째 감소하는 수를 구하는 문제다. 감소하는 수는 자릿수가 왼쪽부터 줄어드는 수이므로 서로 다른 숫자를 내림차순으로 늘어놓은 것과 같다. 0부터 9까지 열 개의 숫자에서 비어 있지 않은 부분집합 하나가 감소하는 수 하나에 대응하니 감소하는 수는 모두 $2^{10} - 1 = 1{,}023$개뿐이다. 0이 0번째이므로 이 수들은 0번째부터 1,022번째까지 있고, $N$이 1,022를 넘으면 $N$번째 수는 없다. 후보가 이렇게 적으므로 전부 만든 뒤 정렬해 $N$번째를 고르면 된다.

만드는 방법은 DFS로, 현재 수의 일의 자리보다 작은 숫자만 뒤에 붙인다. 이렇게 만든 수는 항상 감소하는 수이고, 한 수가 만들어지는 경로는 마지막 자리를 떼어 가며 거슬러 올라가는 하나뿐이라 중복이 없다. 감소하는 수는 마지막 자리를 떼어도 감소하는 수이므로 한 자리 수에서 시작해 한 자리씩 붙여 가며 모든 감소하는 수에 닿는다.

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;
import java.util.*;

public class Main {

    static List<Long> list = new ArrayList<>();

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        int n = Integer.parseInt(br.readLine());
        for (int i = 0; i <= 9; i++) {
            dfs(i);
        }

        if (n >= list.size()) {
            System.out.println(-1);
            return;
        }

        list.sort(Comparator.naturalOrder());
        System.out.println(list.get(n));
    }

    static void dfs(long cur) {
        list.add(cur);
        for (int i = 0; i < cur % 10; i++) {
            dfs(cur * 10 + i);
        }
    }
}
```

가장 큰 감소하는 수 9876543210이 `int` 범위를 넘어 `long`을 썼다.

```c++
#include <bits/stdc++.h>
using namespace std;

vector<long long> v;

void dfs(long long cur) {
    v.push_back(cur);
    for (int i = 0; i < cur % 10; i++) {
        dfs(cur * 10 + i);
    }
}

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    int n;
    cin >> n;

    for (int i = 0; i <= 9; i++) {
        dfs(i);
    }

    if (n >= v.size()) {
        cout << -1;
        return 0;
    }

    sort(v.begin(), v.end());
    cout << v[n];
}
```

```python
import sys

input = sys.stdin.readline

res = []


def dfs(cur):
    res.append(cur)
    for i in range(cur % 10):
        dfs(cur * 10 + i)


n = int(input())
for i in range(10):
    dfs(i)

if n >= len(res):
    print(-1)
else:
    res.sort()
    print(res[n])
```
