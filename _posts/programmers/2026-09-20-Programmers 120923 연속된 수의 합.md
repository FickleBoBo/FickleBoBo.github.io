## 1. 아이디어

합이 주어진 값이 되는 연속한 정수 수열을 구하는 문제다. 항의 개수를 $n$, 합을 $S$라 하면 연속한 정수는 공차가 1인 등차수열이라 평균이 수열의 한가운데에 놓이고, 합이 평균에 $n$을 곱한 값이므로 평균은 $S / n$이다. 첫 수는 한가운데에서 $(n - 1) / 2$만큼 왼쪽이므로 $S / n - (n - 1) / 2$이고, 여기서부터 $n$개를 차례로 늘어놓으면 된다. 해가 있는 입력만 주어지므로 $n$이 짝수이면 $S / n$과 $(n - 1) / 2$가 모두 소수부 0.5를 가지며, 정수 나눗셈으로 각각 내림해 구해도 둘의 차는 그대로다.

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int[] solution(int num, int total) {
        int[] arr = new int[num];
        int a = total / num - (num - 1) / 2;
        for (int i = 0; i < num; i++) {
            arr[i] = a + i;
        }

        return arr;
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

vector<int> solution(int num, int total) {
    vector<int> v(num);
    iota(v.begin(), v.end(), total / num - (num - 1) / 2);
    return v;
}
```

`std::iota`로 첫 수부터 1씩 커지는 값을 채웠다.

```python
def solution(num, total):
    a = total // num - (num - 1) // 2
    return list(range(a, a + num))
```
