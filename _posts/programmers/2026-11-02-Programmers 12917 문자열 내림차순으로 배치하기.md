## 1. 아이디어

문자열의 문자를 큰 것부터 작은 순으로 정렬하는 문제로, 대문자를 소문자보다 작다고 간주한다. 이 규칙은 문자 코드(ASCII)의 크기 순서와 같으므로 비교 규칙을 따로 만들 필요 없이 문자 코드 기준으로 내림차순 정렬하면 된다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.util.*;

class Solution {
    public String solution(String s) {
        char[] arr = s.toCharArray();
        Arrays.sort(arr);
        return new StringBuilder(new String(arr)).reverse().toString();
    }
}
```

`char[]`에는 `Comparator`를 받는 `Arrays.sort`가 없어 오름차순으로 정렬한 뒤 뒤집었다.

```c++
#include <bits/stdc++.h>
using namespace std;

string solution(string s) {
    sort(s.rbegin(), s.rend());
    return s;
}
```

`std::sort`에 역방향 이터레이터 `rbegin`, `rend`를 넘겨 따로 뒤집지 않고 바로 내림차순으로 정렬했다.

```python
def solution(s):
    return "".join(sorted(s, reverse=True))
```
