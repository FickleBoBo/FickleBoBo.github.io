## 1. 아이디어

$N$마리 중 $N / 2$마리를 골랐을 때 서로 다른 종류의 최대 개수를 구하는 문제다. 종류의 수를 $K$라 하면 고른 종류는 $K$를 넘을 수 없고, 고른 마리 수가 $N / 2$이므로 $N / 2$도 넘을 수 없다. 이 두 값 중 작은 쪽은 항상 달성된다. $K \le N / 2$이면 종류마다 한 마리씩 고르고 나머지는 아무 폰켓몬으로 채우면 되며(전체가 $N$마리라 채울 폰켓몬이 남아 있다), $K > N / 2$이면 서로 다른 종류에서 한 마리씩만 $N / 2$마리를 고르면 된다. 그러므로 답은 $\min(K, N / 2)$이고, 필요한 것은 종류의 수뿐이라 중복을 제거해 센다.

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.util.*;

class Solution {
    public int solution(int[] nums) {
        Set<Integer> set = new HashSet<>();
        for (int x : nums) {
            set.add(x);
        }

        return Math.min(set.size(), nums.length / 2);
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int solution(vector<int> nums) {
    return min(unordered_set(nums.begin(), nums.end()).size(), nums.size() / 2);
}
```

```python
def solution(nums):
    return min(len(set(nums)), len(nums) // 2)
```
