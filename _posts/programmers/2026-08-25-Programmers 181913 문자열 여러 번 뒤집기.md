## 1. 아이디어

쿼리 순서대로 구간 $[s, e]$를 직접 뒤집으면 된다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public String solution(String my_string, int[][] queries) {
        char[] arr = my_string.toCharArray();
        for (int[] q : queries) {
            reverse(arr, q[0], q[1]);
        }

        return new String(arr);
    }

    static void reverse(char[] arr, int l, int r) {
        while (l < r) {
            char tmp = arr[l];
            arr[l] = arr[r];
            arr[r] = tmp;
            l++;
            r--;
        }
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

string solution(string my_string, vector<vector<int>> queries) {
    for (auto& q : queries) {
        reverse(my_string.begin() + q[0], my_string.begin() + q[1] + 1);
    }

    return my_string;
}
```

`std::reverse`는 끝 이터레이터를 포함하지 않아 `q[1] + 1`을 넘겼다.

```python
def solution(my_string, queries):
    s = list(my_string)
    for l, r in queries:
        s[l : r + 1] = s[l : r + 1][::-1]

    return "".join(s)
```

문자열은 바꿀 수 없어 리스트로 바꾼 뒤, 구간을 뒤집은 슬라이스를 같은 구간에 대입했다.
