## 1. 아이디어

문자열 $S$에 포함된 정수는 콤마로 구분된다. 따라서 정수의 개수는 콤마를 기준으로 파싱을 해도 되고 그냥 콤마의 수 +1로 구해도 된다.

---

## 2. 복잡도

| 접근 | 시간   | 공간   |
| ---- | ------ | ------ |
| 풀이 | $O(N)$ | $O(N)$ |

($N$ = 입력 문자열의 길이)

---

## 3. 코드

### 풀이 [Java][C++]

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        String[] line = br.readLine().split(",");
        System.out.println(line.length);
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    string line;
    cin >> line;
    cout << count(line.begin(), line.end(), ',') + 1;
}
```
