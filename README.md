> back to basics

[**FickleBoBo.github.io**](https://ficklebobo.github.io) — 개발/IT 전반을 기록하는 개인 기술 블로그. 지금은 PS(프로그래머스·리트코드·코드포스) 풀이 위주지만 점차 넓혀갈 예정입니다. [Jekyll](https://jekyllrb.com/) + [Chirpy](https://github.com/cotes2020/jekyll-theme-chirpy) 테마로 만들었고, GitHub Actions로 자동 빌드·배포됩니다.

## 구성

- PS 풀이 소스 원본은 [`PS`](https://github.com/FickleBoBo/PS) 레포에서 관리하고, 이 레포에는 정리된 포스트만 발행합니다.
- PS 포스트 작성 파이프라인은 `.claude/skills/`의 스킬(`/ps` → `/review` → `/tag` → `/publish`)로 반자동화되어 있습니다.
