## 1. 아이디어

배열의 길이가 홀수이면 짝수 인덱스에, 짝수이면 홀수 인덱스에 $n$을 더하는 문제다(인덱스는 0부터 센다). 두 경우는 인덱스의 홀짝이 배열 길이의 홀짝과 다른 위치에 더한다는 하나의 조건으로 합쳐지므로 경우를 나눌 필요가 없다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int[] solution(int[] arr, int n) {
        for (int i = 0; i < arr.length; i++) {
            if (arr.length % 2 != i % 2) arr[i] += n;
        }

        return arr;
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

vector<int> solution(vector<int> arr, int n) {
    for (int i = 0; i < arr.size(); i++) {
        if (arr.size() % 2 != i % 2) arr[i] += n;
    }

    return arr;
}
```

```python
def solution(arr, n):
    return [x + n if len(arr) % 2 != i % 2 else x for i, x in enumerate(arr)]
```
