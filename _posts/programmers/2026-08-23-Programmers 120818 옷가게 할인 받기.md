## 1. 아이디어

`price`가 50만 원, 30만 원, 10만 원 구간 중 어디에 속하는지에 따라 할인율(20%, 10%, 5%)이 정해지고, 어느 구간에도 속하지 않으면 할인이 없다. 구간이 겹치므로 큰 금액부터 순서대로 확인해야 한 번에 올바른 할인율을 적용할 수 있다. 지불 금액은 정수로 반환해야 하므로 정수 나눗셈으로 소수점 이하를 버린다.

---

## 2. 복잡도

| 접근 | 시간   | 공간   |
| ---- | ------ | ------ |
| 풀이 | $O(1)$ | $O(1)$ |

---

## 3. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int solution(int price) {
        if (price >= 500000) return price * 80 / 100;
        if (price >= 300000) return price * 90 / 100;
        if (price >= 100000) return price * 95 / 100;
        return price;
    }
}
```

