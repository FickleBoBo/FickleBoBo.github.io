## 1. 아이디어

각 원소는 다른 원소와 무관하게 변환되므로 배열을 한 번 순회하며 처리한다. 값이 50 이상이면서 짝수이면 2로 나누고, 50 미만이면서 홀수이면 2를 곱한다. 두 조건은 동시에 성립할 수 없으므로 분기 순서는 결과에 영향을 주지 않으며, 어느 쪽에도 해당하지 않는 값은 그대로 둔다.

---

## 2. 복잡도

| 접근 | 시간   | 공간   |
| ---- | ------ | ------ |
| 풀이 | $O(N)$ | $O(N)$ |

($N$ = `arr`의 길이)

---

## 3. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int[] solution(int[] arr) {
        for (int i = 0; i < arr.length; i++) {
            if (arr[i] >= 50 && arr[i] % 2 == 0) {
                arr[i] /= 2;
            } else if (arr[i] < 50 && arr[i] % 2 != 0) {
                arr[i] *= 2;
            }
        }

        return arr;
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

vector<int> solution(vector<int> arr) {
    for (int& x : arr) {
        if (x >= 50 && x % 2 == 0) {
            x /= 2;
        } else if (x < 50 && x % 2) {
            x *= 2;
        }
    }

    return arr;
}
```

```python
def solution(arr):

    def transform(x):
        if x >= 50 and x % 2 == 0:
            return x // 2
        if x < 50 and x % 2:
            return x * 2
        return x

    return [transform(x) for x in arr]
```
