## 1. 아이디어

문자열의 글자를 규칙에 따라 바꾸는 문제다. 변환은 글자마다 따로 정해지므로 글자를 하나씩 보며 소문자 `"a"`는 `"A"`로, `"A"`를 제외한 대문자는 소문자로 바꾸고 나머지 글자는 그대로 둔다. `"A"`는 대문자지만 바뀌지 않고 그대로 남는다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public String solution(String myString) {
        StringBuilder sb = new StringBuilder();
        for (char c : myString.toCharArray()) {
            if (c == 'a') {
                sb.append('A');
            } else if ('B' <= c && c <= 'Z') {
                sb.append(Character.toLowerCase(c));
            } else {
                sb.append(c);
            }
        }

        return sb.toString();
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

string solution(string myString) {
    string s;
    for (char c : myString) {
        if (c == 'a') {
            s += 'A';
        } else if ('B' <= c && c <= 'Z') {
            s += tolower(c);
        } else {
            s += c;
        }
    }

    return s;
}
```

```python
import string


def solution(myString):
    src = "a" + string.ascii_uppercase[1:]
    dst = "A" + string.ascii_lowercase[1:]
    return myString.translate(str.maketrans(src, dst))
```

`str.maketrans`에 `"a"`와 `"B"`~`"Z"`, 이에 대응하는 `"A"`와 `"b"`~`"z"`를 넘겨 변환표를 만들었다. `translate`는 표에 없는 글자를 그대로 두므로 `"A"`는 바뀌지 않는다.
