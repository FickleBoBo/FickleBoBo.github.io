## 1. 아이디어

한 변이 1인 정사각형을 맨 아랫줄에 $n$개 놓고 위로 갈수록 한 개씩 줄여 가운데에 맞춰 쌓은 계단 모양 도형의 둘레를 구하는 문제다. 윗줄이 항상 아랫줄 안쪽에 놓여 위를 향한 변들은 위에서 내려다보면 겹치거나 비는 곳 없이 맨 아랫줄의 폭을 채우므로, 그 길이의 합은 아랫변의 길이와 같은 $n$이다. 왼쪽과 오른쪽을 향한 변들도 같은 식으로 옆에서 보면 층이 $n$개인 도형의 높이 $n$을 각각 채우므로 둘레는 $4n$이다. $n$이 최대 $10^9$이라 $4n$은 32비트 정수의 범위를 넘을 수 있으므로 64비트 정수로 계산한다.

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        long n = Long.parseLong(br.readLine());
        System.out.println(4 * n);
    }
}
```
