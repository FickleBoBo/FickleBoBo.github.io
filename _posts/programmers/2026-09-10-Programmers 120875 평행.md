## 1. 아이디어

네 점을 두 점씩 이어 만든 두 직선이 평행한 경우가 있는지 판별하는 문제다. 네 점을 둘씩 나누는 방법은 세 가지뿐이므로 모두 검사하면 된다. 첫 직선의 $x$좌표 차와 $y$좌표 차를 $\Delta x_1$, $\Delta y_1$, 둘째 직선의 것을 $\Delta x_2$, $\Delta y_2$라 하면, 입력에는 $x$축이나 $y$축과 평행한 직선이 없어 $\Delta x_1$, $\Delta x_2$가 0이 아니므로 평행은 기울기가 같은 것, 곧 $\Delta y_1 / \Delta x_1 = \Delta y_2 / \Delta x_2$이다. 나눗셈은 몫이 잘리거나 오차가 생길 수 있으니 양변에 $\Delta x_1 \Delta x_2$를 곱한 $\Delta y_1 \Delta x_2 = \Delta y_2 \Delta x_1$로 비교하고, 이 식은 두 직선이 겹칠 때도 성립하므로 겹치는 경우도 평행으로 센다는 조건과 그대로 맞는다.

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int solution(int[][] dots) {
        int[] p1 = dots[0], p2 = dots[1], p3 = dots[2], p4 = dots[3];
        return isParallel(p1, p2, p3, p4) || isParallel(p1, p3, p2, p4) || isParallel(p1, p4, p2, p3) ? 1 : 0;
    }

    static boolean isParallel(int[] p1, int[] p2, int[] p3, int[] p4) {
        return (p1[0] - p2[0]) * (p3[1] - p4[1]) == (p3[0] - p4[0]) * (p1[1] - p2[1]);
    }
}
```
