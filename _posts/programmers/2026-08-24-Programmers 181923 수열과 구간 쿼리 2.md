## 1. 아이디어

각 쿼리 `[s, e, k]`에 대해 `s`부터 `e`까지의 구간을 순회하면서 `k`보다 크면서 가장 작은 값을 찾는다. 답을 매우 큰 값(`INF`)으로 초기화해두고 구간을 순회하며 `k`보다 크면서 지금까지 찾은 값보다 작은 원소를 만날 때마다 갱신하고, 순회가 끝난 뒤에도 값이 `INF` 그대로면 조건을 만족하는 원소가 없다는 뜻이므로 -1로 바꿔서 저장한다.

---

## 2. 복잡도

| 접근 | 시간            | 공간   |
| ---- | --------------- | ------ |
| 풀이 | $O(N \times Q)$ | $O(Q)$ |

($N$ = `arr`의 길이, $Q$ = `queries`의 길이)

---

## 3. 코드

### 풀이 [Java][C++][Python]

```java
import java.util.*;

class Solution {

    static final int INF = 1_000_001;

    public int[] solution(int[] arr, int[][] queries) {
        int[] ans = new int[queries.length];
        Arrays.fill(ans, INF);

        for (int i = 0; i < queries.length; i++) {
            int s = queries[i][0];
            int e = queries[i][1];
            int k = queries[i][2];

            for (int j = s; j <= e; j++) {
                if (k < arr[j] && arr[j] < ans[i]) ans[i] = arr[j];
            }

            if (ans[i] == INF) ans[i] = -1;
        }

        return ans;
    }
}
```
