## 1. 아이디어

$n \times n$ 배열에 `[0][0]`에서 시작해 시계방향 나선으로 1부터 $n^2$까지 적는 문제다. 방향 배열로 오른쪽, 아래, 왼쪽, 위 순서를 따라 한 칸씩 이동하며 적다가 다음 칸이 배열 밖이거나 이미 숫자가 적힌 칸이면 방향을 한 번 돌린다. 나선은 바깥 겹부터 안쪽으로 채워지고 막히는 곳은 늘 한 변의 끝이다. 거기서 시계방향으로 돌린 칸은 같은 겹의 다음 변이거나 한 겹 안쪽의 첫 칸이라 비어 있으므로 한 번만 돌리면 충분하고, $n^2$를 적으면 끝난다.

## 2. 코드

### 풀이 [Java][C++][Python]

`r`, `c`를 0, -1에서 시작하고 `d`를 오른쪽 방향으로 두어 첫 이동이 `[0][0]`에 1을 적게 했다. `dr`, `dc`는 위, 오른쪽, 아래, 왼쪽 순이라 `d`를 하나씩 키우면 시계방향으로 돈다.

```java
class Solution {

    static int[] dr = {-1, 0, 1, 0};
    static int[] dc = {0, 1, 0, -1};

    public int[][] solution(int n) {
        int[][] arr = new int[n][n];
        int r = 0, c = -1, d = 1, num = 1;

        while (num <= n * n) {
            int nr = r + dr[d];
            int nc = c + dc[d];
            if (nr < 0 || nr >= n || nc < 0 || nc >= n || arr[nr][nc] != 0) {
                d = (d + 1) % 4;
                nr = r + dr[d];
                nc = c + dc[d];
            }

            arr[nr][nc] = num++;
            r = nr;
            c = nc;
        }

        return arr;
    }
}
```

```python
def solution(n):
    arr = [[0] * n for _ in range(n)]
    dr = (-1, 0, 1, 0)
    dc = (0, 1, 0, -1)
    r, c, d, num = 0, -1, 1, 1

    while num <= n * n:
        nr, nc = r + dr[d], c + dc[d]
        if not (0 <= nr < n and 0 <= nc < n) or arr[nr][nc] != 0:
            d = (d + 1) % 4
            nr, nc = r + dr[d], c + dc[d]

        arr[nr][nc] = num
        num += 1
        r, c = nr, nc

    return arr
```
