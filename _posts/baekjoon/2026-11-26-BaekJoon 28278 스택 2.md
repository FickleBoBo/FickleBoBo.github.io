## 1. 아이디어

[[BaekJoon] #10828 - 스택](/posts/baekjoon-10828/)과 같은 정수 스택에서 명령이 숫자로 바뀌고 명령의 수 $N$이 1,000,000까지 늘어난 문제로, 배열에 값을 쌓고 쌓인 개수만 관리하는 방식은 모든 연산이 상수 시간이라 그대로 통한다. 넣는 횟수가 $N$번을 넘지 않으므로 크기 1,000,000인 배열이면 충분하다.

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;
import java.util.*;

public class Main {

    static final int MAX_N = 1_000_000;
    static int[] stack = new int[MAX_N];
    static int pos = 0;

    static void push(int x) {
        stack[pos++] = x;
    }

    static int pop() {
        return stack[--pos];
    }

    static int size() {
        return pos;
    }

    static boolean empty() {
        return pos == 0;
    }

    static int top() {
        return stack[pos - 1];
    }

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringBuilder sb = new StringBuilder();
        StringTokenizer st;

        int n = Integer.parseInt(br.readLine());
        while (n-- > 0) {
            st = new StringTokenizer(br.readLine());
            int op = Integer.parseInt(st.nextToken());

            if (op == 1) {
                int x = Integer.parseInt(st.nextToken());
                push(x);
            } else if (op == 2) {
                if (empty()) {
                    sb.append("-1\n");
                } else {
                    sb.append(pop()).append("\n");
                }
            } else if (op == 3) {
                sb.append(size()).append("\n");
            } else if (op == 4) {
                if (empty()) {
                    sb.append("1\n");
                } else {
                    sb.append("0\n");
                }
            } else {
                if (empty()) {
                    sb.append("-1\n");
                } else {
                    sb.append(top()).append("\n");
                }
            }
        }

        System.out.println(sb);
    }
}
```

`bool`은 `cout`에서 1과 0으로 출력되므로 `empty`의 반환값을 분기 없이 그대로 썼다.

```python
import sys

input = sys.stdin.readline
out = []

MAX_N = 1_000_000


class Stack:
    def __init__(self):
        self.st = [0] * MAX_N
        self.pos = 0

    def push(self, x):
        self.st[self.pos] = x
        self.pos += 1

    def pop(self):
        self.pos -= 1
        return self.st[self.pos]

    def size(self):
        return self.pos

    def empty(self):
        return self.pos == 0

    def top(self):
        return self.st[self.pos - 1]


stack = Stack()

n = int(input())
for _ in range(n):
    tokens = input().split()
    op = tokens[0]

    if op == "1":
        stack.push(int(tokens[1]))
    elif op == "2":
        if stack.empty():
            out.append(-1)
        else:
            out.append(stack.pop())
    elif op == "3":
        out.append(stack.size())
    elif op == "4":
        if stack.empty():
            out.append(1)
        else:
            out.append(0)
    else:
        if stack.empty():
            out.append(-1)
        else:
            out.append(stack.top())

print("\n".join(map(str, out)))
```
