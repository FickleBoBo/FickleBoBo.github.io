## 1. 아이디어

3의 배수와 숫자 3이 들어간 수를 건너뛰고 센 $n$번째 수를 구하는 문제다. $n$이 100 이하라서 1부터 하나씩 올리며 두 조건에 걸리지 않는 수만 세어 나가도 충분하다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int solution(int n) {
        int x = 0;
        int cnt = 0;
        while (cnt < n) {
            x++;
            if (x % 3 == 0 || String.valueOf(x).contains("3")) continue;
            cnt++;
        }

        return x;
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int solution(int n) {
    int x = 0;
    int cnt = 0;
    while (cnt < n) {
        x++;
        if (x % 3 == 0 || to_string(x).find('3') != -1) continue;
        cnt++;
    }

    return x;
}
```

`std::to_string`으로 숫자를 문자열로 바꿔 `find`로 문자 `'3'`을 찾았다. `find`가 못 찾으면 반환하는 `std::string::npos`는 -1과 같은 값으로 비교되므로 `!= -1`로 찾았는지 확인했다.

```python
def solution(n):
    x, cnt = 0, 0
    while cnt < n:
        x += 1
        if x % 3 == 0 or "3" in str(x):
            continue
        cnt += 1

    return x
```
