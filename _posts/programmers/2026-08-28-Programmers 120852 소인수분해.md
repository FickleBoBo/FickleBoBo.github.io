## 1. 아이디어

$n$의 소인수를 오름차순으로 한 번씩만 구하는 문제다. 2부터 $x$를 하나씩 올리며 남은 수(처음에는 $n$)가 $x$로 나누어떨어지면 $x$를 기록하고 남은 수에서 $x$를 모두 나눠 없앤다. 합성수 $x$는 더 작은 소인수를 가지는데 그 소인수는 남은 수에 더는 들어 있지 않으므로 합성수로는 나누어떨어지지 않는다. 따라서 나누어떨어지는 $x$는 항상 소수이고 소수 판별이 따로 필요 없다. 남은 수가 1이 되면 소인수를 모두 기록한 것이므로 거기서 멈춘다.

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.util.*;

class Solution {
    public int[] solution(int n) {
        List<Integer> list = new ArrayList<>();
        int x = 2;

        while (n > 1) {
            if (n % x == 0) {
                list.add(x);
                while (n % x == 0) {
                    n /= x;
                }
            }

            x++;
        }

        return list.stream().mapToInt(Integer::intValue).toArray();
    }
}
```

```python
def solution(n):
    res = []
    x = 2

    while n > 1:
        if n % x == 0:
            res.append(x)
            while n % x == 0:
                n //= x

        x += 1

    return res
```
