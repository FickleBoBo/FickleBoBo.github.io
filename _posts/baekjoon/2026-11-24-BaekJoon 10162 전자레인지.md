## 1. 아이디어

$T$초를 300초, 60초, 10초 버튼의 합으로 만들면서 누른 횟수를 최소로 하는 문제다. 60초 버튼을 5번 누르면 300초 버튼 1번으로, 10초 버튼을 6번 누르면 60초 버튼 1번으로 바꿔 횟수를 줄일 수 있으므로 최적해에서 60초 버튼은 4번 이하, 10초 버튼은 5번 이하이다. 이때 60초와 10초 버튼이 만드는 시간은 최대 $60 \times 4 + 10 \times 5 = 290$초로 300초 미만이라 300초 버튼의 횟수는 $T$를 300으로 나눈 몫이다. 남은 시간에서도 10초 버튼이 만드는 시간이 최대 50초로 60초 미만이라 60초 버튼의 횟수는 남은 시간을 60으로 나눈 몫이다. 따라서 큰 버튼부터 가능한 만큼 누르는 그리디로 구한다. 세 버튼이 모두 10초의 배수라 10초 버튼까지 누른 뒤에도 시간이 남으면 $T$초를 맞출 수 없다.

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        int t = Integer.parseInt(br.readLine());

        int a = t / 300;
        t %= 300;

        int b = t / 60;
        t %= 60;

        int c = t / 10;
        t %= 10;

        if (t == 0) {
            System.out.println(a + " " + b + " " + c);
        } else {
            System.out.println(-1);
        }
    }
}
```
