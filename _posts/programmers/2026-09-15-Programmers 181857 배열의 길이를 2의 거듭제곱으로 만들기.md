## 1. 아이디어

배열의 길이를 2의 거듭제곱으로 만들 때 0을 가장 적게 붙이려면 목표 길이는 현재 길이 이상인 2의 거듭제곱 중 가장 작은 것이어야 한다. 1에서 시작해 2배씩 키우다 처음으로 현재 길이 이상이 되는 값이 그것이고, 이미 2의 거듭제곱이면 그 값이 현재 길이와 같아 0이 붙지 않는다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.util.*;

class Solution {
    public int[] solution(int[] arr) {
        int n = 1;
        while (n < arr.length) {
            n <<= 1;
        }

        return Arrays.copyOf(arr, n);
    }
}
```

길이를 늘린 복사본을 `Arrays.copyOf(arr, n)`으로 만들었다. 늘어난 칸은 0으로 채워져 따로 0을 넣지 않아도 된다.

```c++
#include <bits/stdc++.h>
using namespace std;

vector<int> solution(vector<int> arr) {
    int n = 1;
    while (n < arr.size()) n <<= 1;
    arr.resize(n);

    return arr;
}
```

`resize(n)`으로 길이를 늘렸다. 늘어난 칸은 0으로 채워진다.

```python
def solution(arr):
    n = 1
    while n < len(arr):
        n <<= 1

    return arr + [0] * (n - len(arr))
```
