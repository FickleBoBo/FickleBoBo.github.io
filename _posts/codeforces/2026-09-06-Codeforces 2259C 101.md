## 1. 아이디어

점수는 사이에 다른 `1`이 없는 두 `1`을 양 끝으로 하는 구간의 최대 길이이고(`1`이 하나뿐이면 1), `-1`을 `0` 또는 `1`로 바꿔 이를 최대로 만드는 문제다.

`0`이 아닌 첫 원소 앞과 마지막 원소 뒤는 전부 `0`이라, `1`이 놓일 수 있는 범위는 그 둘 사이로 한정된다. 이 범위를 $[s, e]$라 하자. 처음부터 있던 `1`은 어떤 배치에서도 그대로 `1`이다.

범위 안쪽의 `-1`은 전부 `0`으로 바꾼다. `1`로 바꾸면 사이에 다른 `1`이 없는 두 `1`의 구간을 쪼갤 뿐 늘려 주지 않기 때문이다. 반대로 범위의 양 끝 $s$, $e$는 `-1`이면 `1`로 놓는다. 끝을 `0`으로 두면 그 끝을 양 끝으로 하는 구간이 아예 생기지 않아, `1`로 두는 편이 항상 이득이다.

이 배치가 최선인 이유는 다음과 같다. 이 배치의 `1`은 처음부터 있던 `1`과 범위의 양 끝뿐이고, 이웃한 두 `1`을 양 끝으로 하는 조각들이 이 배치의 구간이 된다. 어떤 배치에서든 구간은 범위 $[s, e]$ 안에 있고 처음부터 있던 `1`을 사이에 품을 수 없으므로, 이 조각 중 하나 안에 들어간다.

`0`이 아닌 원소가 하나뿐이면 $s = e$라 그 칸이 `1`이 되어 길이 1짜리 구간이 점수가 된다. 하나도 없으면 바꿀 것이 없어 그대로 출력한다.

## 2. 코드

### 풀이 [C++]

```c++
#include <bits/stdc++.h>
using namespace std;

void solve() {
    int n;
    cin >> n;

    vector<int> a(n);
    for (int& x : a) cin >> x;

    int s = 0, e = n - 1;
    while (s < n && a[s] == 0) s++;
    while (e >= 0 && a[e] == 0) e--;

    if (s <= e) {
        a[s] = a[e] = 1;
        for (int i = s + 1; i < e; i++) {
            if (a[i] == -1) a[i] = 0;
        }
    }

    for (int x : a) {
        cout << x << ' ';
    }
    cout << '\n';
}

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    int t;
    cin >> t;
    while (t--) solve();
}
```
