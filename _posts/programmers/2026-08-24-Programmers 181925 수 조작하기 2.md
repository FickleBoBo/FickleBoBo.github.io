## 1. 아이디어

정수 배열 `numLog`에서 인접한 두 값의 차이를 확인해서 어떤 조작이 있었는지 역으로 알아내는 문제다. 이전 값과 현재 값의 차이가 +1이면 `w`, -1이면 `s`, +10이면 `d`, -10이면 `a`로 판단해서 순서대로 이어 붙이면 조작 문자열이 복원된다.

---

## 2. 복잡도

| 접근 | 시간   | 공간   |
| ---- | ------ | ------ |
| 풀이 | $O(N)$ | $O(N)$ |

($N$ = `numLog`의 길이)

---

## 3. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public String solution(int[] numLog) {
        StringBuilder sb = new StringBuilder();
        for (int i = 1; i < numLog.length; i++) {
            int prv = numLog[i - 1];
            int cur = numLog[i];

            if (prv + 1 == cur) {
                sb.append("w");
            } else if (prv - 1 == cur) {
                sb.append("s");
            } else if (prv + 10 == cur) {
                sb.append("d");
            } else {
                sb.append("a");
            }
        }

        return sb.toString();
    }
}
```

```python
from itertools import pairwise


def solution(numLog):
    res = []
    for prv, cur in pairwise(numLog):
        if prv + 1 == cur:
            res.append("w")
        elif prv - 1 == cur:
            res.append("s")
        elif prv + 10 == cur:
            res.append("d")
        else:
            res.append("a")

    return "".join(res)
```

Python은 `pairwise`로 `numLog`를 인접한 두 값 `(prv, cur)` 쌍으로 순회했다.
