## 1. 아이디어

출력 양식을 행렬로 봤을 때, 행 번호 + 열 번호가 짝수일 때만 별을 출력하면 된다.

---

## 2. 복잡도

| 접근 | 시간     | 공간   |
| ---- | -------- | ------ |
| 풀이 | $O(N^2)$ | $O(1)$ |

($N$ = 입력값 `n`. Java는 전체 출력을 `StringBuilder`에 모았다가 출력하므로 공간 $O(N^2)$)

---

## 3. 코드

### 풀이 [Java][C++]

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringBuilder sb = new StringBuilder();

        int n = Integer.parseInt(br.readLine());

        for (int i = 1; i <= 2 * n; i++) {
            for (int j = 1; j <= n; j++) {
                if ((i + j) % 2 == 0) {
                    sb.append("*");
                } else {
                    sb.append(" ");
                }
            }
            sb.append("\n");
        }

        System.out.println(sb);
    }
}
```
