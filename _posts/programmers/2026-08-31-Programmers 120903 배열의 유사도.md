## 1. 아이디어

두 문자열 배열에 모두 들어 있는 원소의 개수를 구하는 문제다. 각 배열 안에는 중복이 없으므로 같은 원소의 개수는 두 배열의 교집합 크기와 같다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.util.*;

class Solution {
    public int solution(String[] s1, String[] s2) {
        Set<String> seen = new HashSet<>(List.of(s1));
        int cnt = 0;

        for (String s : s2) {
            if (seen.contains(s)) cnt++;
        }

        return cnt;
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int solution(vector<string> s1, vector<string> s2) {
    unordered_set<string> seen(s1.begin(), s1.end());
    int cnt = 0;

    for (string& s : s2) {
        if (seen.contains(s)) cnt++;
    }

    return cnt;
}
```

```python
def solution(s1, s2):
    return len(set(s1) & set(s2))
```

`&`로 두 `set`의 교집합을 구해 크기를 셌다.
