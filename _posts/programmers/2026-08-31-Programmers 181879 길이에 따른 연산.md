## 1. 아이디어

리스트 길이가 11 이상이면 모든 원소의 합을, 10 이하이면 모든 원소의 곱을 반환하는 분기를 그대로 구현하면 된다. 곱이 2,147,483,647을 넘는 입력은 주어지지 않아 32비트 정수로 충분하다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int solution(int[] num_list) {
        if (num_list.length >= 11) {
            int sum = 0;
            for (int x : num_list) {
                sum += x;
            }
            return sum;
        } else {
            int mul = 1;
            for (int x : num_list) {
                mul *= x;
            }
            return mul;
        }
    }
}
```
