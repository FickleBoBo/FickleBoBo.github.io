## 1. 아이디어

별이 $N$개에서 1개까지 줄어드는 오른쪽 정렬 삼각형이다. 위에서부터 $i$번째 줄의 별은 $N - i + 1$개이고 모든 줄의 길이가 $N$으로 같으므로, 그 앞을 공백 $i - 1$개로 채워 오른쪽 끝을 맞춘다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringBuilder sb = new StringBuilder();

        int n = Integer.parseInt(br.readLine());

        for (int i = 1; i <= n; i++) {
            for (int j = 1; j <= i - 1; j++) {
                sb.append(" ");
            }
            for (int j = 1; j <= n - i + 1; j++) {
                sb.append("*");
            }
            sb.append("\n");
        }

        System.out.println(sb);
    }
}
```

```c++
#include <bits/stdc++.h>

```

```python
import sys

input = sys.stdin.readline

n = int(input())

out = []
for i in range(1, n + 1):
    out.append(" " * (i - 1) + "*" * (n - i + 1))

print("\n".join(out))
```
