## 1. 아이디어

[[BaekJoon] #24266 - 알고리즘 수업 - 알고리즘의 수행 시간 5](/posts/baekjoon-24266/)와 달리 삼중 반복문의 $j$는 $i + 1$부터, $k$는 $j + 1$부터 시작해 $i < j < k$인 경우에만 코드1이 실행되는 알고리즘의 수행 횟수와 그 차수를 구하는 문제다. 1부터 $n$까지에서 서로 다른 세 수를 고르면 크기 순서대로 $i$, $j$, $k$가 하나로 정해지므로 수행 횟수는 $\binom{n}{3} = \dfrac{n(n - 1)(n - 2)}{6}$로 3차 다항식이다. 연속한 세 정수의 곱은 6의 배수라 정수 나눗셈으로 정확히 구해진다. $n$이 최대 500,000일 때 나누기 전의 곱은 약 $1.25 \times 10^{17}$이라 64비트 정수로 계산하면 된다.

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        long n = Long.parseLong(br.readLine());
        System.out.println(n * (n - 1) * (n - 2) / 6);
        System.out.println(3);
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    long long n;
    cin >> n;
    cout << n * (n - 1) * (n - 2) / 6 << '\n';
    cout << 3;
}
```

