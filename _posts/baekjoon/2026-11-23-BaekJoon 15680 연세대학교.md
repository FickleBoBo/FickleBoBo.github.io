## 1. 아이디어

입력 $N$이 0이면 영문명 `YONSEI`를, 1이면 슬로건 `Leading the Way to the Future`를 출력한다. $N$은 0 또는 1뿐이라 0인지만 가르고 나머지를 슬로건으로 처리하며, 대소문자는 지문에 적힌 표기대로 써야 한다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        int n = Integer.parseInt(br.readLine());

        if (n == 0) {
            System.out.println("YONSEI");
        } else {
            System.out.println("Leading the Way to the Future");
        }
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    int n;
    cin >> n;

    if (n == 0) {
        cout << "YONSEI";
    } else {
        cout << "Leading the Way to the Future";
    }
}
```

