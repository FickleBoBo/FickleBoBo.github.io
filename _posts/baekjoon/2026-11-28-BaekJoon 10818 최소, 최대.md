## 1. 아이디어

$N$개의 정수에서 최솟값과 최댓값을 구하는 문제다. 모든 수를 한 번씩 보며 지금까지의 최솟값보다 작거나 최댓값보다 큰 수가 나올 때 갱신하면 된다. 입력되는 수가 -1,000,000 이상 1,000,000 이하이므로 최솟값은 1,000,000에서, 최댓값은 -1,000,000에서 시작하면 첫 수부터 같은 방식으로 갱신할 수 있다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        int n = Integer.parseInt(br.readLine());

        int min = 1_000_000;
        int max = -1_000_000;
        StringTokenizer st = new StringTokenizer(br.readLine());
        while (n-- > 0) {
            int x = Integer.parseInt(st.nextToken());
            min = Math.min(min, x);
            max = Math.max(max, x);
        }

        System.out.println(min + " " + max);
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    int n;
    cin >> n;

    vector<int> v(n);
    for (int& x : v) cin >> x;

    auto [mnIt, mxIt] = minmax_element(v.begin(), v.end());
    cout << *mnIt << ' ' << *mxIt;
}
```

`std::minmax_element`는 최솟값과 최댓값을 가리키는 이터레이터 쌍을 반환하므로 `*`로 값을 꺼냈다.

```python
import sys

input = sys.stdin.readline

input()
arr = list(map(int, input().split()))

print(min(arr), max(arr))
```
