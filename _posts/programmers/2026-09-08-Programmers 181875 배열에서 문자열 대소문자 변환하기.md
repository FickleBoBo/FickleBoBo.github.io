## 1. 아이디어

각 문자열을 전부 대문자 또는 전부 소문자로 바꾸는 연산은 이미 그 형태인 문자열에 적용해도 그대로라서, 원소의 현재 대소문자는 볼 필요 없이 인덱스가 홀수면 대문자로, 짝수면 소문자로 바꾸면 된다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public String[] solution(String[] strArr) {
        for (int i = 0; i < strArr.length; i++) {
            if (i % 2 != 0) {
                strArr[i] = strArr[i].toUpperCase();
            } else {
                strArr[i] = strArr[i].toLowerCase();
            }
        }

        return strArr;
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

vector<string> solution(vector<string> strArr) {
    for (int i = 0; i < strArr.size(); i++) {
        if (i % 2) {
            for (char& c : strArr[i]) c = toupper(c);
        } else {
            for (char& c : strArr[i]) c = tolower(c);
        }
    }

    return strArr;
}
```

`char&`로 문자를 하나씩 받아 `std::toupper`와 `std::tolower`를 적용해 제자리에서 바꿨다.

```python
def solution(strArr):
    return [s.upper() if i % 2 else s.lower() for i, s in enumerate(strArr)]
```
