## 1. 아이디어

주어진 입력 그대로 출력하는 문제로 입력이 얼마나 주어지는지는 알 수 없다. EOF를 활용해서 읽을 수 없을 때까지 읽으며 출력하면 된다.

---

## 2. 복잡도

| 접근 | 시간   | 공간   |
| ---- | ------ | ------ |
| 풀이 | $O(N)$ | $O(1)$ |

($N$ = 입력 줄 수)

---

## 3. 코드

### 풀이 [Java][C++]

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        BufferedWriter bw = new BufferedWriter(new OutputStreamWriter(System.out));

        String line;
        while ((line = br.readLine()) != null) {
            bw.write(line);
            bw.newLine();
        }

        bw.flush();
    }
}
```

`BufferedReader`의 `readLine` 메서드는 EOF에서 `null`을 반환함을 활용해서 입력을 받고 `BufferedWriter`로 출력했다.

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    string line;
    while (getline(cin, line)) {
        cout << line << '\n';
    }
}
```

`std::getline` 함수로 줄 단위로 입력을 받아서 그대로 출력했다. `std::getline`은 EOF에서 `false`로 평가됨을 활용해 `while`문의 조건식으로 두어 EOF까지 반복했다.
