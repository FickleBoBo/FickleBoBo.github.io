## 1. 아이디어

$i + j \le k$인 칸의 합을 구하는 문제다. 한 행 안에서 $j$가 커질수록 $i + j$도 커지므로, 처음 $i + j > k$가 되는 칸부터 그 행의 나머지는 볼 필요가 없다. 같은 이유로 $i > k$인 행은 $j = 0$부터 이미 조건을 넘으므로 통째로 건너뛴다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int solution(int[][] board, int k) {
        int sum = 0;
        for (int i = 0; i < Math.min(board.length, k + 1); i++) {
            for (int j = 0; j < board[i].length; j++) {
                if (i + j > k) break;
                sum += board[i][j];
            }
        }

        return sum;
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int solution(vector<vector<int>> board, int k) {
    int sum = 0;
    for (int i = 0; i < min((int)board.size(), k + 1); i++) {
        for (int j = 0; j < board[i].size(); j++) {
            if (i + j > k) break;
            sum += board[i][j];
        }
    }

    return sum;
}
```

`board.size()`는 부호 없는 정수라 `int`인 `k + 1`과 `std::min`으로 비교하려면 `int`로 바꿔야 해서 `(int)`로 캐스팅했다.

```python
def solution(board, k):
    total = 0
    for i, row in enumerate(board[: k + 1]):
        for j, x in enumerate(row):
            if i + j > k:
                break
            total += x

    return total
```

슬라이스 `board[: k + 1]`로 앞쪽 행만 취했다. `k + 1`이 행의 수보다 커도 오류 없이 있는 행까지만 가져온다.
