## 1. 아이디어

`arr`의 원소를 앞에서부터 순서대로 이어 붙이면 된다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public String solution(String[] arr) {
        return String.join("", arr);
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

string solution(vector<string> arr) {
    string ans;
    for (string& s : arr) ans += s;
    return ans;
}
```

```python
def solution(arr):
    return "".join(arr)
```
