## 1. 아이디어

알파벳으로 이루어진 문자열 `myString`의 모든 알파벳을 대문자로 변환하는 문제로 내장 함수를 활용하면 간단하게 해결할 수 있다.

---

## 2. 복잡도

| 시간복잡도 | 공간복잡도 |
| :--------: | :--------: |
|   $O(N)$   |   $O(1)$   |

> N = `myString` 길이

---

## 3. 코드

### 풀이 [Java][C++]

```java
class Solution {
    public String solution(String myString) {
        return myString.toUpperCase();
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

string solution(string myString) {
    for (char& c : myString) {
        c = toupper(c);
    }

    return myString;
}
```
