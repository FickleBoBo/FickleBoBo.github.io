## 1. 아이디어

양의 정수 `a`, `b`가 주어졌을 때, $a \oplus b$와 $b \oplus a$ 중에서 더 큰 값을 반환하는 문제다. 연산 $\oplus$는 두 수를 문자열로 변환해서 문자열 이어붙이기를 한 후 다시 정수로 형변환을 하면 간단하게 처리할 수 있으므로 이를 이용해 두 연산 결과 중 더 큰 값을 반환했다.

---

## 2. 복잡도

| 접근 | 시간   | 공간   |
| ---- | ------ | ------ |
| 풀이 | $O(1)$ | $O(1)$ |

---

## 3. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int solution(int a, int b) {
        int x = Integer.parseInt("" + a + b);
        int y = Integer.parseInt("" + b + a);
        return Math.max(x, y);
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int solution(int a, int b) {
    int x = stoi(to_string(a) + to_string(b));
    int y = stoi(to_string(b) + to_string(a));
    return max(x, y);
}
```

```python
def solution(a, b):
    x = int(f"{a}{b}")
    y = int(f"{b}{a}")
    return max(x, y)
```
