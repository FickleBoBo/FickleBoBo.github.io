## 1. 아이디어

$M \times N$ 크기의 종이를 $1 \times 1$ 조각으로 자르는 데 필요한 최소 가위질 횟수를 구하는 문제다. 종이를 겹쳐서 자를 수 없어 가위질 한 번에 한 조각이 정확히 둘로 갈라지므로 조각이 하나씩만 늘고, 한 장에서 $M \times N$개가 되려면 어떻게 자르든 $M \times N - 1$번이 필요하다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int solution(int M, int N) {
        return M * N - 1;
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int solution(int M, int N) {
    return M * N - 1;
}
```

```python
def solution(M, N):
    return M * N - 1
```
