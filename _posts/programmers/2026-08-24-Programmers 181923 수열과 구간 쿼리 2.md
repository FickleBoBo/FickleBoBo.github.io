## 1. 아이디어

쿼리마다 구간에서 $k$보다 큰 값 중 가장 작은 것을 찾는다. 조건이 '$k$ 이상'이 아니라 '$k$보다 큼'이라 $k$와 같은 값은 후보가 아니다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.util.*;

class Solution {

    static final int INF = 1_000_001;

    public int[] solution(int[] arr, int[][] queries) {
        int[] ans = new int[queries.length];
        Arrays.fill(ans, INF);

        for (int i = 0; i < queries.length; i++) {
            int s = queries[i][0];
            int e = queries[i][1];
            int k = queries[i][2];

            for (int j = s; j <= e; j++) {
                if (k < arr[j] && arr[j] < ans[i]) ans[i] = arr[j];
            }

            if (ans[i] == INF) ans[i] = -1;
        }

        return ans;
    }
}
```

답이 없는 쿼리를 구분하려고 원소의 최댓값 1,000,000보다 큰 값으로 `INF`를 잡았다.

```c++
        int e = queries[i][1];
        int k = queries[i][2];

        }

        if (ans[i] == INF) ans[i] = -1;
    }

    return ans;
}
```

```python
def solution(arr, queries):
    ans = []
    for s, e, k in queries:
        window = [x for x in arr[s : e + 1] if x > k]
        ans.append(min(window) if window else -1)

    return ans
```
