## 1. 아이디어

$P$가 $S$의 부분 문자열인지 판정하는 문제다. 두 문자열의 길이가 최대 1,000,000이라 $S$의 시작 위치마다 $P$를 처음부터 비교하면, $P$의 길이가 $S$의 절반쯤이고 시작 위치마다 비교가 $P$의 끝까지 이어지는 최악의 경우 문자 비교가 약 $2.5 \times 10^{11}$번이 되어 시간 안에 끝나지 않는다. 따라서 이중 반복을 직접 작성하는 대신, 이 길이에서도 시간 안에 동작하는 표준 라이브러리의 부분 문자열 검색을 쓴다.

---

## 2. 코드

### 풀이 [C++][Python]

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    string s, p;
    cin >> s >> p;
    cout << (strstr(s.c_str(), p.c_str()) != nullptr);
}
```

`std::strstr`로 검색했는데, C++ 표준은 시간 복잡도를 정하지 않지만 glibc의 구현은 선형 시간을 보장한다.

```python
import sys

input = sys.stdin.readline

s = input().rstrip()
p = input().rstrip()
print(int(p in s))
```

`sys.stdin.readline`은 줄바꿈까지 읽어 오므로 `rstrip`으로 지워 `p`의 끝에 줄바꿈이 붙은 채 검색하지 않게 했다.
