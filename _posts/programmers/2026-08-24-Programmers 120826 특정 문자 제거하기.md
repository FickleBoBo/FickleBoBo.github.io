## 1. 아이디어

`my_string`에서 `letter`와 일치하는 문자를 전부 제거한 뒤 반환하면 되는 문제다. `letter`는 항상 길이가 1인 문자로 주어지므로, 문자열에서 해당 문자를 지우는 표준적인 방법을 그대로 적용하면 된다.

---

## 2. 복잡도

| 접근 | 시간   | 공간   |
| ---- | ------ | ------ |
| 풀이 | $O(N)$ | $O(N)$ |

($N$ = `my_string`의 길이)

---

## 3. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public String solution(String my_string, String letter) {
        return my_string.replace(letter, "");
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

string solution(string my_string, string letter) {
    my_string.erase(remove(my_string.begin(), my_string.end(), letter[0]), my_string.end());
    return my_string;
}
```

`remove`-`erase` 관용구로 `letter[0]`과 일치하는 문자를 뒤로 몰아낸 뒤 잘라냈다.

```python
def solution(my_string, letter):
    return my_string.replace(letter, "")
```
