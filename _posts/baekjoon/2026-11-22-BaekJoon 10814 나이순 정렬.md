## 1. 아이디어

나이 순으로 정렬하되 나이가 같으면 입력 순서인 가입 순서를 지켜야 하는데, 나이만 키로 삼아 안정 정렬을 하면 같은 나이끼리는 원래 순서가 그대로 남으므로 가입 순서를 따로 비교할 필요가 없다. $N$이 최대 100,000이라 $O(N^2)$ 정렬은 시간이 부족하고 $O(N \log N)$ 정렬이면 충분하다.

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;
import java.util.*;

public class Main {

    static class User {
        int age;
        String name;

        User(int age, String name) {
            this.age = age;
            this.name = name;
        }
    }

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringBuilder sb = new StringBuilder();

        int n = Integer.parseInt(br.readLine());

        User[] users = new User[n];
        for (int i = 0; i < n; i++) {
            StringTokenizer st = new StringTokenizer(br.readLine());
            users[i] = new User(Integer.parseInt(st.nextToken()), st.nextToken());
        }
        Arrays.sort(users, (o1, o2) -> Integer.compare(o1.age, o2.age));

        for (User user : users) {
            sb.append(user.age).append(" ").append(user.name).append("\n");
        }

        System.out.println(sb);
    }
}
```

객체 배열을 `Arrays.sort`로 정렬했고, 이 정렬은 안정 정렬이라 같은 나이의 순서가 유지된다. 출력이 최대 100,000줄이라 줄마다 `System.out.println`을 호출하면 느려서 `StringBuilder`에 모아 한 번에 출력했다.

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    int n;
    cin >> n;

    vector<pair<int, string>> v(n);
    for (auto& [age, name] : v) cin >> age >> name;
    stable_sort(v.begin(), v.end(), [](auto& a, auto& b) {
        return a.first < b.first;
    });

    for (auto& [age, name] : v) {
        cout << age << ' ' << name << '\n';
    }
}
```

`std::sort`는 같은 값의 순서를 보장하지 않아 안정 정렬인 `std::stable_sort`를 썼다. `std::pair`의 기본 비교는 나이가 같으면 이름까지 비교해 가입 순서가 깨지므로 나이만 비교하는 람다를 넘겼다.

```python
import sys

input = sys.stdin.readline

n = int(input())
arr = []
for _ in range(n):
    age, name = input().split()
    arr.append((int(age), name))
arr.sort(key=lambda x: x[0])

print("\n".join(f"{age} {name}" for age, name in arr))
```

리스트의 `sort`에 나이만 키로 넘겨 정렬했고, 이 정렬은 안정 정렬이라 같은 나이의 순서가 유지된다. 출력이 최대 100,000줄이라 줄마다 `print`를 호출하는 대신 `join`으로 모아 한 번에 출력했다.
