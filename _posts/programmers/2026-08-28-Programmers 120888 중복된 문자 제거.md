## 1. 아이디어

중복된 문자를 제거하되 가장 앞에 있는 것을 남기는 문제다. 앞에서부터 훑으며 처음 보는 문자만 이어 붙이면 각 문자는 처음 나온 자리에 한 번만 남고 순서도 그대로다. 대소문자와 공백은 모두 서로 다른 문자로 구분한다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.util.*;

class Solution {
    public String solution(String my_string) {
        StringBuilder sb = new StringBuilder();
        Set<Character> seen = new HashSet<>();

        for (char c : my_string.toCharArray()) {
            if (seen.add(c)) sb.append(c);
        }

        return sb.toString();
    }
}
```

`add`가 새로 추가됐을 때만 `true`를 반환하는 점을 써서 처음 본 문자만 이어 붙였다.

```c++
#include <bits/stdc++.h>
using namespace std;

string solution(string my_string) {
    string s;
    unordered_set<char> seen;

    for (char c : my_string) {
        if (seen.insert(c).second) s += c;
    }

    return s;
}
```

`insert`가 반환하는 쌍의 `second`가 새로 삽입됐는지를 나타내는 점을 써서 처음 본 문자만 이어 붙였다.

```python
def solution(my_string):
    return "".join(dict.fromkeys(my_string))
```

`dict`가 삽입 순서를 유지하는 점을 써서 `dict.fromkeys`로 중복을 없앴다.
