## 1. 아이디어

[BaekJoon 9655번 - 돌 게임](/posts/baekjoon-9655) 문제에서 $N$이 최대 $10^{12}$까지 커진 문제로, `dp` 표를 채울 수 없으니 홀짝 규칙을 이용해야 한다. 1개와 3개가 모두 홀수라서 한 번 가져갈 때마다 남은 돌의 홀짝이 바뀌므로, 처음 돌이 홀수 개이면 상근이는 매번 짝수 개를 넘기며 마지막 돌을 가져가고 창영이는 짝수 개에서 어떻게 가져가도 홀수 개가 남아 0개를 만들 수 없다. 처음 돌이 짝수 개이면 역할이 뒤바뀌어 창영이가 이긴다. 결국 $N$이 홀수이면 상근이, 짝수이면 창영이가 이긴다.

| 풀이 | $O(1)$ | $O(1)$ |

## 3. 코드

### 풀이 [Java][C++]

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        long n = Long.parseLong(br.readLine());
        if (n % 2 != 0) {
            System.out.println("SK");
        } else {
            System.out.println("CY");
        }
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    long long n;
    cin >> n;

    if (n % 2) {
        cout << "SK";
    } else {
        cout << "CY";
    }
}
```
