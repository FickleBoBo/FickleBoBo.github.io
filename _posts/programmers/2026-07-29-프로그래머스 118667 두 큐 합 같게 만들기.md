## 1. 아이디어

두 큐의 합을 같게 만드는 문제로 `queue1`의 합이 더 크면 `queue1`의 앞 원소를 `queue2`의 뒤에 삽입하고, `queue2`의 합이 더 크면 `queue2`의 앞 원소를 `queue1`의 뒤에 삽입하는 과정을 반복만 해주면 된다. 어느 쪽을 옮길지가 매 순간 하나로 정해지므로 탐색이 아니라 단순 반복으로 처리할 수 있다. 이를 효율적으로 수행하기 위해 주어진 배열을 큐에 새롭게 담아서 처리해줬다. 큐의 합은 매번 큐를 순회하는 것은 비효율적이므로 미리 합을 각각 구한 후 원소의 이동이 발생할 때 같이 갱신해줬다.

주어진 두 큐는 합이 같아질 수 없는 경우 역시 존재하는데 이를 위해서는 원소를 이동하는 횟수의 상한을 구해 해당 횟수까지만 반복해보면 된다. 두 큐 간 원소를 이동하는 것은 두 큐를 환형으로 연결했을 때 `queue1`이 차지하는 구간의 시작과 끝 인덱스가 각각 뒤로 밀리는 것과 동일하게 볼 수 있다. 이때 구간의 내용은 시작 인덱스를 두 큐의 길이 합으로 나눈 나머지로 정해지므로, 합이 같아지는 경우가 존재한다면 시작 인덱스가 환형 큐를 한 바퀴 돌기 전에 반드시 나타난다. 즉 한 바퀴를 다 돌아도 합이 같아지지 않으면 그 이후는 이미 확인한 구간의 반복이므로 답이 없다고 볼 수 있고, 이동 횟수의 상한은 이를 넉넉히 덮도록 두 큐의 길이 합의 두 배로 잡아줬다.

## 2. 복잡도

| 시간복잡도 | 공간복잡도 |
| :--------: | :--------: |
|   $O(N)$   |   $O(N)$   |

> $N$ = `queue1` 길이(= `queue2` 길이)

## 3. 코드

### 풀이 [Java][C++]

```java
import java.util.*;

class Solution {
    public int solution(int[] queue1, int[] queue2) {
        Queue<Integer> q1 = new ArrayDeque<>();
        Queue<Integer> q2 = new ArrayDeque<>();

        long sum1 = 0;
        long sum2 = 0;

        for (int x : queue1) {
            q1.offer(x);
            sum1 += x;
        }
        for (int x : queue2) {
            q2.offer(x);
            sum2 += x;
        }

        int cnt = 0;
        int max = 2 * (q1.size() + q2.size());
        while (cnt <= max) {
            if (sum1 > sum2) {
                sum2 += q1.peek();
                sum1 -= q1.peek();
                q2.offer(q1.poll());
                cnt++;
            } else if (sum1 < sum2) {
                sum1 += q2.peek();
                sum2 -= q2.peek();
                q1.offer(q2.poll());
                cnt++;
            } else {
                return cnt;
            }
        }

        return -1;
    }
}
```

```c++
#include <queue>
#include <vector>

using namespace std;

int solution(vector<int> queue1, vector<int> queue2) {
    queue<int> q1;
    queue<int> q2;

    long long sum1 = 0;
    long long sum2 = 0;

    for (int x : queue1) {
        q1.push(x);
        sum1 += x;
    }
    for (int x : queue2) {
        q2.push(x);
        sum2 += x;
    }

    int cnt = 0;
    int mx = 2 * (q1.size() + q2.size());
    while (cnt <= mx) {
        if (sum1 > sum2) {
            sum2 += q1.front();
            sum1 -= q1.front();
            q2.push(q1.front());
            q1.pop();
            cnt++;
        } else if (sum1 < sum2) {
            sum1 += q2.front();
            sum2 -= q2.front();
            q1.push(q2.front());
            q2.pop();
            cnt++;
        } else {
            return cnt;
        }
    }

    return -1;
}
```
