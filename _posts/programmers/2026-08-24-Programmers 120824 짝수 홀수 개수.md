## 1. 아이디어

`num_list`를 순회하며 각 원소를 2로 나눈 나머지로 홀수 개수를 세고, 전체 길이에서 이를 빼 짝수 개수를 구한 뒤 `[짝수 개수, 홀수 개수]` 순서로 반환하면 된다.

---

## 2. 복잡도

| 접근 | 시간   | 공간   |
| ---- | ------ | ------ |
| 풀이 | $O(N)$ | $O(1)$ |

($N$ = `num_list`의 길이)

---

## 3. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int[] solution(int[] num_list) {
        int odd = 0;
        for (int x : num_list) {
            if (x % 2 != 0) odd++;
        }

        return new int[]{num_list.length - odd, odd};
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

vector<int> solution(vector<int> num_list) {
    int odd = 0;
    for (int x : num_list) {
        if (x % 2) odd++;
    }

    return {(int)num_list.size() - odd, odd};
}
```

```python
def solution(num_list):
    odd = sum(x % 2 for x in num_list)
    even = len(num_list) - odd
    return [even, odd]
```
