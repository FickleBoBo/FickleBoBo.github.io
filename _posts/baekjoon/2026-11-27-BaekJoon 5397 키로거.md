## 1. 아이디어

키보드 입력 기록을 순서대로 따라가 최종 비밀번호를 구하는 문제다. 테스트 케이스 하나의 입력이 최대 1,000,000글자라 하나의 문자열 중간에서 글자를 넣고 지우면 매번 뒤 글자를 모두 옮겨야 해 입력 길이의 제곱에 비례하는 시간이 걸릴 수 있다.

화살표, 백스페이스, 글자 입력은 모두 커서에 바로 붙은 글자만 건드리므로 커서의 왼쪽과 오른쪽을 서로 다른 덱으로 관리하면 된다. 그러면 `<`와 `>`는 커서에 붙은 글자 하나를 반대쪽 덱으로 옮기는 일이 되고, 글자 입력과 `-`는 왼쪽 덱의 맨 뒤에서만 일어나 모두 상수 시간에 끝난다. 꺼낼 쪽 덱이 비어 있으면 지우거나 움직일 수 없는 상태이므로 무시한다. 글자가 덱 사이를 이렇게 오가도 두 덱 모두 글자의 좌우 순서가 유지되어, 왼쪽 덱 뒤에 오른쪽 덱을 이어 붙인 것이 비밀번호다.

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringBuilder sb = new StringBuilder();

        int t = Integer.parseInt(br.readLine());
        while (t-- > 0) {
            Deque<Character> f = new ArrayDeque<>();
            Deque<Character> b = new ArrayDeque<>();

            String s = br.readLine();
            for (char c : s.toCharArray()) {
                if (c == '-') {
                    if (!f.isEmpty()) f.pollLast();
                } else if (c == '<') {
                    if (!f.isEmpty()) b.offerFirst(f.pollLast());
                } else if (c == '>') {
                    if (!b.isEmpty()) f.offerLast(b.pollFirst());
                } else {
                    f.offerLast(c);
                }
            }

            for (char c : f) {
                sb.append(c);
            }
            for (char c : b) {
                sb.append(c);
            }
            sb.append("\n");
        }

        System.out.println(sb);
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    int t;
    cin >> t;

    while (t--) {
        deque<char> f, b;

        string s;
        cin >> s;

        for (char c : s) {
            if (c == '-') {
                if (!f.empty()) f.pop_back();
            } else if (c == '<') {
                if (!f.empty()) {
                    b.push_front(f.back());
                    f.pop_back();
                }
            } else if (c == '>') {
                if (!b.empty()) {
                    f.push_back(b.front());
                    b.pop_front();
                }
            } else {
                f.push_back(c);
            }
        }

        for (char c : f) cout << c;
        for (char c : b) cout << c;
        cout << '\n';
    }
}
```

```python
import sys
from collections import deque

input = sys.stdin.readline

t = int(input())
for _ in range(t):
    f = deque()
    b = deque()

    s = input().rstrip()
    for c in s:
        if c == "-":
            if f:
                f.pop()
        elif c == "<":
            if f:
                b.appendleft(f.pop())
        elif c == ">":
            if b:
                f.append(b.popleft())
        else:
            f.append(c)

    print("".join(f) + "".join(b))
```

`sys.stdin.readline`은 줄바꿈까지 읽어 오므로 `rstrip`으로 지워 줄바꿈이 덱에 글자로 들어가지 않게 했다.
