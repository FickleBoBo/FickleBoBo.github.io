## 1. 아이디어

[[BaekJoon] #15649 - N과 M (1)](/posts/baekjoon-15649/)과 달리 1부터 $N$까지가 아니라 입력으로 주어진 $N$개의 자연수에서 $M$개를 중복 없이 골라 만든 순열을 사전 순으로 출력하는 문제다. 입력을 오름차순으로 정렬해 두면 작은 인덱스를 먼저 시도하는 것이 작은 값을 먼저 시도하는 것과 같아지므로, 1부터 $N$까지 고르던 때의 수 자리에 인덱스를 두고 같은 백트래킹을 그대로 쓴다. 사용 여부도 값이 아닌 인덱스로 표시한다. 입력의 수가 모두 다르므로 인덱스가 다르면 값도 달라 같은 수열이 두 번 나오지 않는다.

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;
import java.util.*;

public class Main {

    static StringBuilder sb = new StringBuilder();
    static int n, m;
    static int[] arr;
    static int[] sel;
    static boolean[] vis;

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());

        n = Integer.parseInt(st.nextToken());
        m = Integer.parseInt(st.nextToken());

        arr = new int[n];
        st = new StringTokenizer(br.readLine());
        for (int i = 0; i < n; i++) {
            arr[i] = Integer.parseInt(st.nextToken());
        }
        Arrays.sort(arr);

        sel = new int[m];
        vis = new boolean[n];

        dfs(0);
        System.out.println(sb);
    }

    static void dfs(int depth) {
        if (depth == m) {
            for (int x : sel) {
                sb.append(x).append(" ");
            }
            sb.append("\n");
            return;
        }

        for (int i = 0; i < n; i++) {
            if (vis[i]) continue;

            sel[depth] = arr[i];
            vis[i] = true;
            dfs(depth + 1);
            vis[i] = false;
        }
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int n, m;
int arr[8];
int sel[8];
bool vis[8];

void dfs(int depth) {
    if (depth == m) {
        for (int i = 0; i < m; i++) cout << sel[i] << ' ';
        cout << '\n';
        return;
    }

    for (int i = 0; i < n; i++) {
        if (vis[i]) continue;

        sel[depth] = arr[i];
        vis[i] = true;
        dfs(depth + 1);
        vis[i] = false;
    }
}

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    cin >> n >> m;
    for (int i = 0; i < n; i++) cin >> arr[i];
    sort(arr, arr + n);

    dfs(0);
}
```

```python
import sys
from itertools import permutations

input = sys.stdin.readline

n, m = map(int, input().split())
arr = sorted(map(int, input().split()))
out = [" ".join(map(str, seq)) for seq in permutations(arr, m)]
print("\n".join(out))
```

`permutations`는 입력의 순서대로 고르므로 `sorted`로 정렬한 배열을 넘겨 사전 순을 맞췄다.
