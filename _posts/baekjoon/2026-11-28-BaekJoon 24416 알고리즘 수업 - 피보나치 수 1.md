## 1. 아이디어

$n$번째 피보나치 수를 재귀 호출로 구할 때의 코드1 실행 횟수와 동적 프로그래밍으로 구할 때의 코드2 실행 횟수를 구하는 문제다. 재귀 호출은 코드1에서 1을 반환하거나 두 호출의 결과를 더할 뿐이라 최종 결과는 코드1이 반환한 1들의 합이고, 따라서 코드1의 실행 횟수는 $n$번째 피보나치 수와 같다. 코드2는 $i$가 3부터 $n$까지 도는 반복문 안에 있어 $n - 2$번 실행된다. 재귀를 그대로 실행하며 세면 $n$이 최대 40일 때 호출이 약 $2 \times 10^8$번에 이르므로, 코드1의 횟수는 동적 프로그래밍으로 $n$번째 피보나치 수를 구해 얻는다.

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        int n = Integer.parseInt(br.readLine());

        int[] dp = new int[1 + 40];
        dp[1] = dp[2] = 1;
        for (int i = 3; i <= 40; i++) {
            dp[i] = dp[i - 1] + dp[i - 2];
        }

        System.out.println(dp[n] + " " + (n - 2));
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int dp[1 + 40] = {0, 1, 1};

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    int n;
    cin >> n;

    for (int i = 3; i <= 40; i++) {
        dp[i] = dp[i - 1] + dp[i - 2];
    }

    cout << dp[n] << ' ' << n - 2;
}
```

```python
import sys

input = sys.stdin.readline

dp = [0] * (1 + 40)
dp[1], dp[2] = 1, 1
for i in range(3, 41):
    dp[i] = dp[i - 1] + dp[i - 2]

print(dp[n], n - 2)
```
