## 1. 아이디어

모든 글자를 소문자로 바꾸는 문제다. 이미 소문자인 글자는 변환해도 그대로이고 알파벳 이외의 문자도 없어서 글자마다 조건을 따지지 않고 전부 변환하면 된다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public String solution(String myString) {
        return myString.toLowerCase();
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

string solution(string myString) {
    for (char& c : myString) c = tolower(c);
    return myString;
}
```

문자 하나를 바꾸는 `std::tolower`를 `char&`로 순회하며 문자마다 적용해 제자리에서 바꿨다.

```python
def solution(myString):
    return myString.lower()
```
