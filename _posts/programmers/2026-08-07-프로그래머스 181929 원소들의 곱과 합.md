## 1. 아이디어

모든 원소의 곱과 합의 제곱의 대소관계를 비교하는 문제로 반복문을 활용해 구한 후 비교해줬다.

---

## 2. 복잡도

| 시간복잡도 | 공간복잡도 |
| :--------: | :--------: |
|   $O(N)$   |   $O(1)$   |

> $N$ = `num_list` 길이

---

## 3. 코드

### 풀이 [Java][C++]

```java
class Solution {
    public int solution(int[] num_list) {
        long mul = 1;
        int sum = 0;

        for (int x : num_list) {
            mul *= x;
            sum += x;
        }

        return mul < sum * sum ? 1 : 0;
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;
```
