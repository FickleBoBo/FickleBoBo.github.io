## 1. 아이디어

문구를 한 줄로 적을 때 편지지의 최소 가로길이를 구하는 문제다. 글자 하나가 가로 2cm이고 공백도 한 글자로 치므로, 문구의 길이에 2를 곱한 값이 그대로 답이다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int solution(String message) {
        return message.length() * 2;
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int solution(string message) {
    return message.size() * 2;
}
```

```python
def solution(message):
    return len(message) * 2
```
