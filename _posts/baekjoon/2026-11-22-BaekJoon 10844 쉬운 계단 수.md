## 1. 아이디어

인접한 자리의 차이가 모두 1인 길이 $N$의 수, 곧 계단 수의 개수를 1,000,000,000으로 나눈 나머지를 구하는 문제이다. 끝자리가 $j$인 길이 $i$의 계단 수의 개수를 $f(i, j)$라 하면 끝자리가 $j$이려면 바로 앞 자리가 $j - 1$이거나 $j + 1$이어야 하므로 $f(i, j) = f(i - 1, j - 1) + f(i - 1, j + 1)$이다. 끝자리가 0이면 앞 자리는 1뿐이고 9이면 8뿐이라 이 두 경계에서는 항이 하나이며, 길이 1에서는 0으로 시작하는 수가 계단 수가 아니므로 $f(1, j) = 1$($1 \le j \le 9$)이고 $f(1, 0) = 0$이다. 답은 $f(N, 0)$부터 $f(N, 9)$까지의 합이고, 점화식이 덧셈뿐이라 매 항마다 1,000,000,000으로 나눈 나머지를 취해도 최종 나머지는 같다.

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;

public class Main {

    static final int MOD = 1_000_000_000;

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        int n = Integer.parseInt(br.readLine());

        int[][] dp = new int[1 + n][10];
        for (int j = 1; j <= 9; j++) {
            dp[1][j] = 1;
        }

        for (int i = 2; i <= n; i++) {
            dp[i][0] = dp[i - 1][1];
            for (int j = 1; j <= 8; j++) {
                dp[i][j] = (dp[i - 1][j - 1] + dp[i - 1][j + 1]) % MOD;
            }
            dp[i][9] = dp[i - 1][8];
        }

        long sum = 0;
        for (int j = 0; j <= 9; j++) {
            sum += dp[n][j];
        }

        System.out.println(sum % MOD);
    }
}
```

각 항은 1,000,000,000 미만이지만 열 개를 더하면 `int` 범위를 넘을 수 있어 합은 `long`으로 구했다.

```c++
    }

    for (int i = 2; i <= n; i++) {
        dp[i][0] = dp[i - 1][1];
        for (int j = 1; j <= 8; j++) {
            dp[i][j] = (dp[i - 1][j - 1] + dp[i - 1][j + 1]) % MOD;
        }
        dp[i][9] = dp[i - 1][8];
    }

    long long sum = 0;
    for (int j = 0; j <= 9; j++) {
        sum += dp[n][j];
    }

    cout << sum % MOD;
}
```

각 항은 1,000,000,000 미만이지만 열 개를 더하면 `int` 범위를 넘을 수 있어 합은 `long long`으로 구했다.

```python
import sys

input = sys.stdin.readline

MOD = 1_000_000_000

n = int(input())
dp = [[0] * 10 for _ in range(1 + n)]
for j in range(1, 10):
    dp[1][j] = 1

for i in range(2, n + 1):
    dp[i][0] = dp[i - 1][1]
    for j in range(1, 9):
        dp[i][j] = (dp[i - 1][j - 1] + dp[i - 1][j + 1]) % MOD
    dp[i][9] = dp[i - 1][8]

print(sum(dp[n]) % MOD)
```
