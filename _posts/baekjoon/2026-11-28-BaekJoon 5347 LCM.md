## 1. 아이디어

두 자연수의 최소공배수를 테스트 케이스마다 구하는 문제다. 두 수의 곱은 최대공약수와 최소공배수의 곱과 같으므로, 유클리드 호제법으로 최대공약수를 구해 곱을 나누면 된다. 다만 두 수가 최대 1,000,000이라 최소공배수가 $10^{12}$에 가까워질 수 있으므로 64비트 정수로 계산해야 한다.

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringBuilder sb = new StringBuilder();

        int t = Integer.parseInt(br.readLine());
        while (t-- > 0) {
            StringTokenizer st = new StringTokenizer(br.readLine());
            int a = Integer.parseInt(st.nextToken());
            int b = Integer.parseInt(st.nextToken());
            sb.append(lcm(a, b)).append("\n");
        }

        System.out.println(sb);
    }

    static int gcd(int a, int b) {
        if (b == 0) return a;
        return gcd(b, a % b);
    }

    static long lcm(int a, int b) {
        return (long) a / gcd(a, b) * b;
    }
}
```

`lcm`의 반환 타입을 `long`으로 두고 `a`를 먼저 `long`으로 변환해 곱셈이 `int` 범위에서 이뤄지지 않게 했다.

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    int t;
    cin >> t;

    while (t--) {
        long long a, b;
        cin >> a >> b;
        cout << lcm(a, b) << '\n';
    }
}
```

`a`, `b`를 `long long`으로 받아 `std::lcm`의 결과도 `long long`이 되게 했다. `std::lcm`은 C++17부터 쓸 수 있다.

```python
import math
import sys

input = sys.stdin.readline

t = int(input())
for _ in range(t):
    a, b = map(int, input().split())
    print(math.lcm(a, b))
```

`math.lcm`으로 최소공배수를 바로 구했다. 이 함수는 Python 3.9부터 쓸 수 있다.
