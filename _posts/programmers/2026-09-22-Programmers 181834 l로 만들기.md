## 1. 아이디어

각 글자를 `"l"`과 비교해 알파벳 순서에서 앞서는 글자만 `"l"`로 바꾸는 문제다. 글자 하나를 바꾸는 일이 다른 글자에 영향을 주지 않고 입력이 소문자뿐이므로, 글자마다 `"l"`보다 앞서는지만 보면 된다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public String solution(String myString) {
        char[] arr = myString.toCharArray();
        for (int i = 0; i < arr.length; i++) {
            if ('a' <= arr[i] && arr[i] < 'l') arr[i] = 'l';
        }

        return new String(arr);
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

string solution(string myString) {
    for (char& c : myString) c = max(c, 'l');
    return myString;
}
```

`'l'`보다 작은 글자만 `'l'`이 되므로 `std::max(c, 'l')`로 한 번에 바꿨다.

```python
def solution(myString):
    return myString.translate(str.maketrans("abcdefghijk", "l" * 11))
```

`"a"`~`"k"` 11글자를 모두 `"l"`로 대응시키는 변환표를 `str.maketrans`로 만들고 `translate`로 한 번에 바꿨다. `translate`는 표에 없는 글자를 그대로 둔다.
