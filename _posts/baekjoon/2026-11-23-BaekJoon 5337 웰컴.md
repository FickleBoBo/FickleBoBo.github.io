## 2. 코드

### 풀이 [Java][C++][Python]

문자열 안에서 백슬래시는 이스케이프 문자라 `\`를 한 글자 출력하려고 `\\`로 두 번 썼다.

```java
public class Main {
    public static void main(String[] args) {
        System.out.println(".  .   .");
        System.out.println("|  | _ | _. _ ._ _  _");
        System.out.println("|/\\|(/.|(_.(_)[ | )(/.");
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    cout << ".  .   ." << '\n';
    cout << "|  | _ | _. _ ._ _  _" << '\n';
    cout << "|/\\|(/.|(_.(_)[ | )(/." << '\n';
}
```

```python
print(".  .   .")
print("|  | _ | _. _ ._ _  _")
```
