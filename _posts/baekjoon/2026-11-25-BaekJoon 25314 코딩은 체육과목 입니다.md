## 1. 아이디어

$N$바이트까지 저장할 수 있는 정수 자료형의 이름을 구하는 문제로, `long int`가 4바이트이고 `long`이 하나 더 붙을 때마다 4바이트씩 늘어난다. $N$은 4의 배수로 주어지므로 `long`을 $N / 4$번 쓰고 마지막에 `int`를 붙인다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringBuilder sb = new StringBuilder();

        int n = Integer.parseInt(br.readLine());
        for (int i = 0; i < n / 4; i++) {
            sb.append("long ");
        }
        sb.append("int");

        System.out.println(sb);
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    int n;
    cin >> n;

    for (int i = 0; i < n / 4; i++) {
        cout << "long ";
    }
    cout << "int";
}
```

```python
import sys

input = sys.stdin.readline

n = int(input())
print("long " * (n // 4) + "int")
```
