## 1. 아이디어

`A`와 `B`의 등장 횟수를 비교만 하면 된다.

---

## 2. 복잡도

| 접근 | 시간   | 공간   |
| ---- | ------ | ------ |
| 풀이 | $O(V)$ | $O(V)$ |

($V$ = 입력값 `v`)

---

## 3. 코드

### 풀이 [Java][C++]

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        int a = 0;
        int b = 0;
        int v = Integer.parseInt(br.readLine());
        String s = br.readLine();

        for (int i = 0; i < v; i++) {
            if (s.charAt(i) == 'A') {
                a++;
            } else {
                b++;
            }
        }

        if (a > b) {
            System.out.println("A");
        } else if (a < b) {
            System.out.println("B");
        } else {
            System.out.println("Tie");
        }
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);

    int a = 0;
    int b = 0;

    int v;
    string s;
    cin >> v >> s;

    for (char c : s) {
        if (c == 'A') {
            a++;
        } else {
            b++;
        }
    }

    if (a > b) {
        cout << 'A';
    } else if (a < b) {
        cout << 'B';
    } else {
        cout << "Tie";
    }
}
```
