## 1. 아이디어

세 변으로 삼각형을 만들 수 있는지 판정하는 문제로, 가장 긴 변이 나머지 두 변의 합보다 작아야 한다. 가장 긴 변을 $c$라 하면 다른 변 $a$는 $a \le c$이고 남은 변 $b$는 양수이므로 $a < b + c$가 저절로 성립한다. 그래서 $c$ 하나만 확인하면 되고, 정렬하면 $c$가 맨 뒤에 오므로 앞의 두 변의 합과 비교한다. 합이 더 크면 만들 수 있어 1을, 아니면 2를 반환한다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.util.*;

class Solution {
    public int solution(int[] sides) {
        Arrays.sort(sides);
        return sides[0] + sides[1] > sides[2] ? 1 : 2;
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int solution(vector<int> sides) {
    sort(sides.begin(), sides.end());
    return sides[0] + sides[1] > sides[2] ? 1 : 2;
}
```

```python
def solution(sides):
    sides.sort()
    return 1 if sides[0] + sides[1] > sides[2] else 2
```
