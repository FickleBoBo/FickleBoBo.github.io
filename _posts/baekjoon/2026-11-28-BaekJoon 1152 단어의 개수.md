## 1. 아이디어

문자열에서 공백으로 구분된 단어의 수를 세는 문제다. 단어 사이의 공백은 하나씩이지만 문자열이 공백으로 시작하거나 끝날 수 있어 공백의 수에 1을 더하는 식으로는 셀 수 없다. 공백은 건너뛰고 실제로 나타나는 단어만 세면 앞뒤 공백에 영향받지 않는다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        System.out.println(new StringTokenizer(br.readLine()).countTokens());
    }
}
```

`StringTokenizer`는 앞뒤 공백을 건너뛰고 빈 토큰을 만들지 않아 `countTokens`로 단어 수를 바로 셌다.

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    string s;
    int cnt = 0;

    while (cin >> s) {
        cnt++;
    }

    cout << cnt;
}
```

`cin >>`은 공백을 건너뛰며 한 단어씩 읽으므로 읽기에 성공한 횟수를 셌다.

```python
import sys

input = sys.stdin.readline

print(len(input().split()))
```

`split`을 인자 없이 호출해 앞뒤 공백이 있어도 빈 문자열이 생기지 않게 했다. `split(" ")`는 앞뒤 공백이 있으면 빈 문자열이나 줄바꿈만 남은 조각까지 담아 개수가 늘어난다.
