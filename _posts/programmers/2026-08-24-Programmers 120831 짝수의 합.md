## 1. 아이디어

`n` 이하의 짝수를 모두 더한 값을 구하는 문제다.

가장 직관적인 방법은 `2`부터 `n`까지 `2`씩 증가시키면서 값을 그대로 누적하는 것이다.

짝수의 합은 등차수열의 합 공식으로도 바로 구할 수 있다. `n` 이하의 짝수는 $2, 4, \ldots, 2k$ ($k = \lfloor n / 2 \rfloor$) 형태의 등차수열이므로, 첫째항과 마지막항의 합에 항의 개수를 곱해 $2$로 나누는 공식 $\dfrac{(2 + 2k) \times k}{2}$, 이를 정리하면 $k(k + 1)$로 반복문 없이 한 번에 계산할 수 있다.

---

## 2. 복잡도

| 접근             | 시간   | 공간   |
| ---------------- | ------ | ------ |
| 직접 순회        | $O(N)$ | $O(1)$ |
| 등차수열 합 공식 | $O(1)$ | $O(1)$ |

($N$ = 입력값 `n`)

---

## 3. 코드

### 풀이: 직접 순회 [Java][C++][Python]

```java
class Solution {
    public int solution(int n) {
        int sum = 0;
        for (int i = 2; i <= n; i += 2) {
            sum += i;
        }

        return sum;
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int solution(int n) {
    int sum = 0;
    for (int i = 2; i <= n; i += 2) {
        sum += i;
    }

    return sum;
}
```

```python
def solution(n):
    return sum(range(2, n + 1, 2))
```

### 풀이 2: 등차수열 합 공식 [Java][C++][Python]

```java
class Solution {
    public int solution(int n) {
        int k = n / 2;
        return k * (k + 1);
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int solution(int n) {
    int k = n / 2;
    return k * (k + 1);
}
```

```python
def solution(n):
    k = n // 2
    return k * (k + 1)
```
