## 1. 아이디어

$N$이 3의 거듭제곱일 때 프랙탈 형태로 크기 $N$의 별 모양을 찍는 문제다. 크기 $N$의 패턴은 $N \times N$ 정사각형을 가로세로로 3등분한 $3 \times 3$ 구획으로 나뉘고, 지문대로 가운데 구획만 공백이며 나머지 8개 구획은 크기 $N / 3$의 패턴이다. 그래서 8개 구획에 크기 $N / 3$의 패턴을 그리는 일을 재귀로 하고, 가운데 구획은 호출하지 않아 공백으로 남긴다.

크기가 1이 되면 칸 하나에 별을 찍는다. 크기 3은 칸 8개에 별이 찍히고 가운데 한 칸만 비므로 지문이 준 크기 3의 패턴과 일치한다. 재귀는 구획 단위로 그려지지만 출력은 줄 단위이므로 별이 놓이는 칸을 격자에 먼저 표시한 뒤 줄 순서대로 출력한다.

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;

public class Main {

    static boolean[][] vis;

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        BufferedWriter bw = new BufferedWriter(new OutputStreamWriter(System.out));

        int n = Integer.parseInt(br.readLine());
        vis = new boolean[n][n];

        dfs(0, 0, n);

        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                if (vis[i][j]) {
                    bw.write("*");
                } else {
                    bw.write(" ");
                }
            }
            bw.newLine();
        }

        bw.flush();
    }

    static void dfs(int sr, int sc, int n) {
        if (n == 1) {
            vis[sr][sc] = true;
            return;
        }

        dfs(sr, sc, n / 3);
        dfs(sr, sc + n / 3, n / 3);
        dfs(sr, sc + n / 3 * 2, n / 3);
        dfs(sr + n / 3, sc, n / 3);
        dfs(sr + n / 3, sc + n / 3 * 2, n / 3);
        dfs(sr + n / 3 * 2, sc, n / 3);
        dfs(sr + n / 3 * 2, sc + n / 3, n / 3);
        dfs(sr + n / 3 * 2, sc + n / 3 * 2, n / 3);
    }
}
```

```c++
    if (n == 1) {

    }

    dfs(sr, sc, n / 3);
    dfs(sr, sc + n / 3, n / 3);

    dfs(sr + n / 3 * 2, sc, n / 3);
    dfs(sr + n / 3 * 2, sc + n / 3, n / 3);
    dfs(sr + n / 3 * 2, sc + n / 3 * 2, n / 3);
}

int main() {
    ios::sync_with_stdio(0);

    for (int i = 0; i < n; i++) {

                cout << ' ';
```

```python
import sys

input = sys.stdin.readline
out = []


def dfs(sr, sc, n):
    if n == 1:
        vis[sr][sc] = True
        return
    dfs(sr, sc, n // 3)
    dfs(sr, sc + n // 3, n // 3)
    dfs(sr, sc + n // 3 * 2, n // 3)
    dfs(sr + n // 3, sc, n // 3)
    dfs(sr + n // 3, sc + n // 3 * 2, n // 3)
    dfs(sr + n // 3 * 2, sc, n // 3)
    dfs(sr + n // 3 * 2, sc + n // 3, n // 3)
    dfs(sr + n // 3 * 2, sc + n // 3 * 2, n // 3)


n = int(input())

vis = [[False] * n for _ in range(n)]
dfs(0, 0, n)

for row in vis:
    out.append("".join("*" if x else " " for x in row))

print("\n".join(out))
```
