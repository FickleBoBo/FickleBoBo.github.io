## 1. 아이디어

`start_num`부터 시작해 1씩 감소시키며 `end_num`에 도달할 때까지의 값을 순서대로 리스트에 담으면 된다. 담기는 원소의 개수는 `start_num - end_num + 1`개다.

---

## 2. 복잡도

| 접근 | 시간   | 공간   |
| ---- | ------ | ------ |
| 풀이 | $O(N)$ | $O(N)$ |

($N$ = `start_num - end_num + 1`)

---

## 3. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int[] solution(int start_num, int end_num) {
        int[] arr = new int[start_num - end_num + 1];
        for (int i = 0; i < arr.length; i++) {
            arr[i] = start_num - i;
        }

        return arr;
    }
}
```

결과 길이가 `start_num - end_num + 1`로 정해지므로 배열 크기를 미리 잡고 인덱스별로 채웠다.

```c++
#include <bits/stdc++.h>
using namespace std;

vector<int> solution(int start_num, int end_num) {
    vector<int> v;
    for (int i = start_num; i >= end_num; i--) {
        v.push_back(i);
    }

    return v;
}
```

```python
def solution(start_num, end_num):
    return list(range(start_num, end_num - 1, -1))
```
