## 1. 아이디어

문자열이 현관문 비밀번호로 사용 가능한지 판정하는 문제로, 길이가 6 이상 9 이하이면 `yes`, 아니면 `no`를 출력한다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        BufferedWriter bw = new BufferedWriter(new OutputStreamWriter(System.out));

        int n = Integer.parseInt(br.readLine());
        while (n-- > 0) {
            String s = br.readLine();

            if (6 <= s.length() && s.length() <= 9) {
                bw.write("yes\n");
            } else {
                bw.write("no\n");
            }
        }

        bw.flush();
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    int n;
    cin >> n;

    while (n--) {
        string s;
        cin >> s;

        if (6 <= s.size() && s.size() <= 9) {
            cout << "yes\n";
        } else {
            cout << "no\n";
        }
    }
}
```

```python
import sys

input = sys.stdin.readline

n = int(input())
out = []
for _ in range(n):
    s = input().strip()
    out.append("yes" if 6 <= len(s) <= 9 else "no")

print("\n".join(out))
```

`sys.stdin.readline`은 줄바꿈까지 읽어 오므로 `strip`으로 지웠다. 지우지 않으면 길이가 1 더 커져 9자리가 10자리로 계산된다.
