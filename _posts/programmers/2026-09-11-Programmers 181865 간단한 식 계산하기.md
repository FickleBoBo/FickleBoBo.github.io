## 1. 아이디어

식은 항상 피연산자 $a$, 연산자, 피연산자 $b$가 공백으로 구분된 세 토큰이므로, 공백으로 나눠 두 수를 정수로 바꾼 뒤 연산자에 맞게 계산하면 된다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.util.*;

class Solution {
    public int solution(String binomial) {
        StringTokenizer st = new StringTokenizer(binomial);
        int a = Integer.parseInt(st.nextToken());
        String op = st.nextToken();
        int b = Integer.parseInt(st.nextToken());

        if (op.equals("+")) return a + b;
        if (op.equals("-")) return a - b;
        return a * b;
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int solution(string binomial) {
    stringstream ss(binomial);
    int a, b;
    string op;
    ss >> a >> op >> b;

    if (op == "+") return a + b;
    if (op == "-") return a - b;
    return a * b;
}
```

```python
def solution(binomial):
    a, op, b = binomial.split()
    a, b = int(a), int(b)

    if op == "+":
        return a + b
    if op == "-":
        return a - b
    return a * b
```
