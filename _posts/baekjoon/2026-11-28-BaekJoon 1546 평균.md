## 1. 아이디어

모든 점수를 최고점 $M$으로 나눈 뒤 100을 곱한 값으로 고쳤을 때의 평균을 구하는 문제다. 점수를 고치려면 최고점이 먼저 필요하므로 점수를 모두 받아 $M$을 구한 다음, 각 점수를 고쳐서 더하고 과목 수 $N$으로 나누면 된다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        int n = Integer.parseInt(br.readLine());

        int[] arr = new int[n];
        int max = 0;

        StringTokenizer st = new StringTokenizer(br.readLine());
        for (int i = 0; i < n; i++) {
            arr[i] = Integer.parseInt(st.nextToken());
            max = Math.max(max, arr[i]);
        }

        double sum = 0;
        for (int x : arr) {
            sum += (double) x / max * 100;
        }

        System.out.println(sum / n);
    }
}
```

점수와 최댓값이 모두 `int`라 그대로 나누면 몫만 남으므로 `x`를 `double`로 형변환한 뒤 나눴다.

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    int n;
    cin >> n;

    vector<int> v(n);
    for (int& x : v) cin >> x;
    int mx = *max_element(v.begin(), v.end());

    double sum = 0;
    for (int x : v) {
        sum += (double)x / mx * 100;
    }

    cout << sum / n;
}
```

점수와 최댓값이 모두 `int`라 그대로 나누면 몫만 남으므로 `x`를 `double`로 형변환한 뒤 나눴다. `cout`의 기본 출력은 유효숫자 6자리인데, 평균은 100 이하라 소수점 아래가 3자리 이상 남아 허용 오차 $10^{-2}$ 안에 든다.

```python
import sys

input = sys.stdin.readline

n = int(input())
arr = list(map(int, input().split()))
mx = max(arr)

total = 0
for x in arr:
    total += x / mx * 100

print(total / n)
```
