## 1. 아이디어

`num`을 `n`으로 나눈 나머지가 0인지만 확인해주면 된다.

---

## 2. 복잡도

| 시간복잡도 | 공간복잡도 |
| :--------: | :--------: |
|   $O(1)$   |   $O(1)$   |

---

## 3. 코드

### 풀이 [Java][C++]

```java
class Solution {
    public int solution(int num, int n) {
        return num % n == 0 ? 1 : 0;
    }
}
```

```c++
int solution(int num, int n) {
    return num % n == 0;
}
```
