## 1. 아이디어

알파벳 소문자로 이루어진 문자열 `myString`이 주어졌을 때, `myString`에서 알파벳 `l`보다 앞서는 문자들은 전부 `l`로 바꾼 문자열을 반환하는 간단한 문제다.

---

## 2. 복잡도

| 접근 | 시간   | 공간   |
| ---- | ------ | ------ |
| 풀이 | $O(N)$ | $O(N)$ |

($N$ = `myString`의 길이. C++는 인자를 제자리 수정해 반환해 공간 $O(1)$)

---

## 3. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public String solution(String myString) {
        char[] arr = myString.toCharArray();
        for (int i = 0; i < arr.length; i++) {
            if ('a' <= arr[i] && arr[i] < 'l') arr[i] = 'l';
        }

        return new String(arr);
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

string solution(string myString) {
    for (char& c : myString) c = max(c, 'l');
    return myString;
}
```

```python
def solution(myString):
    return myString.translate(str.maketrans("abcdefghijk", "l" * 11))
```

`str.maketrans`를 활용해서 `abcdefghijk`를 `lllllllllll`로 치환했다.
