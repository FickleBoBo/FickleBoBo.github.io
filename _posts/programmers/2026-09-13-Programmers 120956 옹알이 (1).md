## 1. 아이디어

단어가 네 가지 발음 `"aya"`, `"ye"`, `"woo"`, `"ma"`를 이어 붙여 만들 수 있는지 판별하는 문제로, 각 발음은 한 단어에 많아야 한 번 등장한다. 따라서 단어에서 네 발음을 하나씩 지워 낸 뒤 글자가 하나도 남지 않으면 발음으로만 이루어진 단어다. 이때 지운 자리를 빈 문자열로 두면 양옆의 글자가 붙어 새 발음이 만들어질 수 있으므로(`"wyeoo"`에서 `"ye"`를 지우면 `"woo"`가 되어 발음할 수 있는 단어로 잘못 판정된다) 발음이 아닌 다른 문자로 바꿔 둔다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int solution(String[] babbling) {
        int cnt = 0;
        for (String s : babbling) {
            String res = s
                    .replace("aya", " ")
                    .replace("ye", " ")
                    .replace("woo", " ")
                    .replace("ma", " ");

            if (res.isBlank()) cnt++;
        }

        return cnt;
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int solution(vector<string> babbling) {
    int cnt = 0;
    for (string& s : babbling) {
        for (string p : {"aya", "ye", "woo", "ma"}) {
            int pos = s.find(p);
            if (pos != -1) s.replace(pos, p.size(), " ");
        }

        bool flag = true;
        for (char c : s) {
            if (!isspace(c)) flag = false;
        }
        if (flag) cnt++;
    }

    return cnt;
}
```

각 발음이 한 번만 등장하므로 `find`로 찾은 첫 위치만 `replace`했다. `find`가 못 찾으면 반환하는 `std::string::npos`는 `int`에 담으면 -1이 된다.

```python
def solution(babbling):
    cnt = 0
    for s in babbling:
        for pat in ("aya", "ye", "woo", "ma"):
            s = s.replace(pat, " ")

        if not s.strip():
            cnt += 1

    return cnt
```
