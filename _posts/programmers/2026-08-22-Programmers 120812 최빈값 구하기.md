## 1. 아이디어

정수 배열 `array`가 주어질 때 최빈값을 찾되, 최빈값이 여러 개면 -1을 반환하면 되는 문제다. `array`의 원소가 0 이상 1000 미만으로 제한되므로, 값별 등장 횟수를 크기 1000짜리 배열(또는 해시맵)에 세어두고 가장 큰 카운트를 가진 값을 찾으면 된다. 이때 최댓값 카운트를 가진 값이 둘 이상이면 -1을 반환해야 한다.

---

## 2. 복잡도

| 접근 | 시간   | 공간   |
| ---- | ------ | ------ |
| 풀이 | $O(N)$ | $O(1)$ |

($N$ = `array`의 길이. 원소 값의 상한이 상수라 등장 횟수를 담는 구조의 크기가 입력과 무관하게 상수)

---

## 3. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int solution(int[] array) {
        int[] cnt = new int[1000];
        for (int x : array) {
            cnt[x]++;
        }

        int ans = -1;
        int max = 0;
        boolean uniq = false;

        for (int i = 0; i < 1000; i++) {
            if (cnt[i] > max) {
                ans = i;
                max = cnt[i];
                uniq = true;
            } else if (cnt[i] == max) {
                uniq = false;
            }
        }

        return uniq ? ans : -1;
    }
}
```

```c++
#include <bits/stdc++.h>

int cnt[1000];

int solution(vector<int> array) {
    for (int x : array) cnt[x]++;

    int ans = -1;
    int mx = 0;
    bool uniq = false;

    for (int i = 0; i < 1000; i++) {
        if (cnt[i] > mx) {
            ans = i;
            mx = cnt[i];
            uniq = true;
        } else if (cnt[i] == mx) {
            uniq = false;
        }
    }

    return uniq ? ans : -1;
}
```

```python
from collections import Counter


def solution(array):
    top2 = Counter(array).most_common(2)
    if len(top2) == 1 or top2[0][1] != top2[1][1]:
        return top2[0][0]
    return -1
```

`Counter`로 등장 횟수를 센 뒤 `most_common(2)`로 빈도 상위 2개를 뽑았다. 서로 다른 값이 하나뿐이면 `top2`의 길이가 1이므로 그 값을 그대로 반환했다. 값이 둘 이상이면 1위와 2위의 등장 횟수를 비교해서 두 횟수가 같으면 최댓값 카운트를 가진 값이 둘 이상이라는 뜻이므로 -1을, 다르면 1위 값이 유일한 최빈값이므로 그 값을 반환하면 된다.
