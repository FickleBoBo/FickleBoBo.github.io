## 1. 아이디어

문자열 $s$를 $a^n$으로 나타낼 때 가장 큰 $n$을 구하는 문제로, 이는 $a$가 가장 짧은 반복 단위일 때이므로 $s$의 가장 짧은 주기부터 구한다. $s$의 길이를 $L$, KMP의 실패 함수에서 $s$ 전체의 접두사이면서 접미사이기도 한 가장 긴 부분(자기 자신은 제외)의 길이를 $k$라 하면 가장 짧은 주기는 $L - k$이다. 이 값이 $L$의 약수이면 $s$는 길이 $L - k$인 문자열을 $L / (L - k)$번 반복한 것이라 그 횟수가 답이고, 약수가 아니면 $L$ 미만의 어떤 약수도 주기가 될 수 없어 반복 단위가 $s$ 전체이므로 답은 1이다.

---

## 2. 코드

### 풀이 [C++]

```c++
#include <bits/stdc++.h>
using namespace std;

vector<int> failure(string& s) {
    vector<int> pi(s.size());
    int j = 0;
    for (int i = 1; i < s.size(); i++) {
        while (j > 0 && s[i] != s[j]) j = pi[j - 1];
        if (s[i] == s[j]) pi[i] = ++j;
    }
    return pi;
}

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    while (true) {
        string s;
        cin >> s;

        if (s == ".") return 0;

        vector<int> pi = failure(s);
        int n = s.size();
        int p = n - pi.back();

        cout << (n % p == 0 ? n / p : 1) << '\n';
    }
}
```
