## 1. 아이디어

가장 작은 인덱스를 구하므로 `idx`부터 오른쪽으로 훑다가 처음 만나는 `1`에서 멈추면 된다. `idx`보다 크거나 같은 인덱스가 대상이라 `idx` 자체도 검사한다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int solution(int[] arr, int idx) {
        for (int i = idx; i < arr.length; i++) {
            if (arr[i] == 1) return i;
        }

        return -1;
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int solution(vector<int> arr, int idx) {
    for (int i = idx; i < arr.size(); i++) {
        if (arr[i] == 1) return i;
    }

    return -1;
}
```

```python
def solution(arr, idx):
    return next((i for i in range(idx, len(arr)) if arr[i] == 1), -1)
```

`next`의 두 번째 인자로 -1을 넘겨서 조건에 맞는 인덱스가 하나도 없을 때 예외 대신 -1이 나오게 했다.
