## 1. 아이디어

공백이 없는 한 줄이 주어지므로 읽은 문자열을 그대로 출력하면 된다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;

public class Solution {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        System.out.println(br.readLine());
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    string s;
    cin >> s;
    cout << s;
}
```

`cin >> s`는 공백에서 끊어 읽지만, 이 문제는 공백이 없는 한 줄이라 통째로 읽힌다.

```python
import sys

input = sys.stdin.readline

print(input())
```
