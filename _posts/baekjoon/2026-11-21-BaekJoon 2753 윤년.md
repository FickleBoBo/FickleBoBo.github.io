## 1. 아이디어

윤년이면 1, 아니면 0을 출력한다. 100의 배수는 모두 4의 배수이므로 100의 배수 중에는 400의 배수만 윤년이고, 100의 배수가 아닌 수는 4의 배수이기만 하면 윤년이다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        int y = Integer.parseInt(br.readLine());

        if (((y % 4 == 0) && (y % 100 != 0)) || (y % 400 == 0)) {
            System.out.println(1);
        } else {
            System.out.println(0);
        }
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    int y;
    cin >> y;
    cout << (((y % 4 == 0) && (y % 100 != 0)) || (y % 400 == 0));
}
```

`<<`가 `==`·`&&`·`||`보다 우선순위가 높아 논리식 전체를 괄호로 묶어 `cout`에 넣었고, 이때 `bool`은 `true`와 `false`가 아니라 1과 0으로 출력된다.

```python
import sys

input = sys.stdin.readline

y = int(input())
print(int((y % 4 == 0 and y % 100 != 0) or y % 400 == 0))
```

논리식의 결과는 `True`나 `False`로 출력되므로 `int`로 감싸 1과 0으로 바꿨다.
