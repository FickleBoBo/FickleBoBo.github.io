## 1. 아이디어

곱이 $n$인 자연수 순서쌍 $(a, b)$의 개수를 구하는 문제다. $a$를 정하면 $b = n / a$로 하나로 정해지고 이것이 자연수이려면 $a$가 $n$의 약수여야 하므로, 답은 $n$의 약수의 개수다. 약수의 개수는 1부터 $n$까지 나누어떨어지는 수를 세면 구해지고, $n$이 1,000,000 이하라 이 정도 반복은 통과한다.

더 줄이려면 약수가 $a \times b = n$인 쌍으로 묶인다는 점을 쓴다. 한 쌍의 작은 쪽은 $\sqrt{n}$ 이하이므로 1부터 $\sqrt{n}$까지의 수 $i$만 확인하고, $i$가 약수이면 $n / i$도 약수이므로 둘을 함께 센다. 단 $i = \sqrt{n}$이면 $i$와 $n / i$가 같은 수이므로 한 번만 센다.

## 2. 코드

### 풀이 1: 완전 탐색 [Java][C++][Python]

```java
class Solution {
    public int solution(int n) {
        int cnt = 0;
        for (int i = 1; i <= n; i++) {
            if (n % i == 0) cnt++;
        }

        return cnt;
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int solution(int n) {
    int cnt = 0;
    for (int i = 1; i <= n; i++) {
        if (n % i == 0) cnt++;
    }

    return cnt;
}
```

```python
def solution(n):
    return sum(n % i == 0 for i in range(1, n + 1))
```

조건식이 참이면 1로 세어져 `sum`을 약수의 개수로 썼다.

### 풀이 2: 제곱근까지 탐색 [Java][C++][Python]

```java
class Solution {
    public int solution(int n) {
        int cnt = 0;
        for (int i = 1; i * i <= n; i++) {
            if (n % i == 0) {
                cnt++;
                if (i != n / i) cnt++;
            }
        }

        return cnt;
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int solution(int n) {
    int cnt = 0;
    for (int i = 1; i * i <= n; i++) {
        if (n % i == 0) {
            cnt++;
            if (i != n / i) cnt++;
        }
    }

    return cnt;
}
```

```python
import math


def solution(n):
    cnt = 0
    for i in range(1, math.isqrt(n) + 1):
        if n % i == 0:
            cnt += 1
            if i != n // i:
                cnt += 1

    return cnt
```

`math.isqrt`로 정수 제곱근(내림)을 구했다.
