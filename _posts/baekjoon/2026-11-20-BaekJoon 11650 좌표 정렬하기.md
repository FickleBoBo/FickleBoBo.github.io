## 1. 아이디어

$x$ 좌표가 작은 점이 먼저고 $x$ 좌표가 같으면 $y$ 좌표가 작은 점이 먼저라는 기준은 점을 순서쌍 $(x, y)$로 보고 앞에서부터 사전식으로 비교하는 것과 같다. 그러니 순서쌍을 그대로 정렬하면 되는데, $N$이 최대 $100{,}000$이라 $O(N^2)$ 정렬은 쓸 수 없고 $O(N \log N)$ 정렬이 필요하다.

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringBuilder sb = new StringBuilder();

        int n = Integer.parseInt(br.readLine());

        int[][] arr = new int[n][2];
        for (int i = 0; i < n; i++) {
            StringTokenizer st = new StringTokenizer(br.readLine());
            arr[i][0] = Integer.parseInt(st.nextToken());
            arr[i][1] = Integer.parseInt(st.nextToken());
        }
        Arrays.sort(arr, (o1, o2) -> {
            if (o1[0] != o2[0]) return Integer.compare(o1[0], o2[0]);
            return Integer.compare(o1[1], o2[1]);
        });

        for (int[] pos : arr) {
            sb.append(pos[0]).append(" ").append(pos[1]).append("\n");
        }

        System.out.println(sb);
    }
}
```

`Arrays.sort`에 비교자를 넘기려면 원소가 객체여야 해서, 객체인 `int[]`를 원소로 하는 `int[][]`에 점을 담았다.

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    int n;
    cin >> n;

    vector<pair<int, int>> v(n);
    for (auto& [x, y] : v) cin >> x >> y;
    sort(v.begin(), v.end());

    for (auto [x, y] : v) {
        cout << x << ' ' << y << '\n';
    }
}
```

`std::pair`는 첫 번째 값이 같을 때 두 번째 값을 비교하므로 별도 비교 함수 없이 `std::sort`만 호출했다. 입력은 `auto& [x, y]` 구조화 바인딩으로 `std::pair`에 바로 받았다.

```python
import sys

input = sys.stdin.readline

n = int(input())
pos = [tuple(map(int, input().split())) for _ in range(n)]
pos.sort()

print("\n".join(f"{x} {y}" for x, y in pos))
```

튜플도 앞에서부터 사전식으로 비교하므로 `sort`만 호출했다.
