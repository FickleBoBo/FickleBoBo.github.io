## 1. 아이디어

숫자를 차례로 더하다가 `"Z"`가 나오면 직전에 더한 숫자를 빼는 문제다. `"Z"`는 맨 앞에 오지 않고 연속해서 나오지도 않아 `"Z"` 바로 앞 토큰은 항상 방금 더한 숫자이므로, 되돌릴 숫자를 스택에 쌓을 필요 없이 직전에 더한 숫자 하나만 기억하면 된다.

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.util.*;

class Solution {
    public int solution(String s) {
        StringTokenizer st = new StringTokenizer(s);
        int sum = 0;
        int prv = 0;

        while (st.hasMoreTokens()) {
            String token = st.nextToken();
            if (token.equals("Z")) {
                sum -= prv;
            } else {
                int x = Integer.parseInt(token);
                sum += x;
                prv = x;
            }
        }

        return sum;
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int solution(string s) {
    stringstream ss(s);
    string token;
    int sum = 0;
    int prv = 0;

    while (ss >> token) {
        if (token == "Z") {
            sum -= prv;
        } else {
            int x = stoi(token);
            sum += x;
            prv = x;
        }
    }

    return sum;
}
```

```python
def solution(s):
    total, prv = 0, 0
    for token in s.split():
        if token == "Z":
            total -= prv
        else:
            x = int(token)
            total += x
            prv = x

    return total
```
