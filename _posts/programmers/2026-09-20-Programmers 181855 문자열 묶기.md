## 1. 아이디어

길이가 같은 문자열끼리 묶었을 때 가장 큰 그룹의 크기를 구하는 문제다. 묶는 기준이 내용이 아니라 길이뿐이라 길이별로 몇 개인지만 세면 되고, 그 개수의 최댓값이 답이다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.util.*;

class Solution {
    public int solution(String[] strArr) {
        int[] cnt = new int[1 + 30];
        for (String s : strArr) {
            cnt[s.length()]++;
        }

        return Arrays.stream(cnt).max().getAsInt();
    }
}
```

길이가 최대 30이라 길이를 인덱스로 하는 배열에 개수를 셌고, `max()`는 `OptionalInt`를 돌려주므로 `getAsInt()`로 값을 꺼냈다.

```c++
#include <bits/stdc++.h>
using namespace std;

int solution(vector<string> strArr) {
    vector<int> cnt(1 + 30);
    for (string& s : strArr) cnt[s.size()]++;
    return *max_element(cnt.begin(), cnt.end());
}
```

```python
from collections import Counter


def solution(strArr):
    cnt = Counter(len(s) for s in strArr)
    return max(cnt.values())
```
