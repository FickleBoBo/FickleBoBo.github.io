## 1. 아이디어

별이 $2N - 1$개에서 1개까지 2개씩 줄어드는 가운데 정렬 삼각형이다. 별은 가운데 열을 중심으로 대칭이고, 첫 줄의 별이 $2N - 1$개로 1번째 열에서 시작하므로 그 가운데 열은 $N$번째 열이다. 줄마다 양쪽 끝이 한 칸씩 안쪽으로 들어오므로 위에서부터 $i$번째 줄은 앞 공백 $i - 1$개 뒤에 별 $2(N - i) + 1$개를 찍는다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringBuilder sb = new StringBuilder();

        int n = Integer.parseInt(br.readLine());

        for (int i = 1; i <= n; i++) {
            for (int j = 1; j <= i - 1; j++) {
                sb.append(" ");
            }
            for (int j = 1; j <= 2 * (n - i) + 1; j++) {
                sb.append("*");
            }
            sb.append("\n");
        }

        System.out.println(sb);
    }
}
```
