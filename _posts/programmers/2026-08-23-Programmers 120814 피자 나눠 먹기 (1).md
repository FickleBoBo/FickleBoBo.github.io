## 1. 아이디어

$n$명에게 한 조각씩 주려면 $n$조각이 필요하고 한 판이 7조각이므로, 답은 $n$을 7로 나눈 값의 올림이다. 정수 나눗셈의 몫은 내림이라, 7로 나누기 전에 6을 더하면 나머지가 1 이상일 때만 몫이 1 커져 올림이 된다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int solution(int n) {
        return (n + 6) / 7;
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int solution(int n) {
    return (n + 6) / 7;
}
```

```python
def solution(n):
    return (n + 6) // 7
```
