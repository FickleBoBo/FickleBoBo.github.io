## 1. 아이디어

다이나믹 프로그래밍을 활용해 1부터 특정 수를 만들기 위해 필요한 최소 연산 횟수를 구하면 간단하게 해결할 수 있다. 예를 들면 1은 어떤 연산 없이도 바로 만들 수 있으므로 `dp[1] = 0`이 되며 주어진 연산의 역으로 `dp[1 * 3] = 1`, `dp[1 * 2] = 1`, `dp[1 + 1] = 1`을 구할 수 있다. 인덱스 $i$의 값 `dp[i]`는 1로부터 $i$를 만들기 위해 필요한 최소 연산 횟수가 된다.

---

## 2. 복잡도

| 접근 | 시간   | 공간   |
| ---- | ------ | ------ |
| 풀이 | $O(N)$ | $O(N)$ |

($N$ = 입력값 `n`)

---

## 3. 코드

### 풀이 [Java][C++]

```java
import java.io.*;
import java.util.*;

public class Main {

    static final int INF = 100000;

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        int n = Integer.parseInt(br.readLine());

        int[] dp = new int[1 + n * 3];
        Arrays.fill(dp, INF);
        dp[1] = 0;

        for (int i = 1; i <= n; i++) {
            dp[i * 3] = Math.min(dp[i * 3], dp[i] + 1);
            dp[i * 2] = Math.min(dp[i * 2], dp[i] + 1);
            dp[i + 1] = Math.min(dp[i + 1], dp[i] + 1);
        }

        System.out.println(dp[n]);
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

const int INF = 100000;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    int n;
    cin >> n;

    vector<int> dp(1 + n * 3, INF);
    dp[1] = 0;

    for (int i = 1; i <= n; i++) {
        dp[i * 3] = min(dp[i * 3], dp[i] + 1);
        dp[i * 2] = min(dp[i * 2], dp[i] + 1);
        dp[i + 1] = min(dp[i + 1], dp[i] + 1);
    }

    cout << dp[n];
}
```
