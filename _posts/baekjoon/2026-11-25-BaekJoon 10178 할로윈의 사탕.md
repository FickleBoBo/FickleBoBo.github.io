## 1. 아이디어

사탕 $c$개를 형제 $v$명에게 똑같이 최대한 많이 나누어 줄 때 한 명이 받는 사탕 수와 아버지에게 남는 사탕 수를 구하는 문제로, 한 명이 받는 사탕은 $c$를 $v$로 나눈 몫이고 아버지에게 남는 사탕은 나머지이다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringBuilder sb = new StringBuilder();

        int t = Integer.parseInt(br.readLine());
        while (t-- > 0) {
            StringTokenizer st = new StringTokenizer(br.readLine());
            int c = Integer.parseInt(st.nextToken());
            int v = Integer.parseInt(st.nextToken());
            sb.append("You get ").append(c / v).append(" piece(s) and your dad gets ").append(c % v).append(" piece(s).\n");
        }

        System.out.println(sb);
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    int t;
    cin >> t;

    while (t--) {
        int c, v;
        cin >> c >> v;
        cout << "You get " << (c / v) << " piece(s) and your dad gets " << (c % v) << " piece(s).\n";
    }
}
```

```python
import sys

input = sys.stdin.readline

t = int(input())
for _ in range(t):
    c, v = map(int, input().split())
    print(f"You get {c // v} piece(s) and your dad gets {c % v} piece(s).")
```
