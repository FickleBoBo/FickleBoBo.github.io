## 1. 아이디어

입력한 아이디와 비밀번호로 로그인이 되는지, 비밀번호만 틀렸는지, 아이디가 없는지를 가리는 문제다. 회원의 아이디는 서로 겹치지 않아 아이디가 같은 회원은 많아야 한 명이므로, 그 회원을 찾으면 비밀번호가 맞는지만 보고 결과를 정하고 다른 회원은 더 볼 필요가 없다. 끝까지 아이디가 같은 회원이 없으면 아이디 오류다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public String solution(String[] id_pw, String[][] db) {
        for (String[] row : db) {
            if (!id_pw[0].equals(row[0])) continue;
            return id_pw[1].equals(row[1]) ? "login" : "wrong pw";
        }

        return "fail";
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

string solution(vector<string> id_pw, vector<vector<string>> db) {
    for (auto& row : db) {
        if (id_pw[0] != row[0]) continue;
        return id_pw[1] == row[1] ? "login" : "wrong pw";
    }

    return "fail";
}
```

```python
def solution(id_pw, db):
    for uid, upw in db:
        if id_pw[0] != uid:
            continue

        return "login" if id_pw[1] == upw else "wrong pw"

    return "fail"
```
