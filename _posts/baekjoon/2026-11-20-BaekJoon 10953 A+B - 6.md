## 1. 아이디어

각 줄의 $A$와 $B$가 공백이 아니라 쉼표로 구분되어 있으므로 쉼표를 기준으로 두 수를 나눠 읽는다. 테스트 케이스의 개수 $T$가 먼저 주어지니 $T$번 반복하며 합을 출력한다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringBuilder sb = new StringBuilder();

        int t = Integer.parseInt(br.readLine());
        while (t-- > 0) {
            StringTokenizer st = new StringTokenizer(br.readLine(), ",");
            int a = Integer.parseInt(st.nextToken());
            int b = Integer.parseInt(st.nextToken());
            sb.append(a + b).append("\n");
        }

        System.out.println(sb);
    }
}
```

`StringTokenizer`의 구분자는 기본이 공백류라 두 번째 인자로 `","`를 넘겼다.

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    int t;
    cin >> t;

    while (t--) {
        int a, b;
        char c;
        cin >> a >> c >> b;
        cout << a + b << '\n';
    }
}
```

`cin`은 공백을 기준으로 읽으므로 쉼표는 `char` 변수 `c`에 따로 읽어 버렸다.

```python
import sys

input = sys.stdin.readline

t = int(input())
for _ in range(t):
    a, b = map(int, input().split(","))
    print(a + b)
```

`split`의 기본 구분자는 공백류라 인자로 `","`를 넘겼다.
