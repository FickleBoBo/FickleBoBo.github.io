## 1. 아이디어

광고를 무한히 반복해 보여 주는 전광판에서 어느 순간 보이는 길이 $L$의 문자열이 주어질 때, 가능한 광고의 최소 길이를 구하는 문제다. 길이 $p$인 광고를 반복하면 $p$칸 떨어진 두 문자가 항상 같으므로 보이는 문자열도 $p$를 주기로 가져야 하고, 반대로 보이는 문자열의 주기가 $p$이면 그 앞 $p$글자를 광고로 삼았을 때 이 문자열이 그대로 나타나므로 답은 보이는 문자열의 가장 짧은 주기다. $L$이 1,000,000까지라 주기 후보를 하나씩 대조하면 최악의 경우 $O(L^2)$이 된다. 그런데 보이는 문자열이 주기 $p$를 갖는다는 것은 길이 $L - p$인 접두사와 접미사가 같다는 뜻이므로, KMP의 실패 함수로 접두사이면서 접미사이기도 한 가장 긴 부분(자기 자신은 제외)의 길이 $k$를 구하면 가장 짧은 주기 $L - k$를 $O(L)$에 얻는다.

## 2. 코드

### 풀이 [C++]

```c++
#include <bits/stdc++.h>
using namespace std;

vector<int> failure(string& s) {
    vector<int> pi(s.size());
    int j = 0;
    for (int i = 1; i < s.size(); i++) {
        while (j > 0 && s[i] != s[j]) j = pi[j - 1];
        if (s[i] == s[j]) pi[i] = ++j;
    }
    return pi;
}

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    int l;
    string s;
    cin >> l >> s;

    vector<int> pi = failure(s);
    int p = l - pi.back();

    cout << p;
}
```
