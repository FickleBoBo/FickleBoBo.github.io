## 1. 아이디어

원형으로 놓인 집에서 이웃한 두 집은 함께 털 수 없을 때 털 수 있는 돈의 최댓값을 구하는 문제다. 일렬로 놓인 집이라면 앞에서부터 $i$채의 최댓값을 `dp[i]`라 할 때, $i$번째 집을 털지 않으면 `dp[i - 1]`이고 털면 바로 앞집을 털 수 없어 `dp[i - 2]`에 이 집의 돈을 더한 값이므로 둘 중 큰 쪽이 `dp[i]`다. 원형이면 첫 집과 마지막 집이 이웃해 둘을 함께 털 수 없으니 둘 중 적어도 하나는 반드시 털지 않고, 그 집을 뺀 나머지는 다시 일렬이 된다. 그래서 첫 집을 뺀 구간과 마지막 집을 뺀 구간에서 각각 일렬의 최댓값을 구해 큰 쪽을 답으로 하며, 어떤 선택이든 둘 중 한 구간에 들어가고 구간 안의 선택은 원형에서도 유효해 놓치거나 잘못 세는 경우가 없다. 점화식이 바로 앞의 두 값만 읽으므로 `dp` 배열 전체를 둘 필요 없이 변수 두 개를 굴려도 같은 값이 나온다.

## 2. 코드

### 풀이 1: 배열 DP [Java][C++][Python]

`dp`를 호출마다 새로 만들어 구간 앞의 칸이 0으로 남게 했고, 이 0이 구간 밖의 집을 털지 않은 상태가 된다.

```java
class Solution {
    public int solution(int[] money) {
        int n = money.length;

        int case1 = robRange(money, 1, n - 1);
        int case2 = robRange(money, 2, n);
        return Math.max(case1, case2);
    }

    static int robRange(int[] money, int l, int r) {
        int n = money.length;
        int[] dp = new int[1 + n];

        for (int i = l; i <= r; i++) {
            dp[i] = Math.max(dp[i - 1], dp[Math.max(i - 2, 0)] + money[i - 1]);
        }

        return dp[r];
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int rob_range(vector<int>& money, int l, int r) {
    int n = money.size();
    vector<int> dp(1 + n);

    for (int i = l; i <= r; i++) {
        dp[i] = max(dp[i - 1], dp[max(i - 2, 0)] + money[i - 1]);
    }

    return dp[r];
}

int solution(vector<int> money) {
    int n = money.size();

    int case1 = rob_range(money, 1, n - 1);
    int case2 = rob_range(money, 2, n);
    return max(case1, case2);
}
```

```python
def solution(money):
    n = len(money)

    def rob_range(l, r):
        dp = [0] * (1 + n)
        for i in range(l, r + 1):
            dp[i] = max(dp[i - 1], dp[i - 2] + money[i - 1])

        return dp[r]

    case1 = rob_range(1, n - 1)
    case2 = rob_range(2, n)
    return max(case1, case2)
```

`rob_range(1, n - 1)`의 첫 반복에서 `dp[-1]`을 읽지만 그 칸은 채워지지 않은 0이라 `dp[0]`을 읽는 것과 같아 그대로 두었다.

### 풀이 2: 공간 최적화 DP [Java][C++][Python]

```java
class Solution {
    public int solution(int[] money) {
        int n = money.length;

        int case1 = robRange(money, 0, n - 1);
        int case2 = robRange(money, 1, n);
        return Math.max(case1, case2);
    }

    static int robRange(int[] money, int l, int r) {
        int prv2 = 0, prv1 = 0;

        for (int i = l; i < r; i++) {
            int cur = Math.max(prv1, prv2 + money[i]);
            prv2 = prv1;
            prv1 = cur;
        }

        return prv1;
    }
}
```


```python
def solution(money):
    n = len(money)

    def rob_range(l, r):
        prv2, prv1 = 0, 0

        for i in range(l, r):
            prv2, prv1 = prv1, max(prv1, prv2 + money[i])

        return prv1

    case1 = rob_range(0, n - 1)
    case2 = rob_range(1, n)
    return max(case1, case2)
```

우변을 모두 계산한 뒤 대입하는 다중 대입으로 임시 변수 없이 두 값을 한 번에 갱신했다.
