## 1. 아이디어

등차수열 또는 등비수열의 다음 항을 구하는 문제다. 앞 세 항으로 등차인지 확인하면 된다. 등비수열이 이 확인을 통과하는 경우는 모든 항이 같은 상수열뿐이고 그때는 등차 공식도 같은 값을 주므로, 등차가 아니라고 판정된 경우만 등비로 처리해도 된다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int solution(int[] common) {
        if (common[0] - common[1] == common[1] - common[2]) {
            return common[common.length - 1] + common[1] - common[0];
        } else {
            return common[common.length - 1] * common[1] / common[0];
        }
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int solution(vector<int> common) {
    if (common[0] - common[1] == common[1] - common[2]) {
        return common.back() + common[1] - common[0];
    } else {
        return common.back() * common[1] / common[0];
    }
}
```

def solution(common):
