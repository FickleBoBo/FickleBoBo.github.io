## 1. 아이디어

수 $N$개를 오름차순으로 정렬하는 문제인데 수가 10,000 이하의 자연수뿐이라 값마다 몇 번 나왔는지만 세는 카운팅 소트로 풀 수 있다. $N$이 최대 10,000,000이고 메모리 제한이 8MB라 수를 배열에 저장하면 32비트 정수 배열만으로도 40MB가 되어 정렬할 수 없지만, 크기 10,001의 카운팅 배열은 수를 저장하지 않으니 입력이 아무리 많아도 이 배열의 크기는 늘지 않는다. 센 뒤에는 1부터 10,000까지 차례로 나온 횟수만큼 출력하면 오름차순이 된다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;

public class Main {

    static final int MAX = 10000;
    static int[] cnt = new int[1 + MAX];

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringBuilder sb = new StringBuilder();

        int n = Integer.parseInt(br.readLine());
        while (n-- > 0) {
            cnt[Integer.parseInt(br.readLine())]++;
        }

        for (int i = 1; i <= MAX; i++) {
            for (int j = 1; j <= cnt[i]; j++) {
                sb.append(i).append("\n");
            }
        }

        System.out.println(sb);
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

const int MAX = 10000;
int cnt[1 + MAX];

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    int n;
    cin >> n;

    while (n--) {
        int x;
        cin >> x;
        cnt[x]++;
    }

    for (int i = 1; i <= MAX; i++) {
        for (int j = 1; j <= cnt[i]; j++) {
            cout << i << '\n';
        }
    }
}
```

```python
import sys

input = sys.stdin.readline

n = int(input())
cnt = [0] * (1 + 10000)
for _ in range(n):
    cnt[int(input())] += 1

for x in range(1, 10001):
    for _ in range(cnt[x]):
        print(x)
```
