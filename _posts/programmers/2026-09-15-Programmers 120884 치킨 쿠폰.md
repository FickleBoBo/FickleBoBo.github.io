## 1. 아이디어

시킨 치킨 한 마리마다 쿠폰이 한 장 나오고 쿠폰 10장은 서비스 치킨 한 마리로 바뀌며 서비스 치킨도 쿠폰을 주므로, 쿠폰이 10장 미만이 될 때까지 바꿔서 받는 서비스 치킨의 총수를 구하는 문제다. 쿠폰이 $x$장이면 $\lfloor x / 10 \rfloor$마리를 한꺼번에 받고, 그 마리 수만큼 새 쿠폰이 생기므로 쿠폰은 $\lfloor x / 10 \rfloor + x \bmod 10$장이 된다. 바꿀 때마다 쿠폰이 줄어 반드시 멈추니, 처음 쿠폰 수인 시킨 치킨 수에서 시작해 이를 반복하며 받은 마리 수를 더하면 된다.

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int solution(int chicken) {
        int sum = 0;
        int x = chicken;
        while (x >= 10) {
            sum += x / 10;
            x = x / 10 + x % 10;
        }

        return sum;
    }
}
```
