## 1. 아이디어

정수 `num1`과 `num2`의 곱을 구해주기만 하면 된다.

---

## 2. 복잡도

| 시간복잡도 | 공간복잡도 |
| :--------: | :--------: |
|   $O(1)$   |   $O(1)$   |

---

## 3. 코드

### 풀이 [Java][C++]

```java
class Solution {
    public int solution(int num1, int num2) {
        return num1 * num2;
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int solution(int num1, int num2) {
    return num1 * num2;
}
```
