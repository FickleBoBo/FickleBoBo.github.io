## 1. 아이디어

덮어쓰는 구간은 인덱스 $s$부터 `overwrite_string`의 길이만큼이고 그 앞뒤는 그대로 남으므로, 결과는 `my_string`에서 구간 앞의 부분, `overwrite_string`, 구간 뒤의 부분을 차례로 이어 붙인 것이다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public String solution(String my_string, String overwrite_string, int s) {
        return my_string.substring(0, s) + overwrite_string + my_string.substring(s + overwrite_string.length());
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

string solution(string my_string, string overwrite_string, int s) {
    return my_string.substr(0, s) + overwrite_string + my_string.substr(s + overwrite_string.size());
}
```

```python
def solution(my_string, overwrite_string, s):
    return my_string[:s] + overwrite_string + my_string[s + len(overwrite_string) :]
```
