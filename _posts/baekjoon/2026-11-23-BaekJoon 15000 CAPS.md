## 1. 아이디어

소문자로만 이루어진 문자열의 모든 글자를 대문자로 바꿔 출력한다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        System.out.println(br.readLine().toUpperCase());
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    string s;
    cin >> s;
    for (char c : s) cout << (char)toupper(c);
}
```

`std::toupper`는 `int`를 돌려주므로 `char`로 캐스팅해야 숫자가 아니라 문자로 출력된다.

```python
import sys

input = sys.stdin.readline

s = input().strip()
print(s.upper())
```
