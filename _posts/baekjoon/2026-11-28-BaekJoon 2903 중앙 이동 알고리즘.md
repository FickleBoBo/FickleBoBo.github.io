## 1. 아이디어

정사각형의 변 중앙과 중심에 점을 추가하는 과정을 $N$번 거친 뒤의 점의 수를 구하는 문제다. 과정을 한 번 거칠 때마다 모든 정사각형이 변의 길이가 절반인 정사각형 4개로 나뉘므로 $N$번 뒤에는 처음 정사각형의 각 변이 $2^N$칸으로 나뉘고, 점은 가로와 세로에 $2^N + 1$개씩 격자 모양으로 놓인다. 따라서 중복 없이 센 점의 수는 $(2^N + 1)^2$이며, $N$이 최대인 15여도 약 $1.07 \times 10^9$라 32비트 정수에 담긴다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

2의 `n`제곱은 `1 << n`으로 구했다. `<<`는 `+`보다 우선순위가 낮아 `1 << n`을 괄호로 묶었다.

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        int n = Integer.parseInt(br.readLine());
        System.out.println(((1 << n) + 1) * ((1 << n) + 1));
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    int n;
    cin >> n;
    cout << ((1 << n) + 1) * ((1 << n) + 1);
}
```

```python
import sys

input = sys.stdin.readline

n = int(input())
print(((1 << n) + 1) ** 2)
```
