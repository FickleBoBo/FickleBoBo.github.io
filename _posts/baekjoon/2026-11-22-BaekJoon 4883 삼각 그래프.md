## 1. 아이디어

가장 위쪽 가운데 정점에서 가장 아래쪽 가운데 정점까지 지나간 정점 비용의 합이 최소인 경로를 구하는 문제이다. 간선이 아래 행으로만 향하고 같은 행에서는 왼쪽에서 오른쪽으로만 이어지는 사이클 없는 그래프라, 행은 위에서 아래로, 한 행 안에서는 왼쪽에서 오른쪽으로 계산하면 정점에 들어오는 간선의 출발점 값이 항상 먼저 정해진다. 비용이 정점에 있으므로 정점마다 그 정점까지의 최소 비용을 구하는데, 이는 들어오는 정점들의 최소 비용 중 최솟값에 자기 비용을 더한 값이다. 한 행의 세 정점을 왼쪽, 가운데, 오른쪽이라 하면 왼쪽은 윗행의 왼쪽과 가운데에서, 가운데는 같은 행의 왼쪽과 윗행의 세 정점에서, 오른쪽은 같은 행의 가운데와 윗행의 가운데와 오른쪽에서 들어온다. 시작이 첫 행 가운데라 첫 행에서 가운데는 자기 비용, 오른쪽은 가운데에서 이어지는 하나뿐이라 두 비용의 합이고, 도달할 수 없는 첫 행의 왼쪽은 충분히 큰 값으로 둔다. 비용이 음수일 수 있어 다익스트라는 쓸 수 없지만 위 순서로 한 번 계산하면 최단 경로가 정해지고, 답은 마지막 행 가운데 정점의 값이다.

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;
import java.util.*;

public class Main {

    static final int INF = 1_000_000_000;

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringBuilder sb = new StringBuilder();

        for (int tc = 1; ; tc++) {
            int n = Integer.parseInt(br.readLine());
            if (n == 0) break;

            int[][] arr = new int[n][3];
            for (int i = 0; i < n; i++) {
                StringTokenizer st = new StringTokenizer(br.readLine());
                arr[i][0] = Integer.parseInt(st.nextToken());
                arr[i][1] = Integer.parseInt(st.nextToken());
                arr[i][2] = Integer.parseInt(st.nextToken());
            }

            int[][] dp = new int[n][3];
            dp[0][0] = INF;
            dp[0][1] = arr[0][1];
            dp[0][2] = arr[0][1] + arr[0][2];
            for (int i = 1; i < n; i++) {
                dp[i][0] = Math.min(dp[i - 1][0], dp[i - 1][1]) + arr[i][0];
                dp[i][1] = Math.min(dp[i][0], Math.min(dp[i - 1][0], Math.min(dp[i - 1][1], dp[i - 1][2]))) + arr[i][1];
                dp[i][2] = Math.min(dp[i][1], Math.min(dp[i - 1][1], dp[i - 1][2])) + arr[i][2];
            }

            sb.append(tc).append(". ").append(dp[n - 1][1]).append("\n");
        }

        System.out.println(sb);
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

const int INF = 1'000'000'000;
const int MAX_N = 100000;
int arr[MAX_N][3];
int dp[MAX_N][3];

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    for (int tc = 1;; tc++) {
        int n;
        cin >> n;
        if (n == 0) break;

        for (int i = 0; i < n; i++) {
            for (int j = 0; j < 3; j++) {
                cin >> arr[i][j];
            }
        }

        dp[0][0] = INF;
        dp[0][1] = arr[0][1];
        dp[0][2] = arr[0][1] + arr[0][2];
        for (int i = 1; i < n; i++) {
            dp[i][0] = min(dp[i - 1][0], dp[i - 1][1]) + arr[i][0];
            dp[i][1] = min({dp[i][0], dp[i - 1][0], dp[i - 1][1], dp[i - 1][2]}) + arr[i][1];
            dp[i][2] = min({dp[i][1], dp[i - 1][1], dp[i - 1][2]}) + arr[i][2];
        }

        cout << tc << ". " << dp[n - 1][1] << '\n';
    }
}
```

```python
import sys

input = sys.stdin.readline
out = []

INF = 1_000_000_000

tc = 1
while True:
    n = int(input())
    if n == 0:
        break

    arr = [list(map(int, input().split())) for _ in range(n)]

    dp = [[0] * 3 for _ in range(n)]
    dp[0][0] = INF
    dp[0][1] = arr[0][1]
    dp[0][2] = arr[0][1] + arr[0][2]
    for i in range(1, n):
        dp[i][0] = min(dp[i - 1][0], dp[i - 1][1]) + arr[i][0]
        dp[i][1] = min(dp[i][0], dp[i - 1][0], dp[i - 1][1], dp[i - 1][2]) + arr[i][1]
        dp[i][2] = min(dp[i][1], dp[i - 1][1], dp[i - 1][2]) + arr[i][2]

    out.append(f"{tc}. {dp[n - 1][1]}")
    tc += 1

print("\n".join(out))
```
