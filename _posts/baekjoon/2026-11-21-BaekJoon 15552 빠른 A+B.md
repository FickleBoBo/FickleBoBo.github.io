## 1. 아이디어

각 테스트케이스의 $A + B$를 출력하면 되는데 $T$가 최대 100만이라 계산보다 입출력이 시간을 좌우하므로, 입력은 버퍼를 거쳐 읽고 출력도 줄마다 바로 내보내지 않고 버퍼에 쌓아 두었다가 내보낸다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        BufferedWriter bw = new BufferedWriter(new OutputStreamWriter(System.out));

        int t = Integer.parseInt(br.readLine());
        while (t-- > 0) {
            StringTokenizer st = new StringTokenizer(br.readLine());
            int a = Integer.parseInt(st.nextToken());
            int b = Integer.parseInt(st.nextToken());
            bw.write((a + b) + "\n");
        }

        bw.flush();
    }
}
```

`BufferedWriter`에 쌓은 출력은 `flush`를 호출해야 내보내지므로 마지막에 한 번 호출했다.

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    int t;
    cin >> t;

    while (t--) {
        int a, b;
        cin >> a >> b;
        cout << a + b << '\n';
    }
}
```

`ios::sync_with_stdio(0)`과 `cin.tie(0)`으로 입출력 속도를 높였고, `std::endl`은 매번 `flush`하므로 줄바꿈은 `'\n'`으로 썼다.

```python
import sys

input = sys.stdin.readline

t = int(input())
out = [sum(map(int, input().split())) for _ in range(t)]
print("\n".join(map(str, out)))
```

테스트케이스마다 `print`를 호출하는 대신 결과를 리스트에 모아 `"\n".join`으로 한 번에 출력했다.
