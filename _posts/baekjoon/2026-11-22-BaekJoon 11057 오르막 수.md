## 1. 아이디어

길이가 $N$인 오르막 수의 개수를 10,007로 나눈 나머지를 구하는 문제이다. 맨 앞 자리가 $j$인 길이 $i$의 오르막 수의 개수를 $f(i, j)$라 하면, 맨 앞에 $j$를 붙이려면 나머지 부분이 맨 앞 자리가 $j$ 이상인 길이 $i - 1$의 오르막 수여야 하므로 $f(i, j) = \sum_{k = j}^{9} f(i - 1, k)$다. 인접한 수가 같아도 되므로 $k = j$를 포함하고, 수는 0으로 시작할 수 있어 길이 1은 0부터 9까지 모두 $f(1, j) = 1$이다. 답은 $f(N, 0)$부터 $f(N, 9)$까지의 합이고, 덧셈뿐이라 매 항마다 10,007로 나눈 나머지를 취해도 최종 나머지는 같다.

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;

public class Main {

    static final int MOD = 10007;

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        int n = Integer.parseInt(br.readLine());

        int[][] dp = new int[1 + n][10];
        for (int j = 0; j <= 9; j++) {
            dp[1][j] = 1;
        }

        for (int i = 2; i <= n; i++) {
            for (int j = 0; j <= 9; j++) {
                for (int k = j; k <= 9; k++) {
                    dp[i][j] += dp[i - 1][k];
                }
                dp[i][j] %= MOD;
            }
        }

        int sum = 0;
        for (int j = 0; j <= 9; j++) {
            sum += dp[n][j];
        }

        System.out.println(sum % MOD);
    }
}
```

```python
import sys

input = sys.stdin.readline

MOD = 10007

n = int(input())
dp = [[0] * 10 for _ in range(1 + n)]
for j in range(10):
    dp[1][j] = 1

for i in range(2, n + 1):
    for j in range(10):
        dp[i][j] = sum(dp[i - 1][j:]) % MOD

print(sum(dp[n]) % MOD)
```
