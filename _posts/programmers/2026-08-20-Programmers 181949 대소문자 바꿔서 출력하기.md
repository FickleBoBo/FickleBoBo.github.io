## 1. 아이디어

입력이 알파벳뿐이라 대문자인지만 가르면 나머지는 소문자이므로, 문자마다 반대쪽으로 바꿔 출력하면 된다. 첫 번째 방법은 문자가 대문자 범위에 드는지 비교해 바꿀 방향을 정한다. 같은 알파벳의 대문자와 소문자는 코드값 차이가 일정하므로 `c - 'A' + 'a'`처럼 알파벳 안의 순번은 그대로 두고 기준 문자만 바꿔 옮긴다.

두 번째 방법은 판별과 변환을 표준 라이브러리의 문자 함수에 맡겨, 코드값 계산을 직접 쓰지 않고도 같은 결과를 얻는다.

세 번째 방법은 대문자와 소문자의 코드값이 정확히 32 차이라는 점을 이용한다. 대문자의 코드값은 65부터 90까지, 즉 64에 1부터 26을 더한 값이라 32에 해당하는 비트가 항상 0이고, 소문자는 같은 문자의 대문자와 그 비트만 다르다. 따라서 이 비트를 XOR로 뒤집으면 대문자는 소문자가, 소문자는 대문자가 되어 판별이 필요 없다. 다만 알파벳이 아닌 문자에는 성립하지 않으므로 입력이 알파벳뿐이라는 제약에 기대는 풀이다.

## 2. 코드

### 풀이 1: 아스키 코드 연산 [Java][C++]

산술 결과는 `int`가 되므로 `(char)`로 캐스팅해 숫자가 아닌 문자로 출력했다.

```java
import java.io.*;

public class Solution {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        for (char c : br.readLine().toCharArray()) {
            if ('A' <= c && c <= 'Z') {
                System.out.print((char) (c - 'A' + 'a'));
            } else {
                System.out.print((char) (c - 'a' + 'A'));
            }
        }
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    string s;
    cin >> s;

    for (char c : s) {
        if ('A' <= c && c <= 'Z') {
            cout << (char)(c - 'A' + 'a');
        } else {
            cout << (char)(c - 'a' + 'A');
        }
    }
}
```

### 풀이 2: 문자별 표준 함수 [Java][C++][Python]

```java
import java.io.*;

public class Solution {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        for (char c : br.readLine().toCharArray()) {
            if (Character.isUpperCase(c)) {
                System.out.print(Character.toLowerCase(c));
            } else {
                System.out.print(Character.toUpperCase(c));
            }
        }
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    string s;
    cin >> s;

    for (char c : s) {
        if (isupper(c)) {
            cout << (char)tolower(c);
        } else {
            cout << (char)toupper(c);
        }
    }
}
```

`std::tolower`와 `std::toupper`는 `int`를 반환하므로 `(char)`로 캐스팅해 문자로 출력했다.

```python
import sys

input = sys.stdin.readline

s = input()
print("".join(c.lower() if c.isupper() else c.upper() for c in s))
```
