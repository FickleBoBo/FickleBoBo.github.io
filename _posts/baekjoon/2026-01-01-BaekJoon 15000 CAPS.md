## 1. 아이디어

알파벳 소문자들로 주어진 문자열의 각 문자를 대문자로 출력하면 되는 문제로 내장 함수를 활용하면 된다.

---

## 2. 복잡도

| 접근 | 시간   | 공간   |
| ---- | ------ | ------ |
| 풀이 | $O(N)$ | $O(N)$ |

($N$ = `s`의 길이)

---

## 3. 코드

### 풀이 [Java][C++]

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        System.out.println(br.readLine().toUpperCase());
    }
}
```

`toUpperCase` 메서드로 대문자로 변환된 문자열을 얻을 수 있다.

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    string s;
    cin >> s;
    for (char c : s) cout << (char)toupper(c);
}
```
