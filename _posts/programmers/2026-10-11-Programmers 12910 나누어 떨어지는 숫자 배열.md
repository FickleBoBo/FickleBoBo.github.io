## 1. 아이디어

배열에서 주어진 수로 나누어 떨어지는 원소만 골라 오름차순으로 정렬해 반환하는 문제다. 골라낸 원소만 정렬해도 결과는 같으므로 거른 뒤에 정렬하고, 나누어 떨어지는 원소가 하나도 없을 때만 -1 하나를 담은 배열을 반환하도록 따로 처리한다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.util.*;

class Solution {
    public int[] solution(int[] arr, int divisor) {
        int[] ans = Arrays.stream(arr).filter(x -> x % divisor == 0).sorted().toArray();
        if (ans.length == 0) return new int[]{-1};
        return ans;
    }
}
```

`Arrays.stream`으로 만든 스트림에서 `filter`로 나누어 떨어지는 원소만 거르고 `sorted`로 정렬한 뒤 `toArray`로 배열에 담았다.

```c++
#include <bits/stdc++.h>
using namespace std;

vector<int> solution(vector<int> arr, int divisor) {
    vector<int> v;
    for (int x : arr) {
        if (x % divisor == 0) v.push_back(x);
    }
    sort(v.begin(), v.end());

    if (v.empty()) return {-1};
    return v;
}
```

```python
def solution(arr, divisor):
    ans = sorted(x for x in arr if x % divisor == 0)
    return ans if ans else [-1]
```
