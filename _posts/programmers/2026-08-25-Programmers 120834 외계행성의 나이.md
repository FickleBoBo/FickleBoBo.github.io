## 1. 아이디어

나이의 각 자릿수를 0은 `a`, 1은 `b`, ..., 9는 `j`로 바꿔 알파벳 문자열로 반환하는 문제다. 숫자 $d$에 대응하는 알파벳은 `a`에서 $d$칸 뒤의 문자이므로 자리마다 독립적으로 바꾸면 된다. 정수에서 자리를 뽑으면 낮은 자리부터 나오니 자릿수의 순서를 맞추려면 마지막에 뒤집는다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public String solution(int age) {
        StringBuilder sb = new StringBuilder();
        while (age > 0) {
            sb.append((char) (age % 10 + 'a'));
            age /= 10;
        }

        return sb.reverse().toString();
    }
}
```

`char`로 형변환해 숫자가 아닌 문자로 덧붙였다.

```c++
#include <bits/stdc++.h>
using namespace std;

string solution(int age) {
    string s;
    while (age) {
        s += age % 10 + 'a';
        age /= 10;
    }
    reverse(s.begin(), s.end());

    return s;
}
```

`s += age % 10 + 'a'`는 `int` 결과가 `char`로 변환되어 문자로 덧붙는다.

```python
def solution(age):
    return str(age).translate(str.maketrans("0123456789", "abcdefghij"))
```

`str.maketrans`로 `0`~`9`를 `a`~`j`에 대응시켜 `translate`로 한 번에 바꿔서 자릿수를 뽑아 뒤집지 않았다.
