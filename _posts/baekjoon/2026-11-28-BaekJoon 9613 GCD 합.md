## 1. 아이디어

주어진 수들에서 만들 수 있는 모든 쌍의 최대공약수를 더하는 문제다. 수가 100개 이하라 한 테스트 케이스의 쌍은 많아야 4,950개이고 테스트 케이스도 100개 이하다. 유클리드 호제법 한 번은 수의 크기의 로그에 비례하는 단계면 끝나므로, 모든 쌍의 최대공약수를 하나씩 구해 더해도 충분하다. 다만 최대공약수 하나가 최대 1,000,000이고 쌍이 4,950개까지라 합은 32비트 정수 범위를 넘을 수 있어 64비트 정수에 담아야 한다.

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringBuilder sb = new StringBuilder();

        int t = Integer.parseInt(br.readLine());
        while (t-- > 0) {
            StringTokenizer st = new StringTokenizer(br.readLine());
            int n = Integer.parseInt(st.nextToken());

            int[] arr = new int[n];
            for (int i = 0; i < n; i++) {
                arr[i] = Integer.parseInt(st.nextToken());
            }

            long sum = 0;
            for (int i = 0; i < n - 1; i++) {
                for (int j = i + 1; j < n; j++) {
                    sum += gcd(arr[i], arr[j]);
                }
            }

            sb.append(sum).append("\n");
        }

        System.out.println(sb);
    }

    static int gcd(int a, int b) {
        if (b == 0) return a;
        return gcd(b, a % b);
    }
}
```

`std::gcd`는 C++17부터 쓸 수 있다.

```python
import math
import sys

input = sys.stdin.readline

t = int(input())
for _ in range(t):
    n, *arr = map(int, input().split())

    total = 0
    for i in range(n - 1):
        for j in range(i + 1, n):
            total += math.gcd(arr[i], arr[j])

    print(total)
```

`n, *arr`로 첫 수는 `n`에, 나머지 수는 리스트 `arr`에 받았다.
