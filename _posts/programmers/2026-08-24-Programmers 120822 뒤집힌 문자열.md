## 1. 아이디어

문자열을 거꾸로 뒤집어 반환하는 문제로, 맨 뒤 문자가 맨 앞으로 오도록 문자열을 역순으로 읽기만 하면 된다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public String solution(String my_string) {
        return new StringBuilder(my_string).reverse().toString();
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

string solution(string my_string) {
    reverse(my_string.begin(), my_string.end());
    return my_string;
}
```

```python
def solution(my_string):
    return my_string[::-1]
```

슬라이스의 간격을 -1로 줘서(`[::-1]`) 문자열을 역순으로 읽었다.
