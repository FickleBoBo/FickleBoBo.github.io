## 1. 아이디어

곱하는 수 (2)의 자리 숫자를 일, 십, 백의 자리 순서로 (1)에 곱한 값 (3), (4), (5)와 전체 곱 (6)을 출력하는 문제다. 세 자리 수의 일의 자리는 10으로 나눈 나머지, 십의 자리는 10으로 나눈 몫을 다시 10으로 나눈 나머지, 백의 자리는 100으로 나눈 몫이다. 곱하는 것은 자릿값(예: 80)이 아니라 자리 숫자(8) 하나이다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        int a = Integer.parseInt(br.readLine());
        int b = Integer.parseInt(br.readLine());

        System.out.println(a * (b % 10));
        System.out.println(a * (b / 10 % 10));
        System.out.println(a * (b / 100));
        System.out.println(a * b);
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    int a, b;
    cin >> a >> b;
    cout << a * (b % 10) << '\n';
    cout << a * (b / 10 % 10) << '\n';
    cout << a * (b / 100) << '\n';
    cout << a * b << '\n';
}
```

```python
import sys

input = sys.stdin.readline

a = int(input())
b = int(input())

print(a * (b % 10))
print(a * (b // 10 % 10))
print(a * (b // 100))

```
