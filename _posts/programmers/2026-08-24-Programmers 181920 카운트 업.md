## 1. 아이디어

`start_num`부터 `end_num`까지 1씩 커지며 이어지므로 원소 수는 `end_num - start_num + 1`개이고 첫 원소는 `start_num`이다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int[] solution(int start_num, int end_num) {
        int[] arr = new int[end_num - start_num + 1];
        for (int i = 0; i < arr.length; i++) {
            arr[i] = start_num + i;
        }

        return arr;
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

vector<int> solution(int start_num, int end_num) {
    vector<int> v(end_num - start_num + 1);
    iota(v.begin(), v.end(), start_num);
    return v;
}
```

`std::iota`로 `start_num`부터 1씩 커지는 값을 채웠다.

```python
def solution(start_num, end_num):
    return list(range(start_num, end_num + 1))
```
