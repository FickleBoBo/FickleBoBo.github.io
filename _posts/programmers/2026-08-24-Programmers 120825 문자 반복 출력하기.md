## 1. 아이디어

문자열 `my_string`의 각 문자를 순회하며 해당 문자를 `n`번 반복한 문자열을 이어 붙이면, 각 문자가 `n`번씩 반복된 결과 문자열을 만들 수 있다.

---

## 2. 복잡도

| 접근 | 시간            | 공간            |
| ---- | --------------- | --------------- |
| 풀이 | $O(N \times K)$ | $O(N \times K)$ |

($N$ = `my_string`의 길이, $K$ = `n`. 결과 문자열의 길이가 $N \times K$이므로 시간과 공간 모두 $O(N \times K)$이다)

---

## 3. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public String solution(String my_string, int n) {
        StringBuilder sb = new StringBuilder();
        for (char c : my_string.toCharArray()) {
            sb.append(String.valueOf(c).repeat(n));
        }

        return sb.toString();
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

string solution(string my_string, int n) {
    string s;
    for (char c : my_string) {
        s.append(n, c);
    }

    return s;
}
```

```python
def solution(my_string, n):
    return "".join(c * n for c in my_string)
```
