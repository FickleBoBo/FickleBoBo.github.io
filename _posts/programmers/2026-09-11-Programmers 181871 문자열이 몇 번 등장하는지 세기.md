## 1. 아이디어

원래 문자열에서 찾는 문자열이 등장하는 횟수를 세는 문제로, 겹쳐서 등장해도 각각 센다(`"aaaa"`에서 `"aa"`는 3번). 일치할 때마다 찾는 문자열의 길이만큼 건너뛰면 겹친 등장을 놓친다. 등장은 시작 위치로 하나씩 구별되므로 모든 시작 위치를 한 칸씩 확인해, 그 위치에서 찾는 문자열이 시작하면 센다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

`i`에서 시작하는지는 `i` 이후 처음 등장하는 위치를 찾는 함수에 `i`를 넘겨 그 위치가 `i` 자신인지로 판정했다.

```java
class Solution {
    public int solution(String myString, String pat) {
        int cnt = 0;
        for (int i = 0; i < myString.length(); i++) {
            if (myString.indexOf(pat, i) == i) cnt++;
        }

        return cnt;
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int solution(string myString, string pat) {
    int cnt = 0;
    for (int i = 0; i < myString.size(); i++) {
        if (myString.find(pat, i) == i) cnt++;
    }

    return cnt;
}
```

```python
def solution(myString, pat):
    return sum(myString.find(pat, i) == i for i in range(len(myString)))
```
