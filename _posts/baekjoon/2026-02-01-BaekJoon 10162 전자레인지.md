## 1. 아이디어

각 버튼이 서로 배수, 약수 관계에 있어서 최소 조작을 하려면 지정된 시간이 큰 버튼부터 누르면 된다. 지정된 시간이 가장 작은 버튼이 10초를 더하므로 초기 요리시간을 10으로 나눈 나머지가 0이 아니면 불가능한 경우이다.

---

## 2. 복잡도

| 접근 | 시간   | 공간   |
| ---- | ------ | ------ |
| 풀이 | $O(1)$ | $O(1)$ |

---

## 3. 코드

### 풀이 [Java][C++]

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        int t = Integer.parseInt(br.readLine());

        int a = t / 300;
        t %= 300;

        int b = t / 60;
        t %= 60;

        int c = t / 10;
        t %= 10;

        if (t == 0) {
            System.out.println(a + " " + b + " " + c);
        } else {
            System.out.println(-1);
        }
    }
}
```

```c++
#include <bits/stdc++.h>

        cout << -1;
    } else {
        cout << a << ' ' << b << ' ' << c;
    }
}
```
