## 1. 아이디어

자연수 `n`을 입력받아 2로 나눈 나머지로 홀짝을 판별해, 홀수면 `n is odd`를 짝수면 `n is even`을 출력하면 되는 문제다.

---

## 2. 복잡도

| 접근 | 시간   | 공간   |
| ---- | ------ | ------ |
| 풀이 | $O(1)$ | $O(1)$ |

---

## 3. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;

public class Solution {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        int n = Integer.parseInt(br.readLine());
        if (n % 2 == 1) {
            System.out.println(n + " is odd");
        } else {
            System.out.println(n + " is even");
        }
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    int n;
    cin >> n;

    if (n % 2) {
        cout << n << " is odd";
    } else {
        cout << n << " is even";
    }
}
```

```python
import sys

input = sys.stdin.readline

n = int(input())

if n % 2:
    print(f"{n} is odd")
else:
    print(f"{n} is even")
```
