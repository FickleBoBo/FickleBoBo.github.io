## 1. 아이디어

나무 조각의 위치 변경 과정이 버블 정렬 과정과 동일하다. 따라서 버블 정렬을 구현한 뒤 스왑이 발생할 때 현재 나무 조각의 수들을 출력했다.

---

## 2. 복잡도

| ---- | ------ | ------ |
| 풀이 | $O(1)$ | $O(1)$ |

## 3. 코드

### 풀이 [Java][C++]

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringBuilder sb = new StringBuilder();
        StringTokenizer st = new StringTokenizer(br.readLine());

        int[] arr = new int[5];
        for (int i = 0; i < 5; i++) {
            arr[i] = Integer.parseInt(st.nextToken());
        }

        for (int i = 0; i < 4; i++) {
            for (int j = 0; j < 4 - i; j++) {
                if (arr[j] > arr[j + 1]) {
                    int tmp = arr[j];
                    arr[j] = arr[j + 1];
                    arr[j + 1] = tmp;

                    for (int x : arr) {
                        sb.append(x).append(" ");
                    }
                    sb.append("\n");
                }
            }
        }

        System.out.println(sb);
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    vector<int> v(5);
    for (int& x : v) cin >> x;

    for (int i = 0; i < 4; i++) {
        for (int j = 0; j < 4 - i; j++) {
            if (v[j] > v[j + 1]) {
                swap(v[j], v[j + 1]);

                for (int x : v) {
                    cout << x << ' ';
                }
                cout << '\n';
            }
        }
    }
}
```
