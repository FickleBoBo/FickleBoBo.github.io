## 1. 아이디어

아메리카노 한 잔 가격 5,500원으로 `money`를 나눈 몫이 살 수 있는 잔 수, 나머지가 남는 돈이다. 정수 나눗셈과 나머지 연산 한 번씩으로 구할 수 있다.

---

## 2. 복잡도

| 접근 | 시간   | 공간   |
| ---- | ------ | ------ |
| 풀이 | $O(1)$ | $O(1)$ |

---

## 3. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int[] solution(int money) {
        return new int[]{money / 5500, money % 5500};
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

vector<int> solution(int money) {
    return {money / 5500, money % 5500};
}
```

```python
def solution(money):
    return [money // 5500, money % 5500]
```
