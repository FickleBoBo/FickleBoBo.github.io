## 1. 아이디어

행과 열 중 큰 쪽의 길이를 $n$이라 하면, 모든 칸이 `0`인 $n \times n$ 배열을 만들고 원본을 같은 위치에 복사하는 것으로 충분하다. 행이 더 많을 때는 각 행의 끝에 `0`이 붙고 열이 더 많을 때는 맨 아래에 `0`으로만 된 행이 붙어 문제가 요구하는 모양과 같아진다. 이미 정사각형이면 원본 그대로가 된다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int[][] solution(int[][] arr) {
        int n = Math.max(arr.length, arr[0].length);
        int[][] res = new int[n][n];
        for (int i = 0; i < arr.length; i++) {
            System.arraycopy(arr[i], 0, res[i], 0, arr[i].length);
        }

        return res;
    }
}
```

`System.arraycopy`로 각 행을 새 행의 앞쪽에 복사했다. `new int[n][n]`은 `0`으로 채워져 있어 나머지 칸은 따로 채우지 않았다.

```c++
#include <bits/stdc++.h>
using namespace std;

vector<vector<int>> solution(vector<vector<int>> arr) {
    int n = max(arr.size(), arr[0].size());
    vector<vector<int>> res(n, vector<int>(n));
    for (int i = 0; i < arr.size(); i++) {
        copy(arr[i].begin(), arr[i].end(), res[i].begin());
    }

    return res;
}
```

```python
def solution(arr):
    n = max(len(arr), len(arr[0]))
    res = [[0] * n for _ in range(n)]
    for i, row in enumerate(arr):
        res[i][: len(row)] = row

    return res
```

슬라이스 대입 `res[i][: len(row)] = row`로 각 행의 앞쪽 칸만 원본으로 바꿨다. 슬라이스 길이가 `row`와 같아 행의 길이는 그대로다.
