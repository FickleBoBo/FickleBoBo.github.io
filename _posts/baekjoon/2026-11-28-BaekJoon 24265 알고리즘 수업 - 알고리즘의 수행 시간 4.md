## 1. 아이디어

[[BaekJoon] #24264 - 알고리즘 수업 - 알고리즘의 수행 시간 3](/posts/baekjoon-24264/)처럼 이중 반복문에서 코드1의 수행 횟수와 그 차수를 구하는 문제인데, 바깥의 $i$는 $n - 1$까지만 돌고 안쪽의 $j$는 $i + 1$부터 시작해 $i < j$인 쌍에서만 코드1이 실행된다. $i$가 정해지면 $j$는 $n - i$개이고 $i$는 1부터 $n - 1$까지이므로 수행 횟수는 $(n - 1) + (n - 2) + \cdots + 1 = n(n - 1) / 2$로 2차 다항식이다. 연속한 두 정수의 곱은 짝수라 정수 나눗셈으로도 정확히 구해진다. $n$이 최대 500,000이라 수행 횟수는 약 $1.25 \times 10^{11}$까지 커지므로 64비트 정수로 계산한다.

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        long n = Long.parseLong(br.readLine());
        System.out.println(n * (n - 1) / 2);
        System.out.println(2);
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    long long n;
    cin >> n;
    cout << n * (n - 1) / 2 << '\n';
    cout << 2;
}
```
