## 1. 아이디어

부등호 `ineq`(`">"` 또는 `"<"`)와 등호 여부 `eq`(`"="` 또는 `"!"`)의 조합이 `n`과 `m`의 비교 조건을 나타낸다. `ineq`가 `">"`이면 `eq`가 `"="`일 때 `n >= m`을, 아니면 `n > m`을 확인하고, `ineq`가 `"<"`이면 마찬가지로 `eq`에 따라 `n <= m` 또는 `n < m`을 확인해서, 조건을 만족하면 1을 아니면 0을 반환하면 되는 문제다.

---

## 2. 복잡도

| 접근 | 시간   | 공간   |
| ---- | ------ | ------ |
| 풀이 | $O(1)$ | $O(1)$ |

## 3. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int solution(String ineq, String eq, int n, int m) {
        if (ineq.equals(">")) {
            if (eq.equals("=")) return n >= m ? 1 : 0;
            return n > m ? 1 : 0;
        } else {
            if (eq.equals("=")) return n <= m ? 1 : 0;
            return n < m ? 1 : 0;
        }
    }
}
```
