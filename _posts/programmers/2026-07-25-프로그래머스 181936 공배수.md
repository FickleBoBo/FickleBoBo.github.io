## 1. 아이디어

정수 `number`와 `n`, `m`에 대해 `number`가 `n`의 배수이면서 `m`의 배수이면 1을 아니면 0을 return 하는 문제로 배수여부는 두 수를 나누었을 때 나머지가 0인지 여부로 판단할 수 있다.

---

## 2. 복잡도

| 시간복잡도 | 공간복잡도 |
| :--------: | :--------: |
|   $O(1)$   |   $O(1)$   |

---

## 3. 코드

### 풀이 [Java][C++]

```java
class Solution {
    public int solution(int number, int n, int m) {
        return number % n == 0 && number % m == 0 ? 1 : 0;
    }
}
```

```c++
int solution(int number, int n, int m) {
    return number % n == 0 && number % m == 0;
}
```
