## 1. 아이디어

[[BaekJoon] #15655 - N과 M (6)](/posts/baekjoon-15655/)과 같은 조합이지만 입력에 같은 수가 여러 번 주어질 수 있어서 같은 수열이 여러 번 만들어지므로 중복 출력을 막아야 하는 문제다. 정렬한 배열에서 인덱스가 증가하게 고르면 값이 비내림차순이 되고 한 값은 입력에 있는 개수까지만 쓰이므로, 사용 여부를 표시하지 않고 백트래킹의 다음 칸을 직전 인덱스보다 하나 큰 인덱스부터 시도하면 된다. 한 칸에서 직전에 시도한 값과 같은 값은 건너뛰는데, 같은 값이면 먼저 시도한 쪽의 이후 후보가 나중 쪽의 이후 후보를 모두 포함하므로 나중 쪽에서 나올 수열은 이미 먼저 나와 빠지는 수열이 없다.

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;
import java.util.*;

public class Main {

    static StringBuilder sb = new StringBuilder();
    static int n, m;
    static int[] arr;
    static int[] sel;

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());

        n = Integer.parseInt(st.nextToken());
        m = Integer.parseInt(st.nextToken());

        arr = new int[n];
        st = new StringTokenizer(br.readLine());
        for (int i = 0; i < n; i++) {
            arr[i] = Integer.parseInt(st.nextToken());
        }
        Arrays.sort(arr);

        sel = new int[m];

        dfs(0, 0);
        System.out.println(sb);
    }

    static void dfs(int start, int depth) {
        if (depth == m) {
            for (int x : sel) {
                sb.append(x).append(" ");
            }
            sb.append("\n");
            return;
        }

        int prv = 0;
        for (int i = start; i < n; i++) {
            if (arr[i] == prv) continue;

            prv = sel[depth] = arr[i];
            dfs(i + 1, depth + 1);
        }
    }
}
```

`prv`의 초깃값 0은 입력이 자연수라 어떤 원소와도 겹치지 않는다.

```c++
#include <bits/stdc++.h>
using namespace std;

int n, m;
int arr[8];
int sel[8];

void dfs(int start, int depth) {
    if (depth == m) {
        for (int i = 0; i < m; i++) cout << sel[i] << ' ';
        cout << '\n';
        return;
    }

    int prv = 0;
    for (int i = start; i < n; i++) {
        if (arr[i] == prv) continue;

        prv = sel[depth] = arr[i];
        dfs(i + 1, depth + 1);
    }
}

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    cin >> n >> m;
    for (int i = 0; i < n; i++) cin >> arr[i];
    sort(arr, arr + n);

    dfs(0, 0);
}
```

`prv`의 초깃값 0은 입력이 자연수라 어떤 원소와도 겹치지 않는다.

```python
import sys
from itertools import combinations

input = sys.stdin.readline

n, m = map(int, input().split())
arr = sorted(map(int, input().split()))
out = [" ".join(map(str, seq)) for seq in sorted(set(combinations(arr, m)))]
print("\n".join(out))
```

`combinations`는 입력의 순서를 유지하므로 먼저 `sorted`로 정렬해야 각 수열이 비내림차순이 되고, `set`으로 중복 수열을 없애면 순서를 잃으므로 `sorted`로 사전 순을 다시 맞췄다.
