## 1. 아이디어

배열에서 $n$의 배수만 남기는 문제다. 원소마다 $n$으로 나눈 나머지가 0인지만 보고 앞에서부터 걸러 내면 원래 순서가 그대로 유지된다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.util.*;

class Solution {
    public int[] solution(int n, int[] numlist) {
        return Arrays.stream(numlist).filter(x -> x % n == 0).toArray();
    }
}
```

`Arrays.stream`으로 만든 `IntStream`에서 `filter`로 조건이 참인 원소만 남겼다. `IntStream`은 기본형 스트림이라 `toArray`가 `int[]`를 그대로 돌려준다.

```c++
#include <bits/stdc++.h>
using namespace std;

vector<int> solution(int n, vector<int> numlist) {
    vector<int> v;
    for (int x : numlist) {
        if (x % n == 0) v.push_back(x);
    }

    return v;
}
```

```python
def solution(n, numlist):
    return [x for x in numlist if x % n == 0]
```
