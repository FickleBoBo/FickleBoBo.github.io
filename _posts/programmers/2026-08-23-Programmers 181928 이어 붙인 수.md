## 1. 아이디어

`num_list`를 한 번 순회하면서 홀수는 `odd`에, 짝수는 `even`에 자릿수를 이어 붙인다. `odd = odd * 10 + x` 형태로 누적하면 별도의 문자열 변환 없이 홀수들을 순서대로 이어 붙인 수를 만들 수 있고, `even`도 같은 방식으로 처리한다. 순회가 끝나면 두 값을 더해서 반환하면 된다.

---

## 2. 복잡도

| 접근 | 시간   | 공간   |
| ---- | ------ | ------ |
| 풀이 | $O(N)$ | $O(1)$ |

($N$ = `num_list`의 길이)

---

## 3. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int solution(int[] num_list) {
        int odd = 0, even = 0;

        for (int x : num_list) {
            if (x % 2 != 0) {
                odd = odd * 10 + x;
            } else {
                even = even * 10 + x;
            }
        }

        return odd + even;
    }
}
```
