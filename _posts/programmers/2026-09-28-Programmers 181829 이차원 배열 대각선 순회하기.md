## 1. 아이디어

`i + j <= k`를 만족하는 경우에 대해 `board`에서 합을 구하는 문제로 2차원 배열을 순회하며 인덱스의 합이 `k` 이하인 경우에만 합을 구하면 된다.

---

## 2. 복잡도

| 접근 | 시간            | 공간   |
| ---- | --------------- | ------ |
| 풀이 | $O(N \times M)$ | $O(1)$ |

($N$ = `board`의 행 수, $M$ = 열 수)

---

## 3. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int solution(int[][] board, int k) {
        int sum = 0;
        for (int i = 0; i < Math.min(board.length, k + 1); i++) {
            for (int j = 0; j < board[i].length; j++) {
                if (i + j > k) break;
                sum += board[i][j];
            }
        }

        return sum;
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int solution(vector<vector<int>> board, int k) {
    int sum = 0;
    for (int i = 0; i < min((int)board.size(), k + 1); i++) {
        for (int j = 0; j < board[i].size(); j++) {
            if (i + j > k) break;
            sum += board[i][j];
        }
    }

    return sum;
}
```

```python
def solution(board, k):
    total = 0
    for i, row in enumerate(board[: k + 1]):
        for j, x in enumerate(row):
            if i + j > k:
                break
            total += x

    return total
```
