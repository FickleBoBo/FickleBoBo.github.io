## 1. 아이디어

세 주사위 눈 `a`, `b`, `c`가 모두 같은지, 그중 두 개만 같은지, 모두 다른지를 조건문으로 구분해서 각 경우에 맞는 점수 공식을 적용하면 된다. 모두 같으면 $(a + b + c) \times (a^2 + b^2 + c^2) \times (a^3 + b^3 + c^3)$, 두 개만 같으면 $(a + b + c) \times (a^2 + b^2 + c^2)$, 모두 다르면 $a + b + c$를 반환했다.

---

## 2. 복잡도

| 접근 | 시간   | 공간   |
| ---- | ------ | ------ |
| 풀이 | $O(1)$ | $O(1)$ |

---

## 3. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int solution(int a, int b, int c) {
        if (a == b && b == c) {
            return (a + b + c) * (a * a + b * b + c * c) * (a * a * a + b * b * b + c * c * c);
        } else if (a == b || b == c || c == a) {
            return (a + b + c) * (a * a + b * b + c * c);
        } else {
            return a + b + c;
        }
    }
}
```
