## 1. 아이디어

앞에서부터 5명씩 묶으면 각 그룹의 첫 사람은 인덱스가 5의 배수인 사람이다. 마지막 그룹이 5명이 안 되더라도 그 첫 사람은 포함해야 하므로, 인덱스가 범위를 벗어나기 전까지 5씩 건너뛰며 모으면 그룹 수, 즉 사람 수를 5로 나눈 올림만큼 정확히 나온다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public String[] solution(String[] names) {
        String[] arr = new String[(names.length + 4) / 5];
        int idx = 0;

        for (int i = 0; i < names.length; i += 5) {
            arr[idx++] = names[i];
        }

        return arr;
    }
}
```

올림은 정수 나눗셈만으로 `(names.length + 4) / 5`처럼 구해 결과 배열의 크기로 잡았다.

```c++
#include <bits/stdc++.h>

    vector<string> v;
    for (int i = 0; i < names.size(); i += 5) {
        v.push_back(names[i]);
    }

    return v;
}
```
