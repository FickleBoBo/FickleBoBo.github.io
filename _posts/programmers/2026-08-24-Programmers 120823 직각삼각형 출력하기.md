## 1. 아이디어

정수 `n`을 입력받아, 1부터 `n`까지 순회하면서 i번째 줄에 별을 i개씩 출력하면 높이와 너비가 `n`인 직각삼각형이 완성된다.

---

## 2. 복잡도

| 접근 | 시간     | 공간   |
| ---- | -------- | ------ |
| 풀이 | $O(N^2)$ | $O(N)$ |

($N$ = 입력 `n`. 전체 출력 문자 수가 $N(N+1)/2$이므로 시간은 $O(N^2)$이다. 공간은 한 줄씩 바로 출력하는 C++/Python 기준이며, Java는 전체 출력을 `StringBuilder`에 모아 한 번에 출력하므로 $O(N^2)$이다)

---

## 3. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;

public class Solution {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringBuilder sb = new StringBuilder();

        int n = Integer.parseInt(br.readLine());
        for (int i = 1; i <= n; i++) {
            sb.append("*".repeat(i)).append("\n");
        }

        System.out.println(sb);
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    int n;
    cin >> n;

    for (int i = 1; i <= n; i++) {
        cout << string(i, '*') << '\n';
    }
}
```

```python
import sys

input = sys.stdin.readline

n = int(input())
for i in range(1, n + 1):
    print("*" * i)
```
