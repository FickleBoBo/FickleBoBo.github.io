## 1. 아이디어

구매 금액에 따라 할인율이 정해지는 문제다. 조건이 "이상"으로 겹쳐 있어(50만 원 이상이면 30만 원 이상이고 10만 원 이상이기도 하다) 큰 기준부터 검사해 처음 걸리는 구간의 할인율을 적용한다. 할인율을 퍼센트 값으로 두고 가격에 (100 - 할인율)을 곱한 뒤 100으로 정수 나눗셈하면 지불 금액이 바로 나오고, 소수점 이하를 버리는 조건도 함께 맞는다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int solution(int price) {
        if (price >= 500000) return price * 80 / 100;
        if (price >= 300000) return price * 90 / 100;
        if (price >= 100000) return price * 95 / 100;
        return price;
    }
}
```

