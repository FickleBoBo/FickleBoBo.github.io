## 1. 아이디어

같은 숫자가 몇 개인지에 따라 점수 식이 달라진다. 세 수가 모두 같으면 두 수가 같은지 보는 비교도 참이 되어 두 수만 같은 경우의 식이 잘못 적용되므로, 세 수가 모두 같은 경우를 먼저 검사해야 한다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int solution(int a, int b, int c) {
        if (a == b && b == c) {
            return (a + b + c) * (a * a + b * b + c * c) * (a * a * a + b * b * b + c * c * c);
        } else if (a == b || b == c || c == a) {
            return (a + b + c) * (a * a + b * b + c * c);
        } else {
            return a + b + c;
        }
    }
}
```

```python
def solution(a, b, c):
    if a == b == c:
        return (a + b + c) * (a**2 + b**2 + c**2) * (a**3 + b**3 + c**3)
    elif a == b or b == c or c == a:
        return (a + b + c) * (a**2 + b**2 + c**2)
    else:
        return a + b + c
```

비교 연산자는 이어 쓸 수 있어 `a == b == c`로 세 값이 모두 같은지 한 번에 검사했다.
