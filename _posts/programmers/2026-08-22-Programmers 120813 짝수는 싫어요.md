## 1. 아이디어

정수 `n`이 주어질 때, `n` 이하의 홀수를 오름차순으로 모아 배열로 반환하면 되는 문제다. 1부터 시작해 2씩 증가시키며 `n`을 넘지 않을 때까지 순회하면 조건을 만족하는 값만 이미 오름차순으로 얻어진다.

---

## 2. 복잡도

| 접근 | 시간   | 공간   |
| ---- | ------ | ------ |
| 풀이 | $O(N)$ | $O(N)$ |

($N$ = 입력값 `n`)

---

## 3. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int[] solution(int n) {
        int[] arr = new int[(n + 1) / 2];
        int idx = 0;

        for (int i = 1; i <= n; i += 2) {
            arr[idx++] = i;
        }

        return arr;
    }
}
```

홀수의 개수가 항상 `(n + 1) / 2`개임을 이용해 배열 크기를 미리 정했다.

```c++
#include <bits/stdc++.h>
using namespace std;

vector<int> solution(int n) {
    vector<int> v;
    for (int i = 1; i <= n; i += 2) {
        v.push_back(i);
    }

    return v;
}
```

```python
def solution(n):
    return list(range(1, n + 1, 2))
```

`range`로 홀수만 뽑아 곧바로 리스트로 반환했다.
