## 1. 아이디어

$n$의 약수를 오름차순으로 구하는 문제다. 1부터 $n$까지 차례로 나누어떨어지는지 보면 약수가 이미 오름차순으로 나오고, $n$이 10,000 이하라 전부 확인해도 충분하다.

더 줄이려면 약수가 곱이 $n$인 쌍 $(i, n / i)$로 묶인다는 점을 쓴다. 둘 다 $\sqrt{n}$보다 크면 곱이 $n$을 넘으므로 작은 쪽은 항상 $\sqrt{n}$ 이하이고, 그래서 $i$를 $\sqrt{n}$까지만 확인하며 $i$와 $n / i$를 함께 담으면 모든 약수를 얻는다. $i = n / i$인 제곱수는 한 번만 담고, 담는 순서가 뒤섞이므로 마지막에 정렬한다.

## 2. 코드

### 풀이 1: 완전 탐색 [Java][C++][Python]

```java
import java.util.*;

class Solution {
    public int[] solution(int n) {
        List<Integer> list = new ArrayList<>();
        for (int i = 1; i <= n; i++) {
            if (n % i == 0) list.add(i);
        }

        return list.stream().mapToInt(Integer::intValue).toArray();
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

vector<int> solution(int n) {
    vector<int> v;
    for (int i = 1; i <= n; i++) {
        if (n % i == 0) v.push_back(i);
    }

    return v;
}
```

```python
def solution(n):
    return [i for i in range(1, n + 1) if n % i == 0]
```

### 풀이 2: 제곱근까지 탐색 [Java][C++][Python]

```java
import java.util.*;

class Solution {
    public int[] solution(int n) {
        List<Integer> list = new ArrayList<>();
        for (int i = 1; i * i <= n; i++) {
            if (n % i == 0) {
                list.add(i);
                if (i != n / i) list.add(n / i);
            }
        }

        return list.stream().mapToInt(Integer::intValue).sorted().toArray();
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

vector<int> solution(int n) {
    vector<int> v;
    for (int i = 1; i * i <= n; i++) {
        if (n % i == 0) {
            v.push_back(i);
            if (i != n / i) v.push_back(n / i);
        }
    }
    sort(v.begin(), v.end());

    return v;
}
```

```python
import math


def solution(n):
    st = set()

    for i in range(1, math.isqrt(n) + 1):
        if n % i == 0:
            st.add(i)
            st.add(n // i)

    return sorted(st)
```

`set`에 담아 제곱수의 중복을 없앤 뒤 정렬했다.
