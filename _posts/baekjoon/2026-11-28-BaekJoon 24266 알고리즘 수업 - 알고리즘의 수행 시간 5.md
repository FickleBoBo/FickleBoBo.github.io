## 1. 아이디어

[[BaekJoon] #24265 - 알고리즘 수업 - 알고리즘의 수행 시간 4](/posts/baekjoon-24265/)의 이중 반복문과 달리 세 반복문이 모두 1부터 $n$까지 도는 알고리즘에서 코드1의 수행 횟수와 그 차수를 구하는 문제다. 세 변수가 서로의 값에 상관없이 각각 $n$가지 값을 가지므로 코드1은 $n^3$번 실행되고 차수는 3이다. $n$이 최대 500,000이라 $n^3$은 $1.25 \times 10^{17}$까지 커져 32비트 정수 범위는 넘지만 64비트 정수에는 담긴다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        long n = Long.parseLong(br.readLine());
        System.out.println(n * n * n);
        System.out.println(3);
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    long long n;
    cin >> n;
    cout << n * n * n << '\n';
    cout << 3;
}
```

```python
import sys

input = sys.stdin.readline

n = int(input())
print(n * n * n)

```
