## 1. 아이디어

가장 자주 나오는 값을 찾되 여러 개면 -1을 반환하는 문제다. 원소가 0 이상 1,000 미만이라 값별 등장 횟수를 길이 1,000의 배열에 셀 수 있다. 최빈값은 등장 횟수가 가장 큰 값이므로, 그 최대 횟수를 갖는 값이 하나뿐이면 그 값이 답이고 둘 이상이면 최빈값이 여러 개라 -1이다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int solution(int[] array) {
        int[] cnt = new int[1000];
        for (int x : array) {
            cnt[x]++;
        }

        int ans = -1;
        int max = 0;
        boolean flag = false;

        for (int i = 0; i < 1000; i++) {
            if (cnt[i] > max) {
                ans = i;
                max = cnt[i];
                flag = true;
            } else if (cnt[i] == max) {
                flag = false;
            }
        }

        return flag ? ans : -1;
    }
}
```

```c++
#include <bits/stdc++.h>

int cnt[1000];

int solution(vector<int> array) {
    for (int x : array) cnt[x]++;

    int ans = -1;
    int mx = 0;
    bool flag = false;

    for (int i = 0; i < 1000; i++) {
        if (cnt[i] > mx) {
            ans = i;
            mx = cnt[i];
            flag = true;
        } else if (cnt[i] == mx) {
            flag = false;
        }
    }

    return flag ? ans : -1;
}
```

```python
from collections import Counter


def solution(array):
    top2 = Counter(array).most_common(2)
    if len(top2) == 1 or top2[0][1] != top2[1][1]:
        return top2[0][0]
    return -1
```

`Counter`의 `most_common`으로 등장 횟수 상위 두 값을 바로 얻고, 두 횟수를 비교해 최빈값이 하나뿐인지 알아냈다. `most_common(2)`는 서로 다른 값이 하나뿐이면 한 원소만 돌려주므로, `top2[1]`에 접근하기 전에 길이를 확인했다.
