## 1. 아이디어

자연수 $N$의 각 자릿수를 더하는 문제인데, 10으로 나눈 나머지가 가장 낮은 자리이고 10으로 나눈 몫은 그 자리를 떼어 낸 수이므로 $N$이 0이 될 때까지 이를 반복하면 모든 자리를 빠짐없이 한 번씩 더하게 된다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
public class Solution {
    public int solution(int n) {
        int sum = 0;
        while (n > 0) {
            sum += n % 10;
            n /= 10;
        }

        return sum;
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int solution(int n) {
    int sum = 0;
    while (n > 0) {
        sum += n % 10;

}
```
