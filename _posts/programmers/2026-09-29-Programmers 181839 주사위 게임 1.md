## 1. 아이디어

두 주사위의 눈 `a`, `b`가 모두 홀수인지, 하나만 홀수인지, 둘 다 홀수가 아닌지로 분기 처리해서 주어진 수식에 맞게 계산만 하면 된다.

---

## 2. 복잡도

| 접근 | 시간   | 공간   |
| ---- | ------ | ------ |
| 풀이 | $O(1)$ | $O(1)$ |

---

## 3. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int solution(int a, int b) {
        if (a % 2 != 0 && b % 2 != 0) return a * a + b * b;
        if (a % 2 != 0 || b % 2 != 0) return 2 * (a + b);
        return Math.abs(a - b);
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

}
```
