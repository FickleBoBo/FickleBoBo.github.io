## 1. 아이디어

문자열 `my_string`의 $0$번부터 $n - 1$번 인덱스의 문자까지를 잘라낸 부분 문자열을 반환하면 된다.

---

## 2. 복잡도

| 접근 | 시간   | 공간   |
| ---- | ------ | ------ |
| 풀이 | $O(N)$ | $O(N)$ |

($N$ = 입력값 `n`)

---

## 3. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public String solution(String my_string, int n) {
        return my_string.substring(0, n);
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

string solution(string my_string, int n) {
    return my_string.substr(0, n);
}
```

```python
def solution(my_string, n):
    return my_string[:n]
```
