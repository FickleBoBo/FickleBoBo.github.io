## 1. 아이디어

1부터 $N$까지의 자연수에서 중복 없이 $M$개를 골라 만든 수열, 즉 길이가 $M$인 순열을 사전 순으로 모두 출력하는 문제다. 수열을 앞 칸부터 한 칸씩 채우되 각 칸에서 아직 쓰지 않은 수를 작은 것부터 차례로 넣고 다음 칸으로 내려가며, $M$칸이 모두 차면 출력한 뒤 돌아와 넣은 수를 되돌리고 다음 수를 시도하는 백트래킹으로 만든다. 앞 칸에 작은 수를 둔 수열이 먼저 완성되고 같은 앞부분 안에서도 다음 칸에 작은 수부터 시도하므로 완성되는 순서가 곧 사전 순이라 따로 정렬할 필요가 없고, 쓴 수를 표시해 두었다가 돌아올 때 지워야 다른 가지에서 그 수를 다시 쓸 수 있다. 출력해야 할 수열이 최대 $8! = 40{,}320$개라 모두 만들어 보는 것이 곧 출력의 비용이다.

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;
import java.util.*;

public class Main {

    static StringBuilder sb = new StringBuilder();
    static int n, m;
    static int[] sel;
    static boolean[] vis;

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());

        n = Integer.parseInt(st.nextToken());
        m = Integer.parseInt(st.nextToken());
        sel = new int[m];
        vis = new boolean[1 + n];

        dfs(0);
        System.out.println(sb);
    }

    static void dfs(int depth) {
        if (depth == m) {
            for (int x : sel) {
                sb.append(x).append(" ");
            }
            sb.append("\n");
            return;
        }

        for (int i = 1; i <= n; i++) {
            if (vis[i]) continue;

            sel[depth] = i;
            vis[i] = true;
            dfs(depth + 1);
            vis[i] = false;
        }
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int n, m;
int sel[8];
bool vis[1 + 8];

void dfs(int depth) {
    if (depth == m) {
        for (int i = 0; i < m; i++) cout << sel[i] << ' ';
        cout << '\n';
        return;
    }

    for (int i = 1; i <= n; i++) {
        if (vis[i]) continue;

        sel[depth] = i;
        vis[i] = true;
        dfs(depth + 1);
        vis[i] = false;
    }
}

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    cin >> n >> m;

    dfs(0);
}
```

```python
import sys
from itertools import permutations

input = sys.stdin.readline

n, m = map(int, input().split())
out = [" ".join(map(str, seq)) for seq in permutations(range(1, n + 1), m)]
print("\n".join(out))
```

`permutations`는 입력의 앞쪽 원소부터 고르는 순서로 순열을 내므로 오름차순 `range`를 넘겨 사전 순으로 얻었다.
