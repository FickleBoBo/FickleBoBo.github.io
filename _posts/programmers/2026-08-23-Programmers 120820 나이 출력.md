## 1. 아이디어

2022년 기준 나이로 출생 연도를 구하는 문제다. 나이는 태어난 해에 1살이고 매년 1월 1일에 늘어나므로, 나이를 $a$라 하면 태어난 해로부터 $a - 1$년이 지난 것이다. 따라서 출생 연도는 $2022 - (a - 1) = 2023 - a$이다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int solution(int age) {
        return 2023 - age;
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int solution(int age) {
    return 2023 - age;
}
```

```python
def solution(age):
    return 2023 - age
```
