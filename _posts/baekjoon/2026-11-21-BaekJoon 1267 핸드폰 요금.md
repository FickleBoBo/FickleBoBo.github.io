## 1. 아이디어

요금이 통화 하나마다 청구되므로 통화마다 두 요금제의 요금을 구해 각각 합한 뒤 더 싼 쪽을 출력하고, 합이 같으면 `Y M`과 그 요금을 함께 출력한다. 통화 하나의 시간을 $t$초라 하면 영식 요금은 $(\lfloor t / 30 \rfloor + 1) \times 10$원, 민식 요금은 $(\lfloor t / 60 \rfloor + 1) \times 15$원이다. 통화 시간이 청구 주기에 도달하는 순간 다음 구간으로 넘어가므로(영식은 29초까지 10원이고 30초부터 20원) 올림이 아니라 몫에 1을 더한다.

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        int n = Integer.parseInt(br.readLine());
        StringTokenizer st = new StringTokenizer(br.readLine());

        int ys = 0;
        int ms = 0;

        while (n-- > 0) {
            int x = Integer.parseInt(st.nextToken());
            ys += (x / 30 + 1) * 10;
            ms += (x / 60 + 1) * 15;
        }

        if (ys < ms) {
            System.out.println("Y " + ys);
        } else if (ys > ms) {
            System.out.println("M " + ms);
        } else {
            System.out.println("Y M " + ys);
        }
    }
}
```
