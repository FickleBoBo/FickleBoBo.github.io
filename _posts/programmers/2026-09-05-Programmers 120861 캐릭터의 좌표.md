## 1. 아이디어

주어진 문자열 `keyinput`을 순서대로 훑으며 현재 좌표를 갱신하면 되는 간단한 문제다. `board`의 두 변이 모두 홀수라 중앙 $(0, 0)$에서 각 축으로 갈 수 있는 최대 칸 수는 변 길이의 절반이고, 매 이동마다 좌표를 이 범위로 자르면 판을 벗어나는 입력은 자연히 무시된다.

---

## 2. 복잡도

| 접근 | 시간   | 공간   |
| ---- | ------ | ------ |
| 풀이 | $O(N)$ | $O(1)$ |

($N$ = `keyinput`의 길이)

---

## 3. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int[] solution(String[] keyinput, int[] board) {
        int[] pos = {0, 0};
        int maxx = board[0] / 2;
        int maxy = board[1] / 2;

        for (String s : keyinput) {
            if (s.equals("up")) {
                pos[1] = Math.min(pos[1] + 1, maxy);
            } else if (s.equals("down")) {
                pos[1] = Math.max(pos[1] - 1, -maxy);
            } else if (s.equals("left")) {
                pos[0] = Math.max(pos[0] - 1, -maxx);
            } else {
                pos[0] = Math.min(pos[0] + 1, maxx);
            }
        }

        return pos;
    }
}
```
