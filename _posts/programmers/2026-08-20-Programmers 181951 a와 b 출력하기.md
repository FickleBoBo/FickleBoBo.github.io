## 1. 아이디어

두 수 $a$, $b$는 계산하지 않고 출력만 하므로 정수로 바꿀 필요 없이, 읽은 그대로를 `"a = "`, `"b = "` 뒤에 붙여 한 줄씩 출력한다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;
import java.util.*;

public class Solution {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());

        System.out.println("a = " + st.nextToken());
        System.out.println("b = " + st.nextToken());
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    string a, b;
    cin >> a >> b;
    cout << "a = " << a << '\n';
    cout << "b = " << b << '\n';
}
```

```python
import sys

input = sys.stdin.readline

a, b = input().split()
print(f"a = {a}")
print(f"b = {b}")
```
