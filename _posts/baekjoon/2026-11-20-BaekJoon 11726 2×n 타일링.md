## 1. 아이디어

2×$n$ 직사각형을 1×2 타일과 2×1 타일로 채우는 방법의 수를 구하는 문제다. 맨 오른쪽 위 칸을 덮는 타일이 무엇인지로 경우를 나눈다. 2×1 타일을 세로로 세우면 오른쪽 열이 통째로 채워져 2×$(n - 1)$이 남는다. 1×2 타일을 가로로 놓으면 그 아래 칸은 세로 타일로 덮을 수 없어 같은 모양의 가로 타일로 덮어야 하니 1×2 타일 두 개를 위아래로 쌓아 오른쪽 두 열이 채워지고 2×$(n - 2)$가 남는다. 두 경우는 겹치지 않고 빠지는 경우도 없으므로 2×$n$을 채우는 방법의 수를 $f(n)$이라 하면 $f(n) = f(n - 1) + f(n - 2)$이고 $f(1) = 1$, $f(2) = 2$다.

방법의 수를 10,007로 나눈 나머지를 구해야 하는데 점화식이 덧셈뿐이라 매 항마다 나머지를 취해도 최종 나머지는 같다. 나머지를 취하지 않으면 $n = 1{,}000$에서 값이 정수 자료형을 크게 넘는다.

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;

public class Main {

    static final int MOD = 10007;

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        int n = Integer.parseInt(br.readLine());
        int[] dp = new int[1 + n + 1];
        dp[1] = 1;
        dp[2] = 2;
        for (int i = 3; i <= n; i++) {
            dp[i] = (dp[i - 2] + dp[i - 1]) % MOD;
        }

        System.out.println(dp[n]);
    }
}
```

`n`이 1일 때도 `dp[2]`에 값을 넣으므로 크기를 `1 + n + 1`로 잡아 인덱스를 벗어나지 않게 했다.

```c++
#include <bits/stdc++.h>

const int MOD = 10007;
int dp[1 + 1000] = {0, 1, 2};

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    int n;
    cin >> n;

    for (int i = 3; i <= n; i++) {
        dp[i] = (dp[i - 2] + dp[i - 1]) % MOD;
    }

    cout << dp[n];
}
```
