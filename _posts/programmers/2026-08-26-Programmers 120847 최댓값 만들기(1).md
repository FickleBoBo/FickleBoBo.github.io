## 1. 아이디어

원소 두 개를 골라 곱한 값의 최댓값을 구하는 문제다. 원소가 모두 0 이상이라 곱은 두 수가 클수록 커지므로 가장 큰 두 수를 곱하면 되고, 정렬하면 그 둘이 맨 뒤에 온다. 음수가 섞여 있다면 가장 작은 두 음수의 곱이 더 클 수 있지만 이 문제에는 음수가 없다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.util.*;

class Solution {
    public int solution(int[] numbers) {
        Arrays.sort(numbers);
        return numbers[numbers.length - 2] * numbers[numbers.length - 1];
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int solution(vector<int> numbers) {
    sort(numbers.begin(), numbers.end());
    return numbers[numbers.size() - 2] * numbers[numbers.size() - 1];
}
```

```python
def solution(numbers):
    numbers.sort()
    return numbers[-2] * numbers[-1]
```
