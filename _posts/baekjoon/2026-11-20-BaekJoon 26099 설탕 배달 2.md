## 1. 아이디어

[[BaekJoon] #2839 - 설탕 배달](/posts/baekjoon-2839/)에서 $N$의 상한이 $10^{18}$로 커진다. $N$에 비례해 시간이 드는 방법은 쓸 수 없지만, 3킬로그램 봉지 5개를 5킬로그램 봉지 3개로 바꿀 수 있어 3킬로그램 봉지를 4개 이하만 확인하면 된다는 같은 아이디어는 $N$과 무관하게 다섯 가지 경우만 보므로 그대로 통한다.

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        long n = Long.parseLong(br.readLine());

        if (n % 5 == 0) {
            System.out.println(n / 5);
        } else if (n >= 3 && (n - 3) % 5 == 0) {
            System.out.println((n - 3) / 5 + 1);
        } else if (n >= 6 && (n - 6) % 5 == 0) {
            System.out.println((n - 6) / 5 + 2);
        } else if (n >= 9 && (n - 9) % 5 == 0) {
            System.out.println((n - 9) / 5 + 3);
        } else if (n >= 12 && (n - 12) % 5 == 0) {
            System.out.println((n - 12) / 5 + 4);
        } else {
            System.out.println(-1);
        }
    }
}
```
