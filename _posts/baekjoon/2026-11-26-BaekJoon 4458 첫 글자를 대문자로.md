## 1. 아이디어

각 줄의 첫 글자를 대문자로 바꾸는 문제로, 첫 글자가 항상 알파벳이라고 보장되어 바꿀 글자는 맨 앞 하나다. 나머지는 대소문자까지 그대로 이어 출력하며, 문장에 공백이 있으므로 단어가 아니라 줄 단위로 읽는다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        BufferedWriter bw = new BufferedWriter(new OutputStreamWriter(System.out));

        int n = Integer.parseInt(br.readLine());
        while (n-- > 0) {
            String line = br.readLine();

            bw.write(Character.toUpperCase(line.charAt(0)));
            bw.write(line.substring(1));
            bw.newLine();
        }

        bw.flush();
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    int n;
    cin >> n;
    cin.ignore();

    while (n--) {
        string line;
        getline(cin, line);

        line[0] = toupper(line[0]);
        cout << line << '\n';
    }
}
```

`cin >> n` 뒤에 남은 줄바꿈을 `cin.ignore`로 버려 첫 `std::getline`이 빈 줄을 읽지 않게 했다.

```python
import sys

input = sys.stdin.readline

n = int(input())
for _ in range(n):
    line = input().rstrip()
    print(line[0].upper() + line[1:])
```

`capitalize`는 나머지 글자를 소문자로 바꾸므로, 첫 글자만 `upper`로 바꾸고 나머지는 슬라이스 `line[1:]`를 그대로 이었다.
