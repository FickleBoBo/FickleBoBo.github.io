## 1. 아이디어

[[BaekJoon] #24445 - 알고리즘 수업 - 너비 우선 탐색 2](/posts/baekjoon-24445/)처럼 BFS를 하되 방문 순서 대신 BFS 트리에서의 각 정점의 깊이를 구하는 문제다. 모든 간선의 가중치가 1이라 BFS는 $R$에서 가까운 정점부터 방문하므로 깊이는 $R$에서 그 정점까지 가는 최단 경로의 간선 수와 같다. 최단 거리는 인접 정점을 어떤 순서로 살피든 달라지지 않으므로 인접 리스트를 정렬하지 않아도 된다. 처음 발견한 정점은 BFS 트리에서 지금 꺼낸 정점의 자식이 되므로, 꺼낸 정점의 깊이에 1을 더한 값이 그 깊이다. 깊이를 `-1`로 초기화해 두면 값이 `-1`인지 보는 것으로 방문 여부까지 확인되고, 닿지 못한 정점에는 `-1`이 그대로 남는다.

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;
import java.util.*;

public class Main {

    static int n;
    static List<Integer>[] adj;

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
        StringTokenizer st = new StringTokenizer(br.readLine());

        n = Integer.parseInt(st.nextToken());
        int m = Integer.parseInt(st.nextToken());
        int r = Integer.parseInt(st.nextToken());

        adj = new ArrayList[1 + n];
        for (int i = 1; i <= n; i++) {
            adj[i] = new ArrayList<>();
        }

        while (m-- > 0) {
            st = new StringTokenizer(br.readLine());
            int u = Integer.parseInt(st.nextToken());
            int v = Integer.parseInt(st.nextToken());
            adj[u].add(v);
            adj[v].add(u);
        }

        System.out.println(bfs(r));
    }

    static String bfs(int start) {
        Queue<Integer> q = new ArrayDeque<>();
        q.offer(start);

        int[] dist = new int[1 + n];
        Arrays.fill(dist, -1);
        dist[start] = 0;

        while (!q.isEmpty()) {
            int cur = q.poll();

            for (int nxt : adj[cur]) {
                if (dist[nxt] != -1) continue;
                q.offer(nxt);
                dist[nxt] = dist[cur] + 1;
            }
        }

        StringBuilder sb = new StringBuilder();
        for (int i = 1; i <= n; i++) {
            sb.append(dist[i]).append("\n");
        }

        return sb.toString();
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

const int MAX_N = 1 + 100000;
vector<int> adj[MAX_N];
int dist[MAX_N];

void bfs(int start) {
    queue<int> q;
    q.push(start);

    memset(dist, -1, sizeof(dist));
    dist[start] = 0;

    while (!q.empty()) {
        int cur = q.front();
        q.pop();

        for (int nxt : adj[cur]) {
            if (dist[nxt] != -1) continue;
            q.push(nxt);
            dist[nxt] = dist[cur] + 1;
        }
    }
}

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    int n, m, r;
    cin >> n >> m >> r;

    while (m--) {
        int u, v;
        cin >> u >> v;
        adj[u].push_back(v);
        adj[v].push_back(u);
    }

    bfs(r);

    for (int i = 1; i <= n; i++) {
        cout << dist[i] << '\n';
    }
}
```

`std::memset`은 바이트 단위로 채우는데, `-1`은 모든 비트가 1이라 `int` 배열도 `-1`로 채워졌다.

```python
import sys
from collections import deque

input = sys.stdin.readline


def bfs(start):
    q = deque([start])

    dist = [-1] * (1 + n)
    dist[start] = 0

    while q:
        cur = q.popleft()

        for nxt in adj[cur]:
            if dist[nxt] != -1:
                continue
            dist[nxt] = dist[cur] + 1
            q.append(nxt)

    return dist


n, m, r = map(int, input().split())
adj = [[] for _ in range(1 + n)]
for _ in range(m):
    u, v = map(int, input().split())
    adj[u].append(v)
    adj[v].append(u)

print("\n".join(map(str, bfs(r)[1:])))
```
