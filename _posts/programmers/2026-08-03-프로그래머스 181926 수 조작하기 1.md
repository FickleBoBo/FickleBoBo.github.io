## 1. 아이디어

`control` 문자열을 앞에서부터 순서대로 읽으며 `w`, `s`, `d`, `a`에 대응하는 `+1`, `-1`, `+10`, `-10`을 `n`에 그대로 누적해줬다.

---

## 2. 복잡도

| 시간복잡도 | 공간복잡도 |
| :--------: | :--------: |
|   $O(N)$   |   $O(1)$   |

> $N$ = `control` 길이

---

## 3. 코드

### 풀이 [Java][C++]

```java
class Solution {
    public int solution(int n, String control) {
        for (char c : control.toCharArray()) {
            if (c == 'w') {
                n += 1;
            } else if (c == 's') {
                n -= 1;
            } else if (c == 'd') {
                n += 10;
            } else {
                n -= 10;
            }
        }

        return n;
    }
}
```
