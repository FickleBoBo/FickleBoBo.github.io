## 1. 아이디어

[[BaekJoon] #24262 - 알고리즘 수업 - 알고리즘의 수행 시간 1](/posts/baekjoon-24262/)과 달리 코드1이 1부터 $n$까지 도는 반복문 안에 있는 알고리즘의 수행 횟수와 그 차수를 구하는 문제다. 반복마다 코드1이 한 번씩 실행되므로 수행 횟수는 $n$이고, $n$에 대한 1차 다항식이다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        int n = Integer.parseInt(br.readLine());
        System.out.println(n);
        System.out.println(1);
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    int n;
    cin >> n;
    cout << n << '\n';
    cout << 1;
}
```

```python
import sys

input = sys.stdin.readline

n = int(input())
```
