## 1. 아이디어

정확히 $N$킬로그램을 3킬로그램 봉지와 5킬로그램 봉지로 담을 때 봉지 수를 최소로 하는 문제다. 3킬로그램 봉지를 $k$개, 5킬로그램 봉지를 $m$개 쓴다고 하면 $3k + 5m = N$이고 봉지 수는 $k + m$이다. 3킬로그램 봉지 5개는 5킬로그램 봉지 3개로 바꿀 수 있고 봉지가 2개 줄어드니, 최소 봉지 수를 구할 때는 $k \le 4$인 경우만 보면 된다. $N - 3k$가 5의 배수여야 하는데 $3k$를 5로 나눈 나머지가 $k = 0, 1, 2, 3, 4$에서 모두 다르므로 성립하는 $k$는 많아야 하나이고, 그때 봉지 수는 $(N - 3k) / 5 + k$다. $N - 3k$가 음수여도 5의 배수일 수 있으므로($N = 7$, $k = 4$) $N \ge 3k$를 함께 확인해야 하고, 어떤 $k$도 성립하지 않으면 정확히 $N$킬로그램을 만들 수 없다.

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        int n = Integer.parseInt(br.readLine());

        if (n % 5 == 0) {
            System.out.println(n / 5);
        } else if (n >= 3 && (n - 3) % 5 == 0) {
            System.out.println((n - 3) / 5 + 1);
        } else if (n >= 6 && (n - 6) % 5 == 0) {
            System.out.println((n - 6) / 5 + 2);
        } else if (n >= 9 && (n - 9) % 5 == 0) {
            System.out.println((n - 9) / 5 + 3);
        } else if (n >= 12 && (n - 12) % 5 == 0) {
            System.out.println((n - 12) / 5 + 4);
        } else {
            System.out.println(-1);
        }
    }
}
```
