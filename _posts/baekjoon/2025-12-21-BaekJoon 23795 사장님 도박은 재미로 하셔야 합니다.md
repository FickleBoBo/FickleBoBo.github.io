## 1. 아이디어

윤성이가 판마다 베팅한 양의 정수 형태의 돈이 주어지며 윤성이는 모든 베팅에서 진다. 이때 윤성이가 잃은 돈을 계산해야 하는 문제다. 윤성이가 베팅한 돈의 합계가 윤성이가 잃은 돈이므로 베팅한 돈을 전부 더하면 된다.

무한 루프를 활용해서 베팅한 돈을 계속 더했으며 `-1`이 입력으로 들어온 순간 무한 루프를 종료하고 출력했다.

---

## 2. 복잡도

| 접근 | 시간   | 공간   |
| ---- | ------ | ------ |
| 풀이 | $O(N)$ | $O(1)$ |

($N$ = 입력된 베팅 횟수)

---

## 3. 코드

### 풀이 [Java][C++]

```java
import java.io.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        int sum = 0;
        while (true) {
            int x = Integer.parseInt(br.readLine());
            if (x == -1) break;
            sum += x;
        }

        System.out.println(sum);
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    int sum = 0;
    while (true) {
        int x;
        cin >> x;

        if (x == -1) break;
        sum += x;
    }

    cout << sum;
}
```
