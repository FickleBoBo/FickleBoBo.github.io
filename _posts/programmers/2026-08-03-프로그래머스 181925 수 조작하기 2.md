## 1. 아이디어

인접한 두 로그값의 차이는 항상 `+1`, `-1`, `+10`, `-10` 중 하나다. 그 차이를 보고 각각 `w`, `s`, `d`, `a`로 되돌려 조작 기록 문자열을 복원해줬다.

---

## 2. 복잡도

| 시간복잡도 | 공간복잡도 |
| :--------: | :--------: |
|   $O(N)$   |   $O(1)$   |

> $N$ = `numLog` 길이

---

## 3. 코드

### 풀이 [Java][C++]

```java
class Solution {
    public String solution(int[] numLog) {
        StringBuilder sb = new StringBuilder();
        for (int i = 1; i < numLog.length; i++) {
            if (numLog[i] == numLog[i - 1] + 1) {
                sb.append("w");
            } else if (numLog[i] == numLog[i - 1] - 1) {
                sb.append("s");
            } else if (numLog[i] == numLog[i - 1] + 10) {
                sb.append("d");
            } else {
                sb.append("a");
            }
        }

        return sb.toString();
    }
}
```
