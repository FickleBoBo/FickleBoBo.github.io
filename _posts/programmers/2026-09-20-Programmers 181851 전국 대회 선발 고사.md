## 1. 아이디어

참석 가능한 학생 중 등수가 높은 3명을 뽑는 문제다. 불참하는 학생은 등수와 상관없이 후보에서 빠지므로, 참석 가능한 학생만 등수와 번호를 함께 묶어 등수 오름차순으로 정렬하면 앞의 3명이 선발되고, 정렬된 순서대로 $a$번, $b$번, $c$번 학생이 된다. 등수가 모두 다르므로 동률은 신경 쓰지 않는다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.util.*;

class Solution {
    public int solution(int[] rank, boolean[] attendance) {
        List<int[]> list = new ArrayList<>();
        for (int i = 0; i < rank.length; i++) {
            if (attendance[i]) list.add(new int[]{rank[i], i});
        }
        list.sort((o1, o2) -> Integer.compare(o1[0], o2[0]));

        return 10000 * list.get(0)[1] + 100 * list.get(1)[1] + list.get(2)[1];
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int solution(vector<int> rank, vector<bool> attendance) {
    vector<pair<int, int>> v;
    for (int i = 0; i < rank.size(); i++) {
        if (attendance[i]) v.emplace_back(rank[i], i);
    }
    sort(v.begin(), v.end());

    return 10000 * v[0].second + 100 * v[1].second + v[2].second;
}
```

등수를 첫 번째 값으로 `std::pair`에 담아 비교 함수 없이 `std::sort`로 정렬했다. `std::pair`는 첫 번째 값부터 비교한다.

```python
def solution(rank, attendance):
    res = sorted((r, i) for i, r in enumerate(rank) if attendance[i])
    (_, a), (_, b), (_, c) = res[:3]

    return 10000 * a + 100 * b + c
```

정렬한 앞 3개를 `(_, a), (_, b), (_, c) = res[:3]`로 풀어 번호만 받았다.
