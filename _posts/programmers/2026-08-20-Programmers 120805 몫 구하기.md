## 1. 아이디어

정수 `num1`, `num2`가 주어질 때, `num1`을 `num2`로 나눈 몫을 반환하면 되는 간단한 문제다.

---

## 2. 복잡도

| 접근 | 시간   | 공간   |
| ---- | ------ | ------ |
| 풀이 | $O(1)$ | $O(1)$ |

---

## 3. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int solution(int num1, int num2) {
        return num1 / num2;
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int solution(int num1, int num2) {
    return num1 / num2;
}
```

```python
def solution(num1, num2):
    return num1 // num2
```

Python의 `/`는 실수 나눗셈을 반환하므로 정수 나눗셈 연산자 `//`를 대신 써야 한다.
