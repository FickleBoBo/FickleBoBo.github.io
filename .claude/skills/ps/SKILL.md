# ps — PS 포스트 스캐폴드 생성

PS 레포 한 날짜의 풀이 → `_drafts/{platform}/` 드래프트들. 파일명·front matter·문제 링크·코드까지 자동이고 **`## 1. 아이디어`는 빈 헤딩**(작성은 `review-code` 뒤 사용자나 메인 세션이 하고, 규칙·작성 방식은 [`STYLE.md`](../_shared/STYLE.md)). PS 레포는 `{YYYY-MM}/src/day_{DD}/{접두사}_{번호}/`와 소스 파일 네이밍 규칙을 항상 지킨다고 보고 검증 없이 읽는다.

```
python3 ${CLAUDE_SKILL_DIR}/scripts/scaffold_post.py YYYY-MM-DD
```

- 스크립트는 날짜 하루치만 처리한다. 날짜 구간을 받으면 최신 날짜부터 과거로 하루씩 호출한다. PS 레포에 폴더가 없는 날짜는 에러로 끝나니 건너뛰고 다음 날짜로 간다. 날짜가 없으면 평문으로 요청한다(선택지 UI 금지). 2026-08-17(블로그 개설일) 이전은 거부.
- 이미 포스트/드래프트가 있는 문제(`_drafts`·`_posts`의 front matter `slug` 기준)는 건너뛴다. 같은 문제가 여러 날짜에 있으면 먼저 처리한 날짜(구간이면 더 최근 날짜)의 풀이가 채택된다. 스킵은 이 경우뿐이고 실패한 풀이(`_fail`로 끝나는 폴더)나 대상 저지가 아닌 폴더(`live_*` 등)는 폴더 식별 단계에서 에러(`실패한 풀이(_fail)`, `대상 저지 아님(접두사 …)`)로 보고된다.
- 출력: `생성함: {경로}` / `스킵(이미 있음): {폴더명} — slug={slug}` / `에러({폴더명}): {예외}` + 총계 한 줄. **스킵한 항목은 사용 후 사용자에게 그대로 알린다.** 한 폴더의 에러는 그 폴더만 보고하고 계속한다. 판단은 얹지 않는다.
- 폴더에 있는 소스 파일을 확장자로 판별해 전부 싣는다(저지별 언어는 검사하지 않는다). 브래킷 순서는 `[Java][C++][Python]`.
- 제목·URL은 Programmers·BaekJoon은 문제 페이지의 `<title>`, LeetCode·Codeforces는 공개 API에서 읽는다.
- 미리보기: `bundle exec jekyll serve --drafts`.

## 스캐폴드 규칙 (코드에서 안 보이는 것)

- 같은 언어 파일이 여러 개면(`Main.java`+`Main2.java`) 파일명 끝자리 숫자로 접근법을 나눠 `### 풀이 1`/`### 풀이 2`(하나면 `### 풀이`). 접근 이름(`풀이 2: DP`)은 아이디어와 함께 사용자나 메인 세션이 붙인다(`STYLE.md`).
- 헤딩 바로 아래 설명 = 그 접근법 전 언어 공통, 코드 블록 바로 아래 설명 = 그 언어 전용. 코드 블록을 자기 접근법 구간 밖으로 옮기면 `sync`가 못 찾는다.
- SQL 전용 포스트는 `## 2. 쿼리`, 브래킷 `[MySQL]`, 코드펜스 ` ```sql `.
- 회고는 생성하지 않는다. 실수·오답 원인 같은 구체적 사건이 있을 때만 코드 뒤에 `## 3. 회고`를 직접 추가(`STYLE.md`).
- `description` front matter는 만들지 않는다. `tags`는 `[]`로 두고 `tag` 스킬이 채운다.
