## 1. 아이디어

문자열이 가진 각 한 자리 숫자를 더하는 문제다. 각 자리 숫자의 합이므로 자릿값(10의 거듭제곱)은 곱하지 않고, 각 글자가 나타내는 숫자만 더하면 된다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int solution(String num_str) {
        int sum = 0;
        for (char c : num_str.toCharArray()) {
            sum += c - '0';
        }

        return sum;
    }
}
```

숫자 문자에서 문자 `'0'`을 빼면 그 숫자 값이 되므로 `c - '0'`을 더했다.

```c++
#include <bits/stdc++.h>
using namespace std;

int solution(string num_str) {
    int sum = 0;
    for (char c : num_str) sum += c - '0';
    return sum;
}
```

```python
def solution(num_str):
    return sum(int(c) for c in num_str)
```
