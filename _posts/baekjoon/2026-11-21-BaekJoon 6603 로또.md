## 1. 아이디어

집합 $S$에서 6개를 고르는 모든 조합을 사전 순으로 출력하는 문제다. $k$가 12 이하라 조합이 많아야 $\binom{12}{6} = 924$가지여서 전부 만들어도 충분하다. $S$가 오름차순으로 주어지므로 인덱스가 증가하는 순서로만 6개를 고르는 백트래킹으로 각 자리에서 작은 인덱스부터 시도하면, 같은 조합이 중복되지 않고 값 순서도 인덱스 순서와 같아 사전 순으로 나온다.

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;
import java.util.*;

public class Main {

    static StringBuilder sb = new StringBuilder();
    static int k;
    static int[] arr;
    static int[] sel;

    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        while (true) {
            StringTokenizer st = new StringTokenizer(br.readLine());
            k = Integer.parseInt(st.nextToken());
            if (k == 0) break;

            arr = new int[k];
            for (int i = 0; i < k; i++) {
                arr[i] = Integer.parseInt(st.nextToken());
            }
            sel = new int[6];

            dfs(0, 0);
            sb.append("\n");
        }

        System.out.println(sb);
    }

    static void dfs(int start, int depth) {
        if (depth == 6) {
            for (int x : sel) {
                sb.append(x).append(" ");
            }
            sb.append("\n");
            return;
        }

        for (int i = start; i < k; i++) {
            sel[depth] = arr[i];
            dfs(i + 1, depth + 1);
        }
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int k;
int arr[12];
int sel[6];

void dfs(int start, int depth) {
    if (depth == 6) {
        for (int x : sel) {
            cout << x << ' ';
        }
        cout << '\n';
        return;
    }

    for (int i = start; i < k; i++) {
        sel[depth] = arr[i];
        dfs(i + 1, depth + 1);
    }
}

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    while (true) {
        cin >> k;
        if (k == 0) break;

        for (int i = 0; i < k; i++) cin >> arr[i];

        dfs(0, 0);
        cout << '\n';
    }
}
```

```python
import sys
from itertools import combinations

input = sys.stdin.readline

while True:
    k, *arr = map(int, input().split())
    if k == 0:
        break
    for seq in combinations(arr, 6):
        print(*seq)
    print()
```

`combinations`는 넘긴 리스트의 순서대로 조합을 만들므로, 오름차순으로 주어진 리스트를 그대로 넘겨 재귀 없이 사전 순으로 출력했다.
