## 1. 아이디어

문자열 `myString`에서 `pat`으로 끝나는 가장 긴 부분 문자열을 반환하는 문제로 `myString`의 뒤에서부터 `pat`을 찾아 처음 발견하는 순간 `myString`의 0번 인덱스부터 해당 위치까지로 자르면 가장 긴 부분 문자열이 된다.

---

## 2. 복잡도

| 접근 | 시간            | 공간   |
| ---- | --------------- | ------ |
| 풀이 | $O(N \times M)$ | $O(N)$ |

($N$ = `myString`의 길이, $M$ = `pat`의 길이)

---

## 3. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public String solution(String myString, String pat) {
        return myString.substring(0, myString.lastIndexOf(pat) + pat.length());
    }
}
```

`lastIndexOf` 메서드를 활용해 발견한 가장 뒷 부분 인덱스를 구했다. `pat`까지 포함해서 잘라야 하므로 `pat`의 길이만큼을 추가해서 잘라야 한다.

```c++
#include <bits/stdc++.h>
using namespace std;

string solution(string myString, string pat) {
    return myString.substr(0, myString.rfind(pat) + pat.size());
}
```

`rfind` 함수를 활용해 발견한 가장 뒷 부분 인덱스를 구했다. `pat`까지 포함해서 잘라야 하므로 `pat`의 길이만큼을 추가해서 잘라야 한다.

```python
def solution(myString, pat):
    return myString[: myString.rfind(pat) + len(pat)]
```
