## 1. 아이디어

정수 $n$이 제곱수인지 판별하는 문제다. 제곱수라면 $\sqrt{n}$이 정확히 자연수라서 반올림하든 내림하든 얻은 정수 $r$이 그 값과 같으므로, $r^2 = n$인지 확인하면 된다. 제곱수가 아니면 $r^2 = n$인 정수 $r$이 없어 항상 어긋난다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
class Solution {
    public int solution(int n) {
        long r = Math.round(Math.sqrt(n));
        return r * r == n ? 1 : 2;
    }
}
```

`Math.round`가 `long`을 반환해서 `r`을 `long`으로 받았다.

```c++
#include <bits/stdc++.h>
using namespace std;

int solution(int n) {
    int r = round(sqrt(n));
    return r * r == n ? 1 : 2;
}
```

```python
import math


def solution(n):
    r = math.isqrt(n)
    return 1 if r * r == n else 2
```

`math.isqrt`로 실수를 거치지 않고 정수 제곱근을 구했다.
