## 1. 아이디어

아홉 명 중 키의 합이 100인 일곱 명을 찾는 문제이고 고르는 경우가 $\binom{9}{7} = 36$가지뿐이라 모든 경우를 확인하면 된다. 일곱 명의 합이 100이라는 것은 제외한 두 명의 키 합이 전체 합에서 100을 뺀 값이라는 뜻이므로, 일곱 명을 직접 고르는 대신 제외할 두 명을 고르는 쪽으로도 같은 경우를 훑을 수 있다. 출력이 오름차순이어야 하므로 먼저 정렬해 두고 남은 일곱 명을 앞에서부터 출력한다.

---

## 2. 코드

### 풀이 [Java][C++][Python]

```java
import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        int[] arr = new int[9];
        int sum = 0;

        for (int i = 0; i < 9; i++) {
            sum += arr[i] = Integer.parseInt(br.readLine());
        }
        Arrays.sort(arr);

        for (int i = 0; i < 8; i++) {
            for (int j = i + 1; j < 9; j++) {
                if (sum - arr[i] - arr[j] == 100) {
                    for (int k = 0; k < 9; k++) {
                        if (k != i && k != j) {
                            System.out.println(arr[k]);
                        }
                    }

                    return;
                }
            }
        }
    }
}
```

```c++
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(0);
    cin.tie(0);

    vector<int> v(9);
    for (int& x : v) cin >> x;
    sort(v.begin(), v.end());

    int sum = 0;
    for (int x : v) sum += x;

    for (int i = 0; i < 8; i++) {
        for (int j = i + 1; j < 9; j++) {
            if (sum - v[i] - v[j] == 100) {
                for (int k = 0; k < 9; k++) {
                    if (k != i && k != j) {
                        cout << v[k] << '\n';
                    }
                }

                return 0;
            }
        }
    }
}
```

```python
import sys
from itertools import combinations

input = sys.stdin.readline

arr = sorted(int(input()) for _ in range(9))
for seven in combinations(arr, 7):
    if sum(seven) == 100:
        print(*seven, sep="\n")
        break
```

`sorted`로 미리 정렬한 리스트를 `combinations`에 넘기면 조합이 그 리스트의 순서대로 만들어져 이미 오름차순이라 따로 정렬하지 않았다.
